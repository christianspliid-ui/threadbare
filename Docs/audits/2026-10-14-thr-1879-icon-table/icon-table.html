The carved icon table

Every idea the game draws as an icon, with the carved game-icons.net shape proposed for it, next to the glyph the game draws today. One shape per idea: no shape is used for two ideas.

For Type and icons rollout (THR-1879), building on The icon family (THR-1834) and its sheet. Each shape is drawn at 40 px and at the 18 px it takes inside a chip, in gold so it can be judged; in the game an icon takes its row’s text colour and is gold only where the surface marks importance. “Today” is this computer’s own symbol font, as the game draws it.
