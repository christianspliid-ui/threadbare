## 3. What persists between runs today

- **World-Soul types** (`src/types/worldSoul.ts`): Fundament (12 sphere weights + `cycleCount`), Resonance (≤10 memories, degradation), `HARVEST_ECHO_COUNTS` triumphant 5/3, somber 3/1, bittersweet 4/2, `TWILIGHT_TICK_RANGE` 5–10, `CycleTransition`. Echo kinds live in `src/types/echo.ts` (Legacy/Monument/Relic via `buildEchoDefinition` in `cycleEnd.ts`).
- **Twilight path (live):** `phaseDoomExpiry` (`orchestrator.ts:2731`) sets `phase: 'twilight'` → `useSimulation.ts:196-200` `startTwilight` → `runTwilightTick` → `computeHarvest` (`cycleEnd.ts:103`; type by mandate completed / doom progress > 0.9) → `HarvestScreen`. All cosmic candidates pass through (`useSimulation.ts:224`); the only divine echo is the THR-887 card echo; the screen prints "(selection coming in a future update)" (`HarvestScreen.tsx:97`). `executeCycleTransition`/`blendFundaments` (`worldSoul.ts:84, :265`) have **no non-test caller** — the Fundament is never blended.
- **In-session "Begin Next Cycle"** (`transitionToNewCycle`, `cycleEnd.ts:200-300`): spreads `...state` — **same graph, same ascendant node, same essence pool, same `worldSoul`, same beats/unlocks, same rivals** — and resets only `cycle+1`, `tick 0`, a fresh doom clock of the same archetype (THR-1642/1646), `chronicleEntries`, events, `stealthExposure`, `cardPlayTally`; echoes degrade and accumulate into `echoDefinitions`/`chronicle`. `harvestEchoes` / `phaseTwilight` symbols do not exist.
- **A new game** (page reload, Start Page "New World"): `initializeGameState` builds `worldSoul` from `createDefaultFundament()` (`cycleCount 0`) + `createResonanceState()` (empty) + the fresh aggregate (`gameInit.ts:141, :409-414`); `cosmology.ts` never reads a World-Soul. `App.tsx` has no `worldSoul` reference.
- **Browser storage:** every `localStorage` use in `src/` is a preference — audio mute keys, `useNotificationPreferences`, legend-dismissed flags (`EncounterVeil`, `NudgeStageHeader`, `ChroniclePanel`), fog default (`SettingsModal`), terrain-lab presets. No `sessionStorage`/`indexedDB`; no `saveGame`/`loadGame`. The start-page plan states "The game doesn't have a save system yet" (`Docs/plans/2026-03-23-start-page-design.md:121`).
- **`bankedDiscoveries`:** not in `src/` at all. `BeatRecord` (`types/ascendantBeat.ts:150-168`) carries `beatId, kind, resolvedTurn, outcome, grantedActionIds, seededNodeIds, boundNodeIds?` — the plan's "recorded in BeatRecord" (`2026-06-26-ascendant-beats-divine-cadence.md:249`) was never implemented.
- **Plain statement:** a second run started from the front door inherits **nothing** — no god stat, no unlock, no World-Soul weight, no memory, no echo. Only an in-tab "Begin Next Cycle" continues, and it continues the *same* god and world with a new doom clock.

## 5. Comparable shapes (facts, no recommendation)

- **Hades:** Darkness buys permanent Mirror of Night stats (HP, dash, backstab %, boon rarity), Gems/Diamonds buy House and keepsake/companion unlocks, Titan Blood buys weapon aspects and ranks, Nectar/Ambrosia earn keepsakes; keepsakes and aspects change *what* a run offers, Mirror changes base numbers; in-run boons, Obols and Pom levels reset every run, and Chthonic Keys/Darkness earned in a run are the only thing carried out.
- **Slay the Spire:** per-character card and relic *pool* unlocks (earned by XP across runs) widen what the RNG can offer; Ascension 1–20 only adds difficulty; the character's HP, gold and deck start identical every run — no stat grows across runs, and gold is strictly a run currency.
- **Rogue Legacy:** gold earned in a run is spent at the manor on permanent stat upgrades (HP, MP, strength, armor, unlocks), and whatever is unspent is paid to Charon at the door — so cross-run growth *is* the run economy's output, while heirs, traits and the castle layout reroll each run.
