> "Faction is the most under-served target type in the catalog: hex ~52 actions, agent ~22, location 4, sublocation 4, artifact 4, **faction 2**, army 1 (bind only). ## scope (what this plan does)

Adds 6–8 new faction-targeting verbs to the action catalog, spanning four shapes of faction influence: **fracture** (break it — Schism, Stir Dissent), **redirect** (steer it — Whisper to the Leader, Sanction a Mission), **expose** (reveal hidden state — Reveal Corruption, Unmask the Heretic), **elevate** (raise an internal force — Anoint Successor, Recover Lost Doctrine). Each verb is a one-shot intervention, costs essence, has a clear narrative trigger. Authors the 8 templates in `src/data/unified-action-templates.ts` with `targetCategories: ['faction']`. Implements effect logic: most are graph mutations (`dissentScore +X`, `corruptionRevealed: true`) on the faction node; Schism requires faction-split logic in `factionLifecycle.ts`. Adds prose per Threadbearer voice; tunable constants for every magic number; tests per template effect; integration test for conditional Reveal Corruption.

## scope (what this plan does NOT do — explicit non-goals)

- Does not retire the existing two faction verbs (`action.divine-edict`, `action.anoint-champion`) — they pair with the new verbs as family resemblances.
- Does not invent a new node type for factions — uses the existing faction node shape and adds property mutations.
- Does not depend on THR-396 (reach-domain reassignment) or THR-397 (rarity recurve) — but acknowledges retagging may follow if those land first.
- Does not author faction-scoped encounters — verbs are global UnifiedActionTemplate entries; encounter content is separate scope.
- Does not deliver mortal-loop hooks per verb — the plan operates at the faction-target level.

## impact_class

Reversible. Content additions (8 template rows in `unified-action-templates.ts`) plus modest engine work (faction lifecycle for Schism, conditional revealing for Corruption/Heretic). Pattern-following — every new verb shape rhymes with an existing pattern (Stir Dissent ↔ Incite Unrest, Whisper Leader ↔ Persuade, Anoint Successor ↔ Anoint Champion). The audit said 6–8 is a ceiling; we kept all eight to make faction-as-target a serious category from launch.

## author notes for the judge

Three calls the judge should weigh: (1) **The 8-verb count.** The audit said 6–8; the author kept all eight to establish faction-as-target as a serious category. Reasonable defense in the draft: family-resemblance pairings reinforce the catalog's teaching; tier-2 / tier-3 split fits the unlock curve. (2) **`sanction_mission` as a verb.** Forces the faction to commit to a player-named mission. The author wrote it as a "high-risk redirect" without flagging the protagonist-vs-god framing. (3) **Mortal-loop bridge not addressed.** Faction is the highest-remove target type; the draft operates entirely at faction scale without specifying how a verb produces an encounter on a portfolio mortal. The author wrote the plan with engine-prose-band-test rigor for each verb (constants, conditional reveals, family resemblances) — but the per-verb question "which mortal does this surface?" is absent. The plan-doc closing sections (DoD, coordination, files to touch) suggest the author considered this Codex-shaped pattern-following work; the author's coordination block names model:opus-4-6 for the content pass (prose authoring) and model:sonnet for engine wiring — i.e. the author treated this as ready to ship.
