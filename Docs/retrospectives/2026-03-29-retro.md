The snapshot protocol helps recovery but doesn't prevent data loss for unsnapshotted files. 2. **Linter interference is the most frequent friction.** 5 occurrences across 2 entries. The workaround (re-read + grep verify) works but adds latency to every edit. This is a platform-level Claude Code issue — nothing project-specific can fully fix it, but awareness reduces wasted time.

3. **All impediments have workarounds.** No permanently blocked items. This is healthy — the team is resilient at finding alternatives. The risk is that workarounds become normalized and the underlying issues never get fixed.
