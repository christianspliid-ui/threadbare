# THR-2131 — Nine dead modules deleted with their tests and the sliders only they read

**Shipped 2026-11-02.** Continuous Improvement. Filed by the weekly test-suite health pass (THR-942). It has the same shape as THR-2049.

Each of the nine modules was re-checked for importers at origin/main `ef27c68e`. Every runtime import was from its own test file only. All nine are deleted:

- `src/engine/callbackEligibility.ts` + `callbackEligibility.test.ts`
- `src/engine/controlContestationResolver.ts` + its test. Its name is also removed from the `stepResolutionCore` contract test's importer set and from the `essence-control-reference` wiki page's `sources`.
- `src/engine/encounters/generateEncounterCandidates.ts` + its test. `unifiedCandidates.ts` mentions it only in a doc comment.
- `src/engine/hexVignette.ts` + `hexVignette.test.ts`. `src/types/hexVignette.ts` stays, because `hex-vignette-content.ts` uses it.
- `src/engine/interventionCost.ts` + its test. `dream.ts`'s same-named function is unrelated.
- `src/engine/interventionTracking.ts` + its test. The live thread-node property of the same name is untouched.
- `src/engine/magicPower.ts` + `src/__tests__/engine/magicPower.test.ts`
- `src/engine/vignetteNotification.ts` + its test. That test imported `divineAttention.ts` only as a fixture helper, and `divineAttention.test.ts` still covers that module.
- `src/data/hex-tile-assets.ts` + its test. The `AllSphereName` type moved into `hex-vignette-content.ts`, its only importer (an `import type`).

**Constants and sliders.** The five CMS sliders were removed (`INTERVENTION_MAX_BONUS`, `OPPOSING_/NEUTRAL_SPHERE_COST_MULTIPLIER`, `VIGNETTE_MAX_PER_TICK`, `VIGNETTE_QUEST_PRIORITY_THRESHOLD`). Their constants were removed from `agent-behavior-constants.ts`, together with `VIGNETTE_THREAT_THRESHOLD` and `BOND_EFFICIENCY`, which only the deleted modules read.
