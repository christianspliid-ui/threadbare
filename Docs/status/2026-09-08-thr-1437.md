# THR-1437 — worldgen seeds the living world

**2026-09-08 · Engine (seven passes at the tail of `seedWorld`, thirteen constants) · project Thematic Pressure & Living World**

The starting world used to hold nothing traded, owed, held or known, and fourteen deciding mortals; THR-1403's census showed the cells refusing on exactly that supply. Now the tail of `seedWorld` runs `seedLivingWorld` — territory by province, trade routes with identity nodes, freeholds, possessions, standing quarrels, marks, capital garrisons — each pass behind a constant in `src/data/worldgen-living-constants.ts` (`0` disables it; `WORLDGEN_TERRITORY_MODE 'round_robin'` restores the old territory), each reusing a writer the world already had, sorted-first with id tie-breaks, each reserving its own PRNG stream so the streams before it are untouched.

The acceptance envelope (`census:undertakings`): **seed 42 passes every gate** (23 distinct in the first 150 starts, 5.6 starts per mortal, share 34.9%); seed 99 still fails the variety sample (123 starts, the sample never fills) and starts per mortal (3.5 vs 4), and the cross-seed distinct mean is 23 against 25. Closer by nine cells; not closed. That is a calibration matter now, not supply.

## Decided, veto invited

- **Protagonists stepped down to 14–20 at medium.** The plan's 18–24 measured tick cost +26% (seed 42, 80 → 101 ms steady) and +39% (seed 99, 98 → 136), over the plan's +25% criterion, which prescribes exactly this step. At 14–20: **+14% · +33%** (91 · 130 ms; run-to-run noise ≤ 1 ms). Seed 99 stays above the line, and the growth is in `agent_decision` (3.6 → 6.4 s over 200 ticks) — per-protagonist board breadth now that objects exist, not the count alone. Recorded, not stepped further: a second step would gut the pass the map is for while the driver is elsewhere. Veto handle: *"medium 18–24"* or *"medium 10–16"*.
- **Territory by province** (provisional; *"round-robin territory"* → `'round_robin'`), **standing quarrels** (*"no starting quarrels"* → `WORLDGEN_QUARREL_SENTIMENT_MAX` to `-2`), **seeded marks** (*"no starting secrets"* → `WORLDGEN_SEEDED_MARKS_PER_CULTURE` to `0`).
- **A fourteenth constant**, `WORLDGEN_FREEHOLD_LEADING_REACHES` (gold, stone, heart), hoisted from the plan's prose; the first widening lever if freeholds read as rare (1 on a small map, 8 · 4 on medium).
- The garrison ambition is `resource_acquisition` (the union has no `territory_defense`); the captain gets no want of their own.
- `AGENT_COUNT_BY_MAP_SIZE` keeps its name (the audit called it `WORLDGEN_SPOTLIGHT_AGENTS_BY_MAP_SIZE`).

## Found on the way, fixed

- **Two lanes from one capital collapsed into one identity node**: `createLocation` keyed the id on origin hex + tick. `mintRouteIdentity` now keys it on the lane's two ends (`createLocation` takes an id override).
- **A place founded by nobody threw its mint away**: `createLocation` wrote `constructed_by` to the actor unconditionally, and worldgen's actor is not a node. The builder edge is written only for a builder that exists.
- **W2 left two identical `controls` edges** where a definition faction's home was also its nearest same-culture home; the redundant generic edge is dropped, counted as retargeted.
- **`spawnArmy`'s failure path removes the army id it was given**, so a second garrison for a faction holding two capitals would have deleted the first; guarded by an explicit node check.
- The run-lifecycle wiki page's `sources` named `worldGeneration*.ts`, a file that no longer exists, so the seeder was never gated; the manifest now names `worldSeed.ts` and `seedLivingWorld.ts`.

## Left honest

- The acceptance envelope is red by two gates on seed 99 and the cross-seed distinct mean (23 vs 25). Supply is no longer the cause; the cheap instant cells (`observe × place` 61 of 195 starts on seed 42) and seed 99's start rate are. The calibration pass owns it.
- Garrison captains get no freehold and no possession (W8 runs after W4/W5, per the plan's order).
- Three heavy tests were corrected for fixture reasons (a route count that was 0, a trace ring that evicts a milestone in a busier world, a moment queue that holds only the newest) — against the generated world, never by lowering a constant.
