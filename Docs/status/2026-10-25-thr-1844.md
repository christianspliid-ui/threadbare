# THR-1844 — choices widen across runs: four hungers on run 1, one woken each age, second courts, sealed god cards, and *The world remembers*

**Shipped 2026-10-25.** Slice 3 of the world-remembers plan (`Docs/plans/2026-10-14-thr-1813-the-world-remembers.md`, E8/E9 and § UI pillar). Before this, the account recorded the hunger sets but nothing read them, every market card was offered from run 1, and Remembrance offered the whole hunger catalog.

**Change.**
- `src/engine/accountRecord.ts`: the sealed-set reads (E8). `awakeHungers`, `openCourts` (a hunger's default court, and its second once played), `runOneSealedCardIds` (computed from the catalog: every sphere-bound Tier 3 except that sphere's cheapest by essence cost, and every sphere-bound Tier 4; 23 on today's catalog), `sealedCardIds`, `isCardSealed`, and `drawUnsealedCards` (two picks a run, weight 3 on the god's primary, 2 on its secondary, on `mulberry32(worldSeed + 70007)`). `concludeRun` now unseals two cards, records them on `lastRun.unsealedCardIds`, and traces `account.cards_unsealed`. `wakeHunger` traces `account.hunger_woken`. The second court is now stored under the bare hunger id (`gather`). It used to be stored as `hunger.gather`, which `openCourts` could never match.
- `GameState.sealedCardIds` (optional) is set at world creation from the account (`gameInit.ts`). `offerableCards` skips those cards. Dev routes, tests and the CLI pass no account, so nothing is sealed there.
- `offerAwakeHungers` (`remembrance.ts`): `filterHungers` over the awake set only, topped up to two, and the woken hunger goes first.
- UI: `WorldRemembersBeat.tsx` (new) is the first Remembrance step from run 2 on. It shows what still stands (sphere-tinted echo cards with memory words and the kin/against line), the gods who may wake (twelve chips plus the choice between the two that stir), and the powers that may now rise (the unsealed cards as `ActionCard` faces). *Go on to the stirring* stays disabled with its reason until a hunger is chosen. `TransformationBeat` offers only the open courts. `App` keeps a woken hunger at once, saved unless the session is an override. Nine `ui.*` tooltips were added, and the debug Account tab shows the sealed and unsealed cards.
- Canon: rulebook §1 and the quick reference each gain one line. Two interface contracts were added (`awake-hungers-gate-remembrance`, `sealed-cards-gate-the-offering`).

**Evidence.** `accountRecord.choices.test.ts`: 23 sealed; unseal draw is deterministic and weighted; run 1 has four hungers on default courts; second court opens; woken hunger leads; `offerableCards` never returns a sealed card at rungs 1–4. `WorldRemembersBeat.test.tsx`: echoes, memory words, 12 chips, 2 cards, no digits; Go on gating; empty states; a first run skips the step. Headless sweep on seeds 42/99/7 with an empty account: 300 ticks, then 500 offering draws at each rung through `offerableCards → offeringWeight → drawOffering` gave 18,000 picks and 0 sealed. A ticked run alone never fires `offering.offered` headless, because the rung only opens through play. Browser at 1920×1080 (Vite on :5287, six-echo record): the step fits with the lowest element at 1056 px and no scroll. Waking Kindle enables Go on. Transformation offers Kindle first. Gather shows two courts and Kindle one. `__DEBUG.getAccountRecord()` reports Kindle awake and nothing stirring. Console: 0 errors.

**Not done.** Echo and card names on the step are not links: before a world exists there is no Chronicle or Codex mounted to open (Law 21's "where a page exists"). Slice 2's `echo.monument` sublocation type is not registered in `world-objects.ts` (a pre-existing NodeSchema warning).
