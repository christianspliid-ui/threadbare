# 2026-10-15 — THR-1857: template seams in player prose

**Ticket:** [THR-1857](https://linear.app/threadbare/issue/THR-1857). Found by warm playtest round 2. Content + Engine (+ one UI adapter line).

- **What the player sees.** "Kael Thornweaver works with the patient's own weight", not "work". The plague foreshadowing reads "They want to trace the vector". A genome inn is "The Weary Lantern", not "Inn". A movement waypoint is "Hawkgate Forest", not "Wilderness (14, 14)". The aftermath icon's accessible name is "reputation with the Mason Guild", not "reputation with {target}".
- **How.** `src/engine/subjectVerbAgreement.ts`: `bindNameSubjectVerbs` binds `{s}` to "s" after a name token (`{name}`, `{actor}`, `{agent.name}`, `{name.first}`, optionally one adverb such as "either"), before the name resolves. `enrichProse`, the rite's `fill` and `resolveForeshadowingPlaceholders` call it; the foreshadowing resolver also gains `{s}` / `{es}`. Six hard-coded verbs after `{pronoun.subject*}` became `verb{s}`. `materializeGenome` names an inn or tavern with `generateTavernName` and any other type "<label> (<settlement>)" from `SUBTYPE_SUBLOCATION_MAP`. Waypoints take a map-style proper name from `src/data/waypoint-names.ts` (`nearestSettlement` within 8 hexes + a ground word by terrain, "Nameless Hills" when none is near); a saved coordinate-named waypoint is renamed on reuse. `buildAftermathConsequences` passes the resolved noun to `resolveIcon`.
- **Evidence.** `templateSeams.thr1857.test.ts` (the two content lints over `src/data`, binder, foreshadowing, waypoint and genome names) and an icon test in `buildAftermathConsequences.test.ts`. Seed 42 medium, 300 ticks (CLI `eval`): 1129 locations, 66 waypoints, 0 coordinate names, 0 bare type labels; sample waypoints "West Fieldvale Downs", inns "The Old Goblet".
