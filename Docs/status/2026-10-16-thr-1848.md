# 2026-10-16 — THR-1848: long place names wrap inside the hex tooltip

**Ticket:** [THR-1848](https://linear.app/threadbare/issue/THR-1848). No plan doc (the ticket carries the fix). UI pillar; Engine and Content N/A (no state or words change).

The hex tooltip box is `white-space: nowrap` with a width cap (240 px with place data). The gold title line inherited `nowrap`, so a long name ("The Shattered Sanctum–Hawkgate Road") ran past the box border (Law 33).

- **UI.** `HexTooltip.tsx`: the title line sets `whiteSpace: 'normal'` and `overflowWrap: 'anywhere'`, so the full name wraps inside the box. The height estimate that places the box above the hex now counts the wrapped title lines (`TOOLTIP_TITLE_CHAR_PX` 7.5, `TOOLTIP_TITLE_LINE_PX` 18), so a two-line title still clears the hovered hex.
- **Test.** `src/components/HexMapV2/__tests__/HexTooltip.titleWrap.thr1848.test.tsx` pins `whiteSpace` on the title line and checks that a long title lifts the box.
