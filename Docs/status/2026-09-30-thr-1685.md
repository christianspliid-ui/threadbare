### THR-1685 — a reputation chip about a person names the person (2026-09-30)

**The tag now says who.** On a board-drawn everyday encounter the action targets the settlement, so a chip whose noun is `reputation with {target}` and whose anchor is a cast member read "REPUTATION WITH ARDENMOR" above a sentence about the inspector. It now reads "REPUTATION WITH MAUD HARROW".

- One fix for the whole corpus, no content edits: `buildAftermathConsequences` takes an optional `anchorNameFor`; when a noun's declared anchor is not `$target` / `$here` and resolves to a person, `{target}` in the noun takes that person's name before scene enrichment. Places, factions, cultures, groups and unresolved anchors keep the scene reading.
- `buildChipAnchorNameResolver` in `chipCollaborators.ts`, passed by both chip-emitting adapters (unified and gate duty).
- Evidence: unit arms on the builder (cast anchor names the person; `$target` / `$here` / non-person / unresolved / no-callback all unchanged), a resolver test, and a jsdom render of the real Mason's Commission "Inspector's Trust" chip on a board draw — the tag reads the inspector and never the town.
