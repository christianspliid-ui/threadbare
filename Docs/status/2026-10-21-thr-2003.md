# THR-2003 — The engine-diff gate fits a foreground command again

**Shipped 2026-10-21.** `npm run gate` on an engine diff ran `test:heavy` alone after the parallel stage. That stage took 578–648 s by itself, so the whole gate (669–942 s) passed the Bash tool's 600 s foreground cap. Pickup runs had to background it, and a backgrounded run looks finished to the next run: on 10-21 the 08:25Z run took over PR 2510 from the live 08:11Z run (impediment #1209, 8 recurrences in two days).

**Fix (option a, a removal).** `test:heavy` left the default engine gate. CI's post-merge `heavy-tests.yml` owns it, as THR-1384 intended; `npm run gate -- --heavy` opts back in. The engine diff still owes the 30-tick CLI smoke. CLAUDE.md § Gates, `Docs/canon/verification-gates.md` and `pull-work/SKILL.md` now say the same thing; impediment #1209 is closed with a pointer here.

**Evidence.** Engine-diff gate (a probe comment on `src/engine/orchestrator.ts`, reverted after): 104 s wall, every gate PASS, `test-heavy` absent from the plan. `scripts/__tests__/gate.test.ts` pins both shapes (default: no heavy stage; `--heavy`: heavy stage alone).
