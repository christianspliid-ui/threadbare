# 2026-09-25 — THR-1549: what winning a fight pays, and the chronicle line (Fight endings D2)

**Ticket:** [THR-1549](https://linear.app/threadbare/issue/THR-1549) · **Project:** Physical Conflict · **Plan:** `Docs/plans/2026-09-23-defeat-and-victory.md` (slice D2, §4–5) · **Pillars:** Engine (victory writes, the `fight_ended` event) · Content (the trophy recipe, eleven chronicle lines + two plain variants) · UI N/A (the chronicle panel and the sheet render every write; `TICK_EVENT_COLORS` gains a colour, a `src/data` edit).

## What shipped

- **Victory yields** in `fighterEndingBranch` (`src/engine/fights/fightEnding.ts`), all through existing writers:
  - `overcome` a lair's beast → the **trophy**: one `drawSeededReward` draw (`FIGHT_TROPHY_RECIPE` = `{ possession: 1 }`, band `FIGHT_TROPHY_OUTCOME.overcome[lairTier]`, site `fight_trophy`), so a `reward_tier_bonus` shifts it; a minor lair or none draws nothing (`rewardSkipped`). **Gratitude**: `reputation_with` the nearest settlement within `FIGHT_GRATITUDE_RADIUS_HEXES` (3) of the lair +0.10, ties by node id.
  - `driven_off` → gratitude +0.03. `bargained` → the hoard (one draw) + drift toward mercy.
  - `overcome` a mortal → **standing** +0.05 with the loser's faction ?? home settlement, drift toward courage.
  - `yielded` to a mortal → the victor's standing (`ending.victorStanding`), the other side of D1's humiliation.
- **The chronicle**: every ending returns one `fight_ended` tick event (new additive `TickEvent.type`), id `fight_ended_<actionId>_<tick>`, message from `FIGHT_CHRONICLE_LINES` (`src/data/fight-ending-content.ts`), significance by `FIGHT_EVENT_TIER_BY_FACE` — notable 0.85 becomes a chronicle row through `phaseNarrative`, routine 0.4 does not. A bargain with no prize and a mauling with no new scar use the plain lines.
- `FightEndingRecord` gains `victorStanding`; `eventSignificance` is now set on every ending. The `fight.ending` trace carries `reward`, `rewardSkipped`, `rewardBadOutcome`, `reputation`, `victorStanding`, `eventSignificance`.
- `'fight_trophy'` joins `ContentQuerySite`; `fight_ended` gets a colour in `TICK_EVENT_COLORS`.
