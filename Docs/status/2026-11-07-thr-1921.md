# THR-1921 — One tick runs once

**Shipped 2026-11-07.** Thematic Pressure & Living World. Plan: `Docs/plans/2026-11-07-thr-1921-one-tick-runs-once.md`.

1. **The cause.** `useSimulation.doTick` committed the next state without writing `gameStateRef`, which React refreshes only on render. A second tick in the same task (a bunched interval, or `__DEBUG.tick(n)` right after an interval tick) ran the same tick number again from the stale state: the in-place graph stepped twice and the tick's event ids repeated (`evt_141_10` ×25 as duplicate React keys).
2. **The fix.** `doTick` writes `gameStateRef.current = next` before `setGameState(next)`, like the other five state-advancing callbacks.
3. **A replay names itself.** `SimulationRuntime.lastTickRun` records the last tick `runTick` produced and its graph (written at the end of a successful tick). The same graph object arriving at a tick already run emits one `tick_replayed` trace and, in dev builds, a `[THR-1921]` console warning; the tick still runs (fail-soft). A new world or a loaded save carries a new graph and is never a replay.
4. **Tests.** `src/engine/__tests__/tickReplayDetection.test.ts` (5: record, replay traced once and still run, straight run clean, new world clean, no-runtime legacy). `src/components/Game/hooks/__tests__/doTickAdvancesRef.thr1921.test.tsx` (2) renders the real hook: two `doTick()`s in one `act()` advance by 2; `doTick` + `runTicksSync(3)` by 4. Red before the fix: "expected 1 to be 2", "expected 3 to be 4".

**Evidence:** `npm run gate` PASS (test, typecheck, build, encounter, god-cards, ui-debt, cli-smoke). Browser (bash-vite :5297, Playwright, 1920×1080) at `?view=game&seeded&size=medium`, tracing on: 30 rounds of Play at top speed + `__DEBUG.tick(10)` to tick 301 — 0 "same key" errors, 0 `tick_replayed` traces, 0 replay warnings. The only console error was the TTS health probe on :3001 (no local TTS server). The headless interval landed only once between batches, so the race itself is pinned by the hook test rather than the browser run.
