The proposal placed both terms against siblings it believed were already seated:

- **Undertaking Contract → `Agents.md`, not `Encounters.md`.** The "beside its mirror" argument was void, and Agents.md demonstrably holds the whole undertaking cluster already (*Undertaking*, *Undertaking Verb*, *Kind Row*, *Work*, *Christening*, *Failure-Name Register*, *Freehold*). The See-Also web is strongest there.

It is a variance-axis swap, not a second concept, so it is seated once rather than shard-crossed.

Every code anchor the proposal named was verified present before the definitions were written, and the definitions come from the sources rather than the ticket body: `src/data/content-eval/undertakingContract.ts` (the ten blocks in registration order), `src/data/content-eval/undertakingRetrofitPending.ts`, `scripts/check-undertaking.ts` (the two-way exit condition), `.claude/skills/undertaking-pipeline/reference/batch-brief-format.md`, and the encounter line's own format card at the mirror path.
