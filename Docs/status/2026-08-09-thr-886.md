# THR-886 — The Compulsion reaches a system

**Shipped 2026-08-09.** The sixth and last of THR-885's dispatch hooks. Five of the six landed
in July; The Compulsion — the Haunt hunger's opening card and the Mind sphere's signature —
did not, so casting it did nothing at all.

## Why it waited, and what unblocked it

The obstacle was real and worth respecting. The card's apparent host, `buildCompulsionEvent`,
takes the agent decision pipeline's `ScoredCandidate[]` — a list that exists only for a moment
mid-`phaseAgentDecision`, between scoring and commitment. Aftermath application has no such
list and cannot obtain one without re-running scoring for the actor. THR-885 stopped rather
than synthesize fake candidates to fit the signature, which would have been exactly the
parallel-path failure `nudgeDispatch` exists to prevent.

That left a genuine design question, because the three ways out gave the player materially
different cards. Christian answered in chat on 2026-08-09: **the card plants a weight, not a
menu.** The Compulsion is *a whisper that tilts them* — you plant a pull, their next decision
leans that way on its own, no second choice-screen nested inside a scene already being
resolved. Options 2 (`encounter_seed`) and 3 (widening `buildCompulsionEvent`) are rejected,
not deferred.

The ruling dissolves the obstacle rather than working around it: **a weight is available at
the aftermath seam where a candidate list is not.** So `plant_compulsion` writes a per-agent
`PlantedCompulsion`, and `phaseAgentDecision` folds it into the same `combinedBias` the
identity and omen terms already feed. `premonitionCompulsion` is untouched, which keeps the
pick-one-of-three vision where it already lives — the god's own premonition turn.

## The load-bearing distinction: a person, not a place

The tempting shortcut was to reuse `state.emittedOmens`, which already carries an encounter
bias and already decays. It would have passed a naive "does the bias appear?" check.

It is the wrong carrier, and the difference *is* the card. An omen stains a hex and catches
whoever walks through it; a compulsion is addressed to a mortal and travels with them. Two
mortals on the same tile can hold different urges, or none. Reusing the omen carrier would
have shipped a card whose printed trade reads *"steer them, not the world"* while quietly
steering the world. So `derivePlantedCompulsionEncounterBias` keys on `targetAgentId` where
the omen path keys on hex distance, and a test pins exactly that: the dreamer feels it, a
bystander gets `{}`.

## Two decisions the ticket left to the implementer

**Where the tilt attaches** — expiry, not consume-on-use. "Their next decision" invites
burning the urge the moment it is felt, but `phaseAgentDecision` is a scoring path, a read.
Making it write state would add a mutation to a pure seam *and* burn the urge on selections
the strategic-candidate override can still overturn later in the same phase. A short
`COMPULSION_DEFAULT_DURATION_TICKS` (3, against a 12-tick day) says "next decision" without
either hazard, and matches how emitted omens already age out.

**What the player sees** — an authored `narrativeHook` reaches the chronicle. Flagged during
the design pass and correctly: a tilt that produces no visible trace is indistinguishable from
the do-nothing behaviour this card had before, which is the defect being fixed. The wiring
guide tells authors to write one.

## A silent-no-op class closed on the way past

`encounterBias` is keyed on the closed `EncounterType` union rather than `string`, so a
misspelled encounter type is a **compile error** instead of a card that plants an urge pulling
toward nothing. That is the same failure mode as the card itself — authored content that looks
wired and does nothing — and it costs one type annotation to make unrepresentable.

## Type debt: paid, not added

The first typecheck run came back **+15 net-new errors**. The cause was instructive: adding
trace *categories* without payload interfaces in the `TraceEntry` union — precisely the debt
class **THR-1065** is filed against, where every consumer must launder `trace.category`
through `as string`. Rather than refresh the baseline, the fix declares real
`CompulsionPlantedTrace` / `CompulsionDecayedTrace` interfaces, adds them to the union, adds
`plant_compulsion` to `EncounterAftermathEffectTrace`'s closed `effectKind` union, and routes
the new block's traces through a typed helper mirroring `emitNudgeTrace`. **Ratchet closed at
3451, unchanged from baseline** — the change adds no type debt at all.

## Not claimed

**Nothing travels this path yet.** No shipped card authors a `grants` block, because card
content lands under THR-883 (paused until the authoring format locks). The interface-map row
carries `deferralTicket: THR-883` and is deliberately **not** badged LIVE — badging a path
nothing travels is the THR-614 error class the map exists to prevent. What shipped is the
hook, tested end to end; the first authored hand is what makes it live.
