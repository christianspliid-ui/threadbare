# THR-1300 slice 3 — the undertaking line compiles and proves

**2026-09-03 · engine + content + skill.** Two commands and one predicate. `undertakingWriteSet(template)` names everything a template declares it will change — the mutation, the creation-effect bands with entries, the harm class, the kind row, the must-persist cast, the catalysts — and both the contract's creation block and the live proof read it, so a template that declares nothing is never failed for delivering nothing and one that declares a write cannot pass by delivering none. `check:undertaking-live` builds a seeded world, starts the template on the first autonomous mortal by id through the review lever, drives the real tick loop to a terminal status, and reads every claim off the harvested trace buffer and the graph. `compile:undertaking` turns a content package into a `strategic-packs/factory/` module with its prose pinned byte-identically, its test, and three idempotent registrations.

## What the proof found

The first matrix run failed every template on `started`, then every completed one on `christened`. The first was the proof's own defect twice over: the started trace names its candidate, not its project (`proj_<template>_<actor>_<tick>`), and a medium world emits more traces per tick than the 2000-entry ring holds, so anything read after the run had been evicted. Harvesting per tick and matching on either key fixed it. The second was the engine's: `christenCompletedWork` took the *first* successful op's created id, and for a trade route that is the `trades_with` edge, so `graph.getNode` returned nothing and the road was never named — a defect no test had seen because no test asked whether a route completion christened. It picks the first created *node* now, and the run that had read *completion created no node to name* reads *"The Slate Hollow Trade Route"*.

The compiler round-trip was proven on a fixture copy of the trade-route exemplar: registered ×3, a second `--force` run reported *already registered* ×3 with an identical tree, the emitted test passed 4/4, the ratchet held at 2929, and the live proof proved the compiled copy on seed 42. The fixture was then reverted; nothing factory-compiled ships in this slice.
