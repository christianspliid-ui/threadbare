# 2026-09-26 — THR-1615: a dissolved trade lane takes its road with it, and its towns feel the loss

Content N/A (no authored text changes). UI N/A (no surface reads the removed nodes differently).

## What shipped

1. **The Route dies with its lane.** When `phaseTradeRouteDecay` dissolves a `trades_with` edge, it now removes the Route identity node(s) stamped with that edge's `routeEdgeId`. `removeNode` cascades the `owns` edge a holder took on the road. The `trade_route_dissolved` trace carries `identityNodeIds`.
2. **`isRouteObject` requires a live lane.** The node discriminator on undertaking object shapes now optionally receives the graph (both resolver call sites pass it). A Route identity counts as an object only while its `routeEdgeId` edge stands. `control:claim`, `use` and `change` can no longer enumerate a dead road.
3. **The trade-route-lost shock lands.** The shock used to walk `located_at` out of each end, a shape no settlement carries, so `SHOCK_TRADE_ROUTE_LOST` never fired. It now targets the lane's own ends (`tradeRouteShockTargets`). A Place end resolves up to its Location, and duplicates collapse.
