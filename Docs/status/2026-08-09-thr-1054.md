# THR-1054 — ten `hod.*` templates' authored endings reach players again

**Shipped 2026-08-09.** Content defect found by THR-1046's whole-corpus package
build; third instance of the silent-death family THR-979 and THR-1038 opened.

Ten Holy Order of the Dawn templates authored `aftermathConfig.variants` as
`[<stepIndex>][<band>] = { overview, changes }` — a **second nesting level the
resolver has no reader for**. `resolveAftermathVariant` looks up
`variants[choiceId]`, a step index never matches a choice id, so all ten fell
through to `fallback`, whose `changes: []` was empty on every one of them. The
lost relic, the cleansed corruption, the delivered judgment, the repelled
crusade: written, committed, reviewed, and reachable by nobody.

**All ten re-keyed to `fallback.byOutcome` — the THR-969 route — and that choice
is forced rather than preferred.** The bands are keyed on *how the encounter
ended*, not on *which route was taken*, and none of the ten carries a decided
fork at all: the file contains no `ActionStepBranch` and no `choices`, so
`choiceHistory` can never hold an entry at any `branchOnStep` and `variants` is
unreachable **by construction** on these templates whatever shape it is given.
Re-keying to invented choice ids would have produced a second dead literal that
type-checks. `branchOnStep` is normalized to `0` alongside `variants: {}`,
matching the five well-formed siblings in the same file — with no fork the value
is inert, and leaving `1`/`2` there would claim a decision that does not exist.
No engine change: the resolver was correct the whole time.

**The corpus test is the gate, and it bites in both directions.** The structural
half asserts every `variants` entry across all 191 templates satisfies
`Array.isArray(entry.changes)` — a predicate, not a snapshot count (THR-688 rule
A), so a future template authoring the same nesting joins the population
automatically. The reachability half then resolves each of the ten at each band
it authors and asserts the prose is **distinct from the un-banded fallback** and
carries non-empty changes, because the structural check alone would also pass for
a fix that simply deleted the authored endings. Falsified before trusted: with the
content change stashed, the structural assertion names all ten templates and the
reachability assertion fails on the first band. `assertDecidedAftermathReachable`
could not have caught this — it returns early on templates with no decided fork,
and these have none, which is precisely why the defect survived two prior sweeps
over the same file.

**Independent confirmation from the gate that could not see the content before.**
`check:encounter -- hod.quest.temple_vigil` went from `authors 0 outcome band(s)`
to `authors 1`, and three findings disappeared because the authored material
became visible to it: `no failure-side band`, `variant 0 has no overview`, and
`rewards: nothing persists` — the last one because the band's `hidden_mark` and
`encounter_seed` effects now count. The template still fails the ratchet on
pre-existing, out-of-scope grounds (no nudge hand, no setting envelope, bands
under the floor of three, two unresolvable tokens), so `check:encounter -- --all`
holds at `failing 0, on ratchet 191` — verdict unmoved. The now-visible band
shortfall is filed as THR-1055 rather than absorbed here; authoring seven-plus new
bands across ten templates is content work, not a re-keying.

The typecheck ratchet dropped **3462 → 3458**: the nested band maps were
themselves type errors, buried unreadable in the red baseline (THR-489) exactly as
THR-1038 predicted. Baseline refreshed and committed. 976 files / 15423 tests
green, build clean; CLI end-to-end spawned and resolved the template without a
crash, landing on `success_at_cost` — a band none of the ten authors — and
correctly rendering the base ending's reactions.
