# THR-1394 slice 1 — the world's objects: the catalogue and the guard

**2026-09-03 · engine + content + docs.** The world now has one catalogue of the kinds of things it keeps, in game words, and a mechanism that holds agents to it. `src/data/world-objects.ts` is the registry — 36 kinds, each with its game word, its UL term, the `WorldRefKind` it projects onto, its graph shape (node type + discriminator, edge types + identity node, or a `GameState` slice), its classes, its owning system, its writers and a note recording what was decided. Area → Hex → Location (seven classes over the existing 54 subtypes) → Place (ten classes derived from the sublocation tag table, never copied); Route as an edge kind with five ratified classes; Mortal · Ascendant · God · Faction · Culture · Company · Army · Network · Battle · Companion; Item · Legendary artifact · Holding · Power · Condition · Trait · Agreement · Standing; Ambition · Undertaking · Event · Journey · Divine receipt; Sphere · Reach; the two template kinds as `content`; and the four union members with no world behind them badged retired / dormant / legacy so slice 2 knows what to remove.

## The four guards

- **Write-time.** `src/types/nodeSchema.ts` derives a per-node-type schema from the registry once, and `WorldGraph.addNode` checks every write against it in dev mode — warn once per `(type, value)` per world (`WORLD_OBJECT_WARN_ONCE`, reset in `initializeGameState`), `WORLD_OBJECT_THROW_ON_UNKNOWN` actually consulted, never a crash. A group kind *refines* `actorType: group` on `groupKind`; an edge kind's identity node (the trade route's `location:trade_route`, the holding's artifact face) is claimed on the node type it grows.
- **Contract test.** `src/data/__tests__/worldObjects.test.ts` pins the registry against the vocabularies themselves through the anchor catalog's parser: every `NodeType` claimed, every `LocationSubtype` in exactly one class, the Place classes equal to the tag table, every non-reserved `WorldRefKind` covered, every class member a claimed value, every writer a module that exists, and a 20-tick seed-42 world with zero unregistered values.
- **Generator.** `npm run generate-world-objects` renders `Docs/canon/world-objects.generated.md` and the served `public/world-objects-reference.html` from the registry plus a two-seed census (42 + 99, medium, tick 30) with LIVE / DORMANT badges, and a Drift section — UNREGISTERED census values and PHANTOM union members / content target names — whose `--check` fails above zero. Registered in `EXTERNAL_GENERATED_ARTIFACTS`, so the blocking `Docs gates` job runs it.
- **Process.** `Docs/canon/world-objects.md` is the Step-0 page: the catalogue, what the model settles, and the one-PR rule — registry row + UL term + canon row. Wired into CLAUDE.md's canon table, the canon index, the engine page, the `state-of-game-design` router, the UL (`World Object`, `Area`, `Location`, `Place`, `Route` in `Graph.md`), the wiki manifest, the interface map (`world-object-registry`, LIVE) and the CLI (`objects [kind]`).

## What the first census found — and fixed in the same PR

- **One unregistered value:** every army, battle and company node writes `actorType: group`, which no kind claimed because the group kinds had been registered on a key the writers do not use. The `refines` field is the repair, and the reason the schema now knows a refined value is shared rather than owned.
- **Five phantom content targets:** `market`, `port`, `trading_post` in the merchant, warlord and court packs and the cells' `FOUND_SITE_RULE` (Location-tier rules that could never match — no Location carries them); `fortress` and `construction_site` in `ambition-templates.ts` (`castle` and `camp` now). And `agent_controls_location` compared a holding's `locationType` only, so a held market *Place* could never satisfy "does this agent hold a market?" — it now reads the Location subtype or the bare Place type id.
- **Two chip kinds without a row:** `journey` and `receipt` — registered as state kinds (`GameState.pendingVignettes[]`, `GameState.playerActionReceipts[]`).

Verified: the contract test (11/11), `generate-world-objects:check` at zero drift, the 30-tick seed-42 CLI smoke with `objects` reporting *no unregistered values written this world*. Slice 2 — the possession category stamp, `nodeSubtype` → `eventType`, the `resource` / `relationship` retirements with readers repointed, `routeKind`, the helper renames — closes the ticket.
