## The assertions

Pass on 1–7: prose at standard in narrator mode with the step carryover landing (*"They came up short of the saddle and camped in the scrub."*); aftermath bands rendering per `?outcome=` pin; cast chips linking their grants; zero legacy stance choices or Resume-Intervene; zero authoring-metadata leaks; **zero console errors on every route** (the four warnings are library/engine-level — `THREE.Clock` deprecation ×2, WebGL `texImage3D` ×2 — identical on all routes and pre-existing); and seeds planting and surfacing, The Swindled Family's ending carrying both `PATH` chips with full prose.

**Assertion 8 is the honest gap, and it is recorded as one.** A natural firing in free play still cannot be a browser check on the deployed build, because `window.__DEBUG` is tree-shaken in prod, and an unattended lane must not start a dev server. What was run instead is the engine half — `npm run cli -- --seed 42 --map medium`, `tick 30` → **46 unified actions with no `?spawn=` anywhere**, the large majority `encounter.*`, resolving across the full ladder (clean 27.9% / at-cost 41.7% / fail 22.2% / crit-succ 4.7% / crit-fail 5.6%). So encounters *do* arrive organically. What that does not prove is the browser half: an organically-arrived encounter rendering in the veil. The browser walk proves the veil renders, the CLI proves the engine supplies it, and neither alone is the original assertion — so it is reported as **partially satisfied**, not as a pass.

## The protocol repair

THR-1220's Protocol step 1 has been edited to be satisfiable, which was this ticket's second deliverable. It now names **two surfaces**: (a) the deployed build for the `?spawn=` walk and the `?outcome=` pins, (b) a **local dev build** for the natural firing, driven with `window.__DEBUG.tick(n)`.

## One thing that is not a defect

It cost a few minutes to rule out, so it is written into the verdict comment rather than left for the next walker to rediscover.
