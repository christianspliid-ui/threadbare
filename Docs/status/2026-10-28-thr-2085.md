# THR-2085 — Heavy tests green again: the compulsion test steers toward a scene that needs travel

**Shipped 2026-10-28.** Continuous Improvement. `heavy-tests.yml` went red on main after THR-2071 (board context lean): both tests in `premonitionSteer.integration.test.ts` failed as `undefined`.

**Cause.** The test steers The First toward the runner-up of her last scored board and assumed, on seed 42, that this scene sits in another town, so the steer is spent on a journey and traced again on arrival. THR-2071's context lean reordered the seed-42 board: the runner-up (`reputation.heart.pilgrims_offering`) now sits in The First's own town (`loc_4`). The engine did the right thing. It started the compelled scene in place at tick 24, marked `compelledByGod`. No journey happened, so there was no arrival trace and no held `compelledJourneyTemplateId`.

**Fix (test only).** The steer target is now the first lower-ranked scene on the board that the scorer marks not local (`isLocal: false`, so not on The First's hex). The shared driver asserts the premise by name, with a message: the steer must be spent on a held compelled journey. A moved premise now fails as a named premise, not as `undefined`. The review gate's round 1 noted that a scene in another town may still be attempted remotely; the named premise assertion catches that case. No engine change and no timeout change.

**Evidence.** Both tests pass locally (2/2, ~20 s). `npm run gate` verdict in the PR body.
