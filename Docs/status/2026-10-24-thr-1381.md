# THR-1381 — The end of the age

**Shipped 2026-10-24.** Built from `Docs/plans/2026-10-17-thr-1381-the-end-of-the-age.md` (engine, content and the ceremony in one build). The clock running out no longer opens a popup and seven silent ticks. The player now watches a ceremony, *The age ends*, then opens the harvest. Finishing the Mandate now ends the age too.

**What changed.**
- **Engine.** `phaseDoomExpiry` starts the Twilight when the Mandate is fulfilled, checked before doom (`age.ended { by }`). The doom popup became a Chronicle line ("The Breach: the Unmaking begins."), and so did the Mandate's "Victory!" line ("The Long Peace is fulfilled."). New pure `src/engine/twilight.ts`: `ageEnding`, `firstFate`, `captureAgeMemories`, `buildTwilightBeats`, `openTwilight`, `failTwilight`. `cycleEnd.ts` gains `completeTwilight`. The per-tick Twilight step, its module-level counter and its tick constant are deleted. `concludeRun` now fades and prunes the World-Soul's carried memories and appends up to three of this age's (`resonance.memory_captured` / `memory_evicted`). This is the first production caller of `captureMemory`.
- **Content.** `src/data/twilight-content.ts` holds seven doom openings plus the Mandate's, the First's three fates, the memory lines and the two Chronicle lines. Two new tooltips. A content test fails when a doom file has no row.
- **UI.** `AgeTwilightScreen` is one `HOMED_SURFACES` entry (`age-twilight`: a ceremony that stops time). It renders through `CeremonyHost`, behind a mount boundary whose fallback leads to the harvest. `useSimulation` builds the beats once when the Twilight opens. A throw goes straight to the harvest. New debug levers: `beginTwilight()` and `getTwilightBeats()`. The Account debug tab gains a *Memories* row.
- **Canon.** Rulebook §8 tags flipped to `[IMPL]` and open question 6 resolved. New interface rows: `mandate-completion-ends-age` and `age-end-writes-resonance-memories`.

**Evidence.** `npm run gate` code track: all seven checks PASS (test, typecheck ratchet, build, encounter, god-cards, ui-debt, CLI smoke). Browser check with Vite on port 5237 and Playwright at 1920×1080, `?view=game&seeded&size=medium`: `beginTwilight()` opens the ceremony, and its title, First line and three memory lines match `getTwilightBeats()`. The panel spans y 232–848 with no horizontal scroll. Focus starts on the button. The button opens the harvest, and `getAccountRecord()` lists the three `mem-1-*` memories. Console: 0 errors.

**Review gate.** Round 1 confirmed one finding: a First whose death swept the `thread` edge (a low-reputation death removes the node; an Aspect's echo keeps only `aspect_of`) vanished from the ceremony. Fixed: `markMortalDead` notes `firstRemembered` on the god's node, and `firstFate` reads it (died / Aspect). Round 2 found nothing.
