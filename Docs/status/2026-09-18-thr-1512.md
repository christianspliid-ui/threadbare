# 2026-09-18 — THR-1512: retro-draft's period starts at the newest committed retro report

**Ticket:** [THR-1512](https://linear.app/threadbare/issue/THR-1512) · **Project:** Continuous Improvement · **Pillars:** Engine N/A, Content N/A, UI N/A (process tooling — `scripts/`).

## What was wrong

`npm run retro-draft` found its period boundary by scanning `Docs/impediments.md` for the
`**Retrospective conducted: YYYY-MM-DD**` footer. THR-825 retired that footer in July 2026 (a `---`
fence inside the table split the row list, and the committed report was already the stronger
liveness proof), so the newest footer the script could find was 2026-07-31. Every weekly draft since
then reported a multi-week period — this week's said `From: 2026-07-31`, 689 entries, against a true
cycle of 31 rows — and each retro re-binned the window by hand (~10 min/run, impediment row 1021,
count 4) while the draft's per-category and per-impact tables were unusable as printed.

## What shipped

**The period boundary is the newest committed report** — [`scripts/retro-draft.ts`](../../scripts/retro-draft.ts).
`findLatestRetroReportDate` reads the date off the filenames in `Design/retros/` through the anchored
`RETRO_REPORT_FILENAME` regex (`^retro-YYYY-MM-DD\.md$`), which rejects this script's own
`retro-…-draft.md` output and the parallel `workflow-retro-…` cadence by construction.
`resolvePeriodStart` prefers that date outright; the retired footer scan (`findLastRetroDate`) survives
only as the fallback for a tree with no committed report, and a missing directory fails soft to the
whole log. The report is preferred even when a footer carries a newer date, because the footer has no
writer any more — a newer footer on a current tree can only be hand-authored drift.

**The module is importable.** The unconditional `main()` at module scope is gated on the entry
basename (`retro-draft`), the repo's pattern for scripts that run through the esbuild bundle wrapper,
so [`scripts/__tests__/retro-draft.test.ts`](../../scripts/__tests__/retro-draft.test.ts) can import the
pure helpers without writing a draft. Nine tests: the filename regex, newest-wins over a listing whose
draft and workflow-retro entries both carry newer dates (the falsification arm), order independence,
the footer fallback, and the no-boundary case.

**Retrospective skill, Step 1** names the boundary so a retro no longer expects to re-bin.
