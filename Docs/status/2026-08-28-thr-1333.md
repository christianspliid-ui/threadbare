# The game has a name, and the Reaches have a count (THR-1333)

**Director ruling, verbatim: "the game is called threadbearer, it is available on threadbearer.co on the internet. that is it."** Until today the identity layer ran on three names with no authority — "The Fantasy World Simulator" in CLAUDE.md's first line and the UL's own header, "Threadbare" as the repo/Linear/voice codename, "Threadbearer" only in the design brief's title — and the UL, which wins every terminology dispute, had no entry for any of them. Now it does: **Threadbearer** is canonical (UL Process shard, term 141), Threadbare is explicitly the repo codename, The Fantasy World Simulator is the retired working title surviving only in paths. CLAUDE.md's opening line, the design brief's first sentence, the state-of-game-design router's masthead, and the UL index header all say Threadbearer. Paths, the repo, the Linear team, and the vault folder are deliberately not renamed — identifiers are not the name.

**Eight Reaches, everywhere that still said Nine.** The count was settled 2026-03-28, but the two highest-load surfaces still taught the old one: CLAUDE.md's own Rejected Approaches line ("Domain Capability across Nine Reaches") and game-design-direction's anti-pattern exemplar quoting it. Both now say Eight. The dead pointer to a nonexistent `threadbearer-design` skill in game-design-direction now points at the real design system (`Docs/design-system/laws.md`).

**And the stale-list learned its own lesson.** `Docs/canon/cosmology.md`'s seven-row STALE-SOURCE warning was 100% false — every named surface was fixed on 2026-05-05 (THR-307) and the list was never re-verified, so it sent remediators at ghosts while missing the live pollution. Rewritten to the verified 2026-08-28 reality: the only live Nine-Reaches residue is the vault's Flesh pages (`Domains/reach.flesh.md` + 4 `Actions/Flesh/` pages), now bannered deprecated — with the honest caveat that `src/data/world-model.json` still carries the `reach.flesh` node, so `npm run generate-vault` would resurrect them until the content round removes it from the model. The list's heading now carries its re-verification date and the rule that it must be re-verified at every review.
