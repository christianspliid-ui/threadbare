# 2026-10-16 — THR-1813 slice 1: the world remembers, and each run wakes in a new world

**Ticket:** [THR-1813](https://linear.app/threadbare/issue/THR-1813). Engine, Content and UI pillars. Plan: `Docs/plans/2026-10-14-thr-1813-the-world-remembers.md`.

"Begin next cycle" kept the same map and the same god, and nothing carried between games. Now the end of an age folds the run into a small **account record**, and *Wake in a new world* builds a fresh map on a derived seed, through Remembrance.

- **Engine.** `src/engine/accountRecord.ts` (pure): `emptyAccount`, `migrateAccount`, `concludeRun` (carried echoes age, this run's divine + cosmic + card echoes join, the fundament blends toward the god's spheres and back toward even, two hungers stir, the played hunger's second court opens, the next seed is derived), `wakeHunger`, `tiltCosmology`. `src/engine/accountStore.ts` is the only storage seam (`threadbare.account.v1`; `?account=fresh` / `?account=sample`). `computeHarvest` picks the god's own echoes by rule (Monument → Legacy → Relic), and every echo now carries the god's bought pair. `initializeGameStateFromIdentity` takes the account, tilts the cosmology and loads the live echoes. With no account, or an empty one, it builds today's world unchanged.
- **Run end.** The record is concluded and saved when the harvest opens, so a failed save shows before waking. The wake also calls `resetDecisionCache()`, so an in-tab new world mints the same ids as after a reload. `transitionToNewCycle` has no production caller now.
- **UI.** The harvest screen names what the age leaves behind and has a *Wake in a new world* button (tooltips `ui.harvest_leaves`, `ui.harvest_wake`) plus a save-failure line. The Stirring step shows the unreadable-account line. DebugPanel has a new *Account* tab. New debug levers: `getAccountRecord`, `previewRunEnd`, `endAge`.
- **Canon.** Rulebook §8/§11 and the quick reference carry the new lines. The glossary seats Run, Echo, Memory Word, Account Record and World Tilt (THR-1845). Interface rows: `account-carries-echoes-to-the-next-world`, `world-tilt-shapes-cosmology`.
- **Evidence.** `npm run gate` passed (the ui-debt literals were fixed and rechecked). In the browser at 1920×1080 on `?view=game&seeded&size=medium`: `endAge()` opened the harvest, the record reached `cycleCount: 1` and was stored, and *Wake in a new world* led through Remembrance into a world on seed 570138145 (was 42). Console: 0 errors.
