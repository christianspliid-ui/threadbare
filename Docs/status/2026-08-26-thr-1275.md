### THR-1275 — a possession chip can name the possession; a join lands in the local chapter (2026-08-26)

Two consequence-family anchoring gaps from the full-line-proof run, both worth closing
before the first production 6-batch since `possession` and `membership` are common draws.

**Part 1 — the `$artifact` sentinel.** `spawn_artifact` keys its node with the tick and the
effect index in the id, so no author can write it, and the only literal the anchor gate
accepts is an attachment template — which an artifact is not. Every `possession` chip was
therefore forced to anchor the **holder**: "don't make every chip about a person" enforced in
exactly the wrong direction. Resolved as a sentinel rather than by blessing holder-anchoring,
because THR-1156 holds that a chip anchors a real graph object and the possession is the
object the sentence is about. The mint already stamps `sourceEncounterId`, so the sentinel is
a lookup of that stamp: it prefers an artifact the actor now holds (the only thing separating
two agents resolving one template on one tick), then the newest mint, then id sort.
`check:encounter` refuses `$artifact` on a template that mints nothing.

**Part 2 — `membership_change` enrols you where you are standing.** `resolveFactionNodeId`
matched a `factionDefId` world-wide and, with no membership to read, returned
`matches.sort()[0]` — and **a join has no membership by definition**, so that was the case
that fell through: "the settlement takes them in" could enrol the mortal in a chapter across
the map, invisibly, since the write succeeds and the chip opens a real faction sheet.
Locality now sits between the two old preferences — a hall on the agent's own location wins
outright, else nearest by hex — and stays *below* membership, because a member expelled while
travelling is expelled from their own chapter. An unplaced agent or a hexless location falls
back to the sort rather than guessing: no `?? 0` hex default, since a wrong locality pick
reads as intentional where an admitted arbitrary one does not.

**Evidence.** 18211/18211 tests · ratchet 3009 unchanged · build clean · 30-tick smoke at 384
agents / 42 events · `check:encounter --all` OK. Non-vacuous by controlled arm in both halves:
disabling locality reddens 4 of 9 locality tests with the specific wrong chapter (the other 5
are the deliberate fallback controls); disabling the mint gate and holder preference reddens 3
of 13 anchor tests. Browser-verify substitution: jsdom-render — unattended run, no startable
dev server.
