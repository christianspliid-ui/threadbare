## What shipped

- **The grudge trigger** (`src/engine/fights/grudgeDuelTrigger.ts`, called from `phaseColocationDetection` after detection). For each co-located pair where either side holds an injury-class `hostile_to` (`isInjuryProvenance`; never `old_quarrel`), neither a monster, dead, the avatar, busy, moving, or already picked this pass, and off cooldown: roll `min(GRUDGE_ESCALATION_MAX, GRUDGE_ESCALATION_BASE × (1 + the braver courage lean))` on the pair's own stream (`GRUDGE_ESCALATION_STREAM_SALT`), spawn `fight.duel.grudge`, stamp `fightCooldowns` with `tick + GRUDGE_DUEL_COOLDOWN_TICKS` (80, expiry ticks). The phase now returns `unifiedActions` and `fightCooldowns` when a duel spawns. Detection rolls are identical with the trigger on or off (`{ grudgeDuels: false }`).
- **The actor rule:** the threaded side (higher court position if both; dormant does not count), then the braver side, then the lower id.
- **One live fight per mortal** (`src/engine/fights/fightParticipants.ts`): `fightParticipantIds` holds the actor and the opponent of every unresolved fight, keyed `fightState?.opponentId ?? targetId`, so a duel's opponent is busy from the spawn. The decision phase's busy set reads it; `runGroupMovement` writes no route for a company while any member is in a fight (`anyInFight`).
- **`fight.trigger` source `grudge`** (`FightTriggerGrudgeTrace`): spawns always traced; skips (`busy`, `cooldown`, `grudge_gone`, `no_template`) bounded to once per pair per cooldown window; a missed roll is not traced.
- **`npm run check:grudge-duels`**: the 200-tick CLI evidence (spawns, injury pairs co-located, duels per pair vs `GRUDGE_DUEL_REPEAT_CEILING`, results with `separated`, faces, deaths), with an opt-in `--inject N` that writes real `blood_drawn` grudges at tick 0.
- `isInjuryProvenance` was already exported (THR-1543); nothing to change there.
