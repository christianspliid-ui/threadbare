# THR-1092 — the abstraction detector stopped gating and started ranking

**Shipped 2026-08-13.** Project: Encounter Experience. One classification change, one repointed assertion, two doc surfaces.

**The defect was code contradicting its own docstring.** `countAbstractNouns` is a suffix proxy
(`ness|ity|tion|sion|ment|ance|ence|ism|hood|ship`) whose docstring says, in as many words, that domain vocabulary counts
against a template and that this is "a **ranking** signal, not a verdict on any single line". `auditTemplate()` pushed the
result to `failures`, so it was a verdict on every line.

**Decision: Option 1, demote to a warning** — Christian, chat review 2026-08-12, recorded on the ticket ("it is ok for an
agent to modify the test as long as it is done with open eyes and the test is still well aligned with the outcome"). The four
lexicon/structure detectors — vagueness, not-X-but-Y, thin premise, second person — stay hard gates; the one *proxy* detector
does not. `ABSTRACT_DENSITY_FAIL` was renamed `ABSTRACT_DENSITY_WARN` at the same value (4.5), because a constant named
`_FAIL` that no longer fails anything is the same class of defect the ticket was filed to fix.

**Corpus effect, measured this session over all 683 templates:**

```
                              before   after
failing any detector          : 196      67
  abstraction ONLY (fail)     : 129       0
  other ONLY (fail)           :  53      67
  both (fail)                 :  14       0
warning: abstraction          :   0     143      (129 + 14, exactly)
```

**The ticket's own snapshot had rotted in one day**, in the direction THR-688 rule A predicts: it was measured 2026-08-12 at
209 failing / 128 abstraction-only, and read 196 / 129 today after THR-1066 and adjacent content work landed. The predicate is
what carried; the count did not. The shape of the finding is unchanged — 18.9% of the shipped, reviewed corpus failed on
abstraction and nothing else.

**Demoted, not deleted, and the measurement is the argument.** The eight director-reviewed `encounter.slice.*` templates score
**0.33–1.56**/100w; the templates this threshold was catching run **4.98–7.58**. The signal separates the worked examples from
the rest by roughly an order of magnitude, so it is worth reporting and sorting on — which is what "ranking signal" means, and
why the number stays on `NudgeAuditScores` and now surfaces as a warning line carrying its own density. What the proxy cannot
do is decide, per template, whether a high score is bad prose or a subject that happens to *be* an abstraction: `hod.promotion`
takes 10 of its 14 hits from `ascension`/`devotion`, the House of Devotion's own vocabulary.

**The vacuous-test trap the ticket flagged, closed.** `aftermath-prose-coverage.test.ts:188` filtered `failures` for entries
starting `vagueness` or `abstraction`; demoting would have made the abstraction half assert nothing while still reading as a
two-detector guard. Split in two: the vagueness filter keeps its own test, and a second test asserts abstraction is **absent
from `failures`** (pinning the demotion itself) **and absent from `warnings`** for the reviewed slice. Repointed rather than
dropped because the slice is the exemplar set — whatever the corpus base rate, these eight are expected under the threshold,
and they sit there with 2.94–4.17 of headroom.

**Class-scoping was not retried.** The ticket recorded it as measured and rejected (net −7 failures, 8 templates *newly*
failing, interactive density 2.88 against narrative 2.66 — no outlier class to carve out). That negative result is now also in
the code comment, so the next reader does not spend a run rediscovering it.

**The gate that could have gone red, and did not.** `check:encounter -- --all` runs in CI and exits 1 on a *stale* ratchet
entry — one listed in `RETROFIT_PENDING` but now passing. Demoting a detector is exactly the change that can create those. It
did not: `checked 191 clean 0 failing 0 on ratchet 191`, exit 0, because every ratcheted template also fails composition-contract
items (hand, setting, cast, rewards, aftermath, systems quota), so none of them flipped to passing.

**Evidence.** `npm test` 1007 files / 16023 tests green; `check:typecheck` OK at 3447, unchanged from baseline (not refreshed,
so no re-run owed); `npx vite build` clean; `check:encounter -- --all` exit 0 with no stale entries;
`audit:nudge-batch --ids ac.senior.planar_probe,hod.promotion,social.spy_on,social.intimidate` → `requested 4 resolved 4
missing 0`, **CLEAN**, exit 0, all four now advisory-only with their densities still printed. No engine files touched, so no
smoke owed. Browser-verify N/A — no file under `src/components/`, `src/hooks/`, `src/contexts/` or `src/index.css`, and the
ticket states the same.
