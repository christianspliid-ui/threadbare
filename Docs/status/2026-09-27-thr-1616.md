# 2026-09-27 — THR-1616: movement waypoints carry a registered subtype

**Ticket:** [THR-1616](https://linear.app/threadbare/issue/THR-1616) · **Project:** Thematic Pressure & Living World · **Found by:** THR-1595 (`readers/dying.ts`) · **Pillars:** Engine (the waypoint writer). Content N/A (no encounter or catalog entry changed). UI N/A (engine-only evidence per THR-688 rule C).

## What was wrong

Movement pathing mints a Location on every open hex an actor walks through (`findOrCreateLocationAtHex`, id `loc.transient.<col>.<row>`). None of these waypoints had a `locationSubtype`, so each place-tier sweep returned them without a subtype. There were ~95 per medium world by t300. The comment in `tradeRouteOps.ts` said they were "garbage-collected after passage". Nothing collects them.

## What shipped

- **A registered subtype.** Waypoints are written with `locationSubtype: 'wilderness_waypoint'`. The value joins the `LocationSubtype` union and the **wild** Location class, and the registry names `hexMovementPath` as a Location writer. `locationType` stays `'wilderness'`. The encounter cache reads that first, so the encounters a waypoint draws are unchanged. The entry tax is 0, the same as before. A waypoint from a saved world that has no subtype is stamped when it is reused.
- **Kept, not collected.** An agent can be `located_at` a waypoint mid-journey, so waypoints are permanent. `resolveDurableActorLocation` still refuses them as endpoints. The false comments in `tradeRouteOps.ts` and `strategicAction.ts` are corrected.
- **One-PR rule.** The registry row (`src/data/world-objects.ts`), the UL term **Waypoint** (`Graph.md`) and the canon row (`Docs/canon/world-objects.md`) landed together.
- **Sweeps:** none changed. A subtype-keyed sweep matched no waypoint before (no subtype) and matches none now (the new subtype is in no settlement list). `getLocationNodes` returns waypoints as it did before.

## Result

150 ticks, medium map: seed 42 has 324 Locations, 0 without a subtype, 75 waypoints, all `wilderness_waypoint`. Seed 99 has 317 Locations, 0 without a subtype, 70 waypoints. `generate-world-objects`: 0 unregistered, 0 phantom.
