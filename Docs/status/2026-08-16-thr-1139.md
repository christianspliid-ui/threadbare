# THR-1139 — the premonition names a mortal you can now see

**Shipped 2026-08-16.** UI pillar. Engine and Content N/A (the event already carried `agentId`; the portrait comes from the existing art pipelines).

Christian, reviewing "The God's Will" on the seeded build: *"i would also like a character image of the character who is being interacted with being added to the modal, so you can see at a glance who they are, including their name, and if i click the name i want their character sheet to open up on top so i can see the context."*

Both premonition variants — Whisper and Compulsion — now open with the mortal's portrait above the type label, and the name beneath it is a control that opens their character sheet *over* the premonition. The premonition stays mounted and choosable underneath; this is a context lookup, not a dismissal.

## What changed

- **`PremonitionModal`** renders `EntityVisual` at the `portrait` size, constrained to 84px (`SUBJECT_PORTRAIT_PX`) inside the 520px modal — rounded, not circular, so the face matches the character sheet it opens. The tile and the name both call a new `onViewAgent` prop. Absent that prop the header stays inert text, exactly as it shipped before.
- **The name carries all three parts of Law 1**: image, tooltip, link. The tooltip needed care — `agent.*` is a context-bearing prefix, and `Tooltip`'s own `id` path calls `resolveTooltip` with no context, so it would have resolved to null. That is Law 21's named anti-pattern, a dead hover that looks live. Resolved at the call site instead and handed to `Tooltip` as finished `label`/`desc`.
- **`Modal` gained an optional `zIndex`**, defaulting to `MODAL_Z_DEFAULT` (60) so every existing surface is untouched. `AgentProfileModal` passes `MODAL_Z_ABOVE_INTERRUPT` (65).

## The stacking trap, and why 65 rather than 70

Both surfaces sat at z 60, and `PremonitionModal` renders *later* in `GameView`'s JSX than `AgentProfileModal`. Equal z resolves by DOM order, so the character sheet would have opened silently *behind* the premonition — a correct-looking implementation producing a broken surface, and invisible to anyone reading either component alone.

The ticket suggested 70. That would have tied the sheet with `Tooltip`'s `70 + depth` band, and the profile sheet is full of tooltips — it would have buried its own hovers. 65 sits above the interrupt and below the tooltip band. Both tables in `layout-zones.md` now carry the band, because Law 35 says z-index comes from the stacking table rather than being invented at the call site.

Nothing nested inside `AgentProfileModal` is an independent `Modal` — the Chapter Ledger renders `embedded`, and the portrait lightbox and attachment overlay are `absolute inset-0` within the panel — so raising the sheet buries nothing.
