### 2026-10-03 — THR-1710: the player's own avatar no longer reads as a stranger

**The bug.** Cold playtest round 2, veteran tester: the avatar's sheet said "You haven't observed Vessane's capabilities" and the thread panel badged it "Unaware" — about the player's own mortal shape. The card and sheet are built at a knowledge level derived from familiarity, and the god has no familiarity record with its own avatar, so both resolved at `stranger`. THR-1609's `mortalShape` exemption lifted only the portrait and the knowledge badge; the tabs still read the stranger card. The thread panel's fallback for an unthreaded mortal hard-coded tier 0 ("Unaware"), and the avatar has no thread edge.

**The fix.** `useAgentInteraction` builds both the drawer card and the full sheet through one new predicate, `resolveCardKnowledgeLevel`: any node with an `avatar_of` edge to the ascendant reads at `transparent` (as does every mortal under debug omniscience, THR-1412); everyone else keeps the familiarity rule. The thread panel's unthreaded fallback asks `unthreadedAgentTierName`, which gives the avatar `AVATAR_TIER_LABEL` ("Your mortal shape", `src/data/influence-content.ts`) and every stranger tier 0 as before. The thread panel's Intelligence section, which hid itself for any tier-0 mortal, now also opens for a mortal whose card reads at `transparent` — so the avatar's own knowledge is no longer fogged (found by the review gate; pre-existing).
