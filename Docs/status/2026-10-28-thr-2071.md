# THR-2071 — The board reads the place

**Shipped 2026-10-28.** M3: Dynamic Economy. A town's boom or bust, a haunted or lawless place, a mortal's reputation and faction, a story's next step and what the mortal knows used to shape only `finalScore` (the shortlist gate and God's Will). The live board never read them, so they decided which scenes were offered and played no part in which one a mortal took. Plan: `Docs/plans/2026-10-26-thr-2071-board-reads-the-place.md`.

**What changed.** `scoreUnifiedBoard` multiplies each encounter by a `contextPull`: `(base + BOARD_CONTEXT_WEIGHT × sum) / base`, clamped to [0.5, 2], summing eight Board terms (`boardContextSum`). `ScoredCandidate` gains `factionScoringBoost`. The entry and `decision_board_comparison.boardTop` carry `contextPull` (when not 1) and the named non-zero `contextTerms` (at weight 0 too, so the census can measure the off arm). A code comment in `decisionBoard.ts` classifies every additive term: Board, shortlist-only, or deferred to THR-2073. New `npm run census:board-context`.

**Executor decision: the pull is normalized per board.** The plan's raw pull failed its own kill line. Census, seeds 42/99/7 × 240 ticks, medium, pooled, deterministic (the off arm reproduced 349 undertakings exactly):

| Arm | Undertaking share of non-idle verdicts | Economic: winner carries it vs board share |
|---|---|---|
| Weight 0 (before) | 8.2% | 31.7% vs 27.7% |
| Raw, cap 2 | 5.7% | 34.5% vs 27.7% |
| Raw, cap 1.5 (the halving the plan allows) | 6.3% | 32.9% vs 28.3% |
| **Normalized, cap 2 (shipped)** | **7.5%** | **35.9% vs 26.7%** |

Context terms are mostly positive (reputation sits on most shortlisted scenes), so the raw pull lifted encounters as a family and undertakings lost the board for no reason of their own. `boardContextPulls` divides each board's encounter pulls by their geometric mean (`BOARD_CONTEXT_NORMALIZE`). Every ratio between two encounters is still exactly the scorer's proportion (decision 2), and the board's average encounter reads ×1. So a place decides which scene a mortal takes, not whether they take a scene or an undertaking. A lone encounter reads ×1. Both kill lines pass: undertaking share moved 0.7 points, and the economic lean is stronger than in the raw design.

**Evidence.** `decisionBoardContext.test.ts`, 12 tests: the ticket's booming-town festival predicate, the tie at weight 0, cap, floor, fail-soft, normalization ratios, lone encounter, legacy candidate. `npm run gate` verdict in the PR body.

**Follow-ups.** THR-2073 (the deferred god-verb and movement terms) is unblocked. THR-2040's larder term now reaches the board through this pull, so its re-plan should drop the separate `larderBoardPull`.
