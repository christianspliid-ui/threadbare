1. **A price you can read.** `CostPips` (`src/components/shared/OddsPips.tsx`) drew six pips and a bare "⋯" past the cap, so the number lived only in an aria-label. It now draws the hidden count: "✦✦✦✦✦✦ +4" (`COST_OVERFLOW_LABEL`, `src/data/nudge-card-display.ts`). Live: Agent Thread on the Reach Down card reads "+4".

The sheet's Nature row keeps the reach axis words, so one sheet can read "Fair above all" beside "leaning Cunning". That split was decided under delegation; the alternative was moving the whole sheet off the axis vocabulary.

4. **The carousel's left arrow brings the left face.** `peripheralSlotFor` (`src/components/MeetTheFirst/SensingBeat.tsx`) places side portraits relative to the focused one: previous on the left, next on the right.
5. **The urge names a want, not a place.** `COMPULSION_URGE_NOUNS.explore` is "far places" (was "the open road"), so "Plants an urge in Seren toward far places." reads true in any chapter. Wording fallback, not a context hook, so the systemic wiring guide is unchanged.
