# THR-1919 — scarcity arcs no longer jam

**Shipped 2026-10-17.** A town that holds flashpoint for `SCARCITY_ARC_FLASHPOINT_HOLD_DAYS` (10 days) is **spent**. The town keeps its arc and stays at flashpoint, and it still dissolves with the half-averted scar if its staple recovers. But the arc no longer counts against `SCARCITY_ARC_MAX_ACTIVE` (3), so a famine elsewhere can open the next arc. A spent arc does not re-seed encounters. The phase now advances running arcs first and then opens new arcs into the free slots, so the cap counts every live arc in the world. Before, an early-sorted town could open before later arcs were counted. New fields `phaseSinceTick` / `spentTick` on `scarcityArc`, new trace phase `spent`.

Seed 42 medium, 600 ticks: arcs opened at 8 towns (Ardenmor Keep, Meadowcity, West Fieldvale at t12; Downswick, Greenvale, Golden Wraith Fields at t168; The Forge of Sorrow, The Bone Coast at t324). Before the fix, only 4 towns ever opened an arc. After t480 no settlement without an arc had a scarce staple, so no ninth town opened. Stocks still never recover (THR-1866 regrowth is not built yet).
