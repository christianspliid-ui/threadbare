# 2026-10-14 — THR-1821 (S1): the UI-debt ratchet, and radius / shadow tokens

**Ticket:** [THR-1821](https://linear.app/threadbare/issue/THR-1821), slice S1 of [the component-library plan](../plans/2026-10-14-thr-1821-component-library-and-ui-debt-ratchet.md). Engine and Content N/A; UI tooling and tokens only. No surface changes; browser-verify exempt per the plan (no surface reads the tokens yet, and the script is tooling).

- **The ratchet.** `npm run check:ui-debt` (`scripts/check-ui-debt.ts`, rows as data in `scripts/ui-debt-rows.ts`) counts 14 rows of player-UI debt across `src/components`, `src/hooks`, `src/contexts` (and `src/data` for glyphs) and fails if any row rises above `ui-debt-baseline.json`. Comments are removed by re-printing through the TypeScript compiler; class detectors read string literals only, so identifiers and JSX prose never count. A run that cannot vouch for itself (no compiler, empty root, unparsable file) exits 1 and writes nothing; a halved row is suspect; `--update` refuses to raise a row unless it is named with `--allow-increase=<row>`. Runs in about 2 s. Wired into `npm run gate` (code track) and CI's required `Test · Typecheck · Build` (`UI debt ratchet` step).
- **Baselines** (main @ `eb7799bb`): raw-button 203, colour-hex 371, colour-fn 309, glyph-icon 326, glyph-icon-data 171, lucide-import 5, hand-overlay 17, escape-listener 11, radius-literal 296, shadow-literal 48, uppercase 205, monospace 26, font-face-literal 17 — every row within ±10 % of the plan's measurement. Plus **literal-font-size 204**, registered from THR-1819's spec comment on the ticket (its re-measure: 199).
- **Tokens.** A Tailwind `@theme static` block in `src/index.css`: `--radius-page|panel|control|chip` and `--shadow-page|panel|control|chip`; `--scrim-dim`, `--scrim-heavy`, `--bg-glass`; `--panel-radius` kept as an alias. The built CSS declares all of them. `glowShadow(color, 'soft' | 'strong')` in `shared/sphereTint.ts`.
