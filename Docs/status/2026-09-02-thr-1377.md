# 2026-09-02 — THR-1377: the undertaking corpus states an opinion

**Issue:** [THR-1377](https://linear.app/threadbare/issue/THR-1377/35-of-64-undertaking-templates-author-no-motivations-the-content-pass)
· **Project:** Thematic Pressure & Living World
· **Pillars:** Content (35 templates), Engine (one retained branch, one new invariant test)

## What shipped

All 35 axiologically silent undertaking templates now name a 2-pair `motivations`
set. The corpus arity histogram moves `{0: 35, 2: 24, 3: 5}` → `{2: 59, 3: 5}`;
no template is silent, no set names a non-member of `VALUE_PAIRS`, and no set
repeats a pair.

Authoring followed the rule THR-1349 measured and the ticket recorded: the first
motivation is `REACH_VALUE_PAIR` of the template's dominant `reachProfile` entry,
the second is the bound pair of the next-ranked reach. `REACH_VALUE_PAIR` is
injective over the eight reaches, so that derivation can never produce a duplicate
pair — the rule is total, not a heuristic that needed patching per template.

Two templates deviate, each with the reason recorded at the site:

- `strategic_maintain_authority` — gold and shadow tie at `0.3`; takes shadow's
  `honesty_cunning` rather than gold's, so authority-by-manipulation reads
  distinctly from the three court templates that already spend coin for allegiance.
- `strategic_recruit_companions` — takes the meta pair `courage_prudence` rather
  than iron's, matching its already-authored sibling `strategic_recruit_warband`.

## The neutral-desire branch is retained, not deleted

The ticket allowed either. Retained, because `motivations` is still **optional** on
`StrategicActionTemplate` and `computeBoardDesireMultiplier` takes a bare
`readonly ValuePair[]` — an empty set stays constructible by every caller the type
admits. The new test pins the *shipped corpus*; it cannot pin a template added
between two runs, a downstream pack, or a candidate assembled at runtime. Deleting
the branch would restore "silence is revulsion" for exactly those, silently. The
retention reason is now written at the constant and at the function, and the
`TODO(THR-1377)` marker is resolved.

## The measurement worth carrying forward

Selection is byte-identical before and after — the board is in `'shadow'`, so
contest B still selects and it never reads desire. What moved is the **board's own
preference**, and it moved down:

| | seed 42 before → after | seed 99 before → after |
|---|---|---|
| board–contest agreement | 54.8% → **51.0%** | 39.3% → **37.1%** |
| board undertaking share | 20.7% → **15.7%** | 15.5% → **13.1%** |
| board encounter share | 61.1% → 66.1% | 71.4% → 73.7% |
| board idle share | 18.2% → 18.2% | 13.1% → 13.1% |
| starts / distinct (contest B) | 892 / 54 → 892 / 54 | 891 / 48 → 891 / 48 |

The direction is not a defect and is not tuning — it is the arithmetic of the term
starting to work. `UNDERTAKING_NEUTRAL_DESIRE = 1.0` is the multiplier's identity,
and it sits **above** what a typical authored set scores for an agent whose profile
is near zero on the named pairs. So 35 templates were riding a constant more
generous than speech, and authoring them replaced that constant with a real,
discriminating, usually-lower number. Both seeds stay inside the `[0.10, 0.35]`
gate band, but both moved toward its floor.

**This invalidates the live-arm numbers THR-1349 recorded** (seed 42: 586 starts /
46 distinct). Those were measured with 35 templates on the neutral constant. Whoever
ships the `UNIFIED_DECISION_BOARD_MODE` flip must re-measure the live arm against
this corpus rather than carry those figures forward. Posted to THR-1349 as its own
comment, since that ticket owns the flip.
