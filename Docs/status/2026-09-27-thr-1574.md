# 2026-09-27 — THR-1574: A fight leaves a record on the ground (Blood-soaked, slice 2)

**Ticket:** [THR-1574](https://linear.app/threadbare/issue/THR-1574) · **Project:** Thematic Pressure & Living World · **Plan:** `Docs/plans/2026-09-24-thr-1528-blood-soaked-ground.md` § Engine pillar › 2 · **Pillars:** Engine + Content; UI through existing surfaces (location page condition row, place MEMORY, which already read the record). No component change.

## What shipped

1. **A fight leaves a record.** A new branch, `fightRecordBranch` in `src/engine/fights/fightRecord.ts`, is registered **first** in `FIGHT_END_BRANCHES`, so the record exists even if a later branch throws. Registered first, it cannot carry the ending's face; the plan chose that cost. When a fight had at least one exchange, the branch writes:
   - one `fight_fought` Event per fight (a duel has two sides but one record), id `evt_fight_${actionId}`;
   - `occurred_at` to the fighter's outer-tier Location (a hero in a Place inside a lair is remembered at the lair), falling back to the opponent's ground;
   - `participated_in` from the fighter and the opponent, each with the fight's result;
   - a `lastFightTick` stamp on the place.
2. **What leaves no record.** The no-roll ends (`no_opponent`, `opponent_gone`) and a zero-clash rout write nothing: a mortal who fled at the sight of the beast spilled no blood there. A rout *after* a real clash still counts.
3. **Three fights soak the ground.** Slice 1's rule already weights a fight at `BLOOD_SOAKED_FIGHT_WEIGHT` (0.34), so three inside the ten-day window mint *Blood-soaked*. Slice 1's readers already count and tell the record: `readBloodshed`, the place MEMORY and the debug readout.
4. **Never throws.** The branch catches and traces its own errors (`fight_recorded` trace, also emitted on every skip). The dispatcher's other branches still run.
5. **Inspection:** CLI `battles` now prints a fight record as `fight <result>`. `__DEBUG.getBattleRecords()` rows carry `result`.
6. **Registry and docs:**
   - the Event row's writers gain `fights/fightRecord`, and the `fights` engine domain is claimed by Encounters & Dilemmas (fights run as encounter templates; the interface map already files them there);
   - a new interface contract, `fights-leave-a-record-on-the-ground` (🟢 LIVE);
   - the rulebook and UL *Location Trait* sentence say "or where blood was spilled again and again".
