# THR-1098 — SCAR / BOND / BOON / PATH seated in the Encounters shard

**2026-08-12 · Docs (UL) · Encounter Experience**

THR-1082's design session settled four story-first consequence categories to
replace the six aftermath display kinds (`TOLL`, `MARK`, `SEED`, `PRIZE`,
`STANDING`, `WOUND`). This seats them in the UL as canonical terms.

**Why they belong in the UL and not in a constants file.** The intent-judge
finding on the THR-1082 plan was that a conditional "file it if they graduate"
was wrong, because these words **graduate at birth**: encounter authors declare
`category` on a consequence per the nudge authoring spec, so the vocabulary
crosses engine payload, authoring spec and UI in the same PR that introduces it.
A word three systems must agree on is a UL word.

**Four entries, each carrying the disambiguation it needs.** This shard already
spends real space separating Band Fragment from Context Fragment, because both
are "an authored prose variant selected by a key". Three of the four new terms
land in the same kind of collision, so each says what it is *not*:

- **SCAR** carries the taxonomy note for all four, and records that the retired
  `MARK` display kind is not `[[Hidden Mark]]` — they share a word and nothing
  else, and hidden marks and curse marks are untouched live engine concepts.
- **BOND** is not `[[Bond Reception]]` (how a mortal receives the *god* at the
  Meet-The-First climax) and not `bondQuality` (mentorship edge health). Three
  senses of *bond* now coexist; a BOND chip never reports the god↔mortal thread.
- **PATH** is not `[[Encounter Seed]]` — PATH is the display category, the seed
  is the engine object a PATH chip usually reports the planting of. It also
  records that **`THREAD` was rejected** as the name for this category, since the
  UL already owns *thread*; the rejection is written down because the design
  brainstorm makes it read well and a later session would otherwise revive it.
- **BOON** carries the requirement that makes it different from the growth chip
  it replaces: the *and why*. `"Vara's Stone grew steadily"` named a real change
  and no reason for it.

**MARK's deletion is recorded as load-bearing, not incidental.** It was the
"everything else" bucket, and there is deliberately no fifth catch-all: an
unclassifiable change folds by polarity (`loss`/`mixed` → SCAR, `gain` → BOON,
`info` → PATH), never to a blank and never to a new bucket.

**Two footer counts were stale and are now measured rather than asserted.** The
v1.7 line read "117 canonical + 1 rejected + 2 deprecated" — correct on canonical,
but it **silently dropped the one `proposed` term** (Rebuild Road), implying 120
against an actual 121. Index coverage still claimed "118 of 118" against 121
headings, because the figure was not re-run as terms were added. Both now read
125, verified by the THR-806 shard-vs-index diff run with the repo's own
`slugifyHeading`: **125 headings, 125 anchors, no unindexed terms, no dead
anchors.** The footer now also says to count *every* `**Status:**` line rather
than the statuses you expect — that is the specific error, and it has now been
made twice in different forms.

**One trap found and written into the footer.** A hand-rolled slugifier reports
the two Graph versioning entries as both unindexed *and* dead-anchored — a false
positive on the one pair whose anchors were already repaired once (THR-806).
`slugifyHeading` collapses repeated hyphens, so `worldVersion / touchWorld()`
slugs to single-hyphen `#worldversion-touchworld`, exactly as indexed. The README
now names the collapse, so the next verifier does not re-derive a defect that
isn't there. Logged as impediment #548.

**Not blocked on THR-1082, deliberately.** The ticket states it and the plan doc
agrees: the words ship as proposed unless arbitration renames them, which is a
find-replace at the display layer. THR-1082's PR ([#1415](https://github.com/christianspliid-ui/threadbare/pull/1415))
is held pending an attended pixel pass and does not gate the vocabulary.

Docs-only diff — classified with the THR-917 predicate (empty), closed out on the
docs track: `check:generated-freshness`, `lint:plan-doc`, `check:impediment-ids`.
No `npm test` / `check:typecheck` / `vite build`, which cannot fail on a change
with no code in it.
