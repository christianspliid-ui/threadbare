# 2026-09-20 — THR-1516: `{sphere_flavor}` resolves in social-scene step prose; the pool gets its Law 43 lock

**Ticket:** [THR-1516](https://linear.app/threadbare/issue/THR-1516) · **Project:** Encounter Experience · **Pillars:** Engine (enricher + context), Content (48 phrases, 30-template approach map, two re-authored lines), UI N/A (step prose reaches the existing stage through `stepProseHistory`; no component changed).

## What was wrong

`src/data/social-scene-sphere-coloring.ts` shipped `SPHERE_COLORING` (12 approaches × spheres)
and `getSphereFlavorPhrase()` with its intended usage in its own header — and zero callers.
`enrichProse()` had never learned `{sphere_flavor}`, so every authored occurrence in
`src/data/social-scene-templates.ts` reached the player raw: step 3 of
`social_scene.recruitment_pitch` rendered `… place in something larger. {sphere_flavor}.`
verbatim in the CLI. Same class as THR-933 (`{actor}`) and THR-1036 (word pools): the
corpus adopted a token the enricher did not know. THR-716's second Done-when — a no-raw-braces
lock over the social-scene pool — was never written, which is why a second token sat leaking
for ~50 days after the `{actor}` half shipped.

Two smaller defects surfaced under it. The table was authored for 8 spheres against a 12-sphere
`SphereName` (12 red baseline entries), so an actor aligned to light, darkness, spirit or time
would have stripped silently even once wired. And two lines used the token mid-sentence
(`with {sphere_flavor}, invoking …`, `the hunger for {sphere_flavor} that …`), which no
complete-sentence phrase can fill.

## What shipped

**Engine** — [`src/engine/proseEnrichment.ts`](../../src/engine/proseEnrichment.ts).
`NarrativeContext` gains `actorSphere` and `socialApproach`; `gatherNarrativeContext` fills
both from state it already holds — the sphere via the new exported `resolveActorSphere()`
(`sphereAlignment.primary` on an ascendant, else the dominant `sphereAffinity` score on a
mortal, undefined otherwise), the approach via `getSocialApproachForTemplate(opts.templateId ??
opts.contextFragmentTemplateId)`. `enrichProse` resolves the token right after `{actor}`;
missing either half strips the token *and* the sentence period the corpus writes after it
(so `. .` never appears) and warns once per template, never per render — the `{frag:*}`
shape, with a `resetSphereFlavorWarnings()` test seam. `unifiedActionResolution` threads
`templateId: template.id`; every other encounter-path caller already threads
`contextFragmentTemplateId`, so they get the token without change.

**Content** — [`src/data/social-scene-sphere-coloring.ts`](../../src/data/social-scene-sphere-coloring.ts).
48 new phrases complete all 12 approaches over all 12 spheres. `SOCIAL_SCENE_APPROACHES`
binds every `social_scene.*` id to the approach it speaks in (`recruitment_pitch → recruit`,
`peace_negotiation → mediate`, `extortion → intimidate`, …). **Binding decision:** a
`templateId → SocialApproach` map beside the phrases rather than a per-template field — the
approach is a property of the coloring, the converter's field allowlist stays untouched, and
one file changes when a scene's voice does. The two mid-sentence lines in
`social-scene-templates.ts` now place the token as its own sentence.
`scripts/check-encounter.ts` learns the token in `SIMPLE_TOKENS`.

**Lock** — [`src/engine/__tests__/socialScenePlaceholders.test.ts`](../../src/engine/__tests__/socialScenePlaceholders.test.ts),
15 tests: the ticket's evidence line resolves to `SPHERE_COLORING.recruit.<sphere>`; the pair
selects the phrase; fail-soft strips on a missing approach or sphere and never throws; the
table is complete (predicate over `SPHERE_NAMES`); every template that authors the token is in
the map and every map id names a real template; **every social template × all 12 spheres × every
prose field enriches to zero raw `{…}` of any shape**, and the *phrase* (not a strip) lands
wherever the token is authored; `resolveActorSphere` reads both node shapes and returns
undefined for an all-zero affinity, a bare node, and a missing node; `gatherNarrativeContext`
binds from `templateId` and falls back to the fragment id.

sphere `chaos`, approach `recruit`):


**0 raw tokens across 30 templates**; 23 rendered the flavor step with its phrase inside the
session's tick budget (the rest are covered by the vitest sweep, which enriches every field of
every template under all 12 spheres). Falsification: with the substitution block removed from
`enrichProse`, 7 of the 15 tests go red on the raw token; restored, 15 pass. Neighbouring
suites (`proseEnrichment` 92, `encounterWordPlaceholders` 14, `socialEncounterGeneration` 47)
green. Engine smoke: tick 30 reached, 480 agents.
