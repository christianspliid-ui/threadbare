**Guild Postings reached the other eleven factions.** `GuildQuestPanel` decided whether a
settlement had a guild hall by comparing one contained node's `factionDefId` against the literal
`'adventuring_guild'`, and `hasGuildHall === false` returns `null` — so a hall belonging to any of
the other eleven definitions rendered *nothing at all*, not an empty state. The fix resolves the
hall through `FACTION_DEFINITIONS` instead, mirroring the predicate `factionQuestGeneration` has
always used (`sublocationTypeId === 'sublocation-type.faction-hall'`, or the legacy
`locationSubtype === 'guild-hall'`), which is what a hall actually *is* — the faction that owns it
was never the qualifying property. Measured on the live seeded world (medium, seed 42): settlements
that surface postings went **3 → 27**, the 24 newly-reached ones spread across all eleven remaining
factions — `mercenary_company` 9, `merchant_consortium` 5, `temple_of_spheres` 5, `holy_order_dawn`
5, `lorekeepers_covenant` 5, `rangers_brotherhood` 3, `arcane_circle` 3, `civic_guard` 3,
`builders_fellowship` 3, `underking_court` 2, `thieves_guild` 2. The widening is bounded rather than
open: an unrecognised `factionDefId` on a hall still renders nothing, so the predicate cannot drift
into "any sublocation with a faction-shaped property". The test fixture was pinned to
`FACTION_DEFINITIONS.keys()` rather than to a hand-listed set, so a thirteenth faction cannot be
added without this coverage following it; 13 of the 25 cases were confirmed red against the old
literal by restoring it and re-running. **Deliberately not fixed, and filed instead:** the engine's
own `findGuildLocations` (`engine/ruins/questHooks.ts:126`) carries the *same* literal, so hooks are
still only *posted* near adventuring-guild halls — the eleven newly-visible panels show their empty
state until a stamped ruin falls within radius. That is the engine pillar, which this ticket scopes
N/A and whose predicate is UI-only, so widening it here would have been an unreviewed design call
about which factions commission ruin delves (THR-1026). (THR-818, 2026-08-08)
