# THR-1385 — the tick-cost probe read `unknown` because the engine shares its stdout

**2026-09-06 · Tooling · Bug · Follow-up fix to the THR-1385 probe**

## What was wrong

`measure:tick-cost -- --json` prints one JSON object on stdout, and `check:tick-cost --input <file>`
`JSON.parse`s that captured stream **whole**. But stdout is not the measure script's alone: engine code
on the worldgen path writes diagnostics with `console.log`, and those land *ahead* of the JSON. The
captured file is therefore a log line followed by an object, which is not valid JSON, so the probe
recorded `verdict: 'unknown'` with a parse error instead of a reading.

Reproduced before touching anything:

```
$ npm run --silent measure:tick-cost -- --ticks 12 --map small --json > out.json
     1  [WorldGen] Genome NPC top-up: +78 settlement-authored NPCs
     2  {"seed":42,"map":"small","ticks":12,...}
PARSE FAILED: Unexpected token 'W', "[WorldGen] "... is not valid JSON
```

The hourly lane had been stripping the offending line by hand each run to recover a number. The
2026-09-06 15:00 UTC briefing flagged it as no longer intermittent enough to wait out, and executor-side.

## The fix

`scripts/measure-tick-cost.ts` now wraps the measurement in `measureWithCleanStdout()`. In `--json` mode
— and only there, because that is the mode with a machine contract — `console.log` is routed to
`console.error` for the duration of `measure()`, then restored in a `finally`. The diagnostics stay
visible in lane logs on stderr; stdout carries exactly one JSON object.

**Fixed at the owning layer, not at the symptom.** The narrow fix — turn `worldSeed.ts:1856`'s
`console.log` into a `console.warn` — would have been wrong twice over. That diagnostic is legitimately
useful in the browser console and the CLI, and it is not the only writer: the verification run surfaced a
**second** stdout line, `[WorldGen] Validation errors: [...]`, which a one-line change would have missed
and which would have re-opened the same failure on the next map that trips validation. The boundary that
owns the contract is the script that publishes it, so that is where the guard lives — and it holds for any
future stdout writer on this path.

## Verification

Controlled arms through the real consumer, same measurement, one variable:

```
--- polluted stdout (the shipped failure) ---
[tick-cost] verdict=unknown needs-session=false
[tick-cost] check:tick-cost — could not read ...: Unexpected token 'W', "[WorldGen] "... is not valid JSON

--- clean stdout (after the fix) ---
[tick-cost] verdict=baseline needs-session=false
[tick-cost] tick cost 38 ms/tick steady (small, 12 ticks, 380 agents, top phase agent_decision) — 0 prior row(s) in 7 d, building the baseline.
```

Gates: `npm test` 1157 files / 19325 tests passed; `check:typecheck` OK — 2930 errors, unchanged from
baseline; `npx vite build` built in 14.54s. No engine file touched, so no engine smoke is owed; no UI
file touched, so no browser-verify is owed.
