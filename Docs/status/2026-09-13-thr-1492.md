## Re-verified before deleting (the THR-951 guardrail)

Greps run 2026-09-13 over `src/` + `scripts/`, quoted verbatim in the closing Linear comment. Two of the three were exactly as the ticket recorded; **the third was not**, and that is the finding of this pass.

| Candidate | Verdict |
|---|---|
| `NpcDetailView.tsx` | Clean. Own file + own test + one comment line in `styleguideSync.test.ts`. Deleted with its test. |
| `cultureDetail.ts` | Clean. Zero importers but its own test. Deleted with its test. |
| `AgentDetailPanel.tsx` | **Had a live importer.** `src/engine/activitySummary.ts:11` did `import type { ActivitySummary } from '../components/Game/AgentDetailPanel'` — an engine module reading a type out of an unmounted component. |

The panel was still dead as a *renderer* — no JSX mount anywhere. What was live was a type declaration co-located in its file. So the interface moved to `activitySummary.ts`, beside the only function that builds one, and the component went. The producer owns the shape; the panel was one reader of it.

## The test that could not simply be deleted

`UndertakingSurfaces.test.tsx` asserted only `AgentDetailPanel` — all three describes — so by the sunset rule it dies with the component. But it was also the **only** test anywhere exercising `getUndertakingProgressWord` / `UNDERTAKING_PROGRESS_WORDS`, and that function is live in `momentCardModel.ts` and `JourneyTab.tsx`. Deleting the file wholesale would have dropped real coverage of a live function along with the dead renderer.

So the portable half was **repointed** rather than deleted — CLAUDE.md's rule is *delete or repoint the tests that assert a dead contract's side*. Four arms moved into `src/data/__tests__/domain-words.test.ts`, onto the pure function: every band is a word, never a numeral (Law 13); every band is reachable across the live range; each index maps to its own word; out-of-range completion clamps rather than returning `undefined` (NFP #4). The dead-DOM assertions did not survive, because there is no DOM to assert.

## EntityCard could not retire without the model growing first

`EntityCard` was the older of two section models, with one production consumer. Migrating that consumer onto the canonical `Section` stack turned out to require the canonical model to be able to **say what the retiring one said** — otherwise the replacement is a regression wearing a refactor's clothes. Two things it could not say:

- **A tag chip's axis glyph and its DOM key.** `ChipDescriptor` gains optional `glyph` and `dataKey`. The glyph is [THR-1486](https://linear.app/threadbare/issue/THR-1486)'s reading — a chip's *kind* reads before its word does — and a chip that lost it on the way across would read as a different chip.
- **A trigger's firing chance.** Law 15 gives a probability pips, so rendering triggers as `panel` rows would have dropped the pips and the authored narrative line with them. `SectionKind` gains `'triggers'`; the renderer is `EntityCard`'s block moved across, pips intact.

With those, `AttachmentDetailView` renders a `Section[]` and `EntityCard`, `src/types/entityDetail.ts` and both their tests are gone, along with the styleguide entry, the barrel export, and the `component-selection.md` / `primitives.md` rows.

**One face deliberately changed.** The retiring card took `onViewCodex` and turned an absent handler into `() => {}`. Both production mounts — `AgentProfileModal` and `GameView` — pass nothing, so the sheet shipped a header "Codex →" and a footer "View Full Codex" that did nothing when clicked (Law 21). The affordance now follows the wiring: present when a host supplies one, absent when not.

## FactionSheet's `Section`, and why the swap is not literal

The plan says FactionSheet's local `Section` is "replaced by `shared/Section`". Taken literally that is not possible and would not be right: the shared `Section` renders a `DetailSection` **descriptor**, while FactionSheet's blocks are a network graph, member rows and buttons — *children*, not data. Two different components that happen to share a name.

What was actually forked is the **label**: a local `<h4>` at `--text-xs` / `0.05em` beside the design system's `0.65rem` / `0.12em` display-font treatment. So `SectionLabel` is now exported from `shared/Section` and FactionSheet draws it, keeping its own container. One label rule in one place (Law 27), which is the token conformance the plan asked for, and the visual delta the before/after was requested to catch.
