# THR-1225 — the fiction retirement, finished (2026-08-26)

Prose Doctrine v2 struck the flavor quote by name on 2026-08-25. THR-1224 took it off
the card face and removed its word budget, but left the data: `StepNudge.fiction` stayed
**required**, still carrying its authored text across the whole corpus, because emptying
it edits the same encounter files as the doctrine-v2 rewrite (THR-1223) and would have
conflicted line for line. This is the remainder, run once that rewrite landed.

## What shipped

**767 authored `fiction` strings removed**, then the fields themselves — `StepNudge.fiction`,
`StepNudge.fictionBySetting`, `EncounterStageNudgeCardModel.fiction`, and
`NudgeCardMember.quote` (37 members). The retirement is now **structural rather than
behavioural**: a quote cannot creep back onto a card without a type error first, where
before it was held out only by a component declining to draw a field that still existed.

The count is the first finding. The ticket estimated *"~150 authored strings across
`src/data/encounters/*.ts`"*; the field had exactly one declaration in the type system, so
every `fiction:` in the tree was that field — 195 in the named directory and **572 more in
three data files the ticket did not name**, `meeting-dilemma-library.ts` (424),
`encounter-content.ts` (85) and `civic-guard-encounter-content.ts` (9). Verifying the noun
before the verb is what turned a 150-line estimate into the real membership; a strip that
had trusted the count would have left three quarters of the corpus carrying a removed field.

Removing the field cascaded further than the ticket's scope list, in the honest direction.
`fictionBySetting`'s only consumer was the `bindSettingFiction` fold in
`src/engine/encounters/nudges.ts`; the fold's only input was `NudgeContext.settingClass`;
that field's only producer was `settingClassForAction` in the stage adapter. Removing the
fold made the other three dead by construction, so they went with it rather than being left
as code nothing calls. Template *openings* still vary by setting class — that path is
untouched, and is now the only place setting variation lives.

`unauthoredCardCount()` relaxed to `title` alone, keeping its pinned-at-zero CI gauge.

## What did not ship, and why

**The name clamp stays at 6.** Scope item 4 asked for `NUDGE_NAME_MAX_WORDS` 6 → 4, on the
premise that *"once THR-1223's card-name rewrite lands, the clamp follows the corpus"*.
THR-1223 landed — but it **excluded the camp seven by design** ("they ride THR-1222's
retrofit"), so the corpus it left is only partly migrated. Tightened to 4,
`check:encounter --all` fails four cards across three templates that pass at 6:
`sharpen.turn_it_to_the_light`, `ward_camp.a_gap_in_the_wind`, `ward_camp.set_a_star_over_it`
and `company.betrayal.the_work_calls`. The first three belong to THR-1222, parked in `Todo`
behind a director approval that has not fired; the fourth is on no retrofit list and no
ticket names it.

So the red would have had no owner and no clearing date. The constant's own doc comment
already stated the rule, and THR-1224 had declined the same tightening for the same reason:
*"lowering an error-level cap under content nobody has migrated turns a green corpus red for
work that is already ticketed elsewhere. The clamp follows the corpus, never leads it."*
Reverted, measured green against a stash-and-compare baseline, and deferred as **THR-1255**
with both unblock conditions written down. Scope item 5 resolves as a consequence: with the
clamp and budget apart, `doctrineV2Checks`'s name-budget arm is the only thing that reports
a 5-word name, so it still earns its place rather than being subsumed.

## Tests

Three tests asserted the *behavioural* retirement and had to become structural ones —
`flavorQuoteRetired`, `dealtCardProvenance`, `dealHand`. The first is worth naming: its
second arm existed to pin *where* the retirement happened and said so in as many words —
*"if a later change strips `fiction` from the adapter, this arm is what notices"*. This was
that change; the arm did its job and retired with the field. Each replacement pairs the
absence check with a live assertion on surviving anatomy, so a card model that built nothing
cannot pass vacuously.

`gateDutyNudgeStage`'s cast-placeholder test needed re-aiming rather than deleting. Gate Duty
authored `{cast:suspect_courier}` in both its step prose and its card bodies; with the bodies
gone, the nudge phase carries no cast token at all, so the resolved-name assertion measured
nothing. It now reads `model.scene.pressureProse`, where the enrichment demonstrably lands.
Deleting the assertion instead would have left the raw-token half alone — an absence check
that passes just as green when nothing renders.
