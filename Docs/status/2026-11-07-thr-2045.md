# THR-2045 — An expired agreement keeps the pair's bond

**Shipped 2026-11-07.** M3: Dynamic Economy. No plan doc (bug fully specified in the ticket).

1. **The bug.** Bonds and agreements are both `relates_to` edges, and `bond_change` (`applyBondEdge`) writes onto the first edge between two people, which can be a debt. `expireAgreements` removed the edge when its term ran out and carried nothing off it, so the pair's resentment or trust vanished with the debt.
2. **The fix.** The settle path's helper is now shared: `carryBondOffAgreementEdge` (exported from `src/engine/debtSettle.ts`) moves `sentiment` / `trust` onto the next first edge between the pair, or onto a new bond edge. `expireAgreements` calls it before `removeEdge`, and re-reads each edge live so a bond carried onto a second debt expiring in the same pass moves on again.
3. **Tests.** Three in `src/engine/__tests__/agreementExpiry.test.ts`: a bond on a debt edge reads after expiry; a bond passes through a second debt expiring the same tick; a bondless debt leaves no edge behind.

**Evidence:** `npm run gate` PASS (test, typecheck, build, encounter, god-cards, ui-debt, cli-smoke). Engine-only; no browser evidence owed.
