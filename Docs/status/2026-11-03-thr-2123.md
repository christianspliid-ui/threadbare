# THR-2123 — Legibility 2: Inspector pages read Who, Now, Act, Detail, Out at every size

**Shipped 2026-11-03.** UI Visual Overhaul — Design System v1. Plan: `Docs/plans/2026-11-03-thr-2123-legibility-inspector-pages.md`.

1. **U1 `SubjectHeader.tsx`.** At wide and Full the header is one left-aligned column: kind label and name first, then the picture (still the largest object), then where-line, lede, chips and doing line. The name is `--text-2xl` at every size; `PORTRAIT_NAME_SCALE` is deleted. Docked is unchanged (thumbnail beside the words). One component, two orders.
2. **U2 `InspectorPage.tsx`.** New pure `nowSectionOf(body, size)`: the first visible prose section with a highlight, else the first with a bond, else none. It renders once in a `data-inspector-now` slot under the header and above Act (in the aside at wide and Full); `tabsAt`, the aside list and `hiddenForWidth` skip it. An empty Now draws nothing. The report gains `dressing.nowSection`.
3. **U3 frames, gold, rhythm.** Docked and wide pages render an unframed `<article>` under `PanelLevelScope level="panel"`; Full keeps `Panel level="page"`. The Act row and *In this land* headings are no longer gold; a land row's sub-label is a Text 700 row. Page slots sit `--space-6` apart, the tab panel's top gap is `--space-2`, block gaps `--space-2`.
4. **U4 fold report.** `fold: { who, now, act, tabs }` (true when the slot ends inside the scroll box, null when absent), read only when a host listens. It reaches `getInspectorLab()` cells and `getInspectorState()` (`debug-bridge.d.ts`: `DebugInspectorFold`).
5. **Canon.** `layout-zones.md` § Inspector (page order, Now precedence, empty Now, fold check), `entity-visual-header.md` (the Inspector header), `layout.md` § Frames (a hosted page draws no frame inside its host).
6. **Test.** `inspectorAnatomy.thr2123.test.tsx` covers Done-when (a)–(e) plus the empty Now slot and the docked order.
