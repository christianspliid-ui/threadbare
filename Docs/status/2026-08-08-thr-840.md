**The engine was drifting a shrine every tick and the settlement's Livelihood line said nothing about it.** THR-618 shipped the essence bridge with the clause's guards written to *mirror* `computeSanctitySustenance` exactly, so the sentence could never claim a bargain the drift was not making. The mirror was faithful and the read was not: `resolveEconomicHost` walks a **sublocation** up one `parentLocationId` hop, so a `shrine` or `rite` standing inside a settlement eats from that settlement's larder and drifts every tick — while `LivelihoodLine` read `readEssenceSource(location.properties)`, the location's own bag only. Two of the five source kinds were coupled invisibly, and the sublocation has no Livelihood line of its own to fall back to, because it carries no `resources` bag (which is exactly why the engine walks up in the first place).

THR-618 filed rather than guessed, because widening the UI to scan a location's children needs a **decision** it did not have: whose sentence is it when several sublocation sources pull different ways? That decision is now authored, in `selectLocationSustenanceVoice`, and it rests on one observation — every source here eats from the *same* larder, so they are not independent bargains but one bargain read through different spheres. That is why the line stays one sentence rather than becoming a list. **(1)** The place's own holy ground speaks first — a location carrying a source is describing its own sanctity, and that is its sentence by right, which also makes the change strictly additive: a line that already rendered never changes (NFP #6). **(2)** Otherwise the loudest borrowed source speaks for it, by `|affinityScore|` whichever direction it pulls, because the clause exists to make the drift visible and the loudest drift is the one worth seeing. **(3)** Ties break on host id ascending, so the same world renders the same sentence every tick (NFP #3).

**The mirror is gone, not re-aimed** — and that is the durable half. The UI no longer re-derives the engine's guards; it calls `computeSanctitySustenance` and renders only when the engine returns **no** `reason`, so the two cannot drift apart again. That closes a live gap the mirrored version had: at `ECON_SANCTITY_NURTURE_CEILING` the engine returns `reason: 'ceiling'` with **zero drift** — the land has stopped giving — while the old guards, which checked only `matchedResourceIds.length > 0`, still rendered *"the place is thick with it."* The three guards the engine deliberately does not apply stay in the selector, because they are about what the player may be told rather than what the land is doing: undiscovered stays silent (fog-consistent), desecrated is the `SourceDrainLine`'s sentence, untyped has no sphere to speak in.

Scoped deliberately: no new prose. The land's bargain sounds the same whether the holy ground is the town's own or stands in its courtyard, so the existing per-sphere tables carry it — the authored decision is the composition rule, not new voice.
