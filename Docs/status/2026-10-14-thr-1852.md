# 2026-10-14 — THR-1852: God's Will names the deed, never the template id

**Ticket:** [THR-1852](https://linear.app/threadbare/issue/THR-1852). Warm playtest round 2, 3/3 testers: the God's Will options and both of its toasts read "compelled toward encounter.town.oath_breaker_rite". A recurrence of THR-1802, whose fix put the name first but never fixed the lookup behind it.

- **Engine.** `src/engine/premonitionCompulsion.ts` now names each target with the new `resolveCompulsionEncounterName`, which goes through `getUnifiedTemplateById` (the unified index, then every encounter pool) instead of `getAnyEncounterById` alone. That lookup missed authored encounters that live only in `UNIFIED_ACTION_TEMPLATES` (the Oath-Breaker's Rite, the comet omen, the Temple of Spheres quests) and fell back to the id. A miss, or a name that is itself id-shaped, now reads as the tunable noun `COMPULSION_UNNAMED_ENCOUNTER_NOUN` ("a task nearby").
- **Content.** The one new noun lives in `src/data/premonition-content.ts`.
- **UI.** No component change: the modal and both toasts (`premonitionActions.ts`, `premonitionSteer.ts`) all read the one `encounterName`.
- **Tests.** New `premonitionCompulsionName.test.ts`: the four quoted ids resolve to names, every unified and encounter-pool template yields a non-id name, an unknown id gets the noun, and a compulsion built on the seeded medium world carries names. The THR-1781 integration test now uses the resolved name instead of the id.
- **Browser evidence.** `?view=game&seeded&size=medium` at 1920×1080: options "Pilgrim's Offering", "The Gleaming Vein", "Blamed for the Tithe Barn", "The Page Beneath the Saint"; toasts "Kael Thornweaver is compelled toward Pilgrim's Offering — at their next free choice" and "Your will holds: Kael Thornweaver turns to Pilgrim's Offering." Screenshots in `Docs/audits/2026-10-14-thr-1852/`.
