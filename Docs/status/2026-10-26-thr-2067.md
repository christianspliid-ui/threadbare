# THR-2067 — The trade's lean reaches the live board

**Shipped 2026-10-26.** Cold playtest round 5 milestone; found by the design lane while designing THR-2059.

**What changed.** `computeRoleAffinityMultiplier` (×1.4 on the role's primary reach, ×1.15 on its secondary) multiplied only `finalScore`, which the live decision board never reads. So a healer's trade reordered God's Will's offer but not what she chose. `scoreUnifiedBoard` (`decisionBoard.ts`) now multiplies each encounter's score by `roleAffinityPull = 1 + (roleAffinityMultiplier − 1) × ROLE_AFFINITY_BOARD_WEIGHT`, read off the candidate the scorer already carries. The pull is recorded on the board entry and on `decision_board_comparison.boardTop` wherever it is not 1. A missing or non-finite multiplier reads as no lean (fail-soft).

**Measured.** `npm run measure:role-lean` (new `scripts/role-lean-board-share.ts`), seed 42 × 600 ticks, medium: undertaking share of non-idle board verdicts 5.6% at weight 0 (the old board) → 5.5% at weight 1; 61 of 3036 board winners carried a pull. Well inside ±5 points, so `ROLE_AFFINITY_BOARD_WEIGHT` stays 1 (the full lean).

**Next.** THR-2068 (THR-2059 S1) adds `firstPathPull` beside this multiplier in the same loop; it was mutex with this ticket and is now free to build.
