# THR-1066 — two register defects fixed, and the abstraction gate measured rather than obeyed

**Shipped 2026-08-12.** The two mortal-drawn templates that addressed the *mortal*
as "you" now read in third person and pass `auditTemplate()` cleanly. The four that
remain fail on abstraction alone, and the corpus measurement says that detector is
not discriminating defects — recorded as a verdict here and filed for a decision as
[THR-1092](https://linear.app/threadbare/issue/THR-1092/the-abstraction-detector-is-documented-as-a-ranking-signal-but-wired).

## The membership predicate re-derived from three to six

The ticket warned not to trust its snapshot count once THR-929's remaining
sub-batches landed, "since an outcome rewrite moves the abstraction denominator."
It was right, in both directions. Re-run over THR-929's 30 after it closed
(2026-08-10, PRs #1379 + #1380):

```

✗ ac.senior.planar_probe     abstraction 4.98                     <- new
✗ hod.promotion              abstraction 5.98                     <- new
✗ ag.senior.deep_expedition                     second person x4  <- abstraction 5.60 -> 4.02, now clears
✗ social.spy_on              abstraction 7.58                     <- rose from 6.22
✗ social.intimidate          abstraction 5.56                     <- new
```

`social.spy_on` went *up* because the outcome rewrite shortened it — density has a
denominator, and a ticket that quotes a count instead of a predicate would have
shipped against the wrong set.

## The two register defects were real, and cost nothing to fix

Both are mortal-drawn (`actorAffinities` omits `ascendant`), and the rule exists so
a mortal-drawn scene never addresses the mortal as "you" — the player is a god
watching a person, not that person. House voice was already sitting next door:
`npc_read_intentions` is imperative plus third-person target with no second person
at all, and `ag.senior.bounty_hunt` writes the institution as subject — *"The guild
calls on its sergeants."*

- `npc_eavesdrop` — *"You extend your awareness like smoke"* → *"Awareness spreads
  like smoke"*; *"rises to your attention"* → *"rises to a patient ear"*;
  *"overheard, stolen, yours"* → *"overheard, stolen, carried away."*
- `ag.senior.deep_expedition` — *"The guild entrusts you with leading an
  expedition"* → *"...entrusts one of its sergeants with an expedition"*; *"rallies
  to your banner"* → *"to the banner"*; *"Your leadership holds the team together"*
  → *"Steady command holds..."*

Second person 4 → 0 on both. Abstraction fell as a side effect, because the removed
words were themselves nominalisations (`attention`, `awareness`, `leadership`):
`npc_eavesdrop` 5.08 → 3.39, `ag.senior.deep_expedition` 4.02 → 3.45. **Both now
pass every detector with no detector change.**

## Why the other four were not rewritten

`countAbstractNouns` is a suffix proxy, and its own docstring says it is "a
**ranking** signal, not a verdict on any single line." `auditTemplate()` pushes it
to `failures` anyway. Measured over all 683 templates:

```
failing any detector      : 209
  abstraction ONLY        : 128     <- 18.7% of the shipped corpus
  other ONLY              :  63
  both                    :  18
```

Worst offenders are core reviewed templates whose subject noun *is* the
abstraction — `action.flesh.cultivate` 13.33, `bind_thread_location` 12.96,
`action.stone.build` 9.59. Of the four here, `hod.promotion` takes 10 of its 14
hits from `ascension`/`devotion`, and `social.spy_on` 24 of 43 from
`surveillance`/`intelligence`/`location`. Rewriting to dodge suffixes is the
contortion THR-899 removed.

## Negative result — class-scoping is not the fix, do not retry it

The obvious remedy mirrors THR-1045's `countSecondPerson` carve-out: scope
abstraction to the narrative classes. Measured before adoption, per the THR-877
standard the ticket required, and it does not work:

```
failing now                               : 209
failing if abstraction scoped to narrative: 202   (net -7)
  newly passing : 16
  newly failing :  8    <- incl. loc.incite_unrest 3.96 -> 7.61
  still failing : 130

interactive : 990 hits / 34357w  = 2.88/100w
narrative   : 5202 hits / 195601w = 2.66/100w
```

There is no outlier class to carve out — interactive density is barely above
narrative — and dropping interactive words shrinks the denominator, which is why
eight templates get *worse*. Recorded so the next session does not spend a run
rediscovering it.

## Why the detector was not changed here

Demoting abstraction to a warning is the option the evidence favours (corpus
failures 209 → 81), but it changes what "clean" means for every future WS5
conversion, and `WS5_MIGRATED` is held to `failures === []` by
`ws5-nudge-migration.test.ts` — a gate tied to the THR-883 format locked
2026-08-09. That is a creative-standards call, not a technical verdict, so it is
filed with the measurement attached rather than applied on executor authority. The
ticket's own Done-when allows exactly this: pass cleanly *or* carry a recorded
verdict naming the detector that over-fired.

THR-1092 also records a trap for whoever takes it:
`aftermath-prose-coverage.test.ts:188` filters `failures` for `abstraction`, so
demoting would make that assertion pass **vacuously**.
