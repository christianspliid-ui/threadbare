# THR-1960 — The map stops naming hidden elder ruins

**Shipped 2026-10-21.** The place-name layer named every place it was handed, including elder ruins, which are seeded undiscovered and draw no icon. So "Battlefield Ruin", "Temple Ruin" and "Vault Ruin" showed on the map from the first tick and gave away every hidden delve site.

**Fix.** `partitionHexLabels` (new, exported from `src/components/HexMapV2/overlay/LocationLabelOverlay.tsx`) splits a hex's names the way `LocationIconMesh` lays out its icons. A type in `UNDRAWN_PLACE_TYPES` (the elder ruin) gets no slot and no name. An undiscovered anomaly (`hidden`, set in `HexMapV2.tsx`) keeps its ring slot, because the icon pass gives it one and draws nothing there, but shows no name. The other names on the hex stay under their icons.

**Evidence.** Same view on both builds (`?view=game&seeded&size=medium&nofog`, 1920×1080, k 11.1): main showed 15 labels, seven of them ruin names; this branch shows 6 labels and no ruin name. Console: 0 errors. Node test: `LocationLabelOverlay.partition.test.ts` (4 cases).
