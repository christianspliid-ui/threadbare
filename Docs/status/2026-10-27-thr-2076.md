# THR-2076 — Taking up a place refreshes the structural caches

**Shipped 2026-10-27.** M3: Dynamic Economy. Follow-up to THR-2048 (no plan doc; the fix was written in a duplicate review-gate pass).

**What changed.** The `hold_place` aftermath effect's `taken_up` branch (`src/engine/encounterAftermath.ts`) now sets `mutationSummary.touchedStructure`, as the `raised` branch does. Both call `grantHolding`, which adds an `owns` edge, a holding-face node and a `possesses` edge. Before the fix the branch set only `touchedWorld`, so `applyOutcomeEffectsTable` called `touchWorld` and `structuralCacheVersion` did not move. Structure-keyed caches kept the graph from before the holding after a mortal took up an unheld forge or conditional mine.

**Evidence.** `holdPlace.test.ts` now asserts `touchedStructure` on the taken-up case. It fails with the old line and passes with the fix. `npm run gate`: PASS on all seven gates (code track, engine).
