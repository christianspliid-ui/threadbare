# THR-1250 — the authoring brief taught the pre-register aesthetic first

**2026-08-25 · Encounter Experience · shipped**

Christian's suspicion was right and the mechanism was upstream of every rule anyone had written: *"we are still seeing this weird lyrical abstract language sneaking in even though i have tried three times in a row to make the encounter language simple, clear and to the point."* Three director-level register corrections (THR-609 plainspoken-Malazan, THR-868's lyrical rejection, Prose Doctrine v2) all landed correctly in canon. None of them reached the surface the draft agent actually reads.

`Docs/authoring-brief.md` is the compiled preamble the encounter pipeline tells every drafting agent to read **first**. It carried zero register guidance — `grep -i "register|plain|lyrical"` returned nothing — and opened on Section C, compiled from an April design-direction doc whose principle 2 literally taught the rejected authored-futures model (*"Do I push him to fight or to flee?"*), flatly contradicting Section D of the same file. Section E held 25 editorial triggers against the live SKILL's 31; the six missing were the newest, including the one that says **clarity beats compression**. `check:authoring-brief` hashed only two prose docs, so the SKILL-derived sections drifted with no signal — and the check exited 0 on every path anyway, printing a `warn:` line inside a `continue-on-error` CI step.

**What shipped.**

- **Section A: Register and Narrator Mode now leads the brief** and says in its own first line that it governs every section after it — narrator mode (state facts, never encode them; the ≤80-word opening skeleton), the three registers with baseline as the default, interactive text always plain, both register exemplars inline right and wrong, and rule zero. Section C carries the clamp restated, because the pipeline injects Section C into draft prompts on its own.
- **Section C re-sourced at the source.** Principle 2 replaced with the nudge model; principles 6 and 7 retitled off "Emotionally Resonant Stakes" and "The Roller Coaster", whose worked examples modelled the interiority and atmosphere-for-its-own-sake doctrine v2 bans; every surviving principle carries a one-line register clamp. The supersession record sits in a second paragraph per principle, which the extractor does not compile — the history stays in the plan doc, the instruction that reaches authors is current.
- **Section E is derived from the live SKILL, not copied.** `extractRejectionTriggers` pulls the numbered block at generation time, so divergence is impossible rather than merely detectable; the SKILL joins `AUTHORING_BRIEF_SOURCES`, hashed on its **trigger block alone** so an unrelated edit to that long file does not restamp the brief. All 31 triggers now reach the brief. Two live contradictions fixed on the way past: trigger 5 asked for "how it felt" (interiority) and trigger 25 told authors to encode stakes in the scene's furniture — the rule doctrine v2 explicitly reversed.
- **The gate has teeth.** `check:authoring-brief` exits 1 on drift (the "cannot judge" states still exit 0 — refusing to answer is not answering "diverged"), and the brief is registered in `EXTERNAL_GENERATED_ARTIFACTS` so staleness is **blocking** in the `Docs gates` job, which is the job a SKILL or canon edit actually runs.
- **Exemplar hygiene.** Both May encounter rows were audited and **demoted to wiring-only exemplars** with their verdicts recorded: past tense against doctrine v2's present, facts encoded rather than stated (*"She spoke at exactly the volume that carried no further than the table"*), similes in baseline narration (*"like a missing heartbeat"*). `swollen-ford-exemplar.ts` is the top row. This matters because the pipeline sends every draft agent to "study the top `Encounter` rows".
- **Calibration verdict recorded** (process rule 4): `registerCompliance` stays report-only and does **not** become blocking in `check:encounter`. It ranks rather than identifies defects; a gate was not the missing part (the preamble was); a false-positive register gate damages the prose it protects, with THR-899 as precedent in the same file; and the higher-signal candidate is `doctrineV2Checks`, which is campaign-sized at 302 corpus warnings. Written into `Docs/canon/prose.md` with a named re-open condition so it is not re-litigated per batch.

**Proven, not asserted.** The gate was falsified in both directions: adding a 32nd trigger to the SKILL fails it (exit 1, naming the SKILL); rewording a heading outside the trigger block does not (exit 0). 1077 files / 17914 green, ratchet 3010 unchanged, `vite build` 11.27s. The one red on the first run was the THR-922 coupling guard correctly refusing a new registered artifact with no declared sources — the guard doing its job on the day it was needed.

**Sequencing.** Mutex with THR-1130 held: this lands between retrofit batches, so the **next** batch is the first to draft against the fixed brief.
