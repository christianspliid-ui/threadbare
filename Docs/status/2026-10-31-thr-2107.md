# THR-2107 — Heavy simulation tests green again (premonition steer test)

**Shipped 2026-10-31.** Continuous Improvement. `heavy-tests.yml` went red on the THR-2096 merge: `premonitionSteer.integration.test.ts` › "a compelled journey whose scene is gone on arrival lapses aloud" read `compelledJourneyTemplateId` as `undefined`.

**Cause.** Not an engine regression. The file's two tests each build a seed-42 world in the same process, but `driveToTaken` never called `resetDecisionCache()`, the run-start reset for module-scope id counters. `npcSeeding.ts`'s `npcCounter` kept counting, so the second world's NPCs were `npc_~500+` instead of `npc_0+`. Faction member counts, leader snapshots and personality-trait emergence then diverged from tick 0. The second test passed alone and failed after the first. THR-2096 only moved the seed-42 trajectory enough for the offset world to stop yielding a travel steer that is `taken`.

**Fix.** `driveToTaken` calls `resetDecisionCache()` before building its world, so both tests drive the same world. The assertion is unchanged.

**Evidence.** Both tests of the file pass together (14.5 s + 12.5 s). A diagnostic run built two worlds back to back and diffed their graphs. Without the reset: 8806 differing entries at init, the first being `faction_1.memberCount` 20 vs 21 and `npc_0` missing from run B. `npm run gate`: test, typecheck, build, encounter, god-cards, ui-debt, cli-smoke all PASS.
