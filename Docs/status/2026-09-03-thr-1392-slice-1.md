# THR-1392 slice 1 — the verb × object registry and the one resolver, behind the flag

**2026-09-03 · engine.** An undertaking is now expressible as a **verb** on an **object the world already has**, instead of as one of sixty-four authored fictions. `src/data/undertaking-objects.ts` registers the seven object types once each — attachment, room, settlement, route, company, faction, mark — with a typed graph shape, the edges that say who holds one (`possesses`, `owns`, `controls`, `commanded_by`, `leads`; an edge object is held by its source), a tier read off the object (attachment tier, sublocation category, settlement subtype, route length in hexes, roster or member count, mark magnitude — each defaulting to T2 *and tracing* `undertaking_tier_defaulted` when the source is missing), the grievance lane's harm class, and what each verb variant does to that type. The semantics are the graph ops the corpus already had, re-homed under the object they act on: `razeHolding`, `transferHolding`, `grantHolding`, `createSublocation`, `createLocation`, `createTradeRoute`, `blockadeRoute`, `raiseWarband`, `reinforceWarband`, `disbandGroup`, `applyPlantSchism`, `pressTheMark`, `mintMasterwork`. Four are new and small: seizing an attachment moves its `possesses` edge; undoing one runs the removal funnel; undoing a settlement floors prosperity and sets the `ruins` subtype the battle aftermath already reads; undoing a mark reveals it.

`src/engine/undertakingResolver.ts` is the one resolver. It reads ownership in one place (`ownershipOf`), picks `control`'s variant from it — **claim** when nobody holds the object, **seize** when someone else does, refused on one's own (Christian's merge, 2026-09-03) — dispatches to the declared semantic, and emits `strategic_world_change` naming the object type and id. A verb the type does not declare refuses with `undertaking_cell_unreachable` (`no_semantic_declared`), so the gap is a measurement rather than a silent hole.

## What the pipeline gained

- **The object handle.** `{ kind: 'node', nodeId } | { kind: 'edge', edgeId }` on candidates and projects beside `targetNodeId`, which stays the *place* of the work.
- **Owners through the object.** `resolveTargetOwners` now reads `possesses` (an attachment read as unowned before, so every `undo` against one was refused by construction); the motive gate takes the handle and reads an edge object's owner from its source.
- **The `object` target rule.** `{ type: 'object', objectTypeId, ownership }` enumerates every object of the type in the world under the cell's ownership rule, nearest first (`STRATEGIC_TARGET_SCAN_CAPS.object` = 8).
- **The flag.** `UNDERTAKING_MODEL = 'templates'` in `strategic-action-constants.ts`; on `cells`, `executeInstantMutation` hands any candidate carrying an object to the resolver. With the flag on `templates` — the default, and the state this PR ships in — nothing the player sees changes: the CLI smoke at tick 30 is identical to the pre-change run (489 agents, 47 unified actions).
- **The constants.** Verbs, variants, `MOTIVE_GATED_VERBS`, `OWNERSHIP_BY_VERB`, difficulty / payoff / duration per variant and tier (payoffs pinned inside the tier bands by test), `HARM_ON_SEIZE`, `TIER_DEFAULT_SHARE_MAX`, `CELL_OVERRIDE_MAX_PER_CELL`, the per-type tier bands, and the defaults `found × room` and `found × settlement` use when no override names a type.

## What slice 1 deliberately did not declare

The grammar does not write the consequences. These verb × type cells have no shipped op behind them and are **not** declared — the resolver traces them as unreachable, and slice 2 decides each one on purpose: `improve` × attachment / room / route / faction / mark; `use` × attachment / room / settlement / route / company / faction; `control:seize` × company (suborning is not an op) and × faction; `found` × faction (needs a seed and reach weights — an override) and × mark (needs a secret type — an override); `survey` × everything ([THR-1393](https://linear.app/threadbare/issue/THR-1393) — the `intelligence` object type lands only with its reader).
