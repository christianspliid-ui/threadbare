# THR-2122 — Legibility 1: the shared blocks, the type ladder and the spacing rhythm

**Shipped 2026-11-03.** UI Visual Overhaul — Design System v1. Plan: `Docs/plans/2026-11-02-thr-2122-legibility-shared-blocks.md`.

1. **`Section.tsx` on tokens and the ladder.** A local `SectionShell` draws every section's label, body and the one between-section distance (`--space-6`). Every spacing value is a `var(--space-*)` token (30 uses, from 0); the remaining px literals are sizes (track, marker, meter, border widths), each commented. The off-scale 0.9 / 0.85 / 0.8 / 0.75rem sizes snap to `--text-sm` / `--text-xs`; the R5 headline drops to `--text-lg`. Body, portrait and event prose stop at `--measure-ui`.
2. **The facts block.** The `panel` kind is a `max-content minmax(0, 1fr)` grid: right-aligned labels flush against values, no `space-between`, no per-row gold rule. A pole row's first word sits in the label column.
3. **One section heading.** `SectionLabel` gains `count` ("Retinue · 3", 0 and 1 shown), `as`, `flush`. `SectionHeading` and the hand's "Your cards · N" delegate to it. Detail sections draw no gold heading and no tier rule (`section.gold` stays in the view model). The links-group sub-head is a Text 700 row. An unclickable `event-card` draws no frame.
4. **`--measure-ui: 26em`** in `index.css`, `MEASURE_UI_EM` in `layoutContract.ts`, parity asserted.
5. **Canon:** typography (§ The ladder, `--measure-ui`, gold label ornamental-only), layout (§ Spacing rhythm, § Frames, § Facts block, the token row), primitives (§ 1 rewritten to the label rule, § Blocks), component-selection (seven blocks; anti-pattern "a box around a section").

**Executor decisions.** `SectionLabel` keeps a default `--space-2` bottom margin and takes `flush` for callers that space it themselves, rather than moving the margin out entirely: `InspectorParts` and `FactionSheet` draw it outside `Section` and would otherwise lose their heading gap. `SectionHeading` keeps `ReactNode` children (`SectionLabel`'s `label` widened). A string label and its count render as one text run so the heading reads, and is found, as one phrase. The kill criterion did not fire: the docked person page already scrolled inside its panel before this change, and the gap growth (20 → 24 px) is the decided rhythm.
