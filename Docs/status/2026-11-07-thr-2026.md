# THR-2026 — The paid army turns at once

**Shipped 2026-11-07.** M3: Dynamic Economy. Plan: `Docs/plans/2026-11-07-thr-2026-the-paid-army-turns-at-once.md` (§ Engine pillar, § Done when).

1. **One re-aim body.** `reaimArmies`' per-army loop body moved, unchanged, into `reaimOne(state, armyId, ctxRef, getProjection, whyOverride?)` (`src/engine/warAims.ts`). The daily path calls it per army in id order; the existing daily re-aim suite passes unchanged.
2. **The paymaster predicate.** `onPaymasterSide(graph, armyId, tick)` (`src/engine/warAims/enemy.ts`) is the measure's `friendly` check in engine code: own ≠ commander, and the conquer target's holder is the commander, or is sworn to it and not its enemy.
3. **The guard.** `guardPaymasterTargets` runs every tick as the new inline phase `paymaster_guard`, right after `unrest` (a grep of the `controls` / `sworn_to` writers found none run by a faction in a later phase; `influence.ts` writes an ascendant's `controls`). For each liege-paid army (`payingLiegeOf` first) on the paymaster's side it calls `reaimOne` with `whyOverride: 'target_on_paymaster_side'` (it changes the trace only). `skipsReaim` keeps a sieging, `agenda` or campaign army.
   **Review round 1 (fixed):** the trigger also reads the war-aim context's tax holder (`taxHolderOnPaymasterSide`, only on a town with two or more `controls` edges), so a town whose tax holder is the liege counts even when its first `controls` edge is someone else's. The keep-march bypass is gone. `reaimOne`'s own `stillEnemyTarget` already drops a target when either holder is on the liege's side, so the guard re-aims once and does not churn. Round 2: no findings. Its one note: `seek_fealty` writes `sworn_to` in `faction_actions`, after this phase. That has no effect, because a new oath does not clear hostility, so a town the army was entitled to aim at stays an enemy's.
4. **Trace.** `ReaimWhy` and `WarAimReaimTrace.why` gain `'target_on_paymaster_side'`.
5. **Wiring.** Contract `crown-liege-pays-vassal-wages` extended (sentence + `guardPaymasterTargets`, `onPaymasterSide`); interface map regenerated; reference row; tick-cycle, armies-battles and turn-structure wiki pages.
