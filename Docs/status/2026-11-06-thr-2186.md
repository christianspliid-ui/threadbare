# THR-2186 — "See the work" lands on the work

**Shipped 2026-11-06.** Warm playtest · round 3, a slice decided on THR-1859 (no plan doc).

1. **The Inspector opens on the tab it is asked for.** `openSubject` / `openFromMap` (`inspector/inspectorState.ts`) take an optional `tab`. A new history entry carries it as `InspectorEntry.tab`. Re-asking the subject already shown for a tab updates the entry's tab and bumps `tabSeq`, so the page jumps to it even after the player clicked to another tab. With no tab, the shown page keeps its tab, as before. Back/forward restore each entry's tab, and `nameEntry` keeps it.
2. **The page starts on it.** `InspectorHost` passes `entry.tab` / `entry.tabSeq` to `InspectorPage`, whose `Body` starts on `startTabOf(tabs, initialTab)`: the asked tab when it is drawn at this size, else the first tab (an unknown id never throws). `Body` is keyed on size, tab and sequence.
3. **The openers pass it through.** GameView's `openInspector(subject, size, fromMap, tab)`. `openAgentSheetForId` and `handleViewProfile` (`hooks/useAgentInteraction.ts`) forward their tab. Before, both dropped it on the Inspector path, so every "opens on Journey" link landed on Overview. "See the work →" on a work moment now opens Journey, where "The work" is the first row.
4. **Words.** `ui.thread_work` and `ui.thread_want_most` no longer say "Opens their sheet on the Journey tab". The rows sit on the sheet and open nothing, so they now end "The Journey tab tells it in full." `ui.moment_see_work` keeps its promise.

**Tests:** `inspector/__tests__/inspectorTab.thr2186.test.tsx` (12): the entry's tab, re-ask and sequence, back/forward, the map path, `startTabOf`, and InspectorHost renders. Journey opens with "The work" first. Chronicle opens on Chronicle. No tab opens on the first tab. An unknown tab opens on the first tab with no console error. Re-asking after a click jumps back. It also checks the two tooltip strings and that both openers forward the tab.

**Evidence (1920×1080, bash-vite :5287):** `Docs/evidence/thr-2186/see-the-work-journey-1920.png`. A "A Work Begun" moment (Consecrate a pilgrim way, Kael Thornweaver) was raised with `forceMoments(true)`, and "See the work →" was clicked. `getInspectorState()` returns `agent:ind_dev_the_first`, wide. The selected tab is "Journey", the first row label is "The work", there is no horizontal scroll, and the console shows 0 errors.
