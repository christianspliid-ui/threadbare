# THR-2233 — no journey vision is lost

**Shipped 2026-11-15.** Encounter Experience · decided by the design lane on THR-2232.

- **Journey beats catch up.** `shouldBeatFire` (`src/engine/journeyEngine.ts`) now fires the current phase's next unplayed beat whenever the Doom has *reached* its threshold, not only on the tick it was crossed. A Road of Trials crossing that landed while a vision was still waiting used to be lost for good (3 of 6 measured runs lost one); it now fires on the first free tick. One beat per tick, in order; the phase's `beatHistory` count stays the index, so nothing fires twice; a beat whose phase has ended is not caught up.
- **No backlog for a late First.** The review gate caught that a replacement First threaded mid-Trials would be handed every Trials beat that passed before the bond. The thread edge now keeps `journeyStartDoom` (the Doom at that First's first vision); in that phase the entry vision plays as #0 and the index skips thresholds at or before it (`beatsBeforeJourney`). Saves from before this change have no floor and catch up their current phase's missed beats once.
- **No Return without the Ordeal.** Round 2 of the review gate found the old force-fire (Doom ≥ 0.90, only when storyPhase was already 'return') could never run, so a First that reached the Return phase with no Ordeal went straight to the Return. Now any Return-phase tick with no Ordeal recorded fires the Ordeal first, before the phase-entry branch; the thread records storyPhase 'ordeal' (the fired beat's phase), so the Return follows as the next phase entry. `ORDEAL_FORCE_FIRE_THRESHOLD` is deprecated, no longer read.
- **Traced.** A First's first vision emits `journey.start_floor` (the Doom it began at, and how many of that phase's visions passed before the bond).
- **Evidence.** New tests in `journeyEngine.test.ts` (pending-vision crossing, two-threshold jump, ended-phase handover, reached-not-crossed) fail on the old code and pass now. `npm run gate`: PASS (test, typecheck, build, CLI smoke).
- **Not done here:** the six-run probe re-measure (about 20 min per run, over the lane's command cap) → THR-2239.
