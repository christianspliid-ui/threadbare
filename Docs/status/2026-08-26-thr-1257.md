# THR-1257 — The fourth way to be hurt, and the word for it

**2026-08-26 · Effect Vocabulary Activation · Engine + Content pillars**

THR-1244 taught the engine that being wounded is an event: a harmful *condition* inflicted raises
`damaged`, one lifted early raises `healed`. It wired the three aftermath writers and named the
gap it left. This closes both halves together, because either alone is worse than neither.

**The site.** `actionTriggerPayloads.ts` writes the *same* `has_trait` edge through
`condition_grant` / `condition_remove`, and it is live — an item that cursed its bearer raised
nothing while the stage read as complete. `applyActionTriggerPayloads` now takes `GameState`
(`raiseEffectEvent` needs the state, not the graph), and the orchestrator's call threads its
`runningEffectStates` map and reads the merged one back, because that call sits **inside** the
loop whose end-of-tick assignment would otherwise discard the raise.

**The word.** `isHarmfulCondition` reads `#negative`, which every entry in
`CONDITION_TRAIT_DEFINITIONS` carries and no entry in the catalogs this path grants from did — a
vault curse classified as *not harm*. 47 conditions across four catalogs were normalised onto
`#negative` / `#positive`, so one predicate covers all five (THR-1242 precedent).

**Scope ran wider than the ticket named, and had to.** `condition_remove` matches on **tags**, so
the single authored `tags: ['#wound']` removal reaches every `#wound` condition in the repo —
including `reward-attachment-catalog.ts`'s 35, which the ticket did not list. Normalising only
the catalogs the *grants* name would have shipped a healing half blind to most of what it lifts:
the same live-but-silently-wrong shape, one layer down.

**Falsified, not merely passing.** Dropping one polarity tag turns 7 tests red. Reverting the
orchestrator call to its pre-fix shape leaves the `damaged` trace firing while the downstream
stacking write reads `0` instead of `1` — a raise that looks healthy and has lost its effect,
exactly the bug this was deferred over. `conditionProxyOrchestrator.test.ts` drives real
`runTick`, since the discard happens in the caller where no module test can see it.

**Re-entrancy, asked and answered.** `checkAndFireActionTriggers` has three phase-level callers
and no effect-execution caller, so a raise cannot re-enter the trigger path; no depth guard, and
the header records where that was checked. The polarity guard now pins all 60 condition nodes
across all five catalogs, enumerated by import — a scan would pass silently on a new file.
