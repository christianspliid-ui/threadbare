# 2026-09-25 — THR-1602: internal ids stop reaching the chronicle

**Ticket:** [THR-1602](https://linear.app/threadbare/issue/THR-1602) · **Project:** Onboarding & First-Run Experience (cold playtest round 1) · **Pillars:** Engine + Content; UI N/A (no component changed — the chronicle card renders the same fields, now filled with prose).

## What was wrong

All three cold-playtest testers quoted raw ids from the chronicle: rival schemes launched "against `elder_ruin_1`" and "`loc_36`", scheme chapters were titled `RIVAL-SCHEME-ACTOR_RIVAL_2-CORRUPTIVE-T27 — MATERIALIZE`, a dissolution read `Rule: death_or_transformation` (and was announced every tick after), and rivals set "a economic scheme" in motion. Word-pool prose had the same article fault ("a ancient recognition").

## What changed

- **Names, not ids.** Scheme targeting, the crack beat and contestable sources read `node.name` — where every seeder puts a location's name — before the empty `properties.name`.
- **Scheme chapters get titles.** `Phase` gains an optional `title`; rival scheme phases set "The Hollow Warden's corruptive scheme: materialize". The runner's fallback for any untitled phase is now the humanized phase id, never the composition id (this also removes the id from THR-1585's notable-agenda headline).
- **Dissolution reads as prose** (`ZERO_STATE_RULE_PROSE`) and fires once per node.
- **a / an.** New `src/lib/indefiniteArticle.ts`; applied to the scheme launch toast and the word-pool substitution sites in `narrative.ts` and the dilemma resolver.

## Evidence

Seed 42, medium, 120 ticks, 7,684 event and chronicle texts. Before → after: location/hex ids 25 → 0, scheme ids 16 → 0, `Rule:` keys 0 → 0 (no dissolution in that window; unit-tested instead), "a + vowel" 17 → 0.
