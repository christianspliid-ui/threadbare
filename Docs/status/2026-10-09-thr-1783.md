# 2026-10-09 — THR-1783: God's Will names the pool it bills; the attention control looks like a switch

**Ticket:** [THR-1783](https://linear.app/threadbare/issue/THR-1783) · **Found by:** warm playtest round 1, 3/3 testers on each fault

- **Prices name their sphere.** The whisper and compulsion options read "1 Force essence" / "1 Life essence" instead of a bare "1 essence" with colour as the only cue. `premonitionCostLabel` (`src/components/Game/PremonitionModal.tsx`) uses the shared `sphereWord`, so the word matches the essence bars (the THR-1706 class, missed site).
- **The spend goes through state.** `applyWhisperChoice` / `applyCompulsionChoice` (`src/engine/premonitionActions.ts`) no longer subtract from `state.essencePool` in place. GameView applies the new pure `spendPremonitionEssence` inside its `setGameState` update and records the movement from `prev` → next, which retires the THR-1713 snapshot-and-diff workaround.
- **"Asks you / Lives on" is a switch.** `AutoToggle` (`src/components/Game/ThreadsPanel.tsx`) is now a bordered pill with a sliding knob, exposes `role="switch"` + `aria-checked` (checked = Asks you), and its tooltip ends "Click to switch to …" from a new registry entry `ui.attention.switch_hint`. That copy is kept separate from the mode copy because the warm-start overlay reuses `ui.attention.lives_on` and is not clickable.

**Evidence.** `thr1783WarmRoundFaults.test.tsx` (9 tests): a Force option renders "3 Force essence", a Life whisper renders "2 Life essence", neither apply function mutates the pool, the spend helper bills only the named sphere and fails soft, and the switch exposes `role="switch"` with `aria-checked` flipping on click. Browser capture at 1920×1080 on `?view=game&seeded&size=medium` (worktree Vite + Playwright): the prices read Matter / Force / Life, paying the Force option recorded `force.byCause.premonition = -1` in `__DEBUG.getEssenceMovement()`, and the switch tooltip reads "Click to switch to Lives on." Captures are in `Docs/evidence/thr-1783/`.
