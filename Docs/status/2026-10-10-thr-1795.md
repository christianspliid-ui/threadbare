# 2026-10-10 — THR-1795: the review gate judges the push it is actually given

**Ticket:** [THR-1795](https://linear.app/threadbare/issue/THR-1795) · **Found by:** weekly retro 2026-10-09 (impediments #1143, #1146, #1156).

- **#1143: a failed `gh` lookup no longer means "unarmed".** `viewPr` in `scripts/review-gate.ts` now tells gh's own *no pull requests found* answer apart from a failed lookup (timeout, auth, network, detached HEAD), using the pure `ghLookupError`. Before, any gh failure returned null, which `evaluatePush` read as "no armed PR — not judged". That allowed the push silently, with nothing logged. Replaying the shape against the old script confirmed it: a failed lookup allowed. Now a failed lookup is judged as if the PR were armed. A head with a clean receipt, or a docs-only diff, still goes through. An unreviewed head is denied and the reason names the gh error. The refspec parse (`HEAD:<branch>` from a detached HEAD) was already correct. A new hook-level test pins the exact #1143 shape, and the push is denied.
- **#1146: `cd <dir> && … git push` is judged in `<dir>`.** The new `commandsWithDir` carries a `cd` / `pushd` / `Set-Location` earlier on the line into later commands. `findPush` starts from that directory and then applies `-C`. A relative path joins and an absolute one replaces. `evaluateMerge` honours a leading `cd` too (`mergeDir`). Against the old script, the new hook test named the session tree's SHA. Now it names the pushed commit. `resolveCommandDir` expands `~`. A target it cannot resolve (`$VAR`, `$(…)`, a tree created earlier on the line) falls back to the hook's cwd, never to a phantom path. A phantom path would throw into the fail-soft ALLOW, which review round 1 caught. Denying instead would have blocked ordinary first pushes, which round 2 caught.
- **#1156: receipts carry across `public/*-reference.html` edits.** `isCarrySafeDelta` lets a receipt carry across a delta of top-level reference pages plus docs. Only the carry rule widened. The CI docs-only predicate and the gate's own docs-only allow are unchanged. Any `src/` change still denies, and so does any other `public/` file.
- **Skill.** `.claude/skills/review-gate/SKILL.md` records the reference-page decision, the failed-lookup rule and the `cd` recognition (`last_validated_against: 2026-10-10`).
- **Proof.** There are 9 new tests: 4 pure and 5 against the real hook in a fixture repo. All 39 tests in `scripts/__tests__/review-gate.test.ts` pass, and `npm run gate` (test, typecheck, build, encounter) passes.
