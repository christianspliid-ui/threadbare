# THR-1329 — the kind was never refused, because it was never offered

**Shipped 2026-08-29.** Engine pillar. Content and UI N/A per the ticket — engine
acceptance via CLI + census, no browser evidence owed. Deferral filed at THR-1320's
closeout.

## Both of the ticket's hypotheses were wrong, and so was its fallback

THR-1329 asked why seed 99 mints zero trade routes in 150 ticks and named two candidate
causes: `strategic_establish_trade_route` never completes, or it completes and
`createTradeRoute` refuses. It also offered a third, passing outcome — that seed 99
legitimately supports no routes, in which case the job is to document it and name a
replacement measurement seed.

Counted rather than inferred, on a 150-tick seed-99 run:

| stage | seed 42 | seed 99 |
| ----- | ------- | ------- |
| boards carrying `ambition_dominate_trade` | 53 | **0** |
| `strategic_establish_trade_route` started | 5 | **0** |
| `create_trade_route` attempted | 2 | **0** |
| `create_trade_route` refused | 0 | 0 |
| `trades_with` standing / identity nodes | 2 / 2 | 0 / 0 |

The verb never completes because it is never *started*; it is never started because it is
never a candidate. `createTradeRoute` is never called on either seed's failure path, so
its refusal arms — `location_not_found`, `route_already_exists`,
`no_durable_source_location` — are all innocent. The route pipeline is healthy: seed 42
runs the identical code and founds routes.

The fallback was wrong too. Seed 99 is not a route-less world: **195 of 722 actors clear
the trade ambition's gates, and three actively pursue it.**

## What actually gates it

`phaseAgentDecision` runs the autonomous decision loop over **spotlight-tier individuals
only**. Seed 99's three trade-ambition holders are two `notable` and one `ambient` — zero
spotlight. Seed 42 differs by exactly one actor: `ind_0` "Oswen", its lone spotlight
holder, produced all 53 boards, all 5 undertakings and both routes.

Per-tick attribution, which is what makes it airtight:

| holder-ticks (an actor actively pursuing the trade ambition, per tick) | seed 42 | seed 99 |
| -- | -- | -- |
| emitted **no** strategic board at all | 249 | **300** |
| board listed the ambition | 53 | 0 |
| board **omitted** it | 0 | 0 |

The board never omits the ambition when it runs. On seed 99 it simply never runs for these
actors. Absence with no refusal is invisible by construction — nothing is traced, because
a refusal requires the template to have been *considered*.

**A 12-seed sweep found exactly one route-capable seed: 42.** So the answer to "name the
replacement seed" is that among the standard candidates there isn't one, and seed 42 is
the outlier the route economy has been validated on rather than the norm.

## The instrument, which is the actual fix

The ticket's own framing — *"the defect, if there is one, is that nothing says so"* — is
what shipped. `npm run census:reachability` answers, per seed and per ambition, whether
anybody in this world can take a strategic family at all, and reports the tier split when
the answer is no, so *"nobody qualified"* stays distinguishable from *"the ones who
qualify have no agency path"*:

```
─── seed 99 · 40 ticks · medium ───────────────────
autonomous (spotlight) actors: 17

  UNREACHABLE  ambition_dominate_trade  merchant-expansion  holders 0 autonomous / 1 silenced
  OK           ambition_conquer_territory warlord-expansion holders 3 autonomous / 8 silenced
  ...
  SILENCED — wanted here, but only by actors with no agency path:
    merchant-expansion
  10 strategic templates unreachable this seed
```

It found more than the ticket asked for: the whole `merchant-expansion` family is
unreachable on seed 99, not just the route verb, and `ambition_forge_legend` is
unreachable on **both** seeds because nothing pursues it at all — a different failure
that the tier reading does not explain.

`isAutonomousDecisionActor` is shared with `phaseAgentDecision` rather than copied, so the
instrument measures the population the loop actually runs. An instrument that
re-implements what it measures drifts silently and then reports reachability for a loop
that no longer exists.

**Nothing was widened.** The ticket is emphatic that a world whose merchants have no
viable partners is legitimate, and this reports rather than remedies. The design fork —
should ambitions bias toward spotlight actors, should notable actors carry undertakings at
reduced cadence, or is reporting the whole fix — is filed as THR-1348 with the three
readings costed, because they are genuinely different games and not an executor's call.

## The census passes every gate on a world where a shipped kind cannot exist

Done-when 4 asked whether this shares a cause with seed 99's `undertaking share` census
FAIL (9.7% against a `[0.1, 0.35]` floor). It does not — and the way it does not is the
sharpest confirmation of the ticket's thesis. That gate **no longer fails**: it now reads
**13.7% PASS**, resolved independently between filing and pickup. Every gate on both seeds
now passes, checkpoint liveness reads 100%, and seed 99 still mints zero routes. A kind can
be perfectly live and perfectly absent at once, and until now no instrument said so.

## A capped trace array cannot answer an absence question

The obvious instrument was `strategic_candidate_board.refusals`, which reported 0 route
refusals on seed 99 against 45 on seed 42 — a clean-looking differential, and not evidence.
That array is `.slice(0, 8)`, and seed 99's boards refuse far more than eight templates
each, so a zero means *either* "never considered" *or* "refused every time but never in the
first eight" — opposite stages of the pipeline. The finding only became sound on the
board's uncapped `ambitionIds`. Logged as impediment #937 with the durable rule: a capped
trace field is a sample, and a sample can support existence claims but never absence ones.

The reachability module's own version of that trap was caught by falsifying the guard —
reverting the reachable-set subtraction turns exactly one test red, and without it the
report had claimed `strategic_craft_masterwork` unreachable on a seed where a sibling
ambition offered it to five autonomous holders.
