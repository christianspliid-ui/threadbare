# THR-1292 slice 4/6 — the initiative retirement

**2026-08-27 · Engine + Content + UI · [THR-1292](https://linear.app/threadbare/issue/THR-1292)**

The agent-initiative pipeline is gone. It was a second multi-tick project system running
beside the strategic one — its own scorer, its own progress phase, its own outcome
executor, its own trace family, and a third competitor in the agent decision loop. Slice 3
gave undertakings dice; this slice makes them the *only* way an agent runs a long piece of
work.

## What the player will notice

Agents still found orders, throw festivals, plant spy networks, recruit companions,
consecrate ground, post commissions and take apprentices. All seven were `initiative.*`
templates; all seven are undertakings now, so they roll checkpoints, can go wrong, can halt,
and can force their owner to choose between abandoning and doubling down. The agent panel's
"Active Initiative" card is an **Undertaking** card, and it reads as words rather than a
percentage — *Halfway*, *Nearly done*, *Not going to plan* — per the UI Law.

## Three defects that died with the pipeline

Each was invisible while the system was dead behind its wealth floor:

- **Mentorship's terminal arc inferred completion from absence.** It resolved a *vanished*
  initiative record as a completion, so a record cleared for any reason — including a
  fail-soft catch — graduated an apprentice. The fold takes the verdict as an argument.
- **A latent deadlock.** `markInitiativeFailed` set a status that only the *other* phase
  cleaned up, and only on its own failures — so a mentorship-side failure pinned a
  permanently non-active initiative to the agent, blocking every future one.
- **The eligibility check had drifted into two copies.** Only one of them excluded
  non-`individual` actors, so the scorer could propose a mentorship the runtime then refused
  to bootstrap. There is one copy now, and candidate generation refuses at proposal time.

A fourth is worth recording because a *test* found it rather than a reading: the retired
phase emitted `type: 'world_change'` for the festival-ending event, which has never been a
member of `TickEvent['type']`. It type-errored into the red baseline and the chronicle
filtered it out, so the event never reached a player.
