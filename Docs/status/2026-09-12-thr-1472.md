# THR-1472 — a chip's noun is a character-sheet word

**Shipped 2026-09-12.** Director ruling from the first sitting on the THR-1220 slice, reviewing the Snow on the Pass aftermath: `SCAR · EXHAUSTED` works because it is *"generic & self-sufficient in its explanatory power and so works in different contexts"*; `SCAR · THE NERVE THEY CAME DOWN WITH` does not, *"since you would have to keep this encounter in your memory"* to read it. A tag the player cannot read cold is not a state — it is a souvenir, and the character sheet is where it ends up.

## What changed

**Doctrine.** The rule and its **cover-the-title test** — cover the encounter title and the overview, and the tag alone must still say what the mortal now has — are in `nudge-authoring-spec.md` § Consequence Draw rule 2, with a REVISE trigger (#32) in the encounter-pipeline SKILL list and a rewritten editorial gate question 11. The spec's own example changed too: it used to be `SCAR · TWISTED ANKLE`, which is itself bespoke.

**Gate.** `chipStateNounWordingViolations` (`compositionContract.ts`) mechanises the test in two signals: a noun over `CHIP_STATE_NOUN_MAX_WORDS` (3), or an anchor that is a cast placeholder (`$actor` / `$target` / `$cast:*`) rather than the state object the band wrote. It is scoped to *categorised* chips — an uncategorised change draws no tag — and exempts `reputation with {target}`, whose referent genuinely is the other party. Reported through `check:encounter`'s `[warn]` channel, which never gates: the slice is migrated and the retrofit corpus is not, so an error tier would turn a green corpus red for work ticketed elsewhere.

This is a different failure from the anchor gate it sits beside. Law 56 clause 2 asks whether the referent *resolves*, and `$actor` resolves perfectly — both of the director's examples passed it. The defect was never resolvability.

**Content.** All 28 slice chips re-authored; every tag now reads as a sheet entry. The two nerve scars were the interesting case: backed by a bare `quintessence_shift`, they claimed a state the engine had no word for, so the fix was the word — `trait.condition.shaken`, granted by the bands that name it (`star −0.08`, `heart −0.05`; deliberately not `iron`, which is what separates it from `exhausted`). Christian's candidates were Unsure / Diffident / Stressed; `Shaken` names the event's residue rather than a temperament, which is what a duration-bearing condition models. Three other families followed the same principle — agreements became the generic `AGREEMENT` (his second ruling that sitting), intelligence writes became `KNOWLEDGE`, and item chips name the item and anchor `$artifact` instead of the hands holding it. Two new concepts, `ui.knowledge` and `ui.hidden_mark`, carry the specifics one hover away.
