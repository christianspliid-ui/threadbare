# THR-1316 — WorldRef, the three violation classes, and one badge defined by pointer

**Shipped 2026-08-30.** Seats THR-1212's vocabulary in the Ubiquitous Language and extends the
interface map's badge set by exactly one, per absorbed ruling 3 of
`Docs/plans/2026-08-27-shared-anchor-machinery.md`.

## What landed

**Five UL terms.** `WorldRef` (Graph shard) — the normalised reference to a world object, 13
kinds, the membership spine the generated anchor catalog projects seven consumer vocabularies
against, and deliberately *not* called "anchor" because `EntityNotice` owns that word.
`claim-without-anchor`, `write-without-consumer`, `render-private-pipeline` (Process shard) —
the three violation classes, which until now existed only in code and plan docs.

**The fifth term is `Consequence Chip`, and it was not in the ticket.** The ticket named four
terms but its Done-when said five, and the See-Also web resolved the discrepancy: SCAR, BOND,
BOON and PATH are each described in the UL as "a consequence category", while the head noun
they are categories *of* — the thing UI Law 56 actually governs — had no entry at all. Every
`claim-without-anchor` See-Also would have pointed at a term that did not exist. Same shape as
THR-1314's `undertaking` addition, and recorded here so it reads as a closed gap rather than
scope drift.

**`claim-without-anchor` records the in-tree alias rather than competing with it.**
"Law 56-hollow" was already at `src/types/unifiedAction.ts` before the entry existed, so the
UL entry adopts it as an alias. Minting a rival term would have left code and glossary naming
one defect two ways — the drift the UL exists to end.

**One new badge: 🟣 HOLLOW.** Added to `ContractBadge`, rendered by the generator, and
**defined by pointer** — the canon page links the UL entry and does not restate it. The other
two classes correctly get no badge: `write-without-consumer` *is* 🔴 LEAKED under a general
name, and `render-private-pipeline` is only partially covered, which the UL entry states
rather than the map pretending otherwise.

**HOLLOW is pin-only, and the zero is deliberate.** Symbol matching cannot see the absence of
a referent it was never told to look for, so no mechanical path assigns it; it arrives only
via `badgeOverride`. The generated badge summary now renders `🟣 HOLLOW | 0`, which makes the
emptiness a visible measured fact instead of vocabulary nobody wired. The class's real
population lives at template granularity under `check:chip-anchors` (443 chips in
`chip-referent-baseline.json`), drained by the encounter-factory retrofit line.

New `TICKETED_BADGES` generalises the CI ratchet from LEAKED-only to LEAKED+HOLLOW, so the
first row ever pinned hollow must carry a remediation ticket or the generator exits non-zero.
