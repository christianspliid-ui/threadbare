# 2026-09-29 — THR-1669: a mortal with a promise stops turning back from every encounter journey

**Ticket:** [THR-1669](https://linear.app/threadbare/issue/THR-1669) · **Project:** Thematic Pressure & Living World · **Plan:** `Docs/plans/2026-09-27-thr-1633-written-encounters-land.md` § S2 (deferral from THR-1668), against the THR-1479 appointment regime · **Pillars:** Engine (one rule for the `departing` regime in both decision paths); Content: N/A (no template or prose change); UI: N/A (no surface change — headless evidence per THR-688 rule C).

## What was wrong

The two halves of the THR-1479 `departing` regime disagreed. In the full decision, a departing mortal's promise journey *competes* with the board, and if the board outvotes it the mortal walks to the encounter — "traced, never forced". In the moving-agent path, any journey not headed for the promise was re-routed to it unconditionally on the next tick. So the board's verdict held for exactly one tick: THR-1668's interim measurement caught one mortal on seed 99 setting out for an anomaly 41 times and never arriving with it.

## The rule chosen

**The board's outvote stands for the length of the journey.** A departing mortal's board has already dropped every candidate whose travel + work + onward walk would overrun the slack, so an encounter it picks while departing is, by construction, one the mortal can do and still make the meeting. Turning that journey back re-litigated a decision the regime had already priced.

- `MovementState.appointmentOutvoteSeedId` — set on an encounter journey the full decision queues while the regime is `departing`, naming the promise's seed.
- The moving-agent re-route leaves a journey alone when it still names an encounter target *and* carries this promise's seed id. A journey begun before the regime turned, or rewritten since by the reroute guard (which builds a fresh state), carries no mark and is still turned back — THR-1479's re-route is kept for exactly the case it was built for.
