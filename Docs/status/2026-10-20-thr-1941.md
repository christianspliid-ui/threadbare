# THR-1941 — Nine encounters earn their family tags

**Shipped 2026-10-20.** The first encounter coverage run (THR-1850) scored nine worn family tags below the 0.40 tag-fit cut. Each got one disposition. No tag was removed: every errand tag is applied by id prefix (`ENCOUNTER_FAMILY_TAGS` in `src/engine/encounterSeeding.ts`), and `encounterSeedLiveness.test.ts` fails if an alias row loses a member a shipped seed could draw. The gate caught exactly that when the first try removed `#delve` from the Unfinished Rite.
