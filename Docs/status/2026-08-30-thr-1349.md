# THR-1349 — silence is not revulsion (second pass; cutover still not flipped)

**Date:** 2026-08-30 · **Issue:** [THR-1349](https://linear.app/threadbare/issue/THR-1349/the-decision-board-has-no-variety-term-a-live-board-writes-zero-trade) · **Status:** partial ship, `In Dev`

## The fork this pass was sent to settle

THR-1301's promotion routed one open choice here: *should an undertaking whose authored `motivations` mismatch its proposer's axiological profile be effectively unselectable?* Christian's 2026-08-30T04:56Z ruling put the answer with the agent (`process.md` § User review interface, rule 4). The verdict, with its reasoning, is recorded on the issue and summarised here.

## Verdict — three parts

**1. No desire floor for undertakings.** The framing assumed the board treats the two families asymmetrically. It does not. `computeBoardDesireMultiplier` is the encounter pipeline verbatim, through the same `MINIMUM_DESIRE = 0.05` and `PERSONALITY_SCORE_EXPONENT = 1.5` — `0.05 ** 1.5 = 0.0112`, the exact value the prior pass measured. Flooring undertaking desire would flatten personality out of undertaking choice, which is the opposite of what `PERSONALITY_SELECTION_WEIGHT` exists for and contrary to the ruling's own direction that life comes from threading rather than from loosening gates.

**2. Silence is neutrality, not revulsion — shipped.** `computeDesireScore` sums signed profile values, so an *unauthored* motivation set scores exactly `0` and is indistinguishable downstream from an actor who actively wants none of what the option offers. Both fell to `0.0112`, ~250× below a matched candidate's `2.775`.

That is inert where the pipeline was calibrated and ruinous where the cutover moved it:

| corpus | motivation sets |
| -- | -- |
| encounters | `ENCOUNTER_TYPE_MOTIVATIONS`, a central table, **10 rows, uniformly arity-2** — never silent |
| undertakings | hand-authored per template — **35 of 64 name nothing at all** |

So the floor could never fire for an encounter and fired on 55% of the undertaking corpus. Contest B never read desire, which is why only the cutover exposed it. `UNDERTAKING_NEUTRAL_DESIRE = 1.0` now supplies the axiological term for an unauthored set; floor, ambition boost and exponent are untouched and still shared. It deliberately does **not** loosen the mismatch case — an authored-but-opposed set still floors, pinned by a test.

**3. The trade-route content fix is falsified, not deferred.** The obvious remedy — repoint `strategic_establish_trade_route` (arity 3, two axes outside its own `reachProfile`) at the canonical `ENCOUNTER_TYPE_MOTIVATIONS.trade` pair — was measured before being written and does not work: seed 42 has **one** trade-ambition holder, net-negative on the authored set (`-1.68`) *and* on the canonical one (`-0.16`); 0/1 clears the floor either way. This matches THR-1329's independent finding that seed 42 is the only route-capable seed in twelve and its routes come from a single actor.

## Why the flip still did not land

The flip was implemented, measured, and reverted. All three §4 criteria pass on both seeds under a live board — and two of the three tests the ticket names as its acceptance signal go red:

| | seed 42 | seed 99 |
| -- | -- | -- |
| §4 criteria | all PASS | all PASS |
| undertaking starts, shadow → live → live+fix | 892 → 494 → **586** | 891 → 352 → **425** |
| distinct templates, same arms | 54 → 38 → **46** | 48 → 34 → **39** |

`edgeIntegrity` ("writes trade routes…") and `lairClearing` ("reinfests cleared lairs…") are **vacuity guards on organically produced world content**, and a live board produces measurably less of it. The ticket is explicit that those three are the acceptance signal and never collateral to adjust, so the flip does not ship.

The neutral-desire fix recovers a large part of the gap but not all of it, and the residue is a **third** distinct question, diagnosed rather than guessed: instrumented over 80 ticks, every idle verdict under a live board came from an **empty** board (48/48), none from a sub-floor one, and only 65 of 1307 encounter entries scored below `BOARD_SCORE_FLOOR`. So the floor is not the mechanism. The remaining suspect is a feedback effect — agents committed to multi-tick undertakings stop generating candidates and read as idle while actually being busy — which is a measurement-and-balance question with its own envelope, not a constant to nudge here.
