# THR-1199 — `{fear}` renders as a bare noun, not the whole fear phrase

**Shipped 2026-08-23.** Second defect found in the `FEAR_PROSE` table this week, after THR-1187's pole inversion, and found the same way: by reading the composed sentence rather than the placeholder.

## What was wrong

`fearResolver` built `{fear}` from the full `FEAR_DESCRIPTIONS` string with only the leading `Fears ` stripped, so the placeholder received a noun *phrase* — `being outwitted`, `the loss of the old ways`. Every one of the 107 bodies that carry `{fear}` puts it in bare-singular-noun position: preceded by `The` / `the` / `a` / an adjective, followed by `is` / `of` / `that` / `beneath`. Measured across the table, with no exceptions.

So the two were incompatible on all 18 keys, and the player read lines like:

```
the being outwitted of being outwitted
the the loss of the old ways of loss     <- doubled article and stranded preposition, one clause
The having to deceive is of the person who has already worked out how to use it.
```

## What shipped

The resolver substitutes the bare noun (`FEAR_NOUN = 'fear'`) and no longer reads `FEAR_DESCRIPTIONS` at all. That is the ticket's option 1, and the cost it flagged — "a content surface silently goes dark" — turned out not to apply: `FEAR_DESCRIPTIONS` has two other consumers (`strands.ts` renders it whole in the Fears strand insight, the CMS registry browses it), so the table stays load-bearing. The bodies also name their own fear inline (`the {fear} of being outwitted`), so no content is lost from the line. Option 2 would have been ~108 per-body prose edits to reach the same place.

All 108 bodies now render clean, verified by rendering each one.

## The pin

The defect shipped past two green checks — one asserting each key *has* a template containing `{fear}`, one asserting the rendered text no longer *contains* the literal `{fear}`. A grammatically wrong substitution satisfies both. So the new assertions read the composed sentence:

- **Grammar shapes over all 18 keys × every body**, driven through the real resolver: no surviving placeholder, no doubled article, no doubled preposition, no stranded `of`.
- **A coverage guard** asserting the seed sweep reaches all 18 keys and every body within each — without it the suite would pass on an empty or partial population.
- **A bare-noun contract assertion** recovering what the resolver actually substituted and pinning it to a single space-free token.
- **A per-key golden render** — the reviewed composed line for each of the 18 keys, checked in.

Falsified before shipping: reverting the resolver turns 22 tests red. Worth recording that only **2** of the 18 grammar tests caught it — the doubled-article shape only fires where a description happens to begin with `the`. All 18 golden renders caught it. The ticket's suggestion that a golden sample was "worth considering" was the load-bearing half.

## Found in passing

**THR-1200** — the identical defect one placeholder over. `VALUE_LABELS` holds adjectives (`Honest`, `Courageous`, `Prudent`) and 97 of the 108 bodies put `{value}` in a noun slot: *"that Courageous is maintained"*, *"their Prudent is partly about"*. One body writes the noun literally alongside the placeholder in the same sentence, which is what settles it. Filed with its coordination block, not fixed here — it needs a new `VALUE_NOUNS` table or ~97 body rewrites, and that is a register call, not a mechanical one.
