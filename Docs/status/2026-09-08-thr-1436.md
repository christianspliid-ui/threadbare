# THR-1436 — the registry reads the edges the world writes

**2026-09-08 · Engine (the object registry, the motive gate, one route writer) · project Thematic Pressure & Living World**

Six of the fifteen undertaking object types read ownership through an edge the world never writes, or ignored the one it does, so the cells acting on them refused `no_owned_object` / `no_object_exists` on every seed. No new writer, edge or node: the registry now reads what the writers make.

## The six reads

- **Faction** — the holder is the leader the succession seam already derives (`getFactionLeaderId`: the `leads` edge, else the top `member_of.rank`) through a new optional `ownersOf` reader consulted before any edge walk; `ownedVia` is empty (nobody writes `commanded_by` for a faction). Leaderless reads *unowned* — the precondition `claim × Faction` waits for. A type declares `ownersOf` or a non-empty `ownedVia`, never both (pinned).
- **Companion** — held through `accompanies`, the edge the companion mint writes bearer → companion. `destroy × Companion` is now aimed at *another's* companion; dismissing one's own stays the story's.
- **Condition** — the object is one mortal's *bearing* of a condition, the `has_trait` edge to a condition-class definition, never the shared definition (THR-1395 made those one per kind). The cure removes that bearer's edge only; before this, `cure_condition` removed every bearer's edge — a whole-world cure under a comment that still said "one node per bearer". A borne edge is placed at its bearer, not at the definition. **The cure is signed like the blessing:** a new per-verb `gateExemption` hook lets the type waive the motive gate when the bearer is an ally (THR-1429's own `isAlly`); the board records `gate_exempt:ally` beside the refusals. A stranger's cure, or an enemy's seal, keeps the verb's gate. `CONDITION_CURE_UNGATED_FOR_ALLIES` restores the default. *Decided here, veto invited.*
- **Standing** — a shape may declare several `edgeTypes`; the enumerator walks them in order and keeps one handle per ordered pair, the first type winning: the `reputation_with` score when one exists, the seeded `relates_to` otherwise (56 · 59 pairs at tick 0 where the registry saw 0). Tier from the score's distance from neutral, else the sentiment's magnitude through `UNDERTAKING_STANDING_TIER_SENTIMENT_BANDS`. `hostile_to` stays what the quarrel writes.
- **Item** — `CATALOG_TEMPLATE_IDS` (derived from the reward and anomaly catalogs, never hand-listed) excludes the seeded templates by id — never by prefix or stamp, both of which an instance shares. Item objects: 8 · 9 instead of ~130.
- **Route** — `mintRouteIdentity` in `tradeRouteOps.ts` is the one writer of the route identity node, extracted verbatim from the lifecycle's arm; `create × Route` calls it after a successful `createTradeRoute` and reports the **node** as the object. Route objects existed at no tick before; now every route cell enumerates what a create makes.

## Found on the way

- `complicationEffects.ts` wrote a `relates_to` edge with no `id` — an edge nothing could address again (`getEdge` never finds it). It now carries one; the enumerator also skips an id-less edge rather than throwing in the sort.
- `destroy × Standing` opens the quarrel between the standing's *two parties*, not between the actor and the other party — recorded on THR-1403 as a semantic to review at the flip.
- Under the cells model, `cell.destroy.route` is listed by a profile and does not exist (`template_not_found` ×16 on seed 42) — THR-1403's.

## Measured

`npm run census:ownership` (new; the CLI `objects` readout carries the same column) on medium at tick 0 — seed 42 · seed 99: Faction 49 · 57 objects, **15 · 16 owned** (4 · 5 by a deciding mortal); Condition **4 · 4** borne edges, all owned; Standing **56 · 59** pairs, all owned; Item **8 · 9** objects (7 · 7 owned); Companion 0 (none minted at seeding); Route 0 at tick 0, **1 after one `create × Route`** (the heavy test). The cells census re-run (150 ticks, both seeds, model flipped in the bundle only): `no_owned_object` gone for faction and condition, `no_object_exists` gone for standing; `destroy × Faction` now refuses `no_motive` (271 on seed 99 — owners found, the gate holds); `destroy × Condition` records `gate_exempt` 28 · 15 and still starts 0 (calibration, not reach — THR-1403); `change:raise × Standing` starts 2 and completes 1 on seed 99; `observe × Route` starts 2 and completes 2 on seed 42 after a route is created. Companion cells were never proposed in either run (no companions in either world), so their verdict is vacuous, not earned.
