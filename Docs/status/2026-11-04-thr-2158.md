# THR-2158 — The mortal decides the six seeded quests

**Shipped 2026-11-04.** Encounter Experience, slice 2 of 5 from the THR-2135 decision. The pattern is the THR-866 Apotheosis conversion (`Docs/plans/2026-08-11-thr-866-apotheosis-nudge-conversion.md`); no new design.

Each template used to key its two endings to the ids of the cards the god clicked on step 0, so the click picked the ending. Each now forks on one value axis (`decidedBy`, pole mode). The mortal answers; the god argues with a composed hand.

| Template | Fork axis | `positive` | `negative` |
|---|---|---|---|
| `broker.quest.rival_shrine_betrayal` | `loyalty_ambition` | refuse the trade | accept it |
| `liminal.quest.soul_ferryman` | `sacrifice_survival` | steady the courier (pay the toll) | break the bargain |
| `liminal.quest.road_ambush` | `mercy_ruthlessness` | shield the road | turn the chaos |
| `enc.courtyard_duel` | `courage_prudence` | win on the blade | work the Code |
| `enc.brink_rescue` | `sacrifice_survival` | thread the survivor out | work through the bystander |
| `enc.letters_of_introduction` | `honesty_cunning` | formal channel | old favor |

1. **Fork.** `step1Branch` gains `decidedBy: { axis }`. Branch variants, `aftermathConfig.variants` and `stakes.arms` are re-keyed to `positive` / `negative`, because pole mode writes the bare pole key. `branchOnStep` stays 0, the deciding step (THR-979). Each fallback is unchanged.
2. **Hand on step 0.** Two specials, one leaning each pole, plus `deal: { count: 3 }` from the Repertoire. Step 0 also gains a `purposeLine` and the three missing afterimages, which the hand checklist requires.
3. **Step 1.** The five templates whose step 1 carried approach cards that picked nothing now deal an ordinary hand (`deal: { count: 4 }`) on each arm. The Broker's Ledger never had step-1 cards; its arms are unchanged.
4. **`authoredChoices` removed** from all six. Ending prose is unchanged; the scene-bespoke card prose is gone. The axis per template is recorded in each file header.
5. **Tests.** New `mortal-decides-seeded-quests.test.ts` pins the Done-when over the shipped catalog: no `authoredChoices`, the fork on its axis, a non-empty step-0 hand that argues both poles, the reachability and producibility invariants, `checkNudgeHand` / `checkComposedHand` clean, and the stakes arms. `road-ambush`, `soul-ferryman`, `rival-shrine-betrayal` and the stage-model tests pin the poles instead of card ids. The authoredChoices population floor in two corpus tests is now "non-empty", since the THR-2135 slices shrink that population by design.
