# THR-2021 — a lake hex's land page reads as water, not as a desert

**Shipped 2026-10-25.** The land page for a lake hex (`?view=inspector-lab&kind=extra3&seed=7`, hex 13,3) showed the generic "An unremarkable stretch of land…" tagline and described the Sand-Kings' wind-scoured obelisks as if they stood on dry ground.

**Cause.** `BIOME_PROSE` had no entry for four water terrains: `ocean`, `coastal_shallows`, `lake` and `river`. Every other terrain had one. The ruins block takes its culture from the hex's Area, and the exploration line was the same on every terrain.

**Change.**
- `src/data/prose-layer-content.ts`: biome prose for `ocean` (3), `coastal_shallows` (3), `lake` (4) and `river` (4). Location nodes on those terrains (`biomeResolver`) get it too.
- `src/engine/explorationHooks.ts`: `buildExplorationHooks(descriptors, underwater)`. On a water hex the line reads "Beneath the water lie the … of an older age, drowned and never fully explored." Land hexes keep the line word for word.
- `src/engine/views/subjects/landProse.ts`: `ruinsParagraphs` sets it for `SUBMERGED_RUIN_TERRAINS` (ocean, deep_ocean, tropical_ocean, coastal_shallows, reef, lake). `coast` and `river` are walkable land, so their ruins stay dry (review-gate round 1 caught `isWaterTerrain` counting them as water).

**Kept on purpose.** The culture's history, its quote ("They built to outlast the desert…") and the Area name ("…Wastes") are Area-scoped. The lake lies inside old Sand-King land, so those still apply. Only the ruins' physical placement changes.

**Evidence.** `landProseWaterTerrain.test.ts`: every one of the 42 terrains has biome prose; lake, river, ocean and shallows never use the fallback; a lake hex in Sand-King land gets the underwater line and a desert hex keeps the old one. `landProse.golden.test.ts` is unchanged and passes. `npm run gate` code track: all PASS. No `src/components/` change, so no browser evidence is owed.
