# THR-2088 — Inspire now changes what a mortal decides

**Shipped 2026-10-28.** Thematic Pressure & Living World. Breath of Purpose (`divine.inspire`, the spine gift every god gets) wrote an influence with no value drift, so the mortal's page read "Inspired" and `buildValueOverlay`, the decision path's input, moved nothing.

**Fix.** The card's `apply_influence` now carries `valueDriftRule: { direction: 'own_lean', magnitude: INSPIRE_VALUE_DRIFT }`. This follows the THR-1651 pattern for Dream and Persuade. The calling "seems to come from within", so it deepens the lean the mortal already has on the value pair bound to the god's primary reach. `INSPIRE_VALUE_DRIFT = 0.10` (`src/data/dream-content.ts`). At the inspire decay strength (0.80) it peaks at about 0.08. That puts it between the dream (about 0.04; costs 1 essence) and the compulsion (about 0.105; the god picks the pole). A mortal at exactly 0 on the pair gets no entry and an `influence.no_lean` trace. No "Inspired" chip shows for a change that is not there (Law 56).

**Content.** The receipt gains `inspire_intervention` lines (clean, at cost, found nothing). The card description drops "sustains itself as long as belief remains unchallenged", which was false because the influence decays and lapses. The effects line and the technical-effects line now say what the card does.

**Evidence.** `src/engine/__tests__/inspireValueDrift.test.ts` casts the real template ops through the real executor and asserts a non-zero overlay in the lean's direction, plus an `influence.applied` trace with the drift. It also checks the zero-lean case, the receipt line and the card text. A unit-test text assertion covers the card text in place of a screenshot, because the Done-when is text-shaped (no UI-pillar path changed). `npm run gate` PASS (verdict in the PR body).

**Follow-on.** THR-2086 (Kindle a Spark, Inspire's energy twin) should follow this drift shape.
