## The pipeline the ticket said an unattended run could not do

It could. The recipe's two failure-prone steps were run as written rather than assumed: generate 16:9 at 2K, then **crop near-black letterbox bars before the downscale** — the plate that arrives correctly *sized* but letterboxed in *picture*, which passes every filename, dimension and file-size check (impediment #440). The crop thresholds all channels at ≤12 and scans only the outer quarter so a dark sky is never eaten; it ran unconditionally and reported `letterbox: none found (clean plate)`, then LANCZOS down to exactly 1376×768. The source happened to be exactly the target aspect, so the centre-crop was a no-op — recorded because a *silent* no-op and a *skipped* step are indistinguishable afterwards.
