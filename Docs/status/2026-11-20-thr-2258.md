# THR-2258 — Aftermath rows say what happened

**Shipped 2026-11-20.** Cold playtest round 8: a gift won on a lost step read as a SCAR and linked to "Unknown: no longer in the world"; a strong Mandate deed said "far" beside one ▲; Cracked Brass Horn's help listed twice.

- **Consolation is a BOON.** Harm decides a reward row's gain, not the step band (`unifiedActionResolution.ts`). A harmless draw on a lost step reads "Seren still came away with Fossil Whispers." (`rewardSentence`'s new `consolation` flag) and folds to BOON with a gain glyph. Harmful draws stay SCARs on any band (THR-2095).
- **Links that outlive the grant.** Reward clones now carry `rewardTemplateId`; `rewardLinkTarget` (`rewardPool.ts`) links a trait-shaped grant (condition, blessing, bestowed, spell) as an `attachment` to its template, which stays after the condition expires. Held items keep the `artifact` route to their instance; companions keep theirs.
- **Mandate cluster.** A new two-rung `mandate` magnitude ladder (`DELTA_CLUSTER_BAND_MAP.mandate = [1, 2]`); the deed row sets `band` from the same `MANDATE_DEED_STRONG_POINTS` test as the "far", so strong reads ▲▲ "a clear amount".
- **One source, one HELPS line.** `deriveContributionLines` merges contributions by `kind:sourceId` and sums them before building lines.
- **Residual.** A spent consumable's own artifact link still opens the missing page once the item is gone (the clone is removed); conditions, the reported case, no longer do.
- **Evidence.** `src/engine/__tests__/aftermathRows.thr2258.test.ts` (12 tests, each fix with a falsifying arm); browser substitution: jsdom-free route assertion (concept → `WorldRef` → `NavigationTarget` → `attachment` sheet that renders a named page after the clone is removed).
