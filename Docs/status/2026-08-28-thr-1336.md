# CLAUDE.md learns what game it is building (THR-1336)

**The always-load file was ~28.5k tokens, and roughly 2k of it was about the game.** The gate law (~8k tokens of two-track verification rules with their full incident histories) and the sandbox catalog (~9k tokens of impediment archaeology, junction repair sequences, and Linear API quirks) lived inline — so every agent, every session, spent its opening attention on mklink lore before learning what Threadbearer is. Christian's ruling: "yes slim it down… remove the noise."

The THR-760 pattern, applied twice: **`Docs/canon/verification-gates.md`** is now the authoritative home of the pre-commit/pre-push gate law *and* the browser-verify evidence contract (both moved verbatim, including the THR-777 tree-diffing-gates extension); **`Docs/ops/sandbox-limitations.md`** is the authoritative sandbox catalog. CLAUDE.md keeps the same headings as summaries — the five-bullet gate shape, the five highest-frequency sandbox rules — so every inbound "§ Testing" / "§ Known Sandbox Limitations" reference stays semantically valid, one hop from the detail. The Prioritization essays, the Debug Bridge's forty-line JS comment block, the BEHIND/deploy/merge incident narratives, and the skill-tree demolition history all compressed to their operative content with pointers to the plan docs that own the rationale.

**Measured: CLAUDE.md 110KB → 69KB (~28.5k → ~17.4k tokens, −39%), 529 → ~420 lines, all 19 section headings intact.** With the UL-footer compression from THR-1334, the universal always-load stack drops from ~45k toward ~28k tokens — and the share about the game roughly quadruples. Live references swept: `canon/process.md`'s pre-commit bullet (itself a 4.5KB restatement) is now a true pointer; pull-work's docs-only track, documentation-ownership's vault note, and the weekly-project-hygiene prompt (mirror **and** live copy at `~/.claude/scheduled-tasks/`) all point at the new authorities; both new pages registered in the guidance manifest under `coordination-process` and in the canon index. Honest residue: CLAUDE.md remains ~17k tokens, not the ticket's ~10k aspiration — what's left is operative law and dev reference (the URL table, the DoD checklist, the load-bearing decisions), and cutting further would move content agents genuinely need at first read.

**Closing note — the relocation broke two guards that were pinned to the old address, and the second was unreachable from a docs-only PR.** `PREDICATE_COPIES` (`scripts/docs-only-predicate.ts`) registered `CLAUDE.md` and `Docs/canon/process.md` as required literal copies of the docs-only classification predicate; both now delegate to `npm run classify:diff` instead, so `check:predicate-copies` went red in `Docs gates` and PR #1704 sat armed-but-unmergeable ~106 min. One layer down, `docs-code-decoupling.test.ts` read `CLAUDE.md` for the same literal — and that assertion lives in `npm test`, which a docs-only PR skips by design, so it could not fire until the fix itself made this PR code-track. Both now follow the literal to `Docs/canon/verification-gates.md`, and the registry's doc comment states the rule the original only implied: **a row tracks a literal copy, not a topic — when content moves, the row moves with it**, and a surface that became a pointer loses its row rather than being made to carry a copy it is right not to have. Named risk for rounds 2–5, which relocate more always-load prose: grep the *code* tree for a file's path before moving prose out of it. Impediment #924.
