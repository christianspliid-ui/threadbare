# THR-2137 — Agent Thread finds the townsfolk

**Shipped 2026-11-02.** Onboarding & First-Run Experience. Found by cold playtest round 6 (2/3 testers named it their quit point).

Agent Thread said "Nothing you can see is something Agent Thread can touch" right after the bond. The cause: `buildHexActorIndex` placed a mortal only by `properties.locationId`, and the ambient NPCs `seedNpcsAtLocations` mints carry only a `located_at` edge. Every townsperson was unresolved, so they never reached `hexContents.people`, the hex panel, or the armed-card targets.

**Fix.** `buildHexActorIndex` now reads the actor's `located_at` edge first and the `properties.locationId` mirror only as a fallback, the order `binder.candidateHex` uses. The mirror is stamped at birth and never rewritten by movement, so it also put every mortal that had walked on its birth hex (caught by the review gate). The empty armed line now names a next step: "… can touch. Move closer: only what stands in your sight or a threaded mortal’s can be touched." (`ARMED_WORDS.emptyNext`).

**Knock-on.** `phaseFamiliarityGain` reads the same index, so the avatar now also gains proximity familiarity with townsfolk on its hex. That exposed a crash in fixtures built without `familiarityMap`; the phase now starts from an empty map (fail-soft).

**Tests.** `hexActorIndex.test.ts` (edge-only actor, edge into a Place, edge over a stale `locationId`, `locationId` fallback); `hexActorIndex-generatedWorld.test.ts` (seed 42 small world: every living individual with a `located_at` edge is indexed, with edge-only mortals present); `armedTargets.test.ts` (the new empty line).

**Browser evidence.** `?view=game&seeded&size=medium`, 1920×1080, after `grantAction('bind_thread_agent')` + `armCard`: `getArmedTargets()` → `cardName: 'Agent Thread'`, 20 lit targets, all `castable` (Skinun, Holle, Ingmar, Cordelia, Brenna, Linnea … on hex 19,10), `emptyLine: null`. Console 0 errors. UI Laws: 1/17 (copy in `view-content.ts`), 13/14 (game words, the card's own name), 21/33/37 (no layout change; banner fits the viewport).
