# THR-2132 — The Stage's place tag and the toasts no longer collide

**Shipped 2026-11-02.** UI Visual Overhaul — Design System v1. Found by the weekly UX review (moment *Mid-game table*).

During a Stage moment the place tag ("Wraithwood · where it is happening") sat at the top of the Stage's window strip, the same corner the toast stack owns, and drew over the first toast. At 1920 the strip (280px) was also narrower than a toast (320px), so the Stage panel clipped every toast's first words, and the tag itself truncated.

- **Place tag** (`stage/Stage.tsx`): the tag and the hold line now sit in one column at the window's bottom edge (`data-stage-window-foot`), hold line above the tag. The tag wraps instead of truncating, so a long place name reads in full.
- **Toast stack** (`ToastStack.tsx`): the raw `z-50` is now `Z_BAND.stage` (same height, named — Law 35). A new `stageOpen` prop (passed by `GameView`) narrows the stack to the window strip less its gutters while a Stage moment is open (`TOAST_W_ON_STAGE`), so the panel never covers a toast.

**Tests.** `Stage.test.tsx` — the foot is a child of the window, anchored to the bottom, and the tag wraps. `ToastStackAnchor.test.tsx` — the stack's z-index is `Z_BAND.stage`, no `z-50` class, and its max width follows the window strip when `stageOpen`.

**Browser evidence.** bash-vite on port 5287, Playwright at 1920×1080, `?view=game&seeded&size=medium&forceencounters`, an encounter Stage open (`await __DEBUG.getStage()`), four toasts pushed with `__DEBUG.pushToastFixture`. Measured: tag 1664–1896 × 994–1056, toast stack 1672–1904 × 64–498, Stage panel right edge 1616 — the tag doesn't overlap the toasts, and the panel doesn't overlap them either. All six toasts and the tag read in full. Console: 0 errors after the reload (an earlier run logged three duplicate-key errors from the fixture lever minting same-millisecond ids — dev lever only, not this change). UI Laws judgment: 1, 13/14, 17, 21, 33 (nothing scrolls or renders off-screen), 35 (named band), 37, 45, 49 — hold on the composed surface.
