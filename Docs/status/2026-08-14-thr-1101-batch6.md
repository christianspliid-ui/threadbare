## The half-and-half rule held a fourth time — and shifted

`lead` split **5 full mad-libs to 9 wedged-token**, against `build`'s 7/9, `trade`'s 7/8 and
`assist`'s 6/9. Four families now cluster around half, but this one is the most wedge-heavy yet,
which made 99 token lines cheaper than the count suggests: `political_intrigue`,
`weave_political_alliance` and `drill_the_watch` each carried 9 tokens wedged into prose that was
already authored, so they wanted removal rather than rewriting.

The scoping consequence stands and is now well-evidenced: **a family's token-line count does not
predict its authoring load.** Sample before committing.

## The render pass paid off a fifth time, and found a class no prior batch named

Four defects, none visible in source:

- **Referent binding (new, now impediment #563).** `{their}` and `{they}` are **actor-bound** —
  `enrichProse` substitutes them from the actor's pronouns with no notion of which noun they
  modify. `merchant_caravan` rendered *"every merchant still holding **her** own goods"*;
  `diplomats_maze` carried the same shape pre-existing in *"The ruler turns **her** gaze
  elsewhere"*. Both are grammatical after substitution and simply about the wrong person, so no
  token scan and no read of the template file can find them.
- **Past-tense *to be* after `{they}` has no fix.** `{they} were` renders "she were";
  `{they} was` renders "they was"; `{s}` is a present-tense agreement token and cannot reach it.
  The only remedy is to drop the pronoun subject. This extends the `{s}` ceiling batches 3–5 met.
- **Double-name collisions** in two lines this batch wrote (`council_mediation`,
  `political_intrigue`), where `{actor}` appeared twice in one sentence.

## Vagueness 5 → 0, and the set that ignores scope caught four of them

Every hit was **`the moment`** — a *nominalised placeholder* in the **evasive** set, which is
enforced at zero in **every** field class, not only outcome prose. Four were lines this batch
wrote and one (`diplomats_maze`'s *"the moment is lost"*) was pre-existing. The fifth hit was
`way` in a `toll_bridge` afterimage.

Batches 2–5 each recorded a version of this lesson about `something`; `the moment` is the same
trap wearing better clothes, because it reads as entirely ordinary English. Worth inheriting as a
concrete list rather than a principle: `the situation`, `the matter`, **`the moment`**, `the
atmosphere`, `the tension`, `the dynamic`, `the connection`, `the understanding`, `the balance`,
`the energy`, `the presence`, `the experience`, `the process` are evasive **everywhere**.

Second-person sweep: zero. Intensifiers: 2, both `rather` in comparative constructions
(`would rather not`, `rather than`) — warn-level by construction and exactly the case batch 4
ruled should be left alone rather than contorted around.
