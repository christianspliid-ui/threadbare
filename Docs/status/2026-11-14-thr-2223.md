# THR-2223 — a ruler's Story tab counts its repeats, and "What happened" says what happened

**Shipped 2026-11-14.** Thematic Pressure & Living World · Warm playtest round 4.

- **One chip per chapter template.** `buildConnections` (`src/engine/views/connections.ts`) now folds the Story group by template (`foldStoryRepeats`). Before, it merged rows by `actionId` only (THR-2139). A ruler who ran "The Price on Their Head" five times now shows one chip that reads "five times", where it used to show five identical chips. The chip opens the newest run. The group count (`Story · N`) counts chips, not runs. The repeat word is spelled out ("twice", "seventeen times"; `INSPECTOR_WORDS.storyRepeat`). Only encounter-chapter rows (`eventType: encounter_outcome`) fold, so a fight record or an undertaking outcome that shares a `templateId` keeps its own row. Legacy step nodes carry no `actionId`, so a run is counted at its step 0. Past ninety-nine runs the word reads "more than ninety-nine times". The review gate caught all three in round 2.
- **"What happened" never echoes the title.** If an event has no stored `summary`, `eventFallbackSummary` (`src/engine/detailPageResolvers.ts`) builds the line from the aftermath's ending vocabulary instead of printing the template name. An encounter step reads by its own result: "Queen Ysolde took a step in The Price on Their Head, and it went well." A step never claims the whole chapter was won, which the review gate caught in round 1. An ending with no step reads as the aftermath sentence ("… won X, at a price."). An event with no outcome reads "… took part in X."
- **Superseded assertion.** THR-2139's test said "a second, separate run stays its own row". It now says the two runs fold into one row with "twice", and that a two-step chapter still counts as one run.
- **Not built:** the ticket's fix direction also suggested that the folded chip's detail page list each run with its date and outcome word. Neither Done-when line requires it, and the newest run's page opens instead.
- **Evidence:** `thr2223-story-repeats-and-what-happened.test.ts` (8 tests). `npm run gate` passed on the code track (test, typecheck, build, CLI smoke).
