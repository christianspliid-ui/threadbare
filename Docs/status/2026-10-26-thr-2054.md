# THR-2054 — The First's own sheet agrees with the bond

**Shipped 2026-10-26.** Cold playtest round 5, PC-6 (one fact told two ways). Two of three testers saw their First's sheet deny the bond, were offered a second bind on her, and paid for it without seeing the odds.

**What changed.**

- **Disposition reads the thread.** `portraitWithDispositionResolver` and the floor `actorPortraitFallback` now check the god's `thread` edge to the mortal first. A bonded mortal gets a line from `ACTOR_BONDED_DISPOSITION_TEMPLATES`, keyed on the rite's reception (the edge's `bondReception`, else the newest `riteHistory` entry), which is the same fact the Rite line reads. A bonded mortal never reads "has not yet crossed paths with you".
- **Lines stay put.** `seedFor` no longer XORs in the tick, so a detail-page fallback line changes only when its pool does.
- **No bind on a bound mortal.** `actOnSlots` passes the thread tier for agents too, and counts a thread edge with no `tier` as threaded, so the `bind_thread_*` dedup gate runs on a person's Act row.
- **Odds before the essence.** Each Act-row card carries its `forecastTier` word. Arming the card shows "Odds: Fated" (or the tier) beside the Cast button, before anything is spent.
- **"faltered" → "held at a cost".** `OUTCOME_BAND_WORDS.strained` is a success at cost; the old word read as failure.

**Evidence.** `npm run gate`: PASS. New `firstSheetBond.thr2054.test.tsx`, 10 tests. Browser (bash-vite :5263, 1920×1080, `?view=game&seeded&size=medium`): the Disposition line on Kael Thornweaver reads "Kael Thornweaver is bound to you by thread." and is unchanged after 25 ticks. `getInspectorState().actCards` = `[divine.persuade, observe_agent]` while the god holds Agent Thread. The armed Persuade card shows "Odds: Fated".
