# THR-1949 — review gate and browser evidence scoped to engine and large UI changes

**Shipped 2026-10-25.** Cut 4 of 6 from Christian's 2026-10-15 chat review of the pickup lane.

**Review gate.** `reviewScope` in `scripts/review-gate.ts` decides whether a code diff owes a review: yes when it touches `src/engine/` or `src/types/`, or adds more than `LARGE_UI_ADDED_LINES` (400) non-test lines under `src/components/`, `src/hooks/`, `src/contexts/` (counted from `git diff --numstat origin/main...head`, `__tests__/` and `*.test.*`/`*.spec.*` excluded). Any other code diff with no receipt is allowed (`review optional (THR-1949) — …`). A receipt with open findings still denies whatever the scope, and an unknown UI-line count counts as over the threshold, so a caller that cannot count never waives a review.

**Browser evidence.** `verification-gates.md` § Browser-verify, `definition-of-done.md`, `CLAUDE.md` and the frontend-ui skill now read the ticket's purpose first: nothing a player sees → none (`Browser-verify exempt: <reason>`); a small visible fix (≤ 400 non-test UI lines) → one 1920×1080 screenshot; a larger visible change → the full four parts. Unchanged: engine diffs still owe the 30-tick CLI smoke, and heavy tests run on CI after merge.

**Evidence.** `scripts/__tests__/review-gate.test.ts` 43/43, including the real hook against a fixture repo: a content + small-refactor diff merges with no receipt, adding an engine file to it is denied, and a 401-line UI file is denied. `npm run gate` PASS (track=code).
