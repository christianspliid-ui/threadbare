# THR-2165 — The bonded mortal's name stays whole in the Threads rail

**Shipped 2026-11-05.** Warm playtest round 3 (3 of 3 testers): on a busy row the name printed one letter per line.

**Cause.** `ROW_NAME_STYLE` in `src/components/Game/ThreadsPanel.tsx` set `minWidth: 0` and `overflowWrap: 'anywhere'`, and every mark after it is `flexShrink: 0`. `anywhere` lowers the name's min-content to one glyph, and `minWidth: 0` lets the flex item shrink to it.

**Fix.** The name keeps the flex default `minWidth: auto`, and `overflowWrap: 'break-word'` does not lower min-content, so the name can never get narrower than its longest word. Both head rows (the thread row and the sustained-control row) now set `flexWrap: 'wrap'` with a 4px row gap (`ROW_HEAD_WRAP`). When the marks do not fit beside the name, they move to a second line. A name breaks only between words. A single word wider than the whole rail would still break; no generated name is that long.

**Test.** `ThreadsPanel.test.tsx`: "never lets a busy row squeeze the name below its longest word (THR-2165)" asserts the name style and that the row wraps.

**Gate.** `npm run gate`: test, typecheck, build, encounter, god-cards and ui-debt all PASS (track=code, engine=no).

**Browser evidence.** Worktree Vite on port 5237, headless Chrome (swiftshader) at a true 1920×1080, `?view=game&seeded&size=medium&warm=300`. Live row: "Kael Thornweaver", 144px wide, one line (27px). The marks wrapped to a second line (head row 63px). Stress pass: the live badge was cloned in the DOM until the head held four badges plus the pip. The name stayed on one line, 164px wide, with all four badges on the second line. `window.__DEBUG` is present. Viewport: `innerWidth` 1920, `scrollWidth` 1920, `scrollHeight` 1080, so nothing overflows. Console: only the pre-existing `[GraphSchema]` warnings on generated-past edges, none from this change.
