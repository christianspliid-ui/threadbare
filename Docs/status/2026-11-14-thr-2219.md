# THR-2219 — Doom says what a stage does; no more "many weeks"

**Shipped 2026-11-14.** Thematic Pressure & Living World · Warm playtest round 4.

- **Stage popup.** `phaseDoom` built the stage popup body from each card's title only ("Barrier Thinning"). The new `doomStageCardLine` tells each card as title, its `description`, then its `effectSummary` (the plain "what it does" line), one card per paragraph. `EventPopup`'s compact body now keeps line breaks (`whitespace-pre-line`). The THR-2207 Stay the Unmaking note and button are untouched.
- **Durations.** `durationLabel` went through `countWord`, which stops at nine, so the Doom panel read "four weeks of many weeks". Weeks are now spelled to ninety-nine (`spelledCount`, new), then the reading steps up to years. `countWord` itself is unchanged for its overview-line callers. Every `durationLabel` surface gains this — no reading anywhere says "many weeks" now.
- **Tests.** `doomWakesAtBond.test.ts` runs a real Breach clock to the end and checks every escalation popup carries each card's title, description and effect summary. `DoomClockDetailNoMany.thr2219.test.tsx` renders the panel at 10/13/24/40 weeks with no "many". `doomStagePopupRender.thr2219.test.tsx` renders every generated stage through `routeNotifications` + `EventPopup`.
- **Browser-verify substitution: jsdom-render.** Bash-vite on port 5297 (Playwright, 1920×1080, `?view=game&seeded&size=medium`): the clock was driven past stage 2 (doom tick ~380; the DoomBar announced "Doom has reached Reality Cracks") but the stage popup never rendered under the debug harness (`queuedPopups: 0`), the same wall THR-2207 hit. The composed path is rendered in jsdom instead (the test above).
