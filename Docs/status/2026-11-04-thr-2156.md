# THR-2156 — The path pulls only scenes about the same thing

**Shipped 2026-11-04.** Onboarding & First-Run Experience, cold playtest round 6. The design lane decided it on THR-2144. No plan doc; the ticket was self-scoped.

1. **Type (`src/types/meetingEncounter.ts`).** `SparkVision` gains an optional `themeAxes: readonly [ValuePair, ValuePair]`: two motivation axes and no pole (THR-1525).
2. **Content (`src/data/spark-vision-catalog.ts`).** All 24 paths carry the pair from the ticket's table. A completeness test checks that every entry has two distinct axes from `VALUE_PAIRS`.
3. **Engine (`src/engine/firstPath.ts`).** `FirstPath` carries `themeAxes`. `firstPathPullFor(path, reach, motivations)` pulls ×(1 + `FIRST_PATH_PULL`) only when the scene's Reach is one of the path's two **and** its motivations name one of the path's axes. A path without axes (an old save or a fixture) keeps the THR-2068 reach-only rule. `applyFirstPathPull` passes the cache entry's `motivations`. It is the only place the pull is computed, so God's Will (`fitsPath` reads `firstPathPull`) and the board agree.
4. **Engine (`firstPathFitFor`).** This is a new read-only function beside `firstPathRecallFor`. It returns "Fits {path}." for The First's chapter on its opening step when the path pulls the chapter's scene. The pinned recall chapter gets only the recall line.
5. **Stage (`buildUnifiedEncounterStageModel.ts`).** The fit line goes into the same slot (`para-first-path`) as the recall line. The copy is `FIRST_PATH_FIT_LINE`, the line God's Will already shows.
6. **Tests.** `thr2156PathThemes.test.ts` covers the catalog, Torch + `cg.join` → 1, Reader of secrets + `encounter.shadow_in_the_night` → 1.5, a path with no axes → reach-only, and the Stage model (a fitting chapter, a non-fitting chapter, a stranger's chapter, the recall chapter). `thr2068PathSteers` and `firstPath.thr1988` were updated for the new rule.
