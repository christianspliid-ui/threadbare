# THR-1988 — The path you chose comes back

**Shipped 2026-10-21.** Round-4 cold testers picked a path on "What will they become?" from three cards that showed the same face, and never saw that choice again. Now each of the 24 spark visions has a short name, e.g. *Healer of the many*. The name shows under its card before any click, and it comes back three times. The bond says "Solenne will become the healer of the many." The First's page has a Path row beside the god's mark, with a tooltip naming the Reach it strengthened. Her first chapter after the bond opens with "Solenne has not forgotten the path you showed at the bond: the healer of the many."

**Engine.** `src/engine/firstPath.ts` resolves the stored `sparkVisionId` against the catalog, so there is no new graph data. Once per bond, the tick path (2b.1a, `noteFirstPathRecall`) pins The First's first non-routine chapter on her thread as `firstPathRecalledActionId` and traces `first_path_recalled`. The stage model only reads that pin, on the chapter's opening step. A later chapter never repeats the line. `generateMeetingCallback`, which had no caller and read the unwritten `intentPrimaryReach`, is deleted. `passesFoundingGate` reads the same unwritten field. Rewiring it changes balance, so it is filed as [THR-2009](https://linear.app/threadbare/issue/THR-2009).

**Evidence.** On `?view=game&firstunmet&size=medium` at 1920×1080: the three titles at rest sat at 610–940px, opacity 1, with page height 1080. The bond line rendered. `getFirstPath()` returned `vision.heart.saint`. `first_path_recalled` fired once at tick 12, and the chapter's first paragraph was the recall line. The Path row showed tooltip `ui.first.path.star`. `firstPath.thr1988.test.ts` has 13 tests and `pathAtRestThr1988.test.tsx` has 3.
