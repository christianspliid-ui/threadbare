## The one rename, and why that name

`company.betrayal.the_work_calls` is the common (sphere-less) Boost in
`encounter.company.quiet_offer`'s hand — the god acts on the *company's work* so
it demands the member back, ending a private offer by making them needed loudly.

It was over length, but that was the smaller problem: **it was a declarative
sentence in a hand of imperatives.** Its four siblings read `Price It Out`,
`Stand in the Open`, `Let It Wait`. Prose Doctrine v2 § *Word budgets* is explicit
— *imperative verb + noun, 2–4 words, like a spell*.

`Call Them to Work` is four words, opens on `call` (in `IMPERATIVE_VERB_LEXICON`),
and keeps *work* as the named lever, which is what the `effectLine` and the card's
design comment both turn on. `make` and `let` are **not** in the lexicon, which
ruled out the otherwise-natural `Make the Work Call`.

Worth knowing when reading `cardNameShapeProblem`: its length check sits **after**
two opener guards and returns early, so the old name — opening on `The`, a
fragment opener — was never reaching the length arm at all. It was being reported
as a *mood name*, not an over-long one.

## The gate is live, proved by a controlled arm

A green run at 4 proves nothing on its own — the corpus could simply have no
5-word names left for reasons unrelated to this clamp. So the arm was run:
with the name restored to five words, `check:encounter --all` exits **1** with

```
✗ encounter.company.quiet_offer
    [hand] encounter.company.quiet_offer step 0 (shadow):
    company.betrayal.the_work_calls name is 5 words, over NUDGE_NAME_MAX_WORDS 4
```

and all three templates this ticket depended on are confirmed *checked*, not
skipped — `encounter.sharpen_blades`, `encounter.ward_the_camp` and
`encounter.company.quiet_offer` each render a `✓` line in the same run.

## The corollary the ticket asked for: `doctrineV2Checks`'s name-budget arm — **kept**

The ticket asked, once clamp and budget are equal, whether the arm still earns
its place. Answered rather than left silent.

**It is now strictly redundant in its one live path.** `check-encounter.ts` calls
`doctrineV2Warnings` and `checkNudgeHand` over the same template in the same run,
and `cardNameShapeProblem` checks length only after its opener guards — so its
population is a *subset* of the clamp's, never wider. Every name it warns about is
already an error on the line above. `doctrineV2Checks.test.ts` records the repo's
own principle against exactly this: *"a warn channel restating it would
double-report."*

**Kept regardless**, for the reason `NUDGE_WORD_BUDGETS` states about itself — *a
doctrine row with no constant is a rule no machine reports*, and this arm is the
budget's only reader. Deleting it leaves the doctrine's name row enforced solely
by a **legibility** cap that happens to sit at the same number, and the two are
independently tunable by design. They have already been apart once, for six
weeks — which is precisely the case the arm exists for. The cost of keeping it is
one warn line trailing one error line on names that are already blocked.
