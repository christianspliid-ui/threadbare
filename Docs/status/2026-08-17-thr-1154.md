# THR-1154 — prose and chips are one package

**Shipped 2026-08-17.** Ratifies the chip-anchoring rule, ships the anchor catalog as a
generated artifact, and gives the Encounter Factory a stage that judges the package
rather than its halves.

**Law 56 gained a second clause.** Clause 1 asks whether a write fired; clause 2 asks what
it was *about* — the referent must be an existing graph object, resolvable in the live
world, and the prose must name that particular object. THR-1141 is why it was needed: it
satisfied clause 1 with a real write onto a river that is not a node.

**The anchor catalog is generated, not written.** `npm run generate-anchor-catalog` derives
membership from the live `NodeType` / `ActorType` / `EdgeType` / `AttachmentCategory`
unions — 58 anchorable members across 75 classified, each with its declaration form and
player surface. It runs in `prebuild` and is registered with `check:generated-freshness`.
What keeps it honest is the split: **membership derived, annotation curated, an
unannotated member fails the build by name.** Annotation is not derivable (which surface
shows an anchor is a routing claim spread across `openEntity`, the drawers and the detail
views), and without the guard a new node type would be merely *absent* — which reads
exactly like "not an anchor".

**Pass 3b, the Package critic**, runs on Opus between Systems and the machine gates. Half A
checks every chip against the catalog; Half B answers in writing *what does this encounter
leave behind that a later encounter or system can pick up, and would the player recognise
it happening?* Its verdict reaches the director as a batch-report column. The brief now
names its anchors before the draft, so prose is written toward its chips.

**Both verification findings came back honest.** `nation` has no representation — no node
type, no property, no border model; territory is faction control over locations — so it is
a recorded gap pointing at THR-1155, not an invented row. `named area` is real: `region`
nodes are flood-filled at worldgen and named from historical culture ownership.

**The distinction that most needed writing down.** Only four kinds route a click, so every
location, culture, region, bond and trait is `named` rather than `linked`. Both satisfy
Law 56. A critic reading "unclickable" as "unanchored" would fold most of the corpus's
legitimate consequences, so the catalog, rule 0b and the Package prompt each say so.

**Unblocks** THR-1153's 65-chip sweep and its anchor-resolution gate, both of which were
waiting on this vocabulary; THR-1130's batch-2 brief; and THR-1160.
