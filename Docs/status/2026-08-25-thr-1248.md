# THR-1248 — the dealt-hand corpus

**2026-08-25 · Encounter Experience · Content + Engine**

Every library member is now dealable. `PLAY_PROFILES`, `BAND_FRAGMENTS` and a per-member
`effectLine` went from two reference entries to all 37 members, which is what turns
THR-1247's dealer from a wired path into a working one: an encounter authors 0–2 specials
and declares a fill, and the god's Repertoire supplies the rest from cards the player
already holds.

**The corpus.** Profiles are generic by the same law as the faces — no scene-bespoke
targets, every magnitude data. Fragments are narrator-mode under Prose Doctrine v2: they
state what the god's influence did, plainly, written to `{actor}`/`{they}` and
scene-neutral nouns so the same line reads correctly in the forty encounters it will be
appended to. Every member pays off in at least one failure band; the four big-delta
members (both Heavy Hands, both Undertows) read their failure at both depths.

**Eight liveness pins**, each asserting a non-zero population before asserting over it:
`profiledCardCount()` equals the library size; `dealableMembers()` covers it; the
failure-band rules hold for every member rather than a sample; every fragment uses only
placeholders the enricher resolves; every fragment stays inside its word budget; every
effect line is present, numeral-free and **distinct**, which is the whole reason the field
exists — the type-keyword fallback is identical across a family, so three Boost members
would otherwise deal as three copies of one sentence.

**Three defects found on the way, all fixed here.** A play profile lives outside every
template, so `validateNudgeGrantRefs` structurally could not see its grants — the new
`validateLibraryGrantRefs()` runs the same walk against the same live index, and caught a
dead `assign_ambition` naming a *reactive* ambition on its first run. `checkComposedHand`
shipped with no exerciser at all (it returns `[]` for every template without a `deal`,
i.e. all of them); it now has eight, six of them red arms derived from the golden
exemplar. And `buildNudgePhaseModel` returned `undefined` for a step declaring a `deal`
with zero authored specials — legal content per the spec and the gate — so a fully-dealt
hand could be composed and then rendered by nothing.

**Authoring surfaces** carry the model rather than the old rule: the spec gained § 3b *The
dealt hand* (specials rule, declaration, the closed 12-value tag vocabulary, and what the
dealer already guarantees so an author does not re-check it), step 3 stopped asserting
"hands are fully authored… no runtime generic deck", the pipeline SKILL rewords to
"compose 4–8", and the brief was regenerated. Two paragraphs that described the library
data model as *coming* were corrected to describe it as *here*.

**What is left:** one factory encounter authored under the composed model — THR-1254.
The interface-map row `repertoire-deals-into-encounter-hand` stays PARTIAL until it lands,
now for exactly one reason (no shipped template declares `deal`) rather than two.
