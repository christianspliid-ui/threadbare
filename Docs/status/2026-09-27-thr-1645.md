# 2026-09-27 — THR-1645: one essence store

**Ticket:** [THR-1645](https://linear.app/threadbare/issue/THR-1645) · **Project:** Onboarding & First-Run Experience · **Found by:** onboarding design session (plan `Docs/plans/2026-09-27-thr-1606-what-your-hand-did.md`, § Notes) · **Pillars:** Engine (Content: N/A, no template changes; UI: N/A, since the bar already reads `GameState.essencePool` and now sees every write).

## What was wrong

The player's essence had two stores. `GameState.essencePool` is what the essence bar reads and what `commitPlayerCast` spends. Stillness added its regen to the ascendant node's `properties.essencePool` instead, so the bar never moved when you meditated. `processInfluenceMaintenance` also read and charged the node pool.

## What shipped

- **Stillness** (`resolveSelfActionEffect`, `src/engine/unifiedActionResolution.ts`) adds `STILLNESS_ESSENCE_REGEN` to `GameState.essencePool[primary]`. It is capped at `computeMaxEssence` (the ceiling `phaseEssence` uses) and written as a fresh object, so selectors that compare the pool object see the change.
- **Influence maintenance** (`processInfluenceMaintenance`, `src/engine/influence.ts`) takes a required `pool` argument and charges it in place. It no longer reads or writes the node.
- **Node property** `AscendantProperties.essencePool` is documented as a creation-time snapshot. `createAscendant*` still seeds it, so saved worlds can read it, but nothing writes it after creation.
- **Rival ascendants:** the grep found no other `properties.essencePool` reader or writer. Rival pools live elsewhere (`rivalStates`), so none needed to stay on the node store.

## Found along the way

`processInfluenceMaintenance` has **no production caller**. Thread upkeep is never charged, but the `computeEssenceIncome` readout subtracts it. Filed as [THR-1652](https://linear.app/threadbare/issue/THR-1652) (Deferral) rather than rebalanced inside this bug fix. Both wiki pages now state the gap.

That is +4 from Stillness plus 0.35 passive income, measured on a control tick. The node snapshot stayed at 50 → 50. Trace: `Stillness: +4 chaos essence (now 24)`.
