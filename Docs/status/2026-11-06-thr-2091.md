# THR-2091 — A hex card's sphere push measures distance on the map's own grid

**Shipped 2026-11-06.** Thematic Pressure & Living World. THR-2087's `resolveHexPressureTargets` (`src/engine/hexPressureTarget.ts`) measured hex → place distance with `delivery.hexDistance`, which is odd-r. The map is flat-top odd-q (`src/lib/hexMath.ts`). Off the straight axes, a push could land on the wrong "nearest" place, or a place inside `HEX_PRESSURE_FALLBACK_RADIUS` could read as out of range. Example: (5,5) → (3,6) is 2 hexes on the map, and odd-r says 3.

**Fix.** The resolver imports `hexDistance` from `src/lib/hexMath`. A regression test pins a diagonal place where the two grids disagree.

**Executor notes.** First built 2026-10-30 on branch `thr-2091-oddq` (`a468c964`), which could not ship while the duplicate PR #2654 stayed open. With #2654 closed, this run re-applied the same two-file diff onto a fresh branch off current main rather than merging the week-old branch. The other `delivery.hexDistance` callers were not audited here.
