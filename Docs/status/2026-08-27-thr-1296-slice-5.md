# THR-1296 slice 5 — the remote-anchor rule and banded creation (2026-08-27)

Slices 1–4 built the binder and gave it a consumer: a ledger, a scored board, a mint
valve, and a bind pass running before every checkpoint. Slice 5 is where an undertaking
starts to **cost something to reach** and **leave something behind**.

## Creation effects — the middle of an undertaking is now eventful

Until this slice the only thing a checkpoint could do was move a number.
`StrategicMutationHint` builds at *completion* and has never been able to make a person
at all, so a season-long undertaking produced nothing observable until the day it
finished — and a catastrophic failure produced nothing observable ever.

`creationEffects` bands what an undertaking makes by what its checkpoint actually did:
an advance bears fruit, an advance-at-cost bears fruit *and* the cost, a halt leaves
nothing, and a critical failure puts the disaster in the world. That last band is read
off the **band**, not the effect — `critical_failure` maps to `halt`, so a rule keyed on
the effect alone would make the one outcome whose whole job is to leave a mark the only
one that never could.

Two ways to make a person, and the split is load-bearing: `must-persist` routes through
the mint valve (budgeted, deterministic, born real, registered in the ledger), while
`scene-only` materializes immediately as a walk-on through the encounter support
bundle's own writer — extracted this slice so there is one writer rather than two copies
of the same node shape. Spending the one-per-tick birth budget on a face in one scene is
exactly what would starve it.

## The remote-anchor rule — and the plan sentence that was wrong

The rule: a remote undertaking must anchor through something the agent commands at or
near the site; without one, the verb is not offered. The `commanded_by` edge direction
(army → commander, which three files carry warnings about) is encapsulated once, so no
fourth reader has to get it right.

**§6 specified this gate on distance alone, and shipped that way it deleted a live
subsystem.** The same section predicts remote undertakings will be *rare* in v1; both
cannot hold, because on a real map almost every target sits more than two hexes away and
almost no agent commands an army. Measured: `trades_with` edges written in the 120-tick
seeded smoke went to **zero**, and seven doom-identity milestone tests fell over with
them — 8 failures across 2 files, none of them subsystems this plan touches. A controlled
arm (the predicate forced to `false`, nothing else changed) returned all 25 to green.

The distance rule was not what was wrong; its **scope** was. Remoteness is a property of
the verb — commissioning, garrisoning, raiding are done through others — not of how far
the agent happens to be standing. So it is declared (`StrategicActionTemplate.remote`),
which also makes it the same shape as every other seam here: the engine ships honoring
it, doc 2 authors the rows, and an emptiness-pinning test fails deliberately when the
first one lands. Logged as impediment #842.

## `$anchor`

The winning anchor joins the cast as `$anchor`, must-persist. That is what turns "the
army footing this was destroyed" into a named complication for everything it was
holding up, rather than an undertaking that stalls for reasons the player can never see.
It binds on a template with no authored cast at all — every shipped template in v1 — so
the pass's neutrality claim widened honestly from "no cast" to "no cast **and** no
anchor", pinned by its own paired negative arm.
