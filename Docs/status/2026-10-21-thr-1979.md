# THR-1979 — Five small faults from cold playtest round 4

**Shipped 2026-10-21.**

1. **The rail's cards carry the gift's names.** `buildHandCard` titles a row with `playerFacingTemplateName` (spell name, else name), the rule the gift modal and the cast drawer use. The hand now reads "Agent Thread / Piercing Gaze / Place Thread", the same names the opening modal gave. Rows sort by that shown name.
2. **A rail card no longer opens the Codex.** This was already fixed on main by THR-1914 (Inspector S6, f5b9d891): GameView provides `arming.handPress`, so a press arms the card. No change here.
3. **Map icons stay visible after a rebuild.** The scene rebuild (it reruns when `locations` / `realmProjection` change during play) builds the signifier, location and city-model groups hidden. `useZoomLayerVisibility` now reruns on `sceneEpoch` as well as zoom, and so do the three location-tier sync effects (anomaly, rarity, reach-signature signifiers). A jsdom hook test fails without the fix and passes with it.
4. **Restraint cards say "stand back".** "Stay your hand" choices in five authored encounters (page beneath the saint, comet at the turning, granaries, verdict that burns, mason lord's wall) were `supportive` ("lend strength"); they are `withdrawn` now. A content invariant over every authored card pins it. Corrected the stale comment in `interventionStanceWords.ts`.
5. **The plague scene paints the plague ward.** `selectDilemmaScene` weights each content tag by how often the prose names it (`countDilemmaContentTags`), so AX-VEIL-02 (plague ×2, one "burning" remedy) draws `scene.plague-ward` for every seed.

**Evidence.** `npm run gate` PASS (test, typecheck, build, encounter, god-cards, ui-debt, cli-smoke). Browser (bash-vite on :5247, Playwright, 1920×1080): rail rows read the spell names; `snapshotScene().layersActive` keeps `signifiers` and `locations` after `__DEBUG.tick(60)`; 0 console errors.
