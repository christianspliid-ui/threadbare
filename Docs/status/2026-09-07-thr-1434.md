# THR-1434 — what the player sees of a mortal's work

**2026-09-07 · UI (codex, roster, sheet) + Engine (the deed) · project Thematic Pressure & Living World**

THR-1404's ruling: the sheet shows what a mortal is *up to*, never what they *could do*. Capability lives on a generated codex page; the roster says what each mortal is doing; the ledger names deeds.

## The three surfaces

- **The Undertakings codex section** (`?view=codex`, `src/components/Codex/undertakingCodex.ts`): one card per **live** cell, built from the same registry (`UNDERTAKING_CELL_TEMPLATES`) and the same curated notes (`scripts/undertaking-grid-dispositions.ts`) the designer wiki page reads — 49 cards for 49 live cells, the rail grouped by verb. Each card: the plain phrase, the kind's glyph, the cell in the game's own voice, *who tends to do it* (the callings whose derived spread includes the cell under the division rule — `src/data/division-rule-tables.ts`, THR-1398's tables ported to `src/data`, never hand-listed), *counter-play* (the cell that undoes it, when the grid has one), and whether it needs a reason. `validateUndertakingCodex` fails by name on a cell without a phrase, glyph, lexicon line or note; the live catalog degrades that to one warning.
- **The roster's doing-line** (`ThreadsPanel`): `activeProject.doingLine`, composed once in `getAgentStrategicSummary` — *raising a company at Hawkgate — just begun*, *watching the Old Ruin — going badly*. The verb's gerund on the object the world names (a create cell reads on its kind with an article, at its site), then the trouble word (`getUndertakingTroubleWord`: faltering · going badly · all or nothing) or the progress label. What they hold reads *holds the Old Mill and more*, never a count. Nothing under way renders nothing; no "idle" label.
- **The ledger** (`JourneyTab`'s arc strip): the lifecycle names each finished cell's deed once (`describeDeed`, `src/engine/undertakingDeed.ts`) — `{ verb, word, objectName, objectRef?, phrase }` — on the history entry and as `refs` on the completion event (Law 2, the producer declares). The strip renders *Founded the Saltway.* with the verb word's tooltip (`ui.verb.*`) and the object linked where a page exists (agent → the sheet, location → the place); a kind with no page (a cured fever, a sealed art) is named, not linked. Per-cell deed words where the verb reads wrong (`Cured`, `Sealed`, `Learned`, `Slew`, `Razed`).

## Measured, and left honest

- The division rule reaches every live cell with at least one calling on the shipped tables? Measured: the test allows up to a quarter unclaimed and reports them by name — see the test output on the ticket.
- **The chronicle line's link:** no chronicle surface renders links from a `TickEvent` today (the hex chronicle's event block is label + text). The completion event now carries `refs`, so the first surface that renders references can link the object without parsing English; the sheet's ledger is the reader that shipped.
- The disposition notes are designer prose naming code symbols; the card's *what it does* is the lexicon's own GM line with generic slots instead, which is the game's voice (Law 14). The notes stay on the designer wiki page.
- The roster's trouble-word arm is proven in the unit test; the browser run showed the progress arm (a halt needs a failed checkpoint to land first).
