# THR-1224 — Doctrine v2 tooling: the machines now measure the doctrine

**2026-08-25** · [THR-1224](https://linear.app/threadbare/issue/THR-1224) · Encounter Experience

Prose Doctrine v2 landed as *text* on 2026-08-25 (PR #1606). This aligned the machines to it —
budgets, detectors, the brief-stage rolls, and the card face — so an author writing to the
doctrine is measured against the doctrine rather than against v1.

## What shipped

**The budget table is now a transcription.** `NUDGE_WORD_BUDGETS` is the doctrine's § *Word
budgets* table, row for row: `opening` 80, `factorLine` 12, `bandBase` 60, `bandFragment` 25,
`effectLine` 25, `name` 4. Two rows changed shape. `scene: 60` became `opening: 80` — the field
was named for v1's scene prose and had exactly one consumer, which measured `template.openings`,
so the row now says what it always measured. `fiction: 30` is gone, because a budget on a field
nothing draws can only produce work with no reader.

**Two new warn-level checks** (`src/data/content-eval/doctrineV2Checks.ts`): the opening
skeleton (2–4 paragraphs, within budget, P1 names a place through a sanctioned surface) and the
card-name shape (imperative verb + noun). Both are register judgments, so both warn and neither
gates.

**`check:encounter` prints a warn channel it used to discard.** This is the load-bearing part.
`auditTemplate()` has computed a `warnings` array since THR-1092 and the script dropped it on the
floor — so the one channel for "worth a human's eye, not a defect" reached nobody. The doctrine's
entire budget table is warn-level; adding it to a silent channel would have shipped six rules
that cannot report.

**The Seed Dice roll** (`src/data/content-eval/seedDice.ts`, surfaced through `npm run
draw:hooks`). Five tables — stake shape ×8 with its P2 requirement and closing format,
opposition ×8 with motive and activity sub-rolls, disposition ×5, agent's role ×7, scale ×4 —
each a `drawFromTable` call under its own table id, seeded off the brief slug so a recorded roll
is recomputable by anyone who doubts it. `--coverage` grew a stake-shape column showing which
shapes the spent hooks have been pulling toward.

**The flavor quote is retired from the card face.** `NudgePhaseShell` was the only surface that
ever drew `StepNudge.fiction`; it no longer does. A card is name, effect line, cost, odds.

**All 37 library card titles are imperative** — "Widen The Swing", not "The Wider Swing". Ids did
not move, which is what made a bulk rename safe: every template referencing a member through
`libraryCardId` was untouched.

## The finding worth keeping

The prior run on THR-1223 recorded that `check:encounter --all` **exits 0 on the un-rewritten
corpus**, with a green tick beside `encounter.border.the_unclaimed_relic` — the exact template the
director called *"borderline unreadable"*. That made "check:encounter green" satisfiable before
any work was done.

It still exits 0, and that is correct — these are warn-level rules by ruling. What changed is that
it now *reports*: **302 warnings across the corpus**, and on the calibration template specifically,
every opening flagged as one paragraph with no place named in P1, plus six card names flagged
including `A Little More` — the doctrine's own worked example of a wrong name.

So a green `check:encounter` is not evidence a template holds doctrine v2. Read the warn lines.

## What was deliberately left out

The ticket's sixth scope item — stripping the ~150 authored `fiction` strings from the corpus —
edits `src/data/encounters/*.ts`, the same files the doctrine-v2 rewrite (THR-1223) rewrites line
for line. That is the one place THR-1224's stated mutex reason (*"strips `fiction` and renames
library cards in files the rewrite edits"*) is genuinely applicable, so it was split to
[THR-1225](https://linear.app/threadbare/issue/THR-1225) rather than shipped or skipped silently.

The library rename was *not* split, because the same reason is verifiably inapplicable to it:
`NUDGE_CARD_LIBRARY` lives in `src/data/nudge-card-library.ts`, its own module, which THR-1223
does not touch. Template-level card names — which THR-1223 *does* rewrite — are a different
surface in different files.

`NUDGE_NAME_MAX_WORDS` also stays at 6 while the doctrine target is 4. The two are not drift: 6 is
the hard clamp (past it a label stops fitting its face), 4 is the register target reported as a
warning. Lowering an error-level cap under an un-rewritten corpus would turn a green corpus red
for work ticketed elsewhere — the clamp follows the corpus, never leads it. THR-1225 tightens it.
