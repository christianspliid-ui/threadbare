# 2026-09-26 — THR-1618: The Builder's Legacy no longer starts complete

**Ticket:** [THR-1618](https://linear.app/threadbare/issue/THR-1618) · **Project:** Thematic Pressure & Living World · **Plan:** none (self-scoped bug, found by THR-1595) · **Pillars:** Engine + Content. UI N/A (no surface changes; the mandate tracker reads progress, which is now correct).

## What shipped

1. **`edge_count` can scope itself to the mandate's start.** A new optional param, `sinceMandateStart: true`, counts only edges stamped `properties.tick >= MandateState.assignedTick`. An edge without a numeric `tick` predates the mandate and is excluded. Every worldgen `constructed_by` edge is tickless, and both runtime writers (`createSublocation`, `createLocation`) stamp `tick`. `evaluateMandate` passes `assignedTick` through a new optional `context` argument on `evaluateCondition`. Unscoped conditions count exactly as before.
2. **`builders-legacy.json` uses the scope** on all three stages (2 / 5 / 8 builds).

**Scope choice:** "builds since the mandate started", not "builds by the ascendant's threaded or bonded agents". The start tick is already recorded (`assignedTick`), and the edge already carries its tick. An actor scope would need a thread/bond walk per evaluation, and it would stop counting builds the god inspired through unbonded mortals.

## Evidence

- Unit test `mandate-builders-legacy-scope.test.ts`: on a generated seed-42 small world, setup is at progress 0 at t0. It stays 0 after one `createSublocation` build and reaches 1 after the second. It also checks that unscoped `edge_count` still counts tickless edges.
- CLI, seed 42 medium: t0 has 166 `constructed_by` edges, 0 of them scoped, so setup is unmet. At t30 there are still 0 organic builds. After 2 runtime-shaped builds at t5, 2 are scoped and setup is met.

## Remaining

The mandate templates are a catalogue since THR-1198, and no live run instantiates them. The bug was latent, and this fix keeps the catalogue honest for the CMS view and any future instantiation.
