# 2026-10-15 — THR-1822: the view-model seam (slice 1)

**Ticket:** [THR-1822](https://linear.app/threadbare/issue/THR-1822). Screens should read prepared view data from the engine, not query the world graph inside React. Slice 1 (plan § D16 step 1) builds the seam and moves the map's data onto it. Nothing on screen changes. Engine: the seam, the hex contents index, the map selectors, three out-of-tick writes. Content: N/A (no new words). UI: GameView reads the map through the seam.

- **The seam.** New `src/engine/views/`: `readView()` caches each view model per session on `SimulationRuntime.viewCache`, keyed on `worldVersion` or `structuralCacheVersion` (never graph identity), and returns the same object while the entry is valid. A build that throws returns the selector's typed fallback and traces `view_fallback` once per key. The cache holds at most `VIEW_CACHE_MAX_ENTRIES` (128) entries. Every selector is one entry in `VIEW_SELECTORS`.
- **The map moved.** Agents, thread lines, companies, activity icons, place icons, armies and battles/sieges, and the Dominion lens now come from `views/map/*` and `views/lenses/lensView.ts`. The scene's paint (heraldic colours, army size default, icon keys, the avatar's portrait and sigil) is applied after the read by `components/Game/map/mapViewAdapters.ts`. A heavy-lane golden test compares each selector with a verbatim copy of the GameView memo it replaced, on a 40-tick generated world. The two match exactly.
- **Hex contents index.** `views/hexContents.ts` gives people (by `buildHexActorIndex`'s rule), Locations and visible Places per hex. The land page, *In this land* and Find will read it.
- **Out-of-tick writes bump the world version.** `recordJourneyChoice` (journeyEngine), `recordStoryBeatDismissed` (phaseAttention) and `markBackstoryRead` (retinue) replace three graph writes in UI code. Each ends in `touchWorld`, so a cached view model updates while the game is paused.
- **Ratchet.** `graph-query-in-ui` (173, down from 197) and `graph-write-in-ui` (0) are rows in THR-1821's UI-debt ratchet.
- **Glue and debug.** `ViewSourceContext` and `useView` give components below GameView access to the seam. `__DEBUG.getView(id)`, `listViews()` and `getViewCacheStats()` return what the map was given.
- **Kept in GameView:** the activity-by-hex memos. They are a re-key of `useLocationActivities`, make no graph call, and read the fog-off visibility proxy, which is not part of GameState.
