# 2026-09-26 — THR-1617: a mortal who cannot cast is no longer offered "create a power"

**Ticket:** [THR-1617](https://linear.app/threadbare/issue/THR-1617) · **Project:** Thematic Pressure & Living World · **Plan:** none (self-scoped bug, found by THR-1595) · **Pillars:** Engine. Content N/A (no authored text changes). UI N/A (no surface shows proposal-time refusals differently).

## What shipped

1. **Create cells now reach their eligibility hook.** The candidate board consulted `UndertakingObjectType.eligibility` only when an object handle rode beside the target. A `create` cell targets its *site* (`CREATE_SITE_RULE`) and carries no object handle, so no create hook could ever run. The site now stands in as the handle — the same node the resolver's `ctx.handle` names at completion. No other type declares a `create` hook, so nothing else changes.
2. **Power's `create` hook refuses non-casters.** `POWER.eligibility.create` returns `not_a_caster` when `isCaster` is false. The board records `ineligible:not_a_caster:<actor>` instead of starting a ~40-tick study that the completion handler always refused. The completion-time check stays as the backstop.

## Evidence

Headless, medium map, 300 ticks, seeds 42 and 99. A throwaway harness wrapped `emitTrace`. The control arm deleted `POWER.eligibility` at load, which puts back the pre-fix behaviour.

| seed | arm | `create × power` starts | `power_learned` refused `not_a_caster` | board `ineligible:not_a_caster` |
|---|---|---|---|---|
| 42 | before (hook removed) | 2 | 2 | 0 |
| 42 | after | 0 | **0** | 90 |
| 99 | before (hook removed) | 5 | 4 (1 still running at t300) | 0 |
| 99 | after | 0 | **0** | 88 |

The control arm matches the ticket (2 and 5 starts). `knows_spell` edges are 0 in all four runs: every mortal who reached the cell on these seeds was a non-caster.

Unit tests (`dormantKindsPowersConditions.test.ts`, "THR-1617" block): a non-caster is refused by name on the board, a caster is offered the cell, and the hook agrees with the completion backstop.

## Remaining

Casters still learn no spell at t0 — whether they should is a design call recorded on THR-1595, out of scope here.
