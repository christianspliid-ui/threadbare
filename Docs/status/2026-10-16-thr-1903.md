# 2026-10-16 — THR-1903: carved places on the map

**Ticket:** [THR-1903](https://linear.app/threadbare/issue/THR-1903). UI pillar (the map's place icons); Engine and Content N/A (no world change; the shapes are THR-1904's).

Every place on the map now draws its carved icon in the map's near-black ink: a capital the tower and flag, a city the gate, a lair the cave entrance, and THR-1879's picks for the rest. The hand-drawn silhouettes are gone from `locationIconRegistry.ts`, which now holds only each type's size class.

- **One builder.** `buildMapIconTexture` in `locationIconTextures.ts` rasterises any `iconShape()` result: outline pass, then fill, scaled from the shape's own viewBox, so a 512-grid carved shape and a 100-grid drawing fill the same box. Lenses II (THR-1898) reuses it for badges and battle sprites.
- **256 px textures** (was 128), for the carved detail at close zoom. Size classes and the lair sphere tints and cleared-lair fill are unchanged.
- **Unknown type → fallback.** A place type with no map entry draws the empty-ring fallback at `small` and warns once, instead of nothing. `__DEBUG.getMapChrome().placeIcons.fallbacks` lists them.
- **Three places that were invisible now draw.** `elder_ruin`, `farmland` and `trade_route` had no map entry and were skipped silently. They now have size classes: farmland and trade routes draw their carved picks; elder ruins (delve sites) draw the ring until their shape is picked (THR-1908). Veto invited.
- **Law 58.** `placeIcons.coverage.test.ts` names a type missing a size class or a `PLACE_ICON` row and pins Christian's eleven shapes; `extending.md` has the row.
