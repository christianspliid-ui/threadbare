# 2026-10-06 — THR-1752: essence a god-act earns now counts toward attunement

**Ticket:** [THR-1752](https://linear.app/threadbare/issue/THR-1752) · **Project:** Onboarding & First-Run Experience · **Pillars:** Engine only (Content N/A — no data changes; UI N/A — the counter has no surface of its own beyond the unlocks it gates).

## Why

THR-1713's review gate found that the essence-earned counter (`applyEssenceEarned`, THR-1180) reference-compared the pool before and after each phase. `phaseUnifiedActionProgress` moves essence on the state object it was handed — self-casts reassign `state.essencePool`, the elder-site reward edits it in place — so after that phase the two pools were the same object and the counter banked nothing. Essence earned through god-acts never counted toward a `sphere_attunement` unlock.

## What shipped

- `applyEssenceEarned` takes an optional `poolBefore` (default `prev.essencePool`, so existing callers are unchanged) and diffs against it.
- Both phase funnels (`runInlinePhase`, `runRegisteredPhases`) pass the same by-value `snapshotEssencePool` copy THR-1713 already takes for the movement record.
- Tests run a real phase through `runRegisteredPhases` in both in-place shapes and assert the counter banks the rise.
