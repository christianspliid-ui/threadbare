### THR-1246 — `compile:encounter`: content package in, configured game content out (2026-08-25)

**The ask.** Christian, same sitting as THR-1245: can a script take the authoring agent's output and configure it correctly as game content, to save tokens and leave the agent's context for content substance? Investigation verdict: yes — as a **structured content package + deterministic compiler**, not a markdown parser (free-form md → code is an LLM task; the fix is making the authored artifact structured at the handoff).

**What shipped.** Pass 4 of the Encounter Factory stops hand-writing TypeScript. The implementation agent fills an `EncounterContentPackage` (JSON; prose verbatim, hands, aftermath, support bundle) whose `template` field **is** the real `UnifiedActionTemplate` minus the two derived fields — no parallel format that can drift — and runs `npm run compile:encounter -- <package.json>`. The compiler validates, then configures everything mechanical: emits `src/data/encounters/<slug>.ts` with prose byte-identical (round-trip pinned by evaluating the emitted literal and deep-equalling it against the assembled template), derives `locationSubtypes` via `expandSettings`, **stamps** the binding `consequenceDraw` from id + reach + rarity (hand-copying it is now an error), registers the template in both catalog arrays idempotently (with the THR-733 group-exclusive opt-out), and generates a structural test with this encounter's actual shape baked in.

**The context math.** Pass 4's required reading was the design doc **plus** `src/types/unifiedAction.ts`, two exemplar encounter files, the ~5,700-line registration file, and a test exemplar — schema-learning context paid per encounter, six times per batch. It is now the design doc plus a two-page schema card (`reference/encounter-package-format.md`). The transcription-drift class ("prose is verbatim", wrong union members, missed registration arrays) moves from agent discipline to machine behavior.

**The anti-allowlist design.** The legacy raw-entry converter's documented failure is a silent field allowlist that drops what it does not know. Here the polarity is inverted twice: unknown *top-level* package keys are loud errors, and unknown *template* fields are caught by TypeScript itself — the emitted file annotates a fresh object literal with the real type, so excess-property checking makes `check:typecheck` the deep validator, with no hand-maintained key list to rot. Semantic rules the type cannot carry (hand size 4–8, ≥4 spheres, ≥1 ungated common, ≤1 rider, failure-band coverage, big-delta both bands, envelope honesty, byOutcome keys on the seven-value union) reuse the shipped authoring constants and validators.

**The real-file test arm earned its keep during the build.** `UNIFIED_ACTION_TEMPLATES` turned out to be a *derived* export (`RAW_UNIFIED_ACTION_TEMPLATES.map(...)`), so the first registration implementation inserted into whatever array closed next — caught immediately by the test that applies `registerTemplateInSource` to the real registration file rather than only to a mini fixture. The compiler now targets the raw array, and that arm guards against future landmark drift.

**Verification.** Code track. 1070 files / 17,746 tests green (exit 0 read off the process; 26 new in `encounterPackage.test.ts` including the falsification arms); ratchet OK at 3012 unchanged; `vite build` ✓ 11.07s. **Live proof, full loop:** a demo package compiled end-to-end — files written, both registrations made, `consequenceDraw` stamped `[drive, place]` — then `check:typecheck` held baseline *with the compiled demo in the tree* (the emitted file contributes zero errors), the generated test ran 4/4, and the headless CLI spawned the compiled encounter on the ascendant and resolved it (`resolved:success_at_cost`); demo then reverted before commit. No engine files touched; browser-verify exempt (no UI-pillar files).

**Boundary stated honestly:** the compiler configures; it does not judge. Editorial critics, the Composition Contract (`check:encounter`), and the live proof (`check:encounter-live`) still own content quality and completeness, unchanged.
