# Nudge library completion — the guidance widened, the corpus authored (THR-1178)

**Shipped 2026-08-18.** Workstreams A and B of the four-workstream plan. C (the nine unbuilt card mechanics) is THR-1179; D (sphere attunement) is THR-1180.

Christian's direction was that the nudge framing over-constrains: *"the god is a magical being of great power that manipulates the threads of reality in different ways based on what spheres they have."* The system already agreed — the 21-type library spans mind (Compulsion), time (Omen), spirit (Kindled Ambition), darkness (Undertow), life (Balm). The **guidance** did not, and guidance is what drafts inherit.

## A — the framing was half a rule, and only the second half was written down

*"The god acts in the physics of the scene, never in the dramaturgy of the story."* The clause that does the work is the second one — never author the ending. The first clause was never a rule at all; it was one sphere's **example** that hardened into a constraint through repetition, and it had propagated verbatim to six surfaces. The replacement keeps the prohibition exactly and widens the range:

> **The god acts through their spheres on the fabric of the scene — matter, minds, dreams, fates — never in the dramaturgy of the story. Influence, never authorship.**

Every surface's example set now spans ≥3 non-physical sphere modes — an urge arriving in sleep (mind), a sense that this has happened before (time), an old ambition catching light again (spirit), a face nobody afterwards quite recalls (darkness), a wound that closes cleaner than it should (life) — against the previous sets, which were physical in four of four examples.

Six surfaces closed: `Docs/canon/encounters.md`, `encounter-pipeline/SKILL.md` (framing, the player-as-god constraint, **and** rejection trigger 14), `template-encounter-rewrite/SKILL.md`, `reference/nudge-authoring-spec.md`, and the UL shard `Docs/ubiquitous-language/Encounters.md` — which the plan did not list and which is the **terminology authority**, so leaving it would have left the widened rule losing every disagreement it entered. `grep "physics of the scene"` now returns plan-archive hits only.

**The spec got the failure mode stated in both directions**, because a widening that only says "wider" invites the opposite error. A hand reaching only for physical causes is authoring a twelve-sphere game in one sphere's vocabulary; a hand reaching into the mortal's decision *for* them has crossed the actual line. The test is never how physical the cause is — it is whether the mortal still chooses and fate still rolls. Trigger 14 says so on its own line, since it is the clause a critic reads while deciding to reject.

## B — 34 faces, and the count in the plan was wrong

The plan said 37 unauthored; the predicate (`title === undefined || quote === undefined`) resolves to **34**, which is the number that governs (THR-688 rule A). `unauthoredCardCount()` now reads **0**.

**Content is a separate table joined at assembly**, not fields on the member literals. Sections 1–2 of the library are *generated* from `UNIVERSAL_CORE_TYPES` and `SPHERE_SIGNATURES` — hand-typing 19 members back out to hang prose on them would have reintroduced precisely the drift surface that generation exists to remove. So `CARD_CONTENT` is keyed by member id and `withContent()` joins it in the assembly expression; the tables still cannot disagree.

Three rules governed every face, and the mechanical half of each is now a test: **genericity** (a face must read wherever its type deals — scene grounding is the prose's job, the card's job is the rule), **sphere voice** (a signature member reads as its sphere's mode of power; an `omen` card sounds like time — *"Nothing happens only once."* — not like a recolored boost), and **interactive-plain titles** (2–4 words, unmistakable, no metaphor; the quote is the one element allowed a dry line).

`imageTag` is absent on all 34 deliberately: the image library has no card rows to bind to, so every face falls back to its type's generic art — the documented chain, not a gap. Minting card art slots is THR-832/THR-1170's.

## The test that had to be deleted was the interesting one

`'an unauthored card is legible — it reads as its own keyword'` asserted that **at least one unauthored member exists**, then drew its exerciser from the library. Authoring the corpus falsifies it by construction — the test was pinned to the pre-B state, so completing the work *breaks* it, which is the correct behavior and the reason it could not simply be updated in place.

It is replaced by four rows, and the fourth is the one that matters: the keyword fallback is still live and still needs coverage, but the library now holds **no example of it**. Drawing the exerciser from the corpus would have made the test silently vacuous the day the corpus completed — the standing *vacuous probe on an empty population* shape. It uses a synthetic member instead, so the fail-soft path is tested by something that cannot be completed away.

The other three pin the corpus (`unauthoredCardCount() === 0`, reporting *which* card lost its face), the format (2–4 title words, one-line quote ≤80 chars), and distinctness (no shared title or quote). **The format guard was falsified before it was trusted** — shortening one title to `'Boost'` reds it by name; restoring returns 40/40 green.

The authored test also asserts the **render path**, not just the data: every member's `cardDisplayTitle()` returns its authored title *and* no longer returns its type keyword. Asserting presence alone would have passed with `withContent` dropped from the assembly.

## Scope held

`NUDGE_CARD_TYPES` rows were left alone — status flips are THR-1179's and the file is mutexed on it. That leaves one known cosmetic drift: `stumble`'s `effectShape` reads *"**Physics** turns against the scene's opposition"* on a **chaos**-signed card, which is the same skew A corrects, one layer down. It is a mechanic description rather than authoring guidance, and rewording it here would collide with C's edits to the same rows for no behavioral gain.

`Docs/authoring-brief.md` needed no regeneration: its sources are the wiring guide and the direction doc, neither of which carries the framing. Its hardcoded Sections D/E do carry **pre-nudge-pivot** vocabulary ("approach cards", "god-verbs whisper / send vision / steady / strengthen / withdraw") — real drift, older than this ticket and not in its predicate, filed as **THR-1185**.
