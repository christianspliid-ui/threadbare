# THR-1285 — Two ambition vocabularies, one node type, no way to tell them apart

**Shipped 2026-08-26.** Engine pillar. Bug, filed off the THR-1277 field survey.

## What the ticket said, and what was actually true

The ticket's measurement was right: 13–14 `pursues` edges per run point at ambition nodes
with no `properties.templateId` (14 of 214 on seed 42 at tick 100; reproduced before any
code was touched). Its stated *consequence* was not. The ticket read those as agents whose
"drives resolve to nothing" — "ambition-less in practice while appearing ambitious in the
graph."

They are not agents. Every one of those edges originates from an `actorType: 'faction'`
(13) or `'group'` (1, an army) actor — **zero** from individuals. And both readers the
ticket named filter to `actorType === 'individual'` *before* the `templateId` read
(`ambitionTick.ts:287`, `phaseAgentDecision.ts:287`), so the fail-soft skip they were
blamed for is unreachable by construction for those edges. No agent lost an ambition.

The reason the survey read them as broken is the real defect: `type: 'ambition'` carries
**two incompatible schemas**, and nothing on the node said which one you were holding.
Template ambitions (`ambition.<templateId>`, 6 writers) key into `AMBITION_TEMPLATES`.
Faction ambitions (`amb_<factionId>_<tick>`, 4 writers) key into the closed six-value
`FactionAmbitionType` union — which has **no template registry at all**. So the only
available test, "does it have a `templateId`?", reports every healthy faction ambition as
a broken agent ambition. Stamping a `templateId` on them, as the ticket's step 1 asked,
would have invented an id with no referent.

## What shipped

**`src/engine/ambitionShape.ts`** — the discriminator, on the `sublocationShape.ts`
(THR-1183) precedent, which is the same failure class: readers hand-rolling their own
test and each seeing half the world. `ambitionKind` is stamped at creation by all 10
writers (never a post-hoc repair sweep — the ticket was right about that), with payload
inference as the back-compat read path for worlds saved before the stamp. A node carrying
neither key classifies `'unknown'` rather than being laundered into either set.

**The tripwire.** Both individual-actor readers now ask the module instead of reading
`properties.templateId` directly, and emit one `ambition_progress` trace when an ambition
cannot be evaluated — distinguishing wrong-vocabulary (`faction_kind_ambition`) from
corrupt (`missing_template_id`, `template_not_found`, `unclassifiable_ambition`). The
skip stays fail-soft (NFP #4); the trace is what makes the class visible (NFP #2).

Expected volume in a healthy world is **zero**, and that is stated in the module rather
than implied — a 120-tick seed-42 run emits none. It is a tripwire for a class that has
never occurred, not an instrument for the 14 edges, which it structurally could never see.

**No `node_missing` branch.** The first draft had one; it could not be tested, because
`addEdge` refuses a dangling target and `removeNode` cascades incident edges, so a
dangling `pursues` edge is unreachable through the graph API. The branch was removed
rather than shipped untestable, and a test now pins the invariant it rested on — if a
future change relaxes write-time referential integrity, that test fails and the tripwire
is owed again.

**`AmbitionProgressTrace` declared** (`src/types/trace.ts`). `ambition_progress` had been
in `TRACE_CATEGORIES` since TB-062 with no declared payload, so it was absent from the
`TraceEntry` union and all three of `ambitionTick`'s emit sites were type errors sitting
in the THR-489 baseline. Declaring it is the same fix THR-1175 applied to
`secret_discovered`/`favor_created`, and for the same reason: it removes those three
rather than adding a fourth. Baseline moved **3009 → 3008**.

## Evidence

| Predicate | seed 42 | seed 99 |
|---|---|---|
| Ambition nodes carrying no `ambitionKind` | 0 | 0 |
| `pursues` → template-kind node lacking `templateId` | **0** | **0** |
| `pursues` → node lacking `templateId` (ticket's literal predicate) | 14 | 15 |
| Tripwire traces emitted in a 120-tick run | 0 | — |

The literal predicate stays at 14 **by design** — those are faction ambitions, and driving
it to 0 requires inventing template ids. The corrected predicate is the one that means
what the ticket meant, and it is 0.

Full suite 18247/18247, `check:typecheck` OK, `vite build` OK, 30-tick engine smoke OK.

## Left standing

Ambition nodes are still shared singletons (10 template nodes pursued by ~200 actors).
Whether they should become per-agent instances is owned by the Proactive Agent Actions
wayfinder map, and the ticket explicitly scoped it out; node identity was not touched.
