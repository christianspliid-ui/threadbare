# THR-2161 — The last player picks go

**Shipped 2026-11-05.** Encounter Experience, slice 5 of 5 from the THR-2135 decision, the closer. Pattern: the THR-866 Apotheosis conversion (`Docs/plans/2026-08-11-thr-866-apotheosis-nudge-conversion.md`), as THR-2157 applied it to Flawed Steel's three routes.

The player no longer picks an ending anywhere in the game, and the build now checks that.

| Template | Was | Now |
|---|---|---|
| `mentorship.the-offer` | three step-1 player cards keyed to the endings | step 0 decides in route mode: `steady_their_nerve` (Heart, loyalty +), `let_them_choose` (Stone, prudence), `whisper_the_cost` (Eye, revelation +) |

1. **Mentorship.** Route keys are the old variant keys, so aftermath keys stay. `aftermathConfig.branchOnStep` moves 1 → 0 (the deciding step, THR-979). Step 0 deals one card per route plus `deal: { count: 2 }`; step 1 is an `ActionStepBranch` whose three arms are re-voiced so the apprentice acts. Aftermath overviews that said "the god steadied / chose / watched" now say what the apprentice did. `stakes.arms` covers the two non-fallback routes.
2. **Field and pick path deleted.** `UnifiedActionTemplate.authoredChoices` and `AuthoredChoiceCard` are gone. Also removed: the override in `phaseEncounterVisibility`, the stage's authored-card builder, the authored lookup in `resolveInterveneChoice` (now a plain notification lookup), the check in `stepOffersPlayerMove`, the prose-QA sweep of card intents, and the forward contract adapter's authored output. The 24 local lite-contract builders (and the shared one) drop their dead choice-mapping helpers; output is unchanged, since every template already took the fallback-choice branch.
3. **Invariant.** `assertNoRetiredPlayerPickField` (`src/testing/contentInvariants.ts`) runs inside `assertValidUnifiedTemplate` and catalog-wide in `contentInvariants.test.ts`, with a negative control. Per-template "no authoredChoices" assertions now call it. `assertAuthoredChoicesPriced` and the authored-card UI probes (stance, unpriced card, veil stance, restraint stance) went with the field.
4. **Done-when 1.** `grep -rn authoredChoices src`: every hit is a comment recording the retirement, except the guard's own name constant (`RETIRED_PLAYER_PICK_FIELD = 'authoredChoices'`), which Done-when 2 requires.

**Gate.** `npm run gate`: test, typecheck, build, encounter, god-cards, ui-debt and cli-smoke all PASS (track=code, engine=yes). Typecheck ratchet 2661 → 2657.
