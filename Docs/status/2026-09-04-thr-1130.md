**Game design done in the brief, per the new order.** The consequence hand for each of the
six was rolled with `draw:consequences` and recorded — the gate re-derives each hand from
the template id and fails a mismatch, so this is a claim the gate audits rather than data

the generated anchor catalog and its declaration forms. The hands land on `secret`+`place`,
`thread`+`omen`, `drive`+`movement`, `story_seed`+`movement`, `possession`+`knowledge`, and
`membership`+`omen` — which forces `omen` twice, a `place` write with `targetLocationId`,
`condition` wiring, `membership`, `movement` and `knowledge` into a corpus the portfolio
assessment measures at one omen emitter and one condition user. **Repair, run honestly,
closes gaps that portfolio growth was going to have to close later.**

**Hooks and dice were deliberately not rolled**, with the reason recorded: they exist to
constrain invention, and a retrofit invents no premise. Rolling them would have produced
candidates the batch is forbidden to use. What carries over is the opening skeleton, the
≤80-word budget, and rule zero — with each rewritten opening naming its P3 stake shape so
the batch report can show stake variance mechanically, the dice as vocabulary rather than
generator.
