**2026-09-04 — THR-1391 (UL-proposal): the motive gate's second word gets a definition.**

The gate has named `rivalry` on every decision board since THR-1297 and the UL had no such word, while the **Grudge** entry defined *every* provenance-stamped `hostile_to` as a grudge that "never fades". Two systems disagreeing silently about the same edge is the gap this proposal existed to close, and closing it took writing the definitions **from the engine as shipped rather than from the proposal** — which is where the interesting divergences were.

**Three deliverables, all landed.**

- **Rivalry** (new, `Agents.md`) — the non-injury reading of `hostile_to`. Defined by *exclusion*: the gate reads provenance from all three keys its writers use (`cause`, `reason`, `basis`) and asks one question — is the value in `GRUDGE_PROVENANCE`? Everything else is a rivalry, **including an edge carrying no provenance at all**. So the term already covered four live cases before this ticket named it: a covet (`cause: 'covets'`), an excommunication (`reason: 'excommunicated'`), a quarrel opened by an undertaking's *destroy* on a standing (`cause: 'quarrel'`), and a notable's declared feud (no key at all). The proposal described a two-way carve-out; the shipped predicate is wider than that, and the entry says so.
- **Covet Rivalry** (new, `Agents.md`) — the rivalry the world writes from frustrated wanting, with the counter-as-property-becoming-an-edge model, `COVET_SWITCH_BELOW`, the one-refusal-per-owner-per-board rule, the bound of one live edge, and the ascendant / own-faction / fellow-member guards.
- **Grudge** (amended) — gains the carve-out and two corrections it forced.

**Three places the shipped code and the proposal disagreed, resolved toward the code.**

1. **`covets` is not a fourth `GrudgeCause`.** The ticket said the closed-set clause "gains `covets`". It does not: the writer types it as a *sibling* `CovetCause`, and `GRUDGE_PROVENANCE` was deliberately left unextended — that omission is the entire mechanism keeping a covet a rivalry. Writing it as the ticket described would have documented the opposite of what ships.
2. **A covet rivalry is one-directional.** `writeGrudge` writes both ways because being wronged is a fact about the pair; `writeCovetRivalry` writes only actor → owner, because wanting what someone holds is a fact about the wanter. The Grudge entry's bolded **bidirectional** is now scoped to grudges, and Rivalry carries the directionality note — the gate only ever reads the actor's *outgoing* edges.
3. **"It never fades" is a substrate fact, not a design decision.** Nothing anywhere in the engine removes a `hostile_to`. The clause is re-grounded on that, so it stays true of grudges and becomes true of rivalries by the same rule rather than by a second assertion. No TTL or decay is documented anywhere: the plan dropped its TTL on the intent judge's finding that the "grievance-cooling sweep" it was going to ride is a *write*, not a removal, and an entry describing a decay the engine does not implement would be exactly the drift this ticket closes.

**The census, measured rather than asserted.** The footer's own warning has now come true four times, so the mandated recount ran both directions with the real `slugifyHeading`: **177 headings, 177 index anchors, zero unindexed, zero dead** — 169 canonical, 5 deprecated, 1 proposed, 1 rejected, 1 retired; Agents 49 → 51. The first pass of that diff reported three terms seated-but-unindexed (`reputation_set`, `standing_welcome`, `located_at-edge`) and all three were a **false alarm in my own probe** — a hand-rolled anchor regex of `[a-z0-9-]+` that cannot match an underscore, the same family of error as the hand-rolled slugifier the footer already warns about. The footer now warns about the anchor pattern too.

**Status-line convention.** Both entries use bare `**Status:** canonical` with provenance one line into the body, per the convention impediment #966 settled the day before: the annotated form spreading by imitation is silently mis-rendered by the dashboard's exact-match parser. Written the annotated way first, the two entries would have become instances 11 and 12 of that defect; instead the generator's `missing_status` warnings went **26 → 22**.

**Not done, deliberately:** the proposal asked for a cross-reference "from Motive gate", and no such term is seated. Rather than invent one, the motive-gate cross-references hang off **Undertaking Verb** — which already said "lower, seize and destroy are motive-gated" without ever saying *gated on what* — and that sentence now names all four motives. A `Motive gate` entry is a real gap but a separate proposal, not scope to absorb here (the THR-1390 precedent: seat a term beside siblings that exist, and file the missing sibling separately).
