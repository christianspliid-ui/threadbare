# THR-1394 slice 2 — the cheap drifts landed (closes THR-1394)

**2026-09-03 · engine + content + docs.** The catalogue slice 1 ratified now has the code shaped to it. Every drift the map measured that could be fixed without a design fork is fixed, and the ticket closes.

## What changed

- **Items carry their category.** Every artifact mint — the reward catalogue, the anomaly rewards, the starter attachments, the worldgen relics, the ascendant beat seeds, the consecrated relics, the strategic mints — stamps `attachmentCategory: 'possession'`; the Item kind *refines* that value on `subcategory`, and the census now counts the key, so an artifact carrying a category no kind claims surfaces as UNREGISTERED like any other value.
- **One event kind key.** The faction quest and bounty nodes write `eventType`, the key every other event writer uses, not `nodeSubtype`; the test and the three `edgeSchema` descriptions moved with them.
- **Two node types retired.** `resource` (no writer ever; resources are stocks on a Location, Deposit is a Location class) and `relationship` (never minted; a relationship is the `relates_to` edge) left the `NodeType` union with every reader repointed: the entity-visual resolver, the composition node list, the target-context union, the `controls` / `owns` schema rows, the relationship resolver (edge only now), the encounter-cache debug view, and four tests. `cosmology` stays DORMANT — its two `contextBuilder` reads are dead in a live world and repointing them is its own ticket, not a green-test flip.
- **Routes know their kind.** A `road` edge carries `routeKind` (`road` for a major road, `trail` for a trail), stamped by the road network beside `roadType`.
- **The helpers speak the game words.** `isLocationNode` / `isPlaceNode` / `getLocationNodes` / `getPlaceNodes` replace the code-word names across 33 source files and the live docs; the old names survive one release as deprecated aliases so a branch cut before the rename still compiles.
- **The deferral is filed.** Conditions and experience as `has_trait` edge state, not one trait node per bearer — [THR-1395](https://linear.app/threadbare/issue/THR-1395), with its coordination block.

## What is next

THR-1392 slice 4 resumes on the catalogue: the undertaking object types redrawn as Location (with classes), Place, Route, Item · Condition · Power · Agreement, Standing; then the retirement list, the migration and the flip.
