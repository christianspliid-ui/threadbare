# THR-2028 — the world tilt reaches a place

**Shipped 2026-10-25.** The THR-1843 census found that an account's tilt changed the cosmology profile but no place's sphere scores: place scores come from the hex terrain table plus the location-type bonus, and nothing in that seeding reads the profile. So the next world never leaned toward the old god's spheres on the map.

**Fix.** When a carried World-Soul shapes the world, `initializeGameState` now bends every place's seeded scores (both tiers) by `placeTiltFactors(fundament)`: each sphere's Decided-8 world factor scaled toward 1 by `PLACE_TILT_GAIN` (`src/data/account-content.ts`, 0.05). Scores stay whole numbers: `tiltSphereAffinity` (`src/engine/sphereAffinity.ts`) rounds the fraction up with its own probability on a seeded stream (`PLACE_TILT_SEED_OFFSET`). A plain round turned the tilt into a cliff: on seed 99, two nearby gains went from +0 to +14 Touched places. One trace per world creation, `account.places_tilted` (places shifted / places seeded). No carried fundament → no factors, no draw, no trace: today's world byte for byte. An even fundament → every factor 1, nothing changes.

**Tuning.** With the multiplier at full world strength (gain 1) the tilt added +14 to +63 Touched-or-better places, so the kill criterion tripped. The swept gains, Touched delta after 5 runs (seeds 42 / 99 / 7): 0.03 → +3/+3/+1; **0.05 → +4/+5/+2**; 0.08 → +7/+8/+7. 0.05 is the largest gain that holds the kill criterion on all three seeds. Seed 99 sits exactly at +5.

**Census at 0.05 (tick 0, `--map medium`, Life/Spirit god).** Place `life` sums. Seed 42: 172 even-fundament echoes → 172 sample account → 176 after 1 run → 191 after 5 runs. Seed 99: 253 → 254 → 257 → 269. Seed 7: 229 → 230 → 230 → 238. Touched-or-better: 42 → 43 → 44 → 46; 54 → 55 → 55 → 59; 53 → 53 → 54 → 55. The sample record is one faint run, so its lift is a point or less on some seeds.

**Evidence.** `src/engine/__tests__/worldTilt.test.ts` runs the census and asserts the life sum moves, 5-run ≤ +5 Touched, and that the trace is absent without an account. The existing account and echo suites pass unchanged, so the no-account world is unchanged. `npm run gate`: test, typecheck, build, encounter, god-cards, ui-debt and cli-smoke all PASS.
