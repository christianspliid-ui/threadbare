- **Icon registry.** `src/data/icons/iconRegistry.ts` holds the format (`meaning`, `shape` as path data, `source` game-icons or own), the `IconName` type, one own-drawn `fallback` mark and `ICON_CREDITS` as a function of the registry (empty: no game-icons shape is vendored, so no credits line is owed yet — THR-1879 / THR-1904 vendor the set with it). `shared/iconShape.ts` is the one resolver; an unknown name draws the fallback and warns once.
- **`Icon`** — named sizes (14 / 18 / 24 / 34 px in rem), `currentColor`, and a props union: `decorative` or `label`. An unlabelled meaning-bearing icon is a type error (`@ts-expect-error` fixtures).
- **`Chip`** — four roles. identity routes through the ref router and reads as text on a dead ref or with no router; state always shows the word; count renders nothing at zero, shows 1, and opening never clears it; keyword toggles with `aria-pressed`. A count also has a `badge` form (on `IconButton`) and an `inline` form (after a tab's word).
- **`Tabs`** — `kind="tabs"` (WAI-ARIA, arrows and Home/End move focus and selection) and `kind="toggle"` (`allowNone` turns the pressed one off). Never gold.
- **Live migration:** `IconButton`'s numeric badge renders the count chip's badge form; the top bar's Notables and Rivals buttons name their count (`badgeOf`). `window.__DEBUG.getCountChips()` reads every mounted count chip.
