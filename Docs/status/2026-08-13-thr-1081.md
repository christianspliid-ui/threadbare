# THR-1081 — the ceremonial serif is one token, and the gate that says so is now a predicate

**Shipped 2026-08-13.** THR-1031 added `--font-prose: Georgia, 'Times New Roman', serif` to `index.css` and migrated the four sites in the interrupt family. THR-1081 finishes the job: every remaining component that respelled that stack for itself now reads the token. A font stack copied per component is presentation logic living outside the shared layer, which is Law 27's plainest case — and the copies had *already* drifted on quoting before anyone noticed, which is the argument for a token rather than a convention.

## The ticket's own instruction was to re-derive, and it paid

THR-1081's title says "~7 places" and its body names three files. Both are snapshots, and the ticket says so — its membership predicate (THR-688 rule A) is the grep, not the list: *"Every component declaring a serif font stack that `--font-prose` already names."*

Run at pickup, that grep returned **43 sites across 11 files** — the three named (`BondBeat`, `FormativeTestBeat`, `SensingBeat`), plus `SparkBeat` and `TestingBeat`, plus the entire `Remembrance/` family (`DriveBeat`, `FragmentCard`, `OriginBeat`, `RevealBeat`, `StirringBeat`, `TransformationBeat` — 28 sites on its own, 13 in `TransformationBeat`). A list-driven pass would have shipped a third of the ticket and left the same defect in the flow the player meets *first*.

`BondBeat` was the shape the ticket called out and it held: the file declared `const FONT_PROSE = 'Georgia, "Times New Roman", serif'`, used it four times, and then respelled the literal inline three more times in the same file.

## What the migration does

Two forms, both already precedent in the interrupt family:

| Before | After | Where |
|---|---|---|
| `const FONT_PROSE = 'Georgia, "Times New Roman", serif';` | `const FONT_PROSE = 'var(--font-prose)';` | `BondBeat`, `FormativeTestBeat` — matching `EncounterVeil.tsx:72` and `NudgePhaseShell.tsx:52` |
| `fontFamily: 'Georgia, "Times New Roman", serif',` | `fontFamily: 'var(--font-prose)',` (or the file's own alias where one exists) | the other nine files |

The alias const is kept where a file already had one because it is not a re-declaration of the *stack* — it points at the token, and the interrupt family established that form. `BondBeat`'s three orphaned inline literals now route through the constant the file was already declaring.

## The gate is widened from a list to the predicate

The Done-when asked to widen `encounterVeilLaws.test.ts`'s Law 27 gate "to whatever this ticket migrates". A longer list would have been the literal reading and the wrong one — a list going stale is exactly how eleven files sat unmigrated behind a three-entry gate that was green the whole time.

So the gate sweeps `src/` instead: every non-test `.ts`/`.tsx` file, asserting none matches `/Georgia\s*,\s*['"]Times New Roman/`. The next copy fails a test wherever it lands, including in a component that does not exist yet.

Two scoping decisions, both deliberate:

- **The pattern is the full stack, not a bare `Georgia,`.** `PackageBlocks.tsx` (`'Georgia, serif'`) and the `TaxonomyViewer` stylesheets (`'Georgia', serif`) declare *narrower* stacks that `--font-prose` does not name. Folding them in would assert a migration nobody has agreed, on two dev-facing surfaces; they are noted here rather than swept.
- **Tests are excluded from the sweep.** A source-shape gate necessarily names the literal it forbids, so a sweep including itself could never go green.

**Falsified.** Re-introducing the stack in `StirringBeat` — a file no hard-coded list ever contained — turns the new gate red and leaves the old interrupt-family assertion green. That is the proof the widening does work the list could not.

## Browser-verify substituted; pixel capture owed

Impediment #546, **ninth occurrence**. `preview_start` is refused in unattended runs, so requirement 1 is discharged by substitution per THR-754, with the route decided before claiming (zero discovery tax, sixth run running).

New `src/components/MeetTheFirst/__tests__/proseFontToken.test.tsx` renders the **real** `SensingBeat` and `FragmentCard` under jsdom and reads the DOM they produce — per that row's occurrence-4 rule, a substitution asserts the rendered component, never the helper it calls. Every inline `font-family` on the rendered tree is `var(--font-prose)`, no rendered markup contains `Georgia`, and the prose still reaches the surface (a token migration that blanked the copy would otherwise satisfy every other assertion). Falsified by reverting both components to their pre-fix form: 2/2 red.

**On that row's scope test, this is the cleanest pass it will ever see, and it is asserted rather than argued** (occurrence 6's rule). `--font-prose` holds the *same* stack the components stopped spelling, so the resolved typeface is byte-identical before and after and no glyph metric changes — meaning text cannot reflow and the paint/overflow/z-index class is unreachable by construction. The third test pins that equality, normalising for quoting: a future migration that pointed the token at a *different* stack would fail there, which is precisely when a pixel pass would be owed.

## UI-Laws judgment

**Law 27** — the law this ticket exists for. Before: 43 declarations of one stack across 11 components. After: one token, machine-gated by a tree sweep. **Law 37** is quietly strengthened — MeetTheFirst and Remembrance are multi-beat flows, and 43 independently-editable copies of the flow's typeface is drift waiting to happen; THR-1031 recorded that the interrupt family's four copies had already diverged on quoting. **Laws 1, 13, 14, 17, 21** are untouched: no concept rendering, magnitude, key, tooltip, or entity link is in this diff, and `var(--font-prose)` is a CSS custom property that never reaches the player as text.

No pre-existing violation was introduced. Nothing new was filed — the two narrower serif stacks noted above are a different declaration, not a Law 27 breach against this token.
