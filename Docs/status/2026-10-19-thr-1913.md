# THR-1913 — Inspector S5: card counts on every row, with an inline tray

**Shipped 2026-10-19.** Slice S5 of the Inspector plan (`Docs/plans/2026-10-14-thr-1876-the-inspector.md` § D9 way 2). Every rendered world-ref row in the Inspector — Connections, *In this land*, a `links` section — now carries a count chip ("2 cards") when the god can cast something on that thing; a row with no castable card draws nothing. Pressing the count opens a tray under the row with those cards: one tray at a time, a second press or Esc closes it, a card arms with the row as its target and "Cast on Temple Quarter" casts it through the one cast path (`useCastOnTarget`). The page never navigates.

Engine: `actOnRowCards` / `actOnCounts` / `rowCardsKey` in `engine/views/subjects/actOn.ts`, `INSPECTOR_VIEW_BUDGET_MS` (16) in `viewConstants.ts`. UI: `LinkRowAccessoryContext` in `shared/Section.tsx` (a host adds a trailing element and a row below each link row; absent everywhere else), `inspector/RowCards.tsx` (`RowCardsProvider`, the count chip, the tray), `ActOnRow` gains `compact`. Content: `INSPECTOR_WORDS.rowCards` / `rowTray`, tooltip `ui.inspector.cards`. `__DEBUG.getInspectorState()` adds `rowCounts`, `trayOpen`, `trayArmed`.

**Fix found on the way:** a run started without the remembrance flow (the `?seeded` dev route) carries no `ascendantIdentity`, so `godSpheres` returned null and every Act row — S3's included — was empty there; the retired drawer had read the archetype's spheres. `godSpheres` now falls back to the god node's own `sphereAlignment`. **Done-when note:** Sacred Ground (`sub.sanctify`) targets only shrine, temple, ruin and cave Places, so it can never be cast on a Temple Quarter (plan § D9: card targets unchanged). The browser check armed and cast Vision on the Temple Quarter row of The Bone Coast's page instead — count → arm → "Cast on Temple Quarter (The Bone Coast)" → cast, page and history unchanged.

A row counts only the cards it can cast now; locked cards stay on the thing's own Act row with their reason. Counts are read per row as the row mounts, so a folded row is never counted (a render test counts the calls). Measured on seed 42 medium with every card revealed: the heaviest settlement page's 21 docked rows count in 1.9 ms, the heaviest land page's 10 rows in 0.7 ms — inside the 16 ms frame budget, so kill criterion 6 is not needed.
