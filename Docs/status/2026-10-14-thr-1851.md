# 2026-10-14 — THR-1851: a ruler's card reaches their faction

**Ticket:** [THR-1851](https://linear.app/threadbare/issue/THR-1851), from warm playtest round 2 (3/3 testers never reached a faction sheet). UI + Engine; Content N/A (no new words beyond one CTA label).

- **What the player sees.** On a ruler's card (Notables → a ruler) the "FACTION ALLEGIANCES" line is now a link. Clicking it closes the card and opens the faction sheet, with the leader, members and "Current Agenda" visible. Every card's footer button ("open the full sheet ↗", was "open her sheet ↗" and did nothing) now opens the sheet. Rulers and other mortal individuals get it too. On the "The World Calls — Rising Faction" popup, "Attend" opens the people it named. That people is now a living one, never an elder-age civilisation from "Before you woke".
- **How.** `GameView` mounts `DetailPageOpenerProvider`. Its callback, `useDetailNodeRefOpener`, names the node through `worldRefForNodeId` and sends it to the ref router. A faction opens as a sheet with the card stack cleared, because a card's z-band sits above every sheet; other kinds stack as cards. `DetailPage.sheetRef` (new, optional) gives the footer CTA its address. The CTA renders only when there is an address and a router (Law 25), and event cards no longer offer it. `fromGraphNode` names graph nodes as `WorldRef`s. A culture has no sheet, so it resolves to the Realm minted over it (`realm.<cultureId>`). `ascendantBeat.ts`: `isLivingGroup` excludes `cultureEra: 'historical'` from both the binding and the eligibility count.
- **Evidence.** `npm run gate`: 7/7 PASS. Tests: `detailNodeRefOpener.render.test.tsx` (11 new: a ruler card in the real router + opener tree, the faction click opens the faction sheet, the CTA opens the agent and faction sheets, node→ref naming, culture→Realm), 1 new in `ascendantBeat.test.ts`, updated `DetailModal.test.tsx` / `detailPageGenerator.test.ts` and 4 snapshots (the dead button no longer renders with no router). The Rising Faction beat bound `culture_0` (living), and Attend opened FactionSheet `faction_0`. Console errors: only the local narrator-voice server refusing the connection.
