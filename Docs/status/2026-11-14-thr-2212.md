# THR-2212 — A dealt hand reads how hard the step is

**Shipped 2026-11-14.** Encounter Experience. Plan doc: `Docs/plans/2026-11-13-thr-2203-stop-only-for-real-decisions.md` (slice B).

- **The stakes lean.** `dealHand.ts` adds `stakesTermFor(member, step.difficulty)` to the score. A sphereless card whose type the step's difficulty band favours gets `DEAL_STAKES_WEIGHT` (2, one tag match):
  - easy (below 0.25): Buy The Floor and Spare The Worst (insurance, mercy);
  - middle: Draw On Character (trait_card);
  - hard (from 0.5): Press The Odds and Draw On Character (boost, trait_card).
  - A step with no numeric difficulty gets no lean, which is the old deal.
- **The spread pass guarantees only the primary signature** (`DEAL_SPREAD_PRIMARY_ONLY`). Before, a two-sphere god never reached the four-sphere coverage target, so the pass took every signature card whatever the step was about.
- **Still no PRNG.** The same god at the same step gets the same hand; both read sites (Stage adapter, resolution) pass the full step, so they still agree.
- **Inspectable.** Every candidate in `__DEBUG.getRepertoire().lastDeal` carries `stakesTerm`.
- **Measured** by `src/engine/__tests__/dealStakes.thr2212.test.ts`, the proto census kept as a real test.
