# THR-2127 — The Hand's group chevron turns like the god rail

**Shipped 2026-11-02.** UI Visual Overhaul — Design System v1. Follow-up from THR-2103.

The `disclosure` icon points up at rest. `HandSection`'s grouped mode turned it `rotate(90deg)` only when open, so an open sphere group showed a right-pointing triangle and a folded one pointed up. It now uses the god rail's turn (`AscendantBar.tsx`): 90° folded, 180° open — the same fix THR-2103 made in Threads and the Chronicle's Years toggle. This was the last copy of the old turn.

**Test.** `godRailHand.test.tsx` § "at the rail's limit": the open group's chevron reads `rotate(180deg)`, a folded group's `rotate(90deg)`.

**Browser evidence.** Browser-verify substitution: jsdom render test. The grouped mode only appears when the Hand outgrows its rail region, which the seeded world does not reach deterministically at 1920×1080; the change is one CSS transform value, asserted directly in the render test. UI Laws judgment: Laws 1, 13/14, 17, 21, 33, 37 unaffected (no layout, copy, token or size change; the glyph now points the same way as every other disclosure in the frame).
