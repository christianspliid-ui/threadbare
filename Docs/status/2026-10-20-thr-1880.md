# THR-1880 — The hand-built dialogs move onto the size tiers

**Shipped 2026-10-20.** Slice 2 of the dialog size tiers (`Docs/plans/2026-10-14-thr-1820-dialog-size-tiers.md` § 7 table A, slice 2 rows). Five surfaces, not six: the cycle harvest stays a full-screen ceremony (Christian, 2026-10-14) and left this ticket for the Overlay slice.

**Settings (M).** The 280 px flyout under the top bar is now a centred M `Modal` (960 px at 1080p, 1080 at 1440p). Its sections sit side by side in a grid (`SETTINGS_SECTION_MIN_W` 18rem), so every section shows without scrolling. The "Settings" header, the ⚙ toggle and Escape still close it. Its own `document` Escape and click-outside listeners are gone.

**Effect choice sets (S).** `ChoiceSetModal` is an S `Modal` instead of an `absolute inset-0` box at `min(32rem, 92vw)`. Escape and the backdrop defer, like the Defer button.

**The Divine Court (L).** `ScryOverlay` is an L `Modal` with `SheetColumns`: the court's art (16:9), name, flavour, structure bonus, sacred sites and artifacts on the left, the seats on the right. The two pickers are views in the right column, not boxes over the court, and their `max-h-96` scroll boxes are gone. Each picker's ✕ is one text button, "Back to the court" (`SCRY_BACK_TO_COURT_LABEL` in `src/data/ui-content.ts`). Escape with a picker open returns to the seats, and a second Escape closes the court. A pick returns to the seats with the filled seat ringed in gold for `SCRY_FILLED_SEAT_HIGHLIGHT_MS` (1600). The title picker's back now goes to the seats, not to the agent list, as the plan's text asks. The `document` Escape listener and `SCRY_PANEL_MAX_HEIGHT` are gone. The structure-definition early return now sits after the hooks.

**The Codex (XL).** The `fixed inset-0` layer in `DialogHost` is an XL `Modal` (fixed 85vh) over the dimmed game. Embedded, `Codex` fills the panel (`h-full`) instead of `h-screen`. It still mounts only while open, so the run context is not rebuilt on every render. "Close codex" and Escape close it. The Inspector did not take the Codex (THR-1827 kept its own home), so the row did not retire.

**The warm-start card (S).** `WarmStartOverlay` draws its card on an `Overlay` (`band="focused"`, `backdrop="heavy"`, no Escape, no backdrop close), sized with `dialogSizeStyle('s')` and marked `data-dialog-size="s"`.

**Registry and ratchet.** The five `pending: 'THR-1880'` rows in `DIALOG_SIZE_SURFACES` are cleared. The Codex row now points at `Game/hosts/DialogHost.tsx`. `dialogSize.test.ts` accepts an owner-drawn panel that calls `dialogSizeStyle(<registered tier>)`. `npm run check:ui-debt`: `escape-listener` 2 → 0, `hand-overlay` 9 → 3 (also `raw-button` −2, `colour-fn` −6, `glyph-icon` −2, `shadow-literal` −1); the baseline is updated.
