# THR-2253 — The agency census checks the race forecast

**Shipped 2026-11-20.** Ticket 3 of `Docs/plans/2026-11-19-thr-2246-the-player-can-read-the-race.md`. Scripts only.

- **Census.** `scripts/agency-census.ts` reads the shown race state (`MandateState.raceWatch.shown`, never the debug-forced one) every tick, warm included. It records `raceTurns` with `raceTurnTicks`, `raceFirstSeenAt`, `raceAtClimax` (the state shown on the first tick Doom reaches `DOOM_CLIMAX_START`) and `raceShownAtEnd`, plus `raceState` in each snapshot. It prints one race line per arm. A turn is a move between two shown states that name different endings, the same rule as `settleRace`. First sight, a return from a data gap and `doom_first` ↔ `stalled` are not turns.
- **Predicate.** `raceForecastPredicate` / `raceForecastLine` in `scripts/agency-verdict.ts` have two clauses. (1) Turns ≤ `RACE_MAX_TURNS_PER_AGE` on every measured seed and arm. (2) On each played arm, the state shown at the climax names the clock that ended the age on ≥ `RACE_CLIMAX_MIN_SEEDS` (2) seeds. `close` names neither clock. **Decision (agent, under the plan):** an age that ends before Doom reaches the climax is read on its last tick (`@end`). Without that, every early win, which is what the win predicate asks of the full arm, would fail clause 2. The compare prints the line whenever an arm carries `raceTurns`. Unit tests: `scripts/__tests__/agency-race-predicate.test.ts` (12).
- **Reading: NOT MET.** `race predicate: turns ≤3 per age on 8/9 seed-arms (max 6; over 7/greedy:6) ✗ · greedy names the ending at Doom 0.8 0/3 ✗ · full 3/3 (@end) ✓ → NOT MET`. The win predicate HOLDS on the same run. Kill criterion 1, re-measured on the greedy arm only with temporary constants that did not ship: hold 4 days → turns max 5 ✗, climax 0/3. Hold 4 days plus a 30-sample window → turns max 3 ✓, climax 0/3. Kill criterion 2 applies: the projection model is wrong for a chapters-only player, whose Mandate plateaus near 0.9 while the straight-line pace still projects it finishing first. The race UI (THR-2252) has already shipped. The constants are left as they are, and the decision (remodel or hide) is filed as THR-2267 for the design lane.
