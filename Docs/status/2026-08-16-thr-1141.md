# THR-1141 — Consequence chips report state the engine wrote

**Shipped 2026-08-16.** UI Law 56's code half: the content sweep plus the machine
gate. The docs half (Law 56 itself, spec rule 0, the canon entry) landed
separately in `ac1be7ba`.

## What was wrong

The Unsafe Bridge's fallback ending rendered `PATH · THE RIVER CROSSING` — an
authored chip on a band whose one reaction carried `effects: []`. Nothing in the
simulation tracked the crossing or the ford; the chip was scene prose wearing a
chip's frame. Christian's ruling from the deployed build: *"the chips
specifically show only things that have updated the game state … we do not show
prose in this section. basic game UX."*

A corpus scan resolving every aftermath face the way `applyAftermathOutcomeBand`
does found **27 such chips across 11 templates** — the reported one plus ten
siblings, six of them on the Apotheosis capstone's failure bands, where every
ending describing a mortal left damaged wrote no damage at all.

## What shipped

**Content — all 27 backed, none folded.** Christian flipped the sweep's default
from "fold" to "finish": these were unfinished encounters, not overwritten ones,
so every chip got the write its own sentence claims. Not one line of authored
prose changed. The seven slice chips became intelligence records, hidden marks,
bonds and seeds; the healer's three got a bond, a standing move and a seed; the
eleven mentorship chips got per-choice writes where only per-choice sentences
existed; the six apotheosis failure chips got conditions, quintessence erosion
and asymmetric trust dips.

**Engine — the gate.** `checkCompositionContract` now fails an authored chip
whose ending performs no qualifying write. It resolves per *face* (variant ×
band), because `applyAftermathOutcomeBand` substitutes `changes` and `reactions`
**wholesale** — a sweep that unions the two levels credits a chip on one band
with a write that exists only on another. It reads three authoring routes for
step writes, including `onSuccess`/`onFailure` graph ops and branch sub-steps.

The gate is a **floor**, stated as such: it asks whether the ending writes
*something*, never whether that write is the one the sentence describes. No
machine reads the sentence.

**Vocabulary.** The `ui.consequence.path` tooltip used to read *"Nothing is held
yet"* — copy that licensed exactly the chips the law forbids. It now promises an
opening the world tracks. `EncounterAftermathCategory`'s doc comment carries the
rule, so the type teaches it.

## Two things worth carrying forward

**The first gate draft was wrong in both directions, and the corpus said so.**
It called `soul_ferryman` — the corpus's most systemically-wired encounter —
twelve Law 56 violations, because that encounter writes its consequences as step
`onSuccess` graph ops and authors no aftermath effect at all. And it accepted the
Rewards block's `PERSISTENT_EFFECT_KINDS` as the backing set, which silently
excludes nine kinds that plainly write state (`attachment_grant`, `intelligence`,
`quintessence_shift`, `clearance_gate_tag`, …) because that list is scoped to a
narrower question. Both were caught by running the scan and reading what it
flagged rather than trusting it.

**`check:encounter` cannot see most of the corpus.** It scopes to ids beginning
`encounter.` — 191 of 683 live templates. Eleven of the 27 violations sat outside
that prefix, where the gate could never have found them. The corpus assertion
therefore lives in vitest, which has no such limit. Widening
`ENCOUNTER_ID_PREFIXES` would flip ~100 templates to failing and is squarely the
retrofit ticket's scope, so it was deliberately not done here.

## Evidence

- `npm run check:encounter -- --all` — **red** (exit 1, `failing 1`) on the
  re-introduced unsafe-bridge shape; **green** (exit 0, `checked 191 clean 6
  failing 0`) on the swept corpus, identical to the pre-change baseline.
- `npm test` — 16335/16337, the two residual failures being the documented
  worker-contention flakes (`debug-bridge`, `impediment-id-allocation`), both
  green in isolation and both green on the unmodified tree.
- `npm run check:typecheck` — OK, 3182, unchanged from baseline (no refresh).
- `npx vite build` — built in 15.32s.
- 30-tick CLI smoke — tick 30, 383 agents, 45 events, no exceptions.

Three tests that asserted the dead side of the retired contract were repointed
rather than deleted, the loudest being the healer's `fallback has no reactions
(clean consequence)` — the codified form of the exact defect the law kills.
