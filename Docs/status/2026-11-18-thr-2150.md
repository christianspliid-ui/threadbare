# THR-2150 — Flawed Steel no longer genders its reuse-bound cast

**Shipped 2026-11-18.** Encounter Experience. No plan doc; route from the 2026-11-18 promotion comment on the issue.

- **The change.** `src/data/encounters/flawed-steel.ts`: Maren, Dalla and Torve all set `reuseNpcRoles`, so each slot can bind an existing NPC of any gender. No per-cast pronoun token exists in `src`, so every line that said "she/her" now names the cast, uses the role ("the forge-master", "the captain", "the apprentice") or drops the pronoun. That is about forty lines across the step prose, afterimages, nudge cards, aftermath chips, reactions and band endings. The nudge `flawed_steel.her_own_stamp` keeps its id and is now titled "The Maker's Stamp". The prose stays in game-narration register (Prose Doctrine v2).
