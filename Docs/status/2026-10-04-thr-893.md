### 2026-10-04 — THR-893: the nudge-hand reader sees the encounter the spawner opened

**The bug.** `__DEBUG.getEncounterNudges` — the one nudge-specific state reader the bridge offers for browser-verify — resolved agents by id / prefix / name only, so `@hero` (which every spawner accepts) failed with `no actor matched`. And it read the *first* unresolved unified action for the actor, so with the simulation already running an encounter for that mortal, a spawned encounter's hand was never the one returned.

**The fix.** `findAgent` in `src/engine/debugEncounterTools.ts` is exported and the reader uses it, so the two halves resolve `@hero` / `@avatar` / `@ascendant` identically. A new pure `selectDebugReaderAction` picks the action: an explicit `actionId` argument (new, optional) wins with no fallback; otherwise the newest unresolved action whose notification is open, then the newest unresolved, then the newest of any state. The exemplar template stays out of every pool. The `.d.ts` / JSDoc now name the Swollen Ford (not the deleted Darkhollow Vault) and point to `?spawn=` (THR-883) as the sanctioned route for shipped encounters.

**Stale symptom.** The ticket's "`unifiedActions` length 0" did not reproduce: the spawn creates and stores a unified action today.

**Evidence.** Four new unit tests in `debugEncounterTools.test.ts`. Browser (bash-vite on the worktree, Playwright, tree-identity probe true): on `?view=game&seeded&size=medium&spawn=encounter.slice.unsafe_bridge`, `getEncounterNudges('@hero')` returned `ua_1` with 5 playable cards; after `spawnNudgeExemplar('@hero')` → `ua_2`, both `getEncounterNudges('@hero')` and `getEncounterNudges('@hero', 'ua_2')` returned `ua_2` / `fixture.encounter.swollen_ford` with 6 playable cards.

**Noticed, not fixed.** Both reads report `attended: false` (`effectiveTier !== 'story_beat'`) although the exemplar is staged with `courtPosition: 'the_first'` to reach the attended tier. Either the spawned action's tier is not promoted or the flag reads the wrong field — unexamined here.
