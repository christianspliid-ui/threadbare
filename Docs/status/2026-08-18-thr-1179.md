# THR-1179 — six nudge card types earn `impl`, and the badge stops being an assertion

**Shipped 2026-08-18.** Workstream C of the nudge-library completion asked for the nine
card types whose `status !== 'impl'`. The first real finding was that most of the engine
work was already done: `emit_omen`, `remove_condition`, `spawn_artifact`, `hidden_mark`
and `assign_ambition` are all handled by the existing aftermath applier, the detection
and doom cost channels are dispatched by `nudgeDispatch`, and the Omen's draw bias — the
one piece the plan specified in detail as new — turned out to be **already live and
already bounded and decaying**, through `deriveEmittedOmenEncounterBias` plus
`phaseEmittedOmenDecay`. Six of the nine types were sitting on complete host paths with a
`design` badge on them.

**So the question was never "build the mechanic", it was "what does `impl` claim, and what
proves it".** The library's own definition — *the mechanic is shipped and a card of this
type resolves today* — is not "somebody authored an exerciser", and that distinction is
already load-bearing in shipped content: **The Veil and The Bargain have carried `impl`
since THR-885 while no template authors `costs:` at all.** That is the standing bar, and
it settled a genuine fork without guessing. The alternative reading — that a type needs an
authored scene before it counts — would have put this ticket's work inside
`src/data/encounters/`, which this ticket's own coordination block hands to THR-1130.

**The risk in that bar is the reason for the deliverable.** A host path can rot with no
signal at all, because a grant that no-ops deep inside the applier still prints its
fiction and still tells the player something happened. That is THR-844 verbatim — 66 of
138 hidden-mark entries pointing at a reveal family that never existed, silent for months
— and it is why `nudgeGrantLiveness` is a build gate rather than a lint. So each flipped
badge is now pinned by `src/engine/encounters/__tests__/nudgeTypeMechanics.test.ts`, which
drives the **real** dispatcher over a synthesized card and asserts the **host system's own
state** moved: detection pressure on the actor's resolved region, `hiddenMarks`,
`emittedOmens` (plus a non-empty derived draw bias, since an omen that lands in state and
biases nothing is precisely the failure the card would hide), the artifact node *and* the
edge to it, the `has_trait` edge's removal.

Asserting `dispatchedGrantKinds` instead would have been the vacuous version: that field
is computed from the authored grants *before* any of them are applied, so it reports what
was asked for and never what happened, and it would pass against a completely broken
applier. **The suite was falsified before it was trusted** — stubbing `collectNudgeGrants`
to return `[]` reds exactly the five grant-based tests and leaves the two cost-channel
tests and the guards green, which is the shape a working harness should produce.

The file also pins the **inverse**: a test asserting the still-unbuilt set is exactly
`['stumble', 'undertow', 'whisper']`. Flipping a seventh badge without adding its exercise
fails that assertion by name, so `impl` cannot go back to being a claim about the engine
that nothing exercises.

**Shipped:** Heavy hand (detection pressure), Long game (hidden mark), Kindled ambition
(ambition assignment), Omen (bounded decaying draw bias), Cache (artifact + possession
edge), Balm (condition removal). Magnitudes are named constants in `nudge-constants.ts` —
`HEAVY_HAND_DETECTION_DELTA` sized so a Veil in the same hand nets it off (a property the
test asserts), `OMEN_CARD_INTENSITY` held below 1 so one card bends the story without
pinning it.

**Still unbuilt, and deliberately not guessed at:** Whisper needs a pre-commit reveal
surface that does not exist; Undertow needs value-axis drift; Stumble needs a cast-sourced
modifier. Each is genuinely new engine work rather than a badge correction.

**Found in passing, both recorded rather than swept up.** The wiki type table had drifted
on **twelve** rows — six of them predating this ticket (Gambit, Signature, Bargain, Veil,
Favor, Fellowship all read `DESIGN` while the library read `impl`) — because
`check:wiki-freshness` proves a declared page was *touched*, never that it agrees with its
source. Synced from `NUDGE_CARD_TYPES` by script and logged as impediment **#681** with
the durable fix (derive the table, or diff it in a test), since the repair alone reopens
the moment a status flips again. Separately, the `nudge-card-grants-dispatch-to-host-systems`
interface-map contract still carries the comment *"no shipped card authors `grants`"*,
which `slice.pass.deep_rest` in `vertical-slice.ts` has falsified — left for a scoped pass
rather than dragged into this PR, which would have pulled in the interface-map two-file
edit and its regeneration.
