**The blocker was never the wiring, and the surface that should have shown the result does not contain these cards at all (THR-769, 2026-08-06).** Four `company.*` verbs — Bless this Company, Draw Together, Reunite, Sunder — had shipped artless under THR-74 and THR-732 because the executor lane could not author assets, and THR-732 had deliberately declined to add map entries pointing at files that did not exist: **a mapped-but-missing asset renders a broken image, which is strictly worse than the artless fallback.** That trade-off is sound, but it was resting on nothing — no gate proved the mapped paths were real. So the deliverable is not only the four plates (1376×768 JPEG q95, violet `#cc66ff` for the three spirit verbs, pale teal `#8fd4c0` for entropy-aligned Sunder) but the assertion that **every** path in `ACTION_ART` resolves to a file on disk, falsified against a deliberately broken entry before acceptance. **Wiring cost four lines instead of eight because THR-740 landed first** — `codexRegistry.ts` now imports and spreads the canonical map, so one entry reaches every surface; `actionArt.ts`'s own header still claimed a second parallel map existed and is corrected. **The find is what happened when the Codex was opened to photograph the result:** `getAllCodexEntries()` buckets action entries by an explicit list of id prefixes (`divine.`/`invest.`, `action.`, `hex.`, `loc.`, `sub.`, `artifact.`, plus hand-listed thread ids) and has **no `company.` arm**, so all four verbs are absent from the catalog entirely — 181 action entries across six tabs, none of them a company verb, while `__DEBUG.listActions()` returns all four as live. Pre-existing, not a regression here, filed as **THR-999** with the invariant the fix should pin (every drawer-reaching prefix represented in the catalog, so the *next* new prefix fails a test rather than shipping invisible).
