# 2026-09-28 — THR-1641: guild scenes, wonders and place-trait tags reach the board

**Ticket:** [THR-1641](https://linear.app/threadbare/issue/THR-1641) · **Project:** Thematic Pressure & Living World · **Plan:** `Docs/plans/2026-09-27-thr-1633-written-encounters-land.md` § S4 · **Pillars:** Engine (social generator, cap stage, tag projection); Content (guild id lists repaired, `#anomaly` authored on ten templates, bonus table rekeyed; no new prose); UI: N/A (no surface changes — headless evidence per THR-688 rule C).

## What was wrong

Three kinds of written encounter no mortal could reach, and a place-trait table that moved almost nothing.

1. **Guild social scenes.** 39 guild `.social.` templates, 0 ever offered. The lookup read `FACTION_ENCOUNTER_TEMPLATES`, which holds only the Adventurers' Guild's six, and ten of eleven guild definitions listed ids no file defines.
2. **Anomaly places.** The ten `encounter.anomaly.*` templates were in no encounter-cache array, so nothing drew them.
3. **Place-trait tags.** Nine of `LOCATION_TRAIT_ENCOUNTER_BONUS`'s tags (plus `#loss`, `#fear`) had no drawable bearer; `census:location-traits` read FLAT.

## What shipped

- **Guild scenes:** ids repaired in ten definitions and resolved through `getUnifiedTemplateById`; a template matches the Place the mortals stand in as well as the settlement; the one reserved slot rotates per tick (`FACTION_SOCIAL_SLOT_ROTATE`) — without it only the first scene in each guild's list ever fired. Contract test both ways (`guildSocialTemplates.test.ts`).
- **Anomaly templates:** registered in `CACHE_REGISTERED_REGIONAL_TEMPLATE_IDS` (17 → 27), `#anomaly` authored on all ten, and one shortlist slot (`ANOMALY_SITE_CAP_RESERVE`, Phase 1f) for a wonder within `ANOMALY_SITE_MAX_HEX_DISTANCE` (1) — anomaly places sit on empty wilderness hexes, which the own-hex-first fill never reached.
- **Tags:** the raw entries' `encounterType` now survives conversion and is projected as a tag through a new `tagFields` column on the encounter kind (`#explore`, `#assist`, `#duel`, `#lead`, `#build`, `#steal`, `#create`, `#acquire`, `#hire` seated; `#trade` already was). The bonus table is rekeyed onto tags with ≥ `LOCATION_TRAIT_TAG_MIN_BEARERS` (5) drawable bearers, pinned by a test.
- Contracts `guild-social-templates-reach-shared-members` and `location-trait-tags-have-bearers` registered LIVE.
