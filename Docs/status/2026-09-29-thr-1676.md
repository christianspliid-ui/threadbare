## An engine defect the measurement ran into

`isEncounterAction` recognised only legacy-pool templates and templates with a `branchOnStep` fork. **24 of the 59 factory-registered encounters were linear, and so were classified as no encounter at all.** That covered the realm court, the border and delve batches, most of the vertical slice, and four of these six. They never reached the engagement ledger (the level-success invariant and band KPIs), the chapter archive (the chronicle) or the balance ledger, and the everyday-board gauge could not see them. The predicate now also accepts any template registered in `LOCATION_BRANCHING_ENCOUNTER_TEMPLATES` (`isFactoryEncounterTemplate`), and a test pins that every factory encounter classifies.

## Fixed along the way

- **`compile:encounter` registration.** Since THR-1635 wrapped the location array, the compiler appended template objects to the regional id list. It now finds each array's own close.
- **`compile:encounter` swap stamp.** It stamped the pre-swap hand, so every package with a `consequenceSwap` failed its own gate. It now stamps and tests the post-swap hand.
- **`complication_discovery` event id.** The id collided when one mortal raised two discoveries in a tick (THR-853 uniqueness test). It now carries the action id and position.
- **Heavy fixtures.** `arrivalCommitmentBoard` now pools seeds 42/99/7 at the same 0.6 floor; seed 42 alone moved 0.79 → 0.58 while the five-seed pool stayed 0.72 on both trees. `appointment-generatedWorld` resets decision-cache and reputation-trait state per arm so both arms build the same world.

## Decisions made in-lane (veto welcome)

- The batch lives under `encounter.town.*`. `encounter.slice.*` is reserved for the vertical-slice playthrough. Moving the ids re-rolled every consequence hand; four encounters record one swap each, with reasons.
- Every step is capped at 0.45 (the open-draw ceiling) rather than raising the attention tier, which would have changed how often the player is interrupted.
- The Mason's Commission's appointment was dropped. Appointment sequels must be seed-only templates (THR-1526), and authoring two would have doubled the slot. The appointment floor moves to the next batch.
