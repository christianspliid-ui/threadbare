# THR-1241 — The eleven rules nobody was reading

**2026-08-26 · Powers & Item Generation · Engine pillar**

`rule-overrides-reach-owning-sites` is **🟢 LIVE**. Stage 3 of the effect-vocabulary activation
program ([plan doc](../plans/2026-08-25-effect-vocabulary-activation.md)), and the exact mirror of
the contract that landed a day before it.

THR-1239 had a healthy *consumer* and no producer. This one had a healthy producer and, for eleven
of thirteen `RuleOverrideKey`s, **no consumer at all**. Stage 2 stored every `ActiveRuleOverride`
correctly, `getActiveRuleOverride` folded them correctly, and nothing asked — so an artifact could
promise `death_prevented` and its bearer died on schedule, because the one function that decides a
death never read the key. Five keys had shipped catalog content making a promise the engine could
not keep: `death_prevented`, `awareness_range_bonus`, `healing_multiplier`, `spawn_rate_multiplier`
and `tier_advancement_cost_multiplier`.

**One reader, eleven owning sites.** `src/engine/effects/ruleOverrideConsumers.ts` is called from
the single site that owns each rule — movement cost, encounter awareness, agent lifecycle (death
*and* birth), condition decay, capability growth, faction reputation, cooldown ticking, spell
backlash, the reward draw, and resolution modifiers. The alternative, eleven inline reads, is
eleven chances to disagree about the neutral, the fold, or the trace; an inline `?? 1.0` at a
`*_bonus` site is a permanent bug no test catches, because the number it produces is plausible.

**The one key that already had a consumer was also the one that disagreed.**
`doom_rate_multiplier` was a hand-rolled scan in `phaseDoom` that saw only attachment-declared
overrides (an executor-persisted one was invisible to it), folded unclamped, and ignored duration,
cooldown and suppression state. Migrated onto the shared reader rather than left as a second path.

**Two derived readings the plan left to the executor**, both argued at their sites rather than
buried. `tier_advancement_cost_multiplier` inverts into growth — nothing in this game *buys* a
tier, so the cost of advancing is the growth you still owe, and a cost of `0.5` is growth at `2x`.
`backlash_severity_multiplier` shifts an enum one band along `minor → major → catastrophic`,
because severity is not a number and scaling one that does not exist would have meant inventing it.

**Stated rather than papered over:** `backlash_severity_multiplier` reads inside
`evaluateBacklash`, whose caller `activateSpell` has no production caller — spell activation is
still dormant. The key is live in code and goes live in play when that does. Every other key bites
today. The wiring guide and rulebook both say so in those words, so nobody authors against it
expecting otherwise.

**Determinism held by construction.** Every read happens *after* the rng draw at its site, so the
draw count never depends on whether an override is present — seed 42 medium produces the world it
produced before.

**Tests drive the owning sites, never the reader.** Asserting `readMultiplierOverride` returns
`0.5` would pass against a build where no site calls it — stage 2 wearing the stage 3 name. Each of
the 19 tests runs both arms (bearer and bare control) against an observable outcome: a traversal
cost, a wound countdown, a reputation delta, a tier curve.

Three of them failed on first run, and all three were the *test* being wrong about stage 2's clamp
rather than a defect. `clampMultiplier` floors every multiplier at `1/RULE_OVERRIDE_VALUE_CAP`, so
an authored `0` never reaches the reciprocal's division and a `0.01` cooldown multiplier never
collapses to the minimum. The tests now assert the real bound, and two doc comments that claimed
credit for a guard the fold was actually providing were corrected — the zero-guard in
`capabilityGrowth` is a genuine second belt, but it is unreachable today and now says so.

**Verification.** `npm test` 1081 files / 18014 tests passed; `npx vite build` clean;
30-tick seed-42 medium smoke reached tick 30 with 384 agents, 738 locations, 42 events.
Nine wiki pages updated (the two orchestrator-sourced ones because their phases genuinely now
carry override context — no diff-wide exemption was claimed, since seven of the nine document
behavior that really changed).
