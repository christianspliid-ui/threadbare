# THR-1202 — FEAR_PROSE preservation_transformation reads on its own axis

**Shipped 2026-08-23.** The fourth defect found in `FEAR_PROSE`, and the first that was purely semantic — every character on screen was already grammatical.

## What was wrong

`preservation_transformation` resolves two poles: `preservation`, whose fear is *all they have built crumbling to nothing*, and `transformation`, whose fear is *being enslaved by what they cannot change*. The last two bodies of each key said that. The first four of each said something else — they had been authored against a control/authority axis that `ValuePair` does not carry.

The positive key ran four bodies about management: *cannot delegate without checking*, *the chaos that {value} keeps at bay*. Under the corrected noun register those render as "the preservation ... cannot delegate without checking" — clean prose about the wrong thing. The negative key ran four about withholding power: *the fear of being forced into dominance*, *a practiced smallness*.

Not a swap. There is no partner key these eight belonged to — `revelation_discretion` and `sacrifice_survival` both hold their own coherent four — so they were rewritten onto their actual poles rather than re-homed.

## What shipped

Eight rewritten bodies, four per key, on-axis and in baseline register. Preservation now fears the thing it guards running out of life; transformation now fears the immovable, the door that closes, the discovery of how little was ever up for a vote. All twelve bodies across both keys render through the real resolver with no placeholder survivors.

## The open question the ticket asked, answered

The ticket asked whether an aboutness check is expressible as a test, and licensed a closeout sentence saying no. The answer is that **one already exists and it worked**: `POLE_MANIFEST` in `backstory-content.test.ts` went red on the first run of the rewrite, because both of this pair's reviewed fragments were read off bodies the rewrite deleted. It forced exactly the re-reading it was built to force.

What it cannot do is bounded and now measured. Each key holds six bodies; the manifest pins one. Two controlled arms:

- Off-axis body in an **unpinned** slot → **272/272 green**. Invisible.
- Off-axis body in the **pinned** slot → red on exactly that key, 77 others green.

So it catches a pole swap reliably, and catches an off-axis rewrite only when the rewrite lands on the pinned body. This defect sat in bodies 1–4 and was caught; had it sat in bodies 2–3 it would not have been. Deferred as THR-1203 with both arms recorded.

Also worth noting for whoever reads the suite next: the block labelled "golden render" in `backstoryResolvers.test.ts` derives its expected string from `FEAR_PROSE[key][0]` rather than holding checked-in text, so it cannot go red on a body rewrite. Its comment claims otherwise. It still pins substitution, capitalisation and terminal punctuation — it is just not the review gate the comment describes.
