# THR-1314 — the six-way word, and the one sense that moved

**The collision was three times bigger than the proposal thought, and the cheap side was the other one.**

THR-1314 asked the UL to seat five terms from THR-1297 — `work`, `kind row`, `christening`, `failure-name register`, `holding` — and flagged one collision: `holding` was already the Group Cohesion band (`bound · holding · frayed · breaking`), shipped, player-facing and quoted in the rulebook. The proposal named three ways out, leant toward renaming the newer attachment category, and left the veto open. The orchestrator promoted it with that lean as the standing default, and Christian's ask is still open in `Design/user-actions.md`.

Both of the lean's premises measured false.

**It is a six-way collision, not a two-way one.** "Holding" already reaches the player as the cohesion band, the mandate trend (`MANDATE_TREND_WORD`), an army's defensive stance (`army-words.ts`), the ascendant bar's steady state, a Fury-reach tier word, and a `hunger.preserve` remembrance word. Renaming the cohesion state — the proposal's option 2, and the expensive one — would have fixed one sixth of the problem and left five senses colliding.

**In five of those six the word is a participle** meaning *steady, enduring*: the company **is holding**. The ownership sense is the lone count noun — *a* holding, a mine, a road, a hall. That asymmetry decides the ticket: the odd sense moves, and the five that agree with each other stay.

**Renaming the engine literal is not the cheap side.** Measured: ~30 distinct identifiers, five strategic verbs (`grant_holding`, `transfer_holding`, `release_holding`, `raze_holding`, `assess_holdings`), a trace payload key, a module, and ~500 occurrences — a destructive sweep against NFP #6 that still would not have touched the other five senses. The proposal's "nothing player-facing depends on it yet" was also false: `ATTACHMENT_CATEGORY_NAMES` and `SLOT_TAG_DISPLAY_NAMES` both already carried a shipped display string.

**The resolution: the engine literal `'holding'` is untouched; every player surface says *freehold*.** That is the UI Law 14 boundary doing its job — a `snake_case` union member never reaches a screen, so the player-facing rename costs four data lines instead of ~500 sites. It is also the split the UL already sanctions three times over: `[[Group]]`/`[[Company]]` ("party" survives only as the internal `groupType` value), `[[Actor]]`/`[[Agent]]`, and — closing this very shard — `[[Dissolution Threshold]]`/`[[Broken]]`, whose entry reads *"a naming-collision fix, not a new mechanic. The code literal … is untouched; the UL says [the other word] in prose so the two never get conflated."* This ticket applies that house rule rather than inventing one, which is why it did not need to be Christian's call to make progress.

**`undertaking` was added too.** The proposal recorded it as "already settled at THR-1281, so this adds the vocabulary around it, not the head word" — true as a decision, false as a glossary fact. It was absent from the UL entirely, so all five entries would have See-Also'd a term that did not exist.

Six entries landed in `Agents.md` (Undertaking, Kind Row, Work, Christening, Failure-Name Register, Freehold), each grounded by reading the implementation rather than the ticket: the kind registry's *"until a kind can be undone, it is not a kind"* rule and its deliberately-empty slice-2 shipment; the namer's separately-salted phonetic stream and its anchored-name → possessive → family-noun fallback ladder; the working possessive that holds until completion; the register's residue-class gate, which is why clean failures write nothing; and the freehold's three-object mirror in which *the `owns` edge is the authority and the attachment is a face*.

One thing worth recording for whoever picks up the ownership system next: **`ATTACHMENT_CATEGORY_NAMES` has no consumers.** It is a compile-time exhaustiveness guard — "the enforcement gift", by its own docstring — so the entry updated there is for consistency, not for a render path. The one map that actually reaches a screen is `SLOT_TAG_DISPLAY_NAMES`, feeding the AttachmentsTab heading and the codex sidebar.

**Christian's veto stays open.** This is decide-and-invite-a-veto, not a ruling; reversing it is a four-line data change, by construction.
