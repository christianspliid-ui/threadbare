# THR-1010 — the encounter veil adopts the ratified Laws

**Date:** 2026-08-07 · **Project:** Encounter Experience · **Pillar:** UI

The code migration the 2026-08-06 Law Book ratification (THR-1007) mandated for the
encounter veil: Laws 30, 41, 44, 45 and 46 on the surface the ratification review had
audited by reading source.

## What changed

**Law 30 — one gold, and the ceremonial palette becomes tokens.** `EncounterVeil.tsx`
and `NudgePhaseShell.tsx` each declared their own `GOLD = '#d4af37'`, drifted from
`--accent-gold #d4a040`. The values moved to `index.css` as a named variant set
(`--veil-void`, `--veil-gold`, `--veil-gold-rgb`, `--veil-gold-dim`, `--veil-gold-text`,
five text tones), with `--veil-gold` resolving to `--accent-gold` — the game-wide token
wins, because a component hex diverging from the token is the drift the law names.
`--veil-gold-rgb` carries the channels so the veil's ~53 translucent golds derive from one
value instead of a hex re-typed per alpha.

**Law 41 — property-scoped transitions.** Eleven `transition: 'all …'` in the veil became
explicit property lists, read off each site's own hover handlers.

**Law 44 — reduced motion.** The veil's motion is entirely inline, so a CSS media query
cannot reach it; `usePrefersReducedMotion()` (new, `useSyncExternalStore` over
`matchMedia`) feeds `ceremonialDelay`/`ceremonialDuration` helpers that collapse staggers
and the 8s art zoom to one `--anim-fast` fade. Every beat still renders — Law 44's second
clause — asserted by equal beat counts in both arms.

**Law 45 — contrast floor.** `TEXT_WHISPER` measured 2.25:1 and `TEXT_GHOST` 1.41:1
against `--veil-void`; both now sit at 5.75:1 and 4.97:1, with `--veil-text-atmosphere`
retaining the sub-floor tone for decoration the law still permits.

**Law 46 / Law 23 — hit areas and focus rings.** The 12px boost pips gained a 24px button
around an unchanged 12px dot (`STEP_NAV_MIN_HIT_PX`'s own pattern); seven surfaces
suppressing `:focus-visible` with inline `outline: 'none'` — two of them `tabIndex={0}` —
moved to a new `.focus-ring` utility that keeps the no-ring-on-mouse-click intent and
restores the keyboard ring.

## What the browser found that the source did not

The Enforcement clause requires the laws to hold **on the surface as composed**. Auditing
the running veil at 1920×1080 surfaced five violations invisible to a source read, all of
them fixed here:

- **Gold labels below AA.** "Aftermath" at 2.5:1 and the sphere name at 3.6:1 — each is
  `--veil-gold` at a per-element alpha, so the source reads as "the gold token" while
  painting sub-floor. Added `--veil-gold-text` (0.75 alpha, 5.1:1); Law 45 does not exempt
  an accent.
- **Three more golds outside the veil's own files**, all rendering inside it:
  `EntityVisual`'s medallion edge, `CardKeywordChip`, `OddsPips`' cost frame, and the
  `fated` tier in `nudge-pip-vocabulary.ts` — the last one a `★★★★★` row sitting a few
  pixels from the tokenised gold.
- **A third amber read as a gold**: the near-miss band's `rgba(212, 160, 55, …)`, which
  already had `--accent-near-miss`; it now uses it, plus a new `--accent-near-miss-rgb`.
- **A 20×20 interactive control**, `ProseTtsButton`, the only element under the Law 46
  floor on the composed stage.
- **Six unringed controls** — the five nudge cards and the commit button, i.e. the stage's
  primary input.

Two apparent findings were **not** defects and are recorded so the next audit does not
re-raise them. `transition-property: all` at `duration: 0s` is the property's *initial
value*, not a declaration — a probe that matches on the property alone reports every
untransitioned element in the tree. And `#d4af37` still resolves inside the veil as
`--sphere-order`, the Order sphere's own token, which Law 30 routes deliberately through
`sphereColors.ts`; it is not a second ceremonial gold and changing it would be a design
decision about a sphere's hue.

## Verification

`npm test` 968 files / 15156 tests green; `check:typecheck` 3477, unchanged from baseline;
`vite build` clean. Browser evidence at 1920×1080 on
`?view=game&seeded&size=medium&spawn=encounter.slice.unsafe_bridge`, both stage and
aftermath: one painted gold, zero real `transition: all`, zero sub-AA text (min 4.92:1),
zero interactive elements under 24px, focus ring on 11/11 controls, no page scroll.
Reduced motion verified under real `page.emulateMedia({ reducedMotion: 'reduce' })`, not a
`matchMedia` stub — seven staggered `opacity, transform` entrances (0.6–1.8s delays) and
seven transforms collapse to a single `opacity 0.15s delay 0s` with zero transforms, at an
unchanged 60 rendered beats.

New machine gates in `encounterVeilLaws.test.ts` (16) compute WCAG ratios from the
declared tokens, walk the whole component tree for inline `outline: none`, and reject a
re-introduced `transition: all` — a rendered-output snapshot would go green on all three.
