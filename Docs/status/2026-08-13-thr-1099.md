# THR-1099 — Companion seated, and "retinue" arbitrated to a single sense

**Shipped 2026-08-13.** Project: Encounter Experience. Docs/Content only — the arbitration deliberately changed no code.

**The collision** (intent-judge, during THR-1096's design session): *retinue* already means something player-visible — the
ascendant's court, the mortals at the far end of a thread whose `CourtPosition` is `'retinue'`. The companion direction then
used the word colloquially for the people walking beside one mortal, putting one word on two surfaces.

**Verdict: the divine-court sense keeps the word exclusively.** The companion sense of *the word* is rejected; the mechanic is
untouched and ships as `Companion`. Both assignments were display-vocabulary only — "no schema depends on the word", per the
ticket — so the tie could not break on schema risk. It broke on **incumbency**: already a player-visible label
(`RetinuePanel.tsx:44` renders `Retinue` as a section heading), already a schema value (`CourtPosition`,
`src/types/influence.ts:40`), already rules of play (`rulebook.md:178` + quick-reference), 367 references across `src/` —
against a companion sense with a better word available and **no surface committed to it**, the plan having already chosen
"Companions" and renamed the accessor to `getCompanions`. The status-quo branch therefore costs **zero code edits by
construction**; that is the finding, not an omission.

**Seated** — two canonical entries in **Agents**, the shard holding *who a person is to someone else*. **Retinue** beside
`Thread`, recording the arbitration and the rejected sense inline so a later session finds the decision rather than the open
question. **Companion** beside `Company`, because **that is the pair most likely to be confused**: 2–10 *simulated* agents each
deciding for themselves, versus one *unsimulated* person on a single mortal's sheet — they may coexist and never merge. Both
`canonical` though THR-1096 is unbuilt, per the THR-1098 precedent one day earlier.

**One collateral fix the seating forced:** Draw Together read "even when no companions are in range", which always meant *other
threaded mortals*. Reworded to "no eligible mortals", with a parenthetical recording the change so it is not later misread as a
semantic edit.

times by assuming): 127 terms — 123 canonical, 3 deprecated, 1 proposed — coverage 127 of 127, both anchors resolving, dashboard
regenerated to `127 terms across 8 shards`, every new See-Also resolving first run. THR-1096's plan doc records the arbitration
as permanent, so its executor needs no further UL round-trip. Docs-only diff (THR-917 predicate empty), docs track; no browser
evidence owed, the block's Done-when requiring it only if a player-facing label were renamed.
