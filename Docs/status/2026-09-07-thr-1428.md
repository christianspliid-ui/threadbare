# THR-1428 — the owed readers: every live undertaking cell's write gets its reader

**2026-09-07 · Engine · Content · UI · Thematic Pressure & Living World**

## What shipped

Nine live undertaking cells wrote into systems that nothing read. Each now has the reader
THR-1397 decided it should have, which opens three subsystems a mortal's built work had never
reached — Intelligence & familiarity, Ruins & delves, Spheres & quintessence. **No new cell, kind
or verb.** First plan doc off the wayfinder map THR-1396, the band Christian ordered first.

**R1 — watching earns something.** The shared `observe` semantic keeps its `strategicIntelligence`
write and gains, per kind: `knows_of` familiarity (an Area through its `contains` edges, a Place
plus its parent, a Route's two endpoints, a Faction's nearest controlled seat); a clue on ruin- and
wonder-class Locations whose precision the outcome band decides; and, on `critical_success` only, a
chart or a secret about somebody who was standing there. The band is graded from
`checked.lastCheckpoint.band`, already resolved at the completion seam — no second resolution.

**R2 — a ruin joins the delve layer.** `ruin_settlement` stamps `ruinMagnitude` banded from what the
settlement was; `delveVariant`'s admission scan admits a `ruins` Location once
`ruinedTick + RUINED_SETTLEMENT_DELVE_DECAY_TICKS` has passed. The located-clue requirement is
unchanged, so observe → clue → delve is a climb rather than an open door.

**R3 — a freehold pays.** New `holding_income` phase (`src/engine/holdingIncome.ts`) between
`trade_route_decay` and `prosperity`: a seized route's toll, a freehold's keep, a controlled
Location's prosperity-scaled tithe, once a day, to **mortals only**.

**R4 — casting costs spirit.** `payCosts` returns the capped `doom_increase` total as `soulPrice`
instead of writing `doom`; the `use × Power` cell lands it on quintessence as a `QuintessenceEvent`
and refuses `spell_exhausted` while the caster is spent. `health_sacrifice` still writes `doom`.

**R5 — army supply reads a faction.** `hasReliefLine` took the first incoming `controls` source; a
mortal claimant made it resolve a supply line for an individual's id.

**R6 — the rule, in canon.** *A cell ships with its reader; a wanted cell whose product no phase or
surface reads is not built until one does.* All 20 `wanted` dispositions now carry a `reader`, the
nine paid-off `owes` notes read **Read by**, and `generate-undertaking-grid` fails by name on an
empty one.

## Four defects the work surfaced

1. **`spawnClue` typed `precision` as `number`** while every consumer reads the `CluePrecision`
   string union — `delveVariant` tests `precision === 'located'`, `CLUE_MAX_AGE` keys on the three
   words. The wanderer pack's live *Walk the Mark Down* template wrote `0.7`, so a clue whose own
   completion prose says *"the mark resolves into a place"* could never admit a delve. Narrowed to
   `CluePrecision`; the template now says `'located'`. **Live proof:** seed 42 medium at tick 150,
   8 `undertaking_survey` clues, all `located`.
2. **`tick_exhaust` stamped its deadline from `agentNode.properties.currentTick`**, which no writer
   sets — so every exhaustion deadline landed at `0 + ticks`, already in the past. `payCosts` now
   takes the caller's tick, which is what makes R4's exhaustion reader able to refuse anything.
3. **`ruinSphereAlignment` would have been another write nobody reads.** The plan named it; the
   delve layer reads `sphereAlignment`. Only `ruinMagnitude` is written, and the existing property
   is carried through untouched.
4. **`AgentDetailPanel` is not mounted** — its own header records it, and only its test imports it.
   The live sheet is `AgentProfileModal` → `OverviewTab`, which is where the **Means** and **Knows
   the way to** rows went. Putting them only in the panel the plan named would have shipped UI
   nobody can open, which is the pathology this ticket exists to end.

## The honest limit

**R3 has an empty live population until the cells model flips.** Measured on seed 42 medium at tick
150 under `UNDERTAKING_MODEL: 'templates'`: 0 `owns` edges, 0 strategic `controls`, 0 seized routes.
Nothing enumerates the cells that create holdings until THR-1403. The pass is correct and falsified
at its owning layer (a faction and a mortal each controlling an identical settlement in one world),
but it has nothing to pay yet — a supply fact about the producing cells, not a defect in the reader.
R1's clue fix and R5's supply fix are live on that same run.
