# THR-2160 — The mortal decides the reputation encounters, half two

**Shipped 2026-11-04.** Encounter Experience, slice 4 of 5 from the THR-2135 decision. The pattern is the THR-866 Apotheosis conversion (`Docs/plans/2026-08-11-thr-866-apotheosis-nudge-conversion.md`) as THR-2159 applied it; no new design.

Each template used to key its endings to the ids of the cards the god clicked on step 0, so the click picked the ending ("Carry out the commission." / "Refuse. Warn the condemned instead."). Each now forks through `decidedBy` in pole mode. The mortal decides; the god argues with a composed hand.

1. **Fork.** `decidedBy: { axis }`; branch variants, `aftermathConfig.variants` and `stakes.arms` re-keyed to `positive` / `negative`. `branchOnStep` stays 0 (THR-979). In the Commission and the Crossing the old fallback ending sat on the negative pole, so their fallback and base stakes moved to the positive ending and the old base became `arms.negative`. The Star Pilgrim keeps its fallback on the blessing (`negative`): a fallback copy of the radiance aftermath would add a dead seed site (`star.wider_pilgrimage`) past the `encounterSeedLiveness` ceiling. Its header and the README row say so.
2. **Hand on step 0.** Two specials (one per pole) plus `deal: { count: 3 }` from the Repertoire, a `purposeLine` and the three missing afterimages.
3. **Step-1 prose re-voiced** so the mortal acts ("The agent did not comply…", "The agent opened the full channel…"), not the god.
4. **`authoredChoices` removed** from all eight. The Star Pilgrim's two cards carried THR-528 per-choice Star-virtue marks; they leave with the cards, as THR-2159's did. `REPUTATION_GATED_README.md` Rule 3a table gains the eight rows.
5. **Tests.** New `mortal-decides-reputation-half-two.test.ts` pins the Done-when over the shipped catalog (no `authoredChoices`, the axis + pole keys, both poles argued, non-empty hand, reachability and producibility invariants, `checkNudgeHand` / `checkComposedHand` clean, stakes arms, no "The god" in step-1 prose). `reach-mislabel-relabels.test.ts` reads the Commission's warn arm under its new key, `positive`.
