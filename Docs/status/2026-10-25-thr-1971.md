# THR-1971 — the next world shows what the World-Soul remembers

**Shipped 2026-10-25.** Deferral from the end-of-the-age plan (`Docs/plans/2026-10-17-thr-1381-the-end-of-the-age.md`, § Interface impact, row `age-end-writes-resonance-memories`). THR-1381 writes up to three World-Soul memories at the end of each age, and the account record carries them into the next world, but nothing in that world showed them.

**Change.**
- `src/engine/accountRecord.ts`: `shownWorldSoulMemories(account)`. It returns the live memories (those a memory word still names, so degradation below 0.9), the top `TWILIGHT_MEMORIES_SHOWN` by `significance × (1 − degradation)` via `selectTopMemories`. It returns nothing on a first run or an empty record.
- `src/components/Remembrance/WorldRemembersBeat.tsx`: a *What the World-Soul remembers* section under *What still stands*. Each memory's stored `summary` is shown verbatim with its memory word (still warm / fading / almost gone). A sphere-tinted rule marks the memory's first sphere. With no memories there is no section and no heading.
- `src/data/account-content.ts`: `soulHeading`.
- `src/engine/accountStore.ts`: `sampleAccount()` (`?account=sample`) now carries the run-1 age's three memories, built with the real `TWILIGHT_WORDS` and significance constants, plus a fourth that is past its last memory word so the cut can be seen.

**Evidence.** `WorldRemembersBeat.test.tsx` has three new cases. (1) The step lists each shown summary verbatim, strongest first, with its word, and hides the wordless one. (2) An empty record shows no section and no heading. (3) The ranking: significance × (1 − degradation), capped at three, wordless memories dropped. Browser at 1920×1080 (Vite on :5287, `?account=sample` → New World): the three lines render under *What still stands*. The section spans 441–574 px, the page is 1080 tall and nothing scrolls. `await __DEBUG.getAccountRecord()` on `?view=game&seeded&size=medium&account=sample` reports the same three summaries plus the faded fourth. Console: 0 errors. UI Laws: 1 (each memory word keeps the `ui.memory` tooltip), 13 (no number on the step; checked by the test), 17 (one line per memory, ≤15-word stored summaries), 21 (memories have no page to link to before a world exists, as with THR-1844's echoes), 33 (fits in 1920×1080 without scrolling), 37 (sphere tint from the shared `sphereBrightToken`).

**Not done.** Nothing outstanding.
