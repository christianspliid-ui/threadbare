# THR-1052 — dead nudge `imageTag`s repointed, and the guard that was missing

**Shipped 2026-08-18.** 42 nudge cards across 14 hands named an `imageTag` with no
`ENCOUNTER_IMAGE_LIBRARY` row. Every one of them is now an exact-tag hit, and a corpus
sweep now fails the build if a new one is authored.

## What was actually broken

`NudgePhaseShell` resolves card art with `resolveEncounterImagePath({ tag, kind: 'nudge',
sphere })`. It passes **no `concepts`**, so the tag-query rung cannot fire — sphere alone
scores 4 against an `IMAGE_MATCH_MIN_SCORE` of 10. A tag with no row therefore skipped
exact-tag *and* tag-query and landed on the category generic, `generic.blessing`.

The consequence was not a missing image. It was **sameness**: the author picked art per
card, and the player saw one plate — wisps settling over a plain clay bowl — repeated
across an entire hand. `encounter.shrine_offering` had four cards resolving to the same
picture. Fail-soft by design (NFP #4), and invisible for exactly that reason.

## The fix, and why repoint rather than generate

Repoint, all 42, to the nearest of the 16 shipped `generic.*` rows. Two reasons:

- **The art worklist is closed.** `ENCOUNTER_IMAGE_PLAN` has been declared-but-empty since
  THR-832 batch 4. Opening a new batch is deliberate work with its own doctrine (16:9,
  the genericity bar, no faces) — not something to do in passing.
- **A repoint cannot regress.** A dead tag already rendered `generic.blessing`; pointing it
  at a *considered* row is equal-or-better by construction. The Done-when asks only that
  every tag resolve, and this satisfies it in full.

Each card was matched on what it actually does, read from its own `fiction` and
`effectLine` rather than its tag string — the card's `sphere` (which the library also
carries) broke ties. Some are near-renames the library had drifted past
(`generic.time` → `generic.time-slow`, six years of water-drop art already sitting there);
others are genuine picture matches: `slice.caravan.a_loose_tongue`, a Gambit card whose
outcome "widens both ends", now draws `generic.luck` — a coin on edge, caught before it
tips.

A second pass then fixed the four hands where the first pass had introduced a *new*
collision: repointing is only worth doing if the hand ends up varied, so
`prayer.keep_the_hour`, `prayer.set_the_errand_down`, `rest_reflect.quiet_the_road_behind`,
`shrine.keep_the_old_form` and `shrine.set_down_the_wanting` were re-chosen against their
hands' existing tags. One duplicate pair survives deliberately —
`scout_perimeter`'s two `generic.strength` cards, whose source comment already declares
them a shared "`strength` family".

## The guard, and the hole it closes

`check:image-library` proves the library's rows are honest — every path exists, nothing
sits in both tables. It never asked the other direction: does authored content name a row
that exists? That gap is why 42 dead tags shipped.

`check:encounter --all` catches most of it, but not all: its walk is `nudgeBearingSteps`,
which filters `template.steps` for plain `ActionStep`s — *"branching variants are out of
scope for linear templates"*. A hand inside an `ActionStepBranch` is invisible to it.
Measured here: of the 42, the gate reported **41** and silently passed
`slice.family.sure_marker`, which sits in a branch `fallback` of
`encounter.slice.swindled_family` — a template the gate did check.

So the new sweep lives in `encounterImageResolver.test.ts`, walks branch variants and
fallbacks, and asserts `source === 'exact_tag'` rather than a non-null path — because a
path assertion passes while the chain collapses to the category generic, which is the
precise failure being pinned. It was falsified before being trusted: restoring the one
`sure_marker` tag makes the gate report 0 violations and the test name the offender.

## Deferred

[THR-1170](https://linear.app/threadbare/issue/THR-1170) — the same defect on the
Meet-The-First flow, which is out of this ticket's stated scope and larger:
`meeting-dilemma-library.ts` authors 424 `imageTag`s across three values (`crowd`,
`mercy`, `blade`), none of which is a library row. The meeting beats consume
`NudgePhaseShell` whole, so every card in the game's **opening encounter** currently shows
the same plate. Left as a design call — three unprefixed tags read as an intended trio
that was never generated, so the choice between repointing and opening a new art batch is
not the executor's.
