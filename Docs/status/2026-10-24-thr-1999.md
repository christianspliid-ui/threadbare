# THR-1999 — encounter debts end when their term does

**Shipped 2026-10-24.** Reward agreements (`instantiateAgreementReward`) are `relates_to` edges stamped with `acquiredTick` and the full term as `ticksRemaining`. Nothing counted that term down or removed the edge, so a debt kept showing on the character sheet and the bar's vows row, with the full term as "ticks remaining", and its effects kept applying.

**Change.**
- `expireAgreements` (`src/engine/agreementExpiry.ts`), run as phase 6.625c right after companion expiry, removes every agreement edge whose term has ended. The stored term is left as written, so `acquiredTick + ticksRemaining` stays the end tick every reader computes and old saves keep reading. No-term agreements and the nested fixture shape never expire here; an `active: false` edge is removed only when its term ends.
- `agreementShape.ts` splits `agreementTermEnded` (term only) out of `agreementLapsed` and adds `agreementTermRemaining`.
- `getAgentAttachments` takes an optional `tick`: with it, an agreement shows the ticks left (full term as `totalTicks`) and a term-ended one is dropped. `getAgentDetail` / `getAgentInfoCard` / the agent-interaction hook pass the tick through; the bar's vows row drops term-ended agreements too.

**Evidence.** `src/engine/__tests__/agreementExpiry.test.ts` (5) grants `agreement.debt.minor` through the reward path: at +20 ticks the sheet shows 28 of 48; at +48 the pass removes the edge and it is gone from `getAgentAttachments` (both parties) and the bar. `npm run gate` code track (test, typecheck, build, encounter, god-cards, ui-debt, 30-tick CLI smoke) all PASS. Browser evidence substituted by the unit route (no new surface; the existing rows stop showing lapsed agreements — `extractChips` and `getAgentAttachments` are asserted directly).
