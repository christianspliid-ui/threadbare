Now its odds start at "Uncertain", and chapters you paid into earn it extra cards. A warning comes first so you can save essence.   - **The Return gets a "Go on" button.** Today only Escape closes it: [The Return has a Go on button](https://linear.app/threadbare/issue/THR-2228/the-return-has-a-go-on-button-and-says-what-the-age-has-left-today).

Built in [The ending tells what this god did](https://linear.app/threadbare/issue/THR-2229/the-ending-tells-what-this-god-did-with-its-first-the-ordeal-and-the).
