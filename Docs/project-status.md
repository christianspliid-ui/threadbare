This makes low-variety deserts and non-moving agents visible in the same Threads workflow you already use instead of requiring DebugPanel spelunking.

- **Meet The First Portrait Persistence Fix:** The First now keeps the authored meeting portrait after the bond is formed. The legacy engine now stores per-step resolution snapshots so the UI can surface what really happened instead of only the prose shell.

The filter pipeline now keeps same-hex/threaded candidates alive instead of fail-softing into permanent `no_candidates_after_filter` idle loops, and regression tests cover both the raw capability scorer and full encounter filter pipeline.
