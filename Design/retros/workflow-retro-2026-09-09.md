What remains is exactly one sentence of the row's own durable lesson, verified unbuilt at `a87e8f24`: `grep -niE "linear|LINEAR_API_KEY" scripts/session-precheck.ts` returns nothing, and the fingerprint line at `:626` composes only `rg / git / test / cu / nm / freshness`.
