Icon style: Filled black silhouettes with opacity-based depth. Hand-drawn icons (mountains, hills, dense forest) drawn by Spliid in Inkscape, normalized to 100×100 viewBox. Remaining icons use the same filled-shape approach for visual consistency.

Techniques used:
• Filled shapes with fill="#1a1a1a" and varied opacity (0.2–0.85) for depth layering
• Shadow side fills — overlapping darker shapes on one side suggest light direction
• Cutout shapes — lighter inner paths create openings (cave mouths, windows, tent flaps)
• Minimal strokes — only used for thin details (water lines, light beams, ground lines)

For React integration: Each symbol is self-contained in <symbol> tags. All icons use the same 100×100 viewBox. Reference via <use href="#icon-name"/>. Most icons are 200–600 bytes each.
