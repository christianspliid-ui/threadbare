Avatar Movement — Target Hex Indicator Options

A — Dashed Outline on Target

Current hex = pulsing solid ring. Target hex = dashed ring (static color, no pulse). Clean contrast between "here" and "going there."

Pulsing solid = current Dashed = target

B — Translucent Fill on Target

Target hex gets a soft color wash — reads as a waypoint/destination. Current hex keeps the pulsing ring.

Pulsing ring = current Color wash = target

C — Dotted Path Route

A marching-dots path traces the planned route from current hex through intermediate hexes to the target. Shows the full journey.

Pulsing ring = current Marching dots = route

D — Combined: Dashed Target + Dotted Route

Full picture: pulsing ring on current, marching-dot path showing the route, dashed ring on the destination. Maximum clarity.

Pulse = here Dots = route Dashed = target
