Threadbearer

Post-Tick Bookkeeping

Rule-Override Reads (THR-1241) Two in-tick phases now pass rule-override context to the sites that own a key: the effect-tick phase hands it to tickEffects (so cooldown_multiplier can shorten a dormant stretch) and the condition-decay phase hands it to decayConditions (so healing_multiplier can lift a wound sooner). No phase was added and no ordering changed — the existing phases simply carry what their sites need to read.
Visibility Recalc Recompute fog-of-war from ascendant's line-of-sight and scry targets. Auto-reveal land layer for newly-visible hexes.
Recent Events Buffer Merge tickEvents into recentEvents ring buffer (max 100 entries) for UI consumption.
Tick Summary Trace Emit diagnostic trace: tick #, event count, agents processed, doom stage, essence, mandate progress.
State Cleanup Retire auto_resolve encounter notifications past their autoResolveTick deadline (THR-1068 — marks them resolved; aftermath and legacy-sourced records exempt), then prune old encounter notifications (>50 ticks), stamp completedAtTick on resolved actions, remove stale actions (>100 ticks). Expiry runs before the prune so a record that is both overdue and beyond retention reports as expired rather than silently vanishing; it emits one aggregate encounter_notification trace per tick, never one per record.
Health Validation validateTickOutput() checks for invariant violations. Failures logged to trace buffer but never throw.

Key Concepts Glossary

Unified Action
A 1-6 step action lifecycle: queued, executing, blocking, fallback, resolved. Deterministic progression each tick.
Encounter
A multi-step narrative event an agent participates in. Steps have duration, outcomes grant growth and sphere pressure.
Sphere Pressure
Cosmic energy (9 Spheres) accumulated by phases — doom, encounters, battles, rivals — then batch-applied once per tick.
Domain Capability
Agent competence across Eight Reaches (activity types). Sigmoid-mapped 0-1 score used by the resolution service.
Quintessence
Actor power reserve (current/max). Passive regen, erosion from failure, dissolution at zero. Five threshold states.
Doom Clock
World-level countdown. Advances every tick. Tier crossings escalate entropy. Expiry = game over.
Essence
The player's divine resource. Generated from controlled locations. Spent on interventions (actions on agents/hexes).
Mandate
The player's divine quest. Stage thresholds checked each tick. Completion grants essence and narrative rewards.
Maslow Pipeline
Agent decision model: 6 need layers (survival to self-actualization). Higher layers only activate when lower needs are met.
Familiarity
What an agent knows about entities. Gained by proximity, thread-binding, and encounter participation. Gates available actions.
Colocation
When agents share the same hex/location after movement. Triggers revelations, relationship updates, encounter opportunities.
Trace
Structured debug event emitted by every decision point. Visible in the debug panel (backtick key). The engine's audit trail.
