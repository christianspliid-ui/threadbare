Shield Shape & Composition

What elements should a coat of arms include? Pick the complexity level that fits.

A

Shield Only

A single shield with field divisions, tinctures, and a central charge (animal/symbol). Clean and scalable — works at small hex-map sizes and large UI panels alike.

Shield + division + charge
B

Shield + Supporters

Shield with flanking creatures/figures and a motto scroll beneath. More ornate — great for UI panels, may need simplified version for hex map.

Shield + supporters + motto
C

Full Achievement

Complete heraldic achievement: shield, helm/crown, mantling, supporters, motto, and compartment. Maximum visual impact for UI — hex map would use shield-only extract.

Full achievement — crown, mantling, supporters, quartered shield, motto
