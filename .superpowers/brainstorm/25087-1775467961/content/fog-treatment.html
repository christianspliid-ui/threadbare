Parchment Fog: Unexplored Hex Treatment

How should unexplored hexes look? The parchment replaces the current near-black darkening.

A. Solid Parchment Fill

Unexplored hexes become a uniform dark parchment/leather color from the Threadbare palette. Simple, clean, fast. Like the blank areas of an old map. The hex shape is visible but the terrain is completely hidden.

Pros

  • Simplest to implement (color swap like current)
  • Zero GPU overhead (no textures)
  • Clean hex grid still visible

Cons

  • Less atmospheric than textured
  • Flat appearance may feel cheap

B. Textured Parchment with Cartographic Detail

Unexplored hexes show a procedural parchment texture with subtle cartographic elements — faint compass rose hints, aged paper grain, ink stains. Like the margins of an ancient fantasy map where the cartographer hasn't yet explored. Fits the "Threadbare" worn-surfaces aesthetic.

Pros

  • Rich, atmospheric, fits Threadbare aesthetic
  • Parchment texture is a pre-baked static asset (one texture)
  • Cartographic details reward zooming in

Cons

  • Needs texture on the material (currently pure vertex colors)
  • Moderate implementation: add texture UV + blend

C. Parchment Overlay with Soft Edge

A separate parchment-textured mesh renders ON TOP of the hex grid, covering unexplored areas. The edge where explored meets unexplored has a soft, feathered transition — like the terrain fading into old paper. Terrain peeks through faintly underneath.

Pros

  • Most atmospheric — soft boundary is cinematic
  • Terrain hints visible through the parchment
  • Edge transition feels organic, not grid-locked

Cons

  • Most complex: separate overlay mesh + edge blending
  • Soft edges across hex boundaries harder in InstancedMesh
  • May fight with existing layer culling system

Context

The hex map currently uses MeshBasicMaterial with per-instance vertex colors (no textures). The fog system swaps colors via setColorAt(). Option A stays within this model. Options B and C would require adding texture support or an overlay mesh.
