Textured parchment (unexplored) + sepia terrain (remembered) + full color (visible)

Implementation Approach: ShaderMaterial with Parchment Texture

Replace MeshBasicMaterial on the hex fill with a custom ShaderMaterial that blends between instance color and a parchment texture based on a per-instance fog attribute.

// Per-instance attributes (InstancedBufferAttribute)
instanceColor: vec3   // existing — terrain color (or sepia-shifted for remembered)
aFogState: float   // NEW — 0.0 = unexplored, 0.5 = remembered, 1.0 = visible

// Fragment shader logic
if (fogState < 0.25)
  → sample parchment texture, ignore instance color
else if (fogState < 0.75)
  → use instance color (pre-sepia-shifted by CPU)
else
  → use instance color (full terrain color)

Key Components

Parchment texture Pre-baked 512×512 PNG. Dark parchment with paper grain, subtle ink stains, faint cartographic marks. Single static asset, tiled across all unexplored hexes.
Hex geometry UVs Add UV attribute to buildHexGeometry(). Map hex vertices to 0–1 range. Each hex samples the full texture.
ShaderMaterial Replace MeshBasicMaterial on land + water meshes. Vertex shader passes UVs + fog state. Fragment shader blends texture vs color based on fog state.
Sepia tint (CPU) When a hex enters 'remembered', updateFogColors() writes a sepia-shifted version of the original color to instance color buffer. Simple RGB → sepia matrix.
Fog state attribute New InstancedBufferAttribute (Float32, 1 per instance). Updated alongside instance colors in useFogCulling.
Toggle system Fog on by default. ?nofog URL param to disable. Debug panel toggle. fog console command in CLI and debug bridge. All use same fogEnabled state.
Performance Still 2 draw calls (land + water). Per-instance attribute update is same cost as current setColorAt(). One texture lookup per fragment (cheap on GPU).

Scope boundary

This design covers the visual treatment only. The existing fog engine (visibility.ts, LOS sources, state transitions) is unchanged. We're replacing how the three states look, not how they're computed.
