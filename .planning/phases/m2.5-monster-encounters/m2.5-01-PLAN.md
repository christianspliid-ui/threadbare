    **1. Create `src/engine/lairSeeding.ts`:**

    ```typescript
    import { mulberry32 } from './worldgen/prng';
    import { PASS_SEED_LAIRS } from './worldgen/constants';
    import {
      PROVINCE_ROLE_CAPITAL,
      PROVINCE_ROLE_HEARTLAND,
      PROVINCE_ROLE_BORDERLAND,
    } from './worldgen/types';
    import type { WorldGraph } from '../types/graph';
    import type { HexTile, SphereName } from '../types/index';
    import type { DangerZone } from '../types/monster';
    import { emitTrace } from './tracing';

    export const LAIR_SEEDING_CONSTANTS = {
      WILDERNESS_LAIR_DENSITY: 0.08,
      BORDERLAND_LAIR_DENSITY: 0.03,
      HEARTLAND_LAIR_DENSITY: 0.005,
      CAPITAL_LAIR_DENSITY: 0.0,
      MIN_LAIR_SEPARATION: 3,
      PASS_SEED_LAIRS: 90211,
    } as const;
    ```

    The `seedMonsterLairs` function:
    1. Creates a seeded PRNG: `mulberry32(seed + PASS_SEED_LAIRS)`
    2. Iterates all tiles, skipping ocean/water hexes
    3. Maps each tile's province role to a danger zone using: `provinceRoles[col + row * cols]` — use PROVINCE_ROLE_CAPITAL (0), PROVINCE_ROLE_HEARTLAND (1), PROVINCE_ROLE_BORDERLAND (2); null/undefined → 'wilderness'
    4. Rolls PRNG against density for that zone (capital=0, heartland=0.005, borderland=0.03, wilderness=0.08)
    5. Checks MIN_LAIR_SEPARATION against already-placed lairs (Manhattan distance on offset coords)
    6. Creates a `location` graph node with properties: `{ locationSubtype: 'lair', lairTier: 'minor', dominantSphere, spawnedAtTick: 0, lastEscalationTick: 0, dangerZone }`
    7. Creates a `located_at` edge from lair node to hex location node (hex nodes have id format from seedWorld — check existing hex node IDs in worldSeed.ts)
    8. Emits trace: `{ category: 'lair', event: 'lair_seeded', ... }`

    For `dominantSphere`: read the hex's sphere affinity from `graph.getNode(hexNodeId).properties.sphereAffinity` — pick the sphere with the highest score. If no sphere affinity yet, use a terrain-based fallback map.
