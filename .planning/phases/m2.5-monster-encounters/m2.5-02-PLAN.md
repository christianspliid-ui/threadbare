    1. Guard: `if (state.tick % LAIR_ESCALATION_INTERVAL !== 0) return;`
    2. Create PRNG: `mulberry32(state.seed + state.tick * 71)` (unique multiplier)

    4. For each active lair:

          - Set lair `namedEliteId`, update `lastEscalationTick`
          - Emit `lair_upgraded` trace
       c. If `state.tick - lair.spawnedAtTick >= LAIR_LEGENDARY_MIN_TICKS` and `lairTier === 'major'`:
          - Upgrade to 'legendary'
          - Call `seedMonsterFaction(state, lairNode, lair.dominantSphere)`
          - Update `lastEscalationTick`
          - Emit `lair_upgraded` trace
       d. **Adjacent spawn:** For each adjacent hex (use hex neighbor calculation from existing movement code), if hex is wilderness or borderland and no existing lair within MIN_LAIR_SEPARATION: roll PRNG < LAIR_ADJACENT_SPAWN_CHANCE → spawn new minor lair using `spawnLair` helper from lairSeeding.ts (import it)
    5. Get all cleared_lair nodes: filter for `locationSubtype === 'cleared_lair'`
    6. For each cleared lair:
       - Check reinfestation: `state.tick - clearedAtTick >= LAIR_REINFESTATION_MIN_TICKS`
       - Check hex sphere pressure: query hex node's sphereAffinity, check if dominantSphere score >= LAIR_SPAWN_SPHERE_THRESHOLD
       - Check no controlling faction: no `controls` edge to this lair from any non-monster faction
       - If all conditions met: update to `locationSubtype: 'lair'`, `lairTier: 'minor'`, reset spawn tick
       - Emit `lair_reinfested` trace
