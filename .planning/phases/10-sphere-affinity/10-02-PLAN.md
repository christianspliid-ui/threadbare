Create `src/engine/phaseSpherePressure.ts` implementing the full pressure resolution algorithm from the design doc:

1. **`netPressuresBySphere(pressures: SpherePressureEvent[]): Record<SphereName, number>`** — Sum all pressure magnitudes per sphere.

2. **`cancelOppositions(net: Record<SphereName, number>): Record<SphereName, number>`** — For each of the 4 opposition pairs (Force/Energy, Life/Entropy, Mind/Time, Spirit/Matter), compare absolute net pressures. The larger cancels the smaller; remainder stays in the dominant sphere. Use `SPHERE_OPPOSITES` from cosmology.ts.

3. **`resolveSpherePressure(entity: SphereAffinity, pressures: SpherePressureEvent[], presentAgentAffinities?: SphereAffinity[]): { updated: SphereAffinity; traces: SpherePressureTrace[] }`** implementing:
   - Net pressures by sphere (step 1-2)
   - Cancel oppositions (step 3)
   - For each sphere with non-zero net pressure after cancellation:
     - If destructive (opposing sphere with positive pressure): compute threshold = entity.scores[sphere] + floor(entity.scores[ally]/2) + sum(agent buffers). If abs(pressure) > threshold, erode by excess. Reset progress on erosion.
     - If constructive (same-direction pressure): add to progress. If progress >= triangleCost(currentScore + 1) AND currentScore < MAX_SPHERE_SCORE, level up, subtract cost from progress.
   - Emit SpherePressureTrace for every sphere resolution.

4. **`effectiveHexThreshold(hexAffinity: SphereAffinity, sphere: SphereName, presentAgents: SphereAffinity[]): number`** — hex score + floor(ally/2) + sum(agent scores * AGENT_PRESENCE_RATIO).

5. **`SpherePressureTrace` interface:**
```typescript
interface SpherePressureTrace {
  category: 'sphere_pressure';
  tick: number;
  entityId: string;
  sphere: SphereName;
  outcome: 'absorbed' | 'eroded' | 'progress' | 'level_up';
  incomingPressure: number;

  progressFilled: number;

}
```

   - For each entity: get node from graph, get sphereAffinity (fail-soft: skip if missing), resolve pressures, update node properties.
   - For hex entities: find agents on that hex to compute agent presence buffer.
   - Return updated graph + traces. Clear `pendingSpherePressures: []`.

Determine destructive vs constructive: a pressure event is destructive to sphere S if the pressure's sphere is S's opposite. Constructive if same sphere. Use `SPHERE_OPPOSITES` to check.
