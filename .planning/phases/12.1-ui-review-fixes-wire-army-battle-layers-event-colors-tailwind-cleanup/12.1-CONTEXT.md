<decisions>
## Implementation Decisions

### Priority 1: Wire Army/Battle Layers to HexMapV2
- `GameView.tsx` must call `buildArmyRenderData(graph)` and `buildBattleIndicatorData(graph)` and pass results as `armies` and `battles` props to `<HexMapV2>`
- `HexV2View.tsx` must also accept and pass these props (dev route `?view=hexv2`)
- `HexV2View.tsx` `HexV2ViewProps` interface needs `armies` and `battles` fields

### Priority 2: Conflict Event Colors
- Add entries to `TICK_EVENT_COLORS` in `src/data/uiColorPalette.ts` for all 6 new event types:
  - `army_mobilization`, `army_disbanded`, `battle_started`, `battle_resolved`, `siege_established`, `army_attrition`
- Colors should be thematically appropriate (reds/oranges for battle, muted for attrition/disbanded)

### Priority 3: ArmiesTab Tailwind Refactor
- Replace all inline `style` objects in ArmiesTabContent with Tailwind classes
- Replace magic pixel values (`padding: '8px'`, `marginBottom: '6px'`, `fontSize: '11px'`) with Tailwind scale (`p-2`, `mb-1.5`, `text-xs`)
- Replace duplicated color hex values (`#f87171`, `#60a5fa`) with imports from `uiColorPalette.ts` or CSS custom properties
- Add Destruction Log section (missing from plan 12-07 Task 5): recent destruction events from trace buffer

### Claude's Discretion
- Exact color values for new TICK_EVENT_COLORS entries
- Whether to use `text-xs` (12px) or `text-[11px]` for the compact debug display
- Layout details of the Destruction Log section

</decisions>
