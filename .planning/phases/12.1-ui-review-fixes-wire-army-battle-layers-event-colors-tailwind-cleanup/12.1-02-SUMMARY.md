## What Was Built

**Task 1 — Conflict Event Colors:**
Added 7 new entries to `TICK_EVENT_COLORS` in `src/data/uiColorPalette.ts`:
- `domain_revealed: '#a78bfa'` — violet, knowledge/revelation theme
- `army_mobilization: '#f97316'` — orange, military mobilization
- `army_disbanded: '#78716c'` — stone gray, low emphasis
- `battle_started: '#ef4444'` — red-500, combat starting
- `battle_resolved: '#dc2626'` — red-600, combat concluded
- `siege_established: '#fb923c'` — orange-400, matches `SIEGE_COLOR` from BattleIndicatorLayer
- `army_attrition: '#a8a29e'` — warm gray, degradation

These entries are consumed by `NarrativeLog` and `NarrativeFeed` via the `TICK_EVENT_COLORS` lookup, so conflict chronicle events now show colored dots instead of falling through to the gray `#78716c` fallback.

**Task 2 — ArmiesTabContent Tailwind + Destruction Log:**
- Replaced army card container inline styles (`padding: '8px'`, `background: 'var(--bg-raised)'`, `borderRadius: '4px'`, `marginBottom: '6px'`, `fontSize: '11px'`) with `className="p-2 bg-[var(--bg-raised)] rounded mb-1.5 text-[11px]"`
- Replaced battle card containers with the same Tailwind pattern
- Section headers moved from spread-style objects to `className="text-sm font-medium mb-2"` with a single `style={{ color: ... }}`
- Replaced hardcoded `'#f87171'` with `FIELD_BATTLE_COLOR` import for battle section header and momentum indicator
- Added import `{ FIELD_BATTLE_COLOR, SIEGE_COLOR }` from BattleIndicatorLayer
- Added **Destruction Log** section after battles section, querying locations with `locationSubtype === 'ruins'`
