<objective>
Implement two encounter retirement mechanisms: max completions per template (hard retirement after N completions) and outgrowth lock (encounters below agent capability are filtered out). Together these create natural progression pressure.

Purpose: Without retirement, agents cycle through the same 5-8 encounters indefinitely (round-robin). Retirement forces agents to seek harder encounters or travel to new locations, creating natural progression arcs.

Output: Max completions filter in phaseAgentDecision.ts, outgrowth lock filter in encounterFilterPipeline.ts, new constants, tests.
</objective>

    /** After this many completions of the same template, it is permanently retired for that agent.

    export const MAX_COMPLETIONS_PER_TEMPLATE = 5;

     * must be before the encounter is outgrown and filtered out.
     * Agent capability is 0–1 scaled to 0–100 for comparison.
     * Example: at threshold 35, an agent with cap=0.55 (55) outgrows diff=20 encounters (55-20=35).
     * @range 25–50 (lower = more aggressive retirement) */
    export const OUTGROWTH_CAP_THRESHOLD = 35;

    export const OUTGROWTH_FILTER_ENABLED = true;
