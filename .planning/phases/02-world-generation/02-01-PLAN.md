    **1. Create `src/engine/worldgen/passes/pass02-elevation.ts`:**

    `runElevationPass(ctx: WorldGenContext, params: WorldGenParams): void` — mutates ctx.elevation, ctx.isOcean, ctx.ridges, ctx.canyons, ctx.sampleElevation.

    Algorithm:
    a. Create noise function: `createNoise2D()` from simplex-noise, seeded via `mulberry32(seed + PASS_SEED_ELEVATION)`.
    b. Generate base elevation: multi-octave fractal noise for each hex (ELEVATION_SCALE, ELEVATION_OCTAVES, ELEVATION_PERSISTENCE, ELEVATION_LACUNARITY). Normalize to [0, 1].
    c. Generate ridges: `generateRidges(ctx, params, rng)`:
       - Place RIDGE_COUNT_DEFAULT (or params.ridgeCount) ridge start points at random locations in the land area
       - Each ridge grows as a random walk with directional momentum (orientation angle +/- 15 degrees per step)
       - Ridge length: random between RIDGE_MIN_LENGTH and RIDGE_MAX_LENGTH hexes
       - Fork probability: RIDGE_FORK_PROBABILITY per step, max 2 forks per ridge
       - Store orientation as the average direction of the spine
       - Return Ridge[] array
    d. Apply ridge elevation overlay: for each hex, compute `ridgeElevationAt(hex, ridges)` using cosine falloff over RIDGE_FOOTHILLS_HEXES distance. Add to base elevation (clamped to [0, 1]).
    e. Generate canyons: `generateCanyons(ctx, rng)`:
       - Dry rift canyons: CANYON_DRY_RIFT_COUNT linear paths through highland terrain, subtract CANYON_DEPTH_FACTOR from elevation along path
       - River-carved canyons will be added in Plan 03 during hydrology pass
    f. Apply province bias: for each hex, blend elevation toward the province's target elevation based on distance from province seed. Mountain provinces bias toward 0.7-0.85, lowland provinces bias toward 0.35-0.5, forest provinces toward 0.4-0.55. Bias strength decays with distance (exponential: `exp(-dist * PROVINCE_BIAS_DECAY_RATE)`).
    g. Set sea level: `ctx.isOcean[i] = ctx.elevation[i] < SEA_LEVEL ? 1 : 0`
    h. Store continuous sampling function:

    **2. Create `src/engine/worldgen/passes/pass03-coastline.ts`:**

    `runCoastlinePass(ctx: WorldGenContext, params: WorldGenParams): void` — refines elevation near sea level.

    Algorithm:
    a. High-frequency coastal noise: apply an extra noise layer (COASTAL_NOISE_SCALE, COASTAL_NOISE_OCTAVES) ONLY to hexes within 3 hexes of the land/sea boundary. This creates fine inlets, peninsulas, bays.
    b. Island chain generator: place ISLAND_CHAIN_COUNT chains. Each chain is a sequence of ISLAND_CHAIN_LENGTH hexes stepping from a random coastal hex outward into the ocean, raising elevation above sea level. Larger islands (>3 hexes) get mini-ridge internal elevation.
    c. Peninsula generator: PENINSULA_COUNT long narrow land features extending from coastline. Similar to ridge generation but horizontal and at sea-level elevation.
    d. Bay carver: BAY_CARVE_COUNT deep inlets cut into coastline by lowering elevation of coastal hexes in a funnel shape.
    e. Recalculate isOcean after all coastline modifications.

    **3. Implement 7-point hex sampling utility** (in pass02-elevation.ts or a shared util):

    ```typescript
    export function sample7Point(
      col: number, row: number,
      sampleFn: (c: number, r: number) => number,
      hexSize: number
    ): number {
      const center = sampleFn(col, row);
      let sum = center;
      for (let i = 0; i < 6; i++) {
        const angle = (Math.PI / 3) * i - Math.PI / 6; // flat-top hex corners
        const cornerCol = col + hexSize * Math.cos(angle);
        const cornerRow = row + hexSize * Math.sin(angle);
        sum += sampleFn(cornerCol, cornerRow);
      }
    ```
