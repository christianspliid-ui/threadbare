    `runHydrologyPass(ctx: WorldGenContext, params: WorldGenParams): void`

    This pass integrates the existing hydrology modules into the pipeline. The key ordering is critical (from RESEARCH.md anti-patterns):

    a. **Fill depressions first** — call the depression filling logic. The existing `depressionLakes.ts` has `promoteDepressionLakes(data)` which requires `drainageElevation` and `filledDepth` to be computed first. Read `depressionLakes.ts` carefully to understand the internal `fillDepressions` function. If `fillDepressions` is not exported, either:

       The goal: `ctx.drainageElevation` and `ctx.filledDepth` are populated, depressions are identified.

    b. **Generate rivers** — call `generateRivers(ctx)` from `riverGeneration.ts`. This uses `drainageElevation` for steepest-descent routing. It populates `ctx.hasRiver`, `ctx.riverPaths`.

    c. **Promote depression lakes** — call `promoteDepressionLakes(ctx)` to identify filled depressions as lakes. Populates `ctx.lakeIds`.

    d. **Generate lake outflows** — call `generateLakeOutflows(ctx)` from `lakeOutflow.ts`. Generates rivers flowing out of lakes.

    e. **Delta generation** (new): for each riverPath that ends at an ocean hex (isOcean === 1), check if the river is long enough. If river length > 10 hexes and the terminal hex is coastal:

       - Each branch is 2-4 hexes long, flowing into ocean
       - Mark branch hexes in hasRiver and add to riverPaths
       - Use `mulberry32(seed + PASS_SEED_HYDROLOGY)` for determinism

    f. **Wetland placement** (new): for each hex that is:
       - Within WETLAND_RIVER_MOUTH_RADIUS of where a river meets ocean/lake AND elevation < WETLAND_ELEVATION_MAX AND moisture > WETLAND_MOISTURE_THRESHOLD → mark for wetland classification (store in a separate `isWetland: Uint8Array` on ctx, or set terrain directly here — the biome pass in Plan 02 Task 2 handles the actual terrain type assignment based on these conditions, so this pass should store the metadata for the biome pass to consume)

       Implementation approach: add a `wetlandAffinity: Float32Array` to WorldGenContext (in types.ts if not already there). Set values 0-1 indicating wetland likelihood. The biome pass (pass07-biome.ts from Plan 02) already has wetland override logic that checks elevation and moisture — enhance it to also check `wetlandAffinity > 0` for river-mouth/lake-shore specific placement. If the biome pass was already written (Plan 02 executes before Plan 03 since wave 2 < wave 3), update pass07-biome.ts to incorporate wetlandAffinity.

    g. **Canyon integration** (river-carved): for each river that flows through highland terrain (elevation > ELEV.HIGHLAND), depress elevation along the river path by CANYON_DEPTH_FACTOR. This creates river-carved canyon features. Update ctx.elevation for affected hexes.

    ```typescript
    import { WorldGenPipeline } from './worldgen/WorldGenPipeline';
    import type { WorldGenParams } from './worldgen/types';
    import type { CosmologyProfile, HexTile } from '../types';

    export function generateWorld(
      cosmology: CosmologyProfile,
      cols: number,
      rows: number,
      seed: number,
    ): HexTile[] {
      // Build WorldGenParams from existing arguments
      // For now, use defaults for new params. Culture roster will come from game state.
      const params: WorldGenParams = {
        cols, rows, seed,
        ridgeCount: 4,
        seaLevelThreshold: 0.38,
        landShape: 'continent',
        mountainDensity: 'moderate',
        livingCultures: [],  // Will be populated when culture system is integrated
        lostCultures: [],
      };

      const pipeline = new WorldGenPipeline();
      const ctx = pipeline.run(params);

      // Convert WorldGenContext to HexTile[]
      return toHexTilesFromContext(ctx);
    }

    function toHexTilesFromContext(ctx: WorldGenContext): HexTile[] {
      const tiles: HexTile[] = [];
      for (let row = 0; row < ctx.rows; row++) {
        for (let col = 0; col < ctx.cols; col++) {
          const i = row * ctx.cols + col;
          tiles.push({
            coord: { col, row },
            geoParams: {
              elevation: ctx.elevation[i],
              temperature: ctx.temperature[i],
              moisture: ctx.moisture[i],
            },
            terrain: ctx.terrain[i],
            hasRiver: ctx.hasRiver[i] === 1 ? true : undefined,
          });
        }
      }
      return tiles;
    }
    ```
