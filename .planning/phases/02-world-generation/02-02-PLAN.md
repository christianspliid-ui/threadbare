<objective>
Build climate field generation, temperature reassessment, biome classification, and adjacency smoothing passes.

Purpose: Transform the elevation field from Plan 01 into a fully classified terrain map. Temperature and moisture fields are generated with latitude gradients, altitude penalties, prevailing wind, and orographic rain shadow from ridge data. After hydrology (Plan 03) modifies the landscape, temperature reassessment moderates climate near lakes and rivers. The single Whittaker classification pass then assigns one of 27 terrain types per hex, with elevation overrides for highlands, wetland overrides near water, and desert sub-type selection. A final smoothing pass eliminates impossible biome adjacencies.

Output: Four new pipeline passes (climate, tempReassess, biome, smoothing) with full test coverage for rain shadow, latitude gradient, lake effect, all override categories, and adjacency rules.
</objective>

    **2. Create `src/engine/worldgen/passes/pass04-climate.ts`:**

    `runClimatePass(ctx: WorldGenContext, params: WorldGenParams): void`

    Temperature computation per hex:
    ```
    latitudeTemp = 1 - Math.abs(row - rows/2) / (rows/2)  // 1.0 at equator, 0.0 at poles
    altitudePenalty = Math.max(0, ctx.elevation[i] - SEA_LEVEL) * TEMP_ALTITUDE_PENALTY / (1 - SEA_LEVEL)
    noiseContrib = (noise2D(col * TEMP_NOISE_SCALE, row * TEMP_NOISE_SCALE) + 1) / 2 * TEMP_NOISE_WEIGHT
    maritimeModeration = computeMaritimeModeration(i, ctx)  // pulls toward 0.5 if within TEMP_MARITIME_RADIUS of ocean
    temperature[i] = clamp(latitudeTemp * TEMP_LATITUDE_WEIGHT + noiseContrib - altitudePenalty + maritimeModeration, 0, 1)
    ```

    Maritime moderation: BFS from all ocean hexes up to TEMP_MARITIME_RADIUS, store distance. Moderate = `TEMP_MARITIME_STRENGTH * (1 - dist / TEMP_MARITIME_RADIUS) * (0.5 - rawTemp)`.

    Moisture computation per hex:
    ```
    coastalBonus = MOISTURE_COASTAL_BONUS * exp(-coastDist * MOISTURE_COASTAL_DECAY)
    noiseContrib = (noise2D(col * MOISTURE_NOISE_SCALE, row * MOISTURE_NOISE_SCALE) + 1) / 2 * MOISTURE_NOISE_WEIGHT
    rainShadowPenalty = computeRainShadow(col, row, ctx.ridges)
    moisture[i] = clamp(coastalBonus + noiseContrib + 0.3 - rainShadowPenalty, 0, 1)
    ```

    Rain shadow: for each ridge, compute the angle from hex to nearest spine point. If that angle is within +/-60 degrees of the prevailing wind direction (meaning hex is downwind), apply `RAIN_SHADOW_PENALTY * exp(-distFromSpine * RAIN_SHADOW_DECAY)`. Hexes on the windward side get a moisture BONUS of half the shadow penalty amount.

    Store continuous functions:
    ```typescript
    ctx.sampleTemperature = (col, row) => { /* re-evaluate temperature formula at fractional coords */ };
    ctx.sampleMoisture = (col, row) => { /* re-evaluate moisture formula at fractional coords */ };
    ```

    `runTempReassessPass(ctx: WorldGenContext): void`

    Lake effect: scan all hexes. For hexes where `lakeIds[i] >= 0`, find all non-lake hexes within LAKE_EFFECT_RADIUS.     **3. Create `src/engine/worldgen/passes/pass07-biome.ts`:**

    `runBiomePass(ctx: WorldGenContext): void`

    For each land hex (isOcean === 0):
    a. Base classification: `terrain[i] = classifyBiome(elevation[i], temperature[i], moisture[i])` (reuse existing function from terrain.ts)
    b. Elevation overrides (WGEN-09): if elevation >= ELEV.HIGH_MOUNTAIN → 'high_mountains'; if >= ELEV.MOUNTAIN → 'mountains'; if >= ELEV.HIGHLAND → 'hills' (unless classifyBiome already returned a highland type). Check for plateau (high elevation + flat — elevation variance among neighbors < 0.05) and mountain_pass (local minimum along a ridge spine — elevation lower than all 6 neighbors which are higher elevation).
    c. Forested hills: if elevation >= ELEV.HIGHLAND and base terrain is a forest type → 'forested_hills'
    d. Wetland overrides (WGEN-10): if elevation < WETLAND_ELEVATION_MAX AND moisture > WETLAND_MOISTURE_THRESHOLD → classify as wetland. Specific type selection: near river mouths (within WETLAND_RIVER_MOUTH_RADIUS of where a river meets ocean/lake) → 'floodplain'; near lake shores (within WETLAND_LAKE_SHORE_RADIUS) → 'marsh'; remaining wet lowlands → 'swamp' or 'moor_bog' based on temperature (cold → 'moor_bog', warm → 'swamp').
    e. Desert sub-types (WGEN-11): if base terrain is 'desert', use local noise `fractalNoise(col, row, seed + PASS_SEED_BIOME, 2, 0.5, 2.0, DESERT_SUBTYPE_NOISE_SCALE)` to select: <0.2 → 'sand_dunes', <0.4 → 'sand_desert' (mapped from 'desert'), <0.6 → 'rocky_desert', <0.8 → 'badlands', else → 'desert' (hardened clay placeholder — note: the TerrainType union doesn't include 'hardened_clay', so use 'rocky_desert' as the fifth variant or check if 'hardened_clay' needs adding to the type union; if not in union, use the closest existing type).
    f. Volcanic placement (WGEN-13): if elevation > VOLCANO_MIN_ELEVATION AND temperature > VOLCANO_MIN_TEMPERATURE, apply `fractalNoise(col, row, seed + 99999) > (1 - VOLCANO_CHANCE)` → 'volcano'.

    For ocean hexes: classify by depth — elevation < ELEV.DEEP_OCEAN → 'deep_ocean', < ELEV.SHALLOWS → 'ocean', else → 'coastal_shallows'.
