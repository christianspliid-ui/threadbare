<interfaces>
From signifierRegistry.ts (Plan 01):
```typescript
export interface SignifierPath {
  d: string;       // SVG path data
  opacity: number; // 0.2-0.7 range
}
export interface SignifierVariant {
  paths: SignifierPath[];
  viewBox: string; // '0 0 100 100'
}
export const SIGNIFIER_REGISTRY: Record<string, SignifierVariant[]>;
```

Style standard reference (from Design/mountain-hand-drawn.svg):
- viewBox: "0 0 100 100"
- fill: "#1a1a1a", stroke: "none"
- Complex organic paths with irregular vertices (not geometric shapes)
- Asymmetric: left side has filled shapes (sun shadow), right side has thinner/open shapes
- Multi-layer: multiple path elements at different opacities (0.2-0.7 range)
- Background rect exists in SVGs but is NOT included in registry paths (only the #1a1a1a paths)

Key style traits:
- steppes-hand-drawn.svg: Three rolling hill profiles with grass tufts, organic curves, left side more filled
- deepforest-hand-drawn.svg: Dense canopy silhouette with multiple overlapping tree crowns
- hills-hand-drawn.svg: Three rows of rolling ridgelines, layered front-to-back at different opacity
- mountain-hand-drawn.svg: Two mountain peaks with irregular rocky profiles, left face more filled
