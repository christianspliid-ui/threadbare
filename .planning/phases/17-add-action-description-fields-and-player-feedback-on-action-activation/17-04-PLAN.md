**ParticleBurstMesh.ts:**

Create a new module following the BattleIndicatorMesh factory+tick pattern, but using `THREE.Points` instead of `THREE.Sprite`.

```typescript
import * as THREE from 'three';
import { hexToWorld } from '../../../lib/worldPosition';
import { LAYER_Z } from './RenderLayers';

// NFP #1: All tunable constants named
export const PARTICLE_CONSTANTS = {
  /** Number of particles per burst */
  COUNT: 16,
  /** Total animation duration in ms */
  LIFETIME_MS: 800,
  /** Maximum expansion radius in world units */
  EXPAND_RADIUS: 2.5,
  /** Point size (sizeAttenuation applies) */
  POINT_SIZE: 6.0,
  /** Initial opacity */
  SPAWN_OPACITY: 0.8,
  /** Z position for particles */
  Z_LAYER: LAYER_Z.PARTICLE_BURST,
} as const;

export interface ActiveBurst {
  points: THREE.Points;
  startMs: number;
  /** Cached random directions per particle (unit vectors * random magnitude) */
  directions: Float32Array;  // x,y pairs: [dx0, dy0, dx1, dy1, ...]
  cx: number;  // center x in world space
  cy: number;  // center y in world space
}
```

Implement `spawnParticleBurst(scene, hexCol, hexRow, hexSize, color, nowMs): ActiveBurst`:
- Use `hexToWorld` to get center coords, store as `cx`/`cy` on the burst
- Create Float32Array positions starting at center
- Create random radial directions (evenly spaced with slight jitter)
- Use `THREE.Points` with `THREE.PointsMaterial` (additive blending, transparent, depthWrite false)
- Add to scene, return ActiveBurst

Implement `tickParticleBursts(scene, bursts, nowMs): ActiveBurst[]`:
- For each burst, compute `t = elapsed / LIFETIME_MS`
- If t >= 1.0: remove from scene, dispose geometry + material, skip
- Otherwise: update positions as `burst.cx + direction * expandFactor`, update opacity as `SPAWN_OPACITY * (1 - t)`, mark needsUpdate
- Return surviving bursts
