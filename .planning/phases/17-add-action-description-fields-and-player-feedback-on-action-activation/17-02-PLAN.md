The `migrateEncounterTemplate()` function converts EncounterTemplate to UnifiedActionTemplate. Encounter templates may have varying names. For encounter-sourced templates, add spellName and description in the migration function output — use the encounter template's existing `name` field to derive a spell name if one isn't already set. The simplest approach: add a `ENCOUNTER_SPELL_NAMES: Record<string, { spellName: string; description: string }>` lookup table keyed by encounter template id, and apply it during migration:

