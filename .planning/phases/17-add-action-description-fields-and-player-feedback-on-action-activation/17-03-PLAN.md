Since `createUnifiedAction` dispatches to the tick loop (outcome resolves asynchronously in future ticks), the toast fires on dispatch with optimistic/neutral messaging. This is the same pattern as divine interventions — feedback is immediate, outcome resolution is deferred to the simulation. Build the toast:

  id: `toast_action_${Date.now()}`,
