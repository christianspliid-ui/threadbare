## Spacing Scale

Declared values — all multiples of 4, sourced from `src/index.css` `--space-*` tokens:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`--space-1`) | Icon gaps, glyph-to-name vertical gap within card sections |
| sm | 8px (`--space-2`) | Inline element spacing, cost badge padding |
| md | 16px (`--space-4`) | Default element spacing, focused card horizontal padding |
| lg | 24px (`--space-6`) | Section padding, art frame vertical margin |
| xl | 32px (`--space-8`) | Card fan drawer bottom margin |
| 2xl | 48px | Major layout section breaks |
| 3xl | 64px | Page-level spacing (not used in card layer) |

Exceptions:

- **Art frame height (focused card):** 112px (28 × 4px grid units). Landscape rectangle, fills the zone between spell name and type line. Must preserve 5:7 card ratio at 280px card width — art frame is the primary variable-height zone.
- **Hand card total height:** 140px (100px width × 1.4 CARD_ASPECT). No change to existing ratio.
- **Focused card total height:** 392px (280px width × 1.4 CARD_ASPECT). Existing ratio preserved — content sections must sum to fit.
- **Type line height:** 20px (single line, compact). Reach glyph + CRUD type label side by side.
- **Particle burst radius (HexMapV2):** 32px screen-space at hero-local zoom — scales with zoom tier.

> Source: CONTEXT.md decisions; `src/components/Game/ActionCard.tsx` SIZE_CONFIG

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#1a1a1f` (`--bg-surface`) | Card body background, drawer background, toast background |
| Secondary (30%) | `#222228` (`--bg-raised`) | Card raised surface (existing ActionCard bg), art frame placeholder fill |
| Accent (10%) | `#d4a040` (`--accent-gold`) | Type line divider, ornamental card edge top-highlight, section heading labels |
| Sphere color (dynamic) | Per-sphere from `SPHERE_ICONS` registry | Left border glow on focused card, cost badge border, glow burst animation, particle burst color, toast left-border stripe |
| Destructive | `#f87171` (`--negative`) | Not used in this phase — no destructive actions |

**Accent reserved for:**
- Ornamental 2px top-edge gradient on focused card (`.card-gold-edge::before` pattern)
- Type line horizontal rule (1px `--border-gold` line between art frame and type line)
- Section heading labels inside the description text box (if used)
- Cost badge border fallback when no sphere color is available

**Sphere color application rules:**
- Focused card: 4px left border + `${sphereColor}0A` to `transparent` background gradient (existing pattern, unchanged)
- Art frame placeholder: sphere-tinted gradient — `${sphereColor}20` at top-left to `#111114` at bottom-right (`--bg-deep`)
- Glow burst keyframe: `0 0 0 0 ${sphereColor}40` → `0 0 0 32px ${sphereColor}60` → `0 0 0 0 ${sphereColor}00` over 600ms
- Toast left border: 3px solid sphere color
- Particle burst: sphere color with 80% opacity at spawn, fade to 0% over particle lifetime
- Outcome overlay (success): `#10b981` (`--positive` / emerald) tint — existing spent overlay pattern
- Outcome overlay (failure): `#f87171` (`--negative` / red) tint — 40% opacity, cracked/dimmed icon

**Art frame placeholder (until card art generation phase):**
- Background: `linear-gradient(145deg, ${sphereColor}20 0%, #111114 100%)`
- Border: `1px solid ${sphereColor}30`
- Center: sphere Unicode glyph from `SPHERE_ICONS[sphere].symbol` at 32px, color `${sphereColor}60`
- No other content — pure tinted rectangle

> Source: `src/index.css` color tokens; `src/data/uiColorPalette.ts`; `src/data/sphereIcons.ts`; ActionCard.tsx; CONTEXT.md

## Component Inventory

### ActionCard — Focused Layout (redesigned, MTG classic frame)

Structure top-to-bottom within the existing 280×392px bounds:

```
┌─────────────────────────────────┐  ← 280px wide
│ [Spell Name]        [Cost badge]│  ← 36px zone
├─────────────────────────────────┤
│                                 │
│      Art Frame (placeholder)    │  ← 112px zone
│                                 │
├─────────────────────────────────┤  ← gold rule 1px
│ [Reach glyph] TYPE LINE · CRUD  │  ← 20px zone
├─────────────────────────────────┤
│ Technical description text      │
│ (2-3 sentences, regular weight) │  ← ~80px zone (flex, expands)
│                                 │
│ ─────────────────────────────── │  ← 1px border-subtle rule
│ Flavor text (italic, dimmer)    │  ← ~48px zone (flex, expands)
├─────────────────────────────────┤
│ [Risk: xx%]          [N hex]    │  ← 28px zone (stats row, mt-auto)
└─────────────────────────────────┘
```

**Spell name zone (36px):**
- Left: spell name in Cinzel 18px/600, `--text-primary`
- Right: cost badge (existing pill design, unchanged)
- Bottom padding: 8px before art frame

**Art frame zone (112px):**
- Full card width minus 16px horizontal card padding (so frame spans 248px at 280px card width)
- Sphere-tinted gradient background + sphere glyph (see Color section)
- Border radius: 4px (matches card radius pattern)
- No image until card art generation phase — this is the reservation slot

**Type line (20px):**
- Sphere glyph symbol (16px, sphere color) + space + REACH_DISPLAY_NAME (uppercase, 16px, `--text-tertiary`, letter-spacing 0.08em) + " · " + CRUD_TYPE (uppercase, 16px, `--text-tertiary`)
- Separated from art frame by 1px `--border-gold` horizontal rule above

**Description text box:**
- Font: Alegreya Sans 16px/400, `--text-secondary`, line-height 1.5
- 2-3 sentences of qualitative game-mechanical text
- No numbers/percentages — qualitative language only ("bolsters", "weakens", "severs")

**Flavor text (italic):**
- Font: Alegreya Sans 16px/400 italic, `--text-tertiary` (dimmer than description), line-height 1.5
- Separated from description by 1px `--border-subtle` rule
- Source: `narrativeTemplates.initiation` from the action template (existing field)

**Stats row (28px):**
- Identical to existing risk + range row — no change
- `mt-auto` so it always anchors to card bottom

### ActionCard — Hand Layout (art-only with name overlay)

At 100×140px:
- **Background:** Art frame placeholder fills entire card (sphere gradient with glyph, same rules as focused art frame)
- **Name overlay:** Absolute positioned at card bottom — 8px padding, `--bg-abyss` at 70% opacity backdrop, Cinzel 16px/600, `--text-primary`, max 2 lines
- **Cost badge:** Top-right, unchanged from current implementation
- **No description, flavor text, type line, or stats row visible** — all detail is focused-only

This replaces the current glyph + name + description layout at hand size. The art-only treatment makes the fan more visual and card-game-like.

### Glow Burst Animation

CSS `@keyframes` named `cardGlowBurst` — added inline like existing `cardPulse`:

```css
@keyframes cardGlowBurst {
  0%   { box-shadow: 0 0 0 0px ${sphereColor}40; transform: scale(1); }
  40%  { box-shadow: 0 0 24px 12px ${sphereColor}60; transform: scale(1.02); }
  100% { box-shadow: 0 0 0 0px ${sphereColor}00; transform: scale(1); opacity: 0.7; }
}
```

- **Duration:** 600ms (`DRAWER_CLOSE_DELAY_MS` from `DIVINE_INFLUENCE_CONSTANTS`) — matches existing intervention timing
- **Easing:** ease-out
- **After burst completes:** card opacity drops to 0.7 (spent state), action resolves, toast appears

### Toast — Action Outcome

Extends existing `ToastStack` / `ToastItem` system (no new component needed):

- **Left border:** 3px solid sphere color (new visual distinction vs existing system toasts)
- **Icon:** Success = `✓` in `--positive` (#10b981); Failure = `✕` in `--negative` (#f87171)
- **Title:** Sphere name + outcome, e.g. "Force — Action Complete" or "Void — Action Failed"
- **Body:** `consequenceMessage` from template if present; fallback to `narrativeTemplates.success/failure`
- **Duration:** 4000ms auto-dismiss (Claude's discretion — matches existing intervention feedback rhythm)
- **Position:** Existing toast stack position (top-right), no change to stack layout

### Hex Particle Burst (HexMapV2)

New WebGL particle system triggered on action activation. Claude's discretion for exact implementation — contract specifies:

- **Trigger:** Action resolves successfully — dispatched via callback from `useAgentInteraction` to HexMapV2
- **Target:** The target hex world position (converted via hex-to-world coordinate transform)
- **Shape:** Radial burst of 12-20 point sprites expanding outward from target hex center
- **Color:** Sphere color at 80% opacity, fading to transparent over particle lifetime
- **Duration:** 800ms total (spawn + expand + fade). Particles do not loop.
- **Z layer:** `LAYER_Z.BATTLE_INDICATOR` zone (above agents, below labels). Assign new `LAYER_Z.PARTICLE_BURST` constant just above `LAYER_Z.BATTLE_INDICATOR`.
- **Scale:** Particle size 4-8px at hero-local zoom; hidden at continental and full-world zoom (below zoom threshold)
- **Reuse pattern:** Particle system is a standalone mesh/emitter that can be triggered for any future effects (not hardcoded to actions)

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | "Activate" — shown in focused card hint bar when action is available. Single word is intentional: the focused card already displays the spell name in the title zone, making "Activate" contextual within the card-game frame (equivalent to "Play" in MTG). Adding a noun would duplicate information already visible on screen. |
| Hand card name overlay | Exact spell name (e.g. "Call to Arms", "Bellum Fortis") — no description |
| Art frame placeholder label | _(none visible)_ — placeholder is purely visual, no text besides the sphere glyph symbol |
| Type line format | `[REACH NAME] · [CRUD TYPE]` e.g. "IRON · DESTROY" or "GOLD · CREATE" — both uppercase, no extra punctuation |
| Description text style | Sentence case, 2-3 sentences. Present tense. No numbers. Examples: "Summons the martial will of an agent's host force. Troop cohesion tightens and defensive capability rises. Effects are amplified near fortifications." |
| Flavor text style | Italicized, slightly archaic voice. May quote or echo Ars Magica/Latin flavor. Example: *"Steel remembers the hand that forged it."* |
| Toast — action success title | "{Sphere Name} — Action Resolved" (e.g. "Force — Action Resolved") |
| Toast — action failure title | "{Sphere Name} — Action Failed" |
| Toast — consequence body | From `consequenceMessage` template if present; else from `narrativeTemplates.success` or `narrativeTemplates.failure`. Never shown empty — fallback to "The outcome ripples outward." |
| Lock reason (unchanged) | Existing `slot.lockedReason` text — no change in this phase |
| Focused card — activated state | _(no copy)_ — spent overlay uses `✓` glyph only, no text |
| Empty action drawer (no slots) | _(no change in this phase)_ — existing empty state behavior |
| Destructive confirmation | Not applicable — no destructive actions in this phase |

**Spell naming guidelines (Claude's discretion for 108+ templates):**
- Mix English and Latin — prefer evocative over literal ("Whisper of Coin" over "Bribe Agent")
- Ars Magica style: action + object, or evocative noun phrase
- Per-reach tonal consistency: Iron reach = martial/decisive; Gold reach = commercial/subtle; Veil reach = hidden/quiet; Star reach = cosmic/distant
- Max 3 words per spell name — must fit 280px card name zone in Cinzel 18px

## Animation & Timing Contract

All durations sourced from or aligned with `DIVINE_INFLUENCE_CONSTANTS` in `src/data/intervention-feedback-content.ts`:

| Event | Duration | Source |
|-------|----------|--------|
| Glow burst on card | 600ms | `DRAWER_CLOSE_DELAY_MS` — matches existing intervention animation length |
| Card transitions to spent opacity (0.7) | 200ms | `CARD_SPENT_MS` |
| Audio tone plays | 200ms | `AUDIO_DURATION_MS` |
| Hex particle burst (total) | 800ms | Claude's discretion — slightly longer than card burst for world-space drama |
| Toast appears after glow burst | ~600ms after click (action resolves, then toast) | Matches existing drawer close delay pattern |
| Toast auto-dismiss | 4000ms | Claude's discretion |
| Drawer closes after activation | `DRAWER_CLOSE_DELAY_MS` (600ms) | Existing pattern — unchanged |

**Sequence on activation:**
1. Click focused card → `handlePlayAction()` fires
2. Glow burst begins on card (0ms)
3. Audio tone plays (0ms, overlapping)
4. At 600ms: action resolves in engine, drawer begins closing
5. Hex particle burst begins at target hex (~600ms)
6. Toast appears in stack (~650ms, after resolution)
7. Particle burst fades out (~1400ms total from click)

## Accessibility Contract

- **ActionCard focusable:** `tabIndex={0}` on available cards, `tabIndex={-1}` on playing cards — existing pattern preserved
- **ARIA disabled:** `aria-disabled={true}` on locked/unavailable cards — existing pattern preserved
- **Keyboard activation:** Enter/Space on focused card triggers activation — existing pattern preserved
- **Flavor text semantic:** Wrap in `<p className="italic">` not `<em>` — screen readers should read it as prose, not as emphasized inline text
- **Art frame alt:** Art frame placeholder div is decorative; add `aria-hidden="true"` to the placeholder element
- **Particle burst:** Purely decorative WebGL effect; no ARIA changes needed (canvas is already aria-hidden)
- **Toast announcements:** Existing ToastStack behavior — no change. Toasts are `role="status"` or equivalent via AnimateMount wrapper.
