
Structure (following UI-SPEC ThreadDetailView anatomy):
```
[Type badge] Entity Name   [x close]   -- header, bg-deep, border-bottom gold
[Tier badge] Tier name
---
[Decision data fields — adaptive]      -- body, bg-surface, overflow-y-auto, 18px Alegreya Sans
Only populated fields shown
---
[View Full Profile ->]                  -- footer, links to modal
```

Header:
- Type badge: category label ("Agent", "Location", "Faction", "Army", "Artifact") in small caps
- Entity name: `var(--font-display)`, `var(--text-base)` (18px), weight 700
- Close button (x): top-right, `aria-label="Close detail"`, calls `onClose`
- Tier badge: `TIER_COLORS[tier]` background at 20% opacity, tier name text in tier color, `var(--text-xs)`, weight 700

Body — dispatch per category, using `var(--font-body)`, `var(--text-base)` (18px), weight 400. Only render fields with non-null/non-empty values (adaptive display):

**Agent detail** (when `agentInfoCard` is provided):
- Domain capabilities: show the 8 reach domains as a compact 2x4 grid of `{domain}: {tier}` labels. Use `agentInfoCard.domainCapabilities` if available. Each entry shows reach name + capability tier number.
- Sphere alignment: show dominant sphere with `getSphereColor()` colored dot + sphere name
- Thread tier: tier name + tier badge
- Quintessence: show `agentInfoCard.quintessence` label if present (uses IPK prose, not number)
- Current activity: `node.activityLabel` (from ThreadedAgent)
- If `agentInfoCard` is null/undefined, show just the basic fields from ThreadedAgent (name, location, activity, tier)

**Location detail:**
- Sphere character: if hex has sphere data, show dominant sphere name
- Prosperity: `node.prosperityLabel`
- Agents present: count of agents at location (query via `graph.getIncomingEdges(node.id, 'located_at')` if graph provided). Show first 3 names, then "+N more" if more
- Controlling faction: `node.controllingFaction` or omit if null
- Active threats: omit for now (no easy query — placeholder for future)

**Faction detail:**
- Territory extent: `"{node.territoryCount} hexes"` if > 0
- Members: `"{node.memberCount} members"`
- Threaded members: count of agents in ThreadsPanel that have `factionName === node.name` (pass as prop or compute from threadedNodes)

**Army detail:**
- Strength: `"{node.size} strong"`
- Current location: `node.locationName`
- Objective: `node.objective`
- Commander: if available from node properties
- Faction: `node.factionName`

**Artifact detail:**
- Bearer: `"Carried by {node.bearerName}"` or `"(location unknown)"`
- Location: `"In {node.locationName}"` if bearerName is null but locationName exists

Footer:
- "View Full Profile" link in `var(--accent-gold)` color, `cursor: pointer`, calls `onViewProfile(node.id, node.category)`
