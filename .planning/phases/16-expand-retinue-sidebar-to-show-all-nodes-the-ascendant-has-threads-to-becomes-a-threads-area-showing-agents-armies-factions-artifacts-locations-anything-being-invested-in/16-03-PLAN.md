**1. Check TargetCategory in `src/types/targetContext.ts`:**

The existing `TargetCategory` type is `'actor' | 'location' | 'hex' | 'self'`. Thread-creation templates targeting factions and armies need `targetCategories: ['actor']` (since factions and armies are actor nodes). Templates targeting locations need `targetCategories: ['location']`. Templates targeting artifacts need... check if `'artifact'` is a TargetCategory. If not, artifacts are not targetable via the existing system and need either:
- Adding `'artifact'` to TargetCategory (if the action system supports it)
- Or deferring artifact thread-creation to a future phase

If `'artifact'` is not in TargetCategory and adding it requires changes to the targeting pipeline, defer the artifact template and note it as a gap. Do NOT add a broken template.
