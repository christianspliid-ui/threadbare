**New function `getThreadedNodes()`:**

1. Call `graph.getOutgoingEdges(ascendantId, 'thread')` to get all thread edges
2. For each edge, get target node via `graph.getNode(edge.target)`
3. Skip if node is null or tier === 0
4. Classify based on node type + actorType:
   - `node.type === 'actor'` AND `props.actorType === 'individual'` => `'agent'`
   - `node.type === 'actor'` AND `props.actorType === 'faction'` => `'faction'`
   - `node.type === 'actor'` AND `props.actorType === 'group'` AND `props.armyState != null` => `'army'`
   - `node.type === 'location'` => `'location'`
   - `node.type === 'artifact'` OR `node.type === 'artifact_legendary'` => `'artifact'`
   - All other types: skip (do not include god, culture, etc.)
5. For each category, extract type-specific data:
   - **Agent:** Resolve location via `located_at` outgoing edge. Get faction via `member_of` edge. Get portrait via `getPortraitUrl()`. Get primary domain from `domainCapabilities`. Activity label defaults to `'Idling'` (enrichment happens at call site, same as existing `getRetinueAgents` pattern).
   - **Location:** Read `hexCol`, `hexRow` from properties. Derive prosperity label from `prosperityScore`: `prosperityScore >= 70 ? 'Prosperous' : prosperityScore >= 40 ? 'Stable' : prosperityScore >= 10 ? 'Struggling' : 'Destitute'`. Get controlling faction via incoming `controls` edges from actor nodes with `actorType === 'faction'`.
   - **Faction:** Count territory via outgoing `controls` edges to location nodes. Count members via incoming `member_of` edges.
   - **Army:** Read `armyState.size`, `armyState.objective` (default `'Standing'`). Get location via `located_at` outgoing edge. Get faction via `member_of` edge.
   - **Artifact:** Find bearer via incoming `possesses` or `bonded_to` edges. If bearer found, use bearer name. Otherwise check `located_at` for location.
6. Sort within each category: tier descending, then name ascending (same sort as getRetinueAgents)
7. Return `ThreadedNode[]` — all categories mixed, sorted by tier desc then name asc

**Also add a helper:**

```typescript
export function groupThreadedNodes(nodes: ThreadedNode[]): Record<ThreadCategory, ThreadedNode[]> {
  const groups: Record<ThreadCategory, ThreadedNode[]> = {
    agent: [], location: [], faction: [], army: [], artifact: [],
  };
  for (const node of nodes) {
    groups[node.category].push(node);
  }
  return groups;
}
```
