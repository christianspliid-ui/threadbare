# Phase 07.1 Plan 01: Stencil Coastline Clipping Summary

**One-liner:** GPU stencil-buffer coastline: land hexes clip to organic shoreline shape, water hexes render as full hexagons, fog works on both via globalToMeshMap routing.

## What Was Built

Implemented stencil-buffer coastline clipping across three rendering passes:

**Pass 1 — Stencil Write (renderOrder = -1):** CoastlineMesh now creates invisible geometry (colorWrite: false, stencilWrite: true) from the organic coastline contours using STENCIL_THRESHOLD = 0.30. This writes 1 into the GPU stencil buffer for every pixel that is "inside" the land area.

**Pass 2 — Land Hex Fill (renderOrder = 0):** The land InstancedMesh uses stencilFunc = THREE.EqualStencilFunc and stencilRef = 1. Land hex pixels only render where the stencil is 1 — i.e., inside the organic coastline shape. This clips all coastal land hexes to the shoreline boundary.

**Pass 3 — Water + Coastline (renderOrder = 0 and 1):** The water InstancedMesh renders normally as full hexagons with no stencil constraints. Shallow depth band fills and lake shore fills render above at renderOrder COASTLINE (1).

### Key Changes

**RenderLayers.ts:** Added `STENCIL_WRITE: -1` constant — the stencil write pass must render before all geometry.

**HexSceneSetup.ts:** Added `stencil: true` to WebGLRenderer constructor — enables the stencil buffer.

**HexFillMesh.ts:** Refactored `createHexFillMesh` from returning one InstancedMesh to returning `HexFillMeshResult` with `landMesh`, `waterMesh`, `landTileIndices`, `waterTileIndices`. Land mesh has stencil properties set; water mesh is unmodified. `updateHexColors` updated to accept `HexFillMeshResult`.

**CoastlineMesh.ts:** Replaced the disabled early-return with full stencil implementation. Exports `STENCIL_THRESHOLD = 0.30`. Creates stencil write meshes from coastlineData.loops, shallow band fills from shallowLoops, lake fills from lakeLoops. Accepts optional `lakeIds?: Int16Array` as 5th parameter.

**HexMapV2.tsx:** Updated scene init to add both `fillResult.landMesh` and `fillResult.waterMesh` to the scene. Builds `globalToMeshMap` (global tile index → {mesh, instanceIdx}) at init for O(1) fog routing. Fog update effect updated to route `setColorAt` through globalToMeshMap instead of single fillMesh. Both meshes get `instanceColor.needsUpdate = true` after fog updates.

## Deviations from Plan

None — plan executed exactly as written. The `updateFogColors` function from FogCulling.ts was not reused (as anticipated in the plan) — the fog logic was inlined in HexMapV2.tsx to route through globalToMeshMap. This keeps FogCulling.ts unchanged as planned.
