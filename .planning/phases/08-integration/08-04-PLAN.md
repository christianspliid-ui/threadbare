The familiarity integration tests fail because the test setup calls `initializeGameState(...)` which generates a world with specific seed 42, grid 20x15. The test then tries to find a worshipper agent that shares the same hex as the avatar, but no such worshipper exists at those coordinates with this seed/grid combination.

The core issue: `initializeGameState` places worshippers at their own locations, and the avatar at its own location. The test assumes at least one worshipper will be co-located with the avatar, but this depends on world generation placing agents in the same hex — which may not happen with a 20x15 grid.

**Fix approach: Manually place a worshipper in the avatar's hex after init.**

After `state = result.state;` in `beforeEach`, add code to:

1. Find the avatar's hex coordinates:
```typescript
const avatarEdges = state.graph.getIncomingEdges(state.ascendantId, 'avatar_of');
const avatarId = avatarEdges[0].source;
const avatarLocEdges = state.graph.getOutgoingEdges(avatarId, 'located_at');
const avatarLocation = state.graph.getNode(avatarLocEdges[0].target);
const avatarHexCol = avatarLocation?.properties?.hexCol;
const avatarHexRow = avatarLocation?.properties?.hexRow;
```

2. Find a worshipper and move it to the avatar's location:
```typescript
const worshipEdges = state.graph.getEdgesByType('worships');
if (worshipEdges.length > 0) {
  const worshipperId = worshipEdges[0].source;
  const worshipperLocEdges = state.graph.getOutgoingEdges(worshipperId, 'located_at');
  if (worshipperLocEdges.length > 0) {
    const locNode = state.graph.getNode(worshipperLocEdges[0].target);
    if (locNode) {
      // Move worshipper's location to avatar's hex
      state.graph.updateNodeProperties(worshipperLocEdges[0].target, {
        hexCol: avatarHexCol,
        hexRow: avatarHexRow,
      });
    }
  }
}
```
