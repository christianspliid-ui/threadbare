  <action>
    Create `AgentSpriteMesh.ts`:

    Export `AgentSpriteGroup` interface:
    ```typescript
    {
      portraitGroup: THREE.Group;  // hero-local zoom sprites (portraits with rings)
      dotGroup: THREE.Group;       // regional zoom sprites (colored dots)
      continentalGroup: THREE.Group; // continental zoom retinue-only tiny dots
      spriteMap: Map<string, { portrait: THREE.Sprite; dot: THREE.Sprite; continental?: THREE.Sprite }>;
      dispose: () => void;
    }
    ```

    Export `createAgentSpriteMesh(agents: AgentRenderData[]): AgentSpriteGroup`:
    - Creates 3 THREE.Group instances, all with renderOrder = RENDER_ORDER.AGENTS (9)
    - Groups agents by hex key (`${hexCol},${hexRow}`)
    - For each hex group: calculate RING positions using `getRingSlotOffset(i, count, AGENT_RING_RADIUS)` from movementPath.ts. Sort agents by id for stable ordering.
    - For each agent:
      - Compute world position: `hexToPixel({col, row}, HEX_SIZE)` plus RING offset, with Y-flip
      - Create portrait sprite (hero-local): SpriteMaterial with faction dot texture initially (portrait loaded async later), scale based on AGENT_PORTRAIT_RADIUS * 2 (14 SVG units, converted to world scale: `14 / HEX_CONSTANTS.HEX_SIZE * HEX_CONSTANTS.HEX_SIZE` = 14 world units). Position at computed world pos, z = AGENT_SPRITE_Z.
      - Create dot sprite (regional): SpriteMaterial with faction dot texture (from buildFactionDotTextureCache), scale based on AGENT_TOKEN_RADIUS * 2 (8 world units). Same position.
      - If isRetinue: create continental sprite (tiny dot, scale based on AGENT_DOT_RADIUS * 2 = 5 world units). Use retinue dot texture.
      - Store all sprites in spriteMap keyed by agent id.
    - Set initial visibility: all groups hidden (visibility managed by caller's zoom handler).
    - Return AgentSpriteGroup.

    Export `updateZoomVisibility(group: AgentSpriteGroup, zoomLevel: number): void`:
    - zoomLevel >= AGENT_ZOOM_THRESHOLDS.HERO_LOCAL (15): portraitGroup.visible=true, dotGroup.visible=false, continentalGroup.visible=false
    - zoomLevel >= AGENT_ZOOM_THRESHOLDS.REGIONAL (5) and < 15: portraitGroup.visible=false, dotGroup.visible=true, continentalGroup.visible=false
    - zoomLevel >= AGENT_ZOOM_THRESHOLDS.CONTINENTAL (1.5) and < 5: portraitGroup.visible=false, dotGroup.visible=false, continentalGroup.visible=true
    - zoomLevel < 1.5: all hidden

    Export `async function loadAgentPortraits(group: AgentSpriteGroup, agents: AgentRenderData[]): Promise<void>`:
    - For each agent with a portraitUrl: call loadPortraitTexture, then swap the portrait sprite's material.map to the loaded texture and set material.needsUpdate=true.
    - Run all loads in parallel via Promise.allSettled (fail-soft: rejected loads keep dot texture).

    Export `updateAgentPositions(group: AgentSpriteGroup, agents: AgentRenderData[]): void`:
    - Re-groups agents by hex, recalculates RING offsets, updates sprite positions.
    - For agents that moved: updates position on portrait, dot, and continental sprites.
    - For new agents: creates new sprites. For removed agents: disposes and removes.

    Handle count badge: when >MAX_RING_AGENTS (6) agents on a hex at regional zoom, only show MAX_RING_AGENTS dots and the rest are hidden. The count badge itself is an HTML overlay handled separately (can be added to LocationLabelOverlay or a small AgentCountOverlay — defer to Plan 04 if needed, or add a simple one here).

    Dispose function: iterate all sprites in all groups, dispose materials and textures.
