      - Converts fromHex/toHex to world positions via hexToPixel + Y-flip

      - Returns AgentAnimState with startTime=performance.now(), phase='moving'

    - Export `tickAgentAnimations(animStates: Map<string, AgentAnimState>, spriteMap: Map<string, { portrait: THREE.Sprite; dot: THREE.Sprite; continental?: THREE.Sprite }>): void`:
      - Called each frame from render loop.
      - For each active animation:
        - If phase='moving': t = min(1, (now - startTime) / duration). Evaluate bezier at t. Update all sprite positions (portrait, dot, continental).
        - When t >= 1: transition to 'settling' phase, record settle start time.
        - If phase='settling': t = min(1, (now - settleStart) / settleDuration). Apply subtle bounce (scale 1.05 -> 1.0 lerp). When done: remove from animStates.
      - NFP #4: If sprite not found in spriteMap, skip silently.
