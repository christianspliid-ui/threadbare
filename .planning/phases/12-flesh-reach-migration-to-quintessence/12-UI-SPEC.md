## Spacing Scale

4px base. All values are multiples of 4. Use CSS custom property tokens — never raw pixel values.

| Token | Value | Usage |
|-------|-------|-------|
| `--space-1` | 4px | Icon gaps, micro padding, inline margins |
| `--space-2` | 8px | Tight spacing within elements, chip padding |
| `--space-3` | 12px | Gap between related items (reach cells in grid) |
| `--space-4` | 16px | Standard panel padding, element spacing |
| `--space-5` | 20px | Comfortable section spacing |
| `--space-6` | 24px | Section separation within modals |
| `--space-8` | 32px | Large separation, between panels |

Exceptions:
- Reach grid cells in 2×4 layout: `gap: var(--space-2)` (8px) between cells — same as the current 3×3 grid
- Archetype epithet in agent profile header: `margin-top: var(--space-1)` (4px) below agent name — visually tight to name, not a full section break
- IPK (Interactive Prose Keyword) spans: `padding: 0 var(--space-1)` (0 4px) — inline, no vertical padding

*Source: design-system/tokens.md (pre-populated)*

## Typography

All sizes from `Docs/design-system/typography.md`. Phase 12 introduces no new font sizes.

| Role | Token | Size | Family | Weight | Line Height | Usage |
|------|-------|------|--------|--------|-------------|-------|
| Body prose | `--text-base` | 18px | Alegreya Sans | 400 (regular) | 1.7 | Chronicle prose, Quintessence IPK sentence |
| Label / metadata | `--text-xs` | 16px | Alegreya Sans | 400 (regular) | 1.2 | Reach badge text, grid cell domain labels, archetype knowledge-gate placeholder |
| Secondary body | `--text-sm` | 17px | Alegreya Sans | 400 (regular) | 1.4 | Agent name in lists, domain values in grid cells |
| Panel heading | `--text-xl` | 26px | Cinzel | 600 (semibold) | 1.1 | AgentProfileModal title (agent name) |
| Archetype epithet | `--text-sm` | 17px | Cinzel | 400 (regular) | 1.2 | Archetype epithet displayed below agent name in profile header |

**Weights declared (exactly 2):**
- 400 regular — all body, labels, metadata, archetype epithet
- 600 semibold — panel titles only (Cinzel headings)

**Letter spacing:**
- Cinzel display headings: `0.04em`
- Uppercase section labels: `0.12em`
- Archetype epithet (Cinzel regular): `0.04em`
- Reach domain labels (uppercase `--text-xs`): `0.12em`

**Minimum size rule:** `--text-xs` (16px) is absolute floor. No smaller text anywhere.

## Component Inventory — Phase 12 Changes

These are the specific component surfaces touched by Phase 12. No new components are introduced.

### AgentDetailPanel.tsx — Grid layout change

**Current:** 3×3 grid (`DOMAINS_GRID` as 3 rows of 3)
**Target:** 2×4 grid (2 rows of 4 reaches)

```
Row 1: [iron]  [gold]  [shadow] [veil]
Row 2: [heart] [eye]   [stone]  [star]
```

- Grid CSS: `display: grid; grid-template-columns: repeat(4, 1fr); gap: var(--space-2)`
- Each cell: `--bg-raised` background, `--border-subtle` border, `border-radius: 4px`
- Domain label: `--text-xs`, uppercase, `--text-tertiary`, `letter-spacing: 0.12em`
- Capability tier value: `--text-sm`, `--text-secondary`
- Remove `flesh` entry from `DOMAIN_NAMES` constant
- At 1920×1080: 2-row layout fits within the right sidebar (360px target width) — 4 cells per row at ~82px each with 8px gaps

### ProwessTab.tsx — Grid layout change (mirror of AgentDetailPanel)

**Current:** 3×3 grid (`ALL_DOMAINS` as 3 rows of 3)
**Target:** 2×4 grid (same layout as AgentDetailPanel)

- Same grid CSS as AgentDetailPanel
- Must be updated in the **same commit** as AgentDetailPanel — both maintain independent `DOMAINS_GRID`/`ALL_DOMAINS` constants
- Verify at `?view=game` 1920×1080 after change

### AgentProfileModal.tsx — Archetype epithet in header

**Where:** Below the agent name in the modal header, above the tab strip
**Reveal condition:** Knowledge-gated — only rendered when `knowledge.revealedFacets` includes `'archetype'` or knowledge level is `'intimate'` or higher
**Hidden state:** No placeholder text shown — absence of epithet is silent when not revealed
**Format:** "The [Dominant] of [Modifier-domain]" — e.g., "The Protector of Secrets"
**Typography:** `--text-sm` (17px), Cinzel regular (400), `--accent-gold`, `letter-spacing: 0.04em`
**Spacing:** `margin-top: var(--space-1)` (4px) below the agent name heading

Visual treatment:
- Rendered as a single italicized line in Cinzel at gold color — signals narrative significance without competing with the agent name
- If epithet is null (no lean >0.6 or not yet revealed): render nothing, no gap
- Do NOT use `--text-muted` for an "unknown" placeholder — absence is preferred

### MeetingEncounterModal.tsx — Archetype framing prose

**Change:** Remove flesh emoji. Add archetype framing prose in the encounter narrative section when both parties have revealed archetypes.
**Treatment:** Archetype labels in encounter prose render as `--text-secondary` weight, Cinzel, inline with narrative framing — not as explicit UI labels
**If archetype unknown:** Omit from framing prose entirely

### IPK — Quintessence display (existing ProseKeyword component, no change needed)

Quintessence levels are surfaced via the existing `ProseKeyword` (IPK) component from Phase 10. No visual contract changes to the component itself. The content contract:
- Word displayed: one of the 10 lexicon words (Fraying, Flickering, Tenuous, Steady, Rooted, Resonant, Crystalline, Radiant, Transcendent, Absolute)
- Tooltip on hover (600ms delay): brief definition of the Quintessence level (e.g., "Fraying — existence is unraveling. This entity is near dissolution.")
- No numeric value displayed — prose word only
- IPK renders inline within chronicle/description prose — not as a standalone UI element

*Source: CONTEXT.md, RESEARCH.md, Docs/design-system/components.md (pre-populated)*

## Interaction Contract

### Reach Grid (2×4)

- **At rest:** `--bg-raised` background, `--border-subtle` 1px border
- **Hover:** `--bg-hover` background, `--border-medium` border — via `onMouseEnter`/`onMouseLeave` per established pattern in `Docs/design-system/interactions.md`
- **No selection state on reach cells** — they are informational display, not interactive selectors
- **Cursor:** `default` (not pointer) — these are read-only display cells

### Archetype Epithet

- **No click interaction** — display-only
- **Cursor:** `text` (default for text content)
- **No tooltip** — the full epithet is already the most expanded form of the information

### IPK Quintessence Keyword

- **Hover tooltip** at 600ms delay — shows the level definition copy from the table above
- **Cursor:** `help` (indicates tooltip available)
- **No click action** — inline prose keyword, read-only
- Follows existing `ProseKeyword` component interaction contract from Phase 10

### Knowledge Gate Transition

When archetype knowledge is revealed mid-session, the epithet should appear without animation (instant render). No reveal animation needed — the Chronicle event that triggers the revelation is the narrative moment.
