  <action>
    Create src/components/HexMapV2/scene/RiverMesh.ts following the Scene Module Factory pattern.

    CRITICAL: Use mesh quad strips for river width (per user decision). Do NOT use Three.js
    linewidth -- WebGL clamps it to 1 on most hardware.

    1. Export function createRiverMesh(riverPaths: RiverPath[], tiles: HexTile[], seed: number): THREE.Group

    2. River path curve generation (port from RiverOverlay.tsx):
       - For each RiverPath, convert hex coords to pixel positions via hexToPixel(coord, HEX_CONSTANTS.HEX_SIZE)
       - Apply Y-flip: threeY = -svgY
       - Subdivide points between hex centers (MEANDER_SUBDIVISIONS = 4 intermediate points per segment)
       - Apply perpendicular noise displacement using SimplexNoise (seeded) for organic meander
       - Apply Chaikin smoothing (2 passes) for final curve

    3. Quad strip generation (the width-varying mesh):
       - For each point along the smoothed curve, compute:
         a. Tangent direction (normalized vector from prev to next point)
         b. Normal direction (perpendicular to tangent, rotated 90 degrees)
         c. Width at this point: lerp from RIVER_WIDTH_SOURCE to RIVER_WIDTH_MOUTH based on
            position along the path (t = pointIndex / totalPoints). Width represents half-width
            in world units.
       - For each point, emit two vertices: center + normal * halfWidth, center - normal * halfWidth
       - Build triangle strip indices: for N points, create (N-1) * 2 triangles connecting
         successive cross-sections

    4. Combine all river paths into one merged BufferGeometry for minimal draw calls.
       Use a single THREE.Mesh with MeshBasicMaterial({ color: WATER_PALETTE.river, side: THREE.DoubleSide }).

    5. Constants (NFP #1 -- all tunable, named):
       - RIVER_WIDTH_SOURCE = 0.3 (world units half-width at river source -- thin stream)
       - RIVER_WIDTH_MOUTH = 1.8 (world units half-width at river mouth -- wide river)
       - RIVER_MEANDER_SUBDIVISIONS = 4
       - RIVER_MEANDER_NOISE_SCALE = 0.035
       - RIVER_MEANDER_AMPLITUDE = 0.35 (fraction of HEX_SIZE for max perpendicular displacement)
       - RIVER_SMOOTH_PASSES = 2 (Chaikin corner-cutting iterations)
       - RIVER_SEED_OFFSET = 5501 (so river noise differs from coastline noise)
       - RIVER_Z_OFFSET = 0.03 (z position to sit above coastline and grid layers)

    6. Fail-soft: empty riverPaths returns empty THREE.Group. A river with < 2 hexes is skipped.
       Invalid hex coords (no matching tile) are skipped without crashing.
  </action>
