    - Test 3: given two adjacent hexes with elevation diff < TICK_THRESHOLD, output has zero vertices for that edge
    - Test 4: tick count = clamp(floor(elevDiff / TICK_DENSITY_STEP), 3, 8) -- verify 3 ticks for minimum qualifying diff
    - Test 5: tick count = 8 for very large elevation difference (clamp ceiling)
    - Test 6: shared edges are not double-counted (same edgeSet dedup pattern as HexGridLines)
    - Test 7: given all-flat terrain (all same elevation), output has zero vertices
  </behavior>
  <action>
    Create src/components/HexMapV2/scene/ElevationTicks.ts following the Scene Module Factory pattern.
    Reuse the edge deduplication pattern from HexGridLines.ts.

    1. Export function createElevationTicks(tiles: HexTile[]): THREE.LineSegments

    2. Build a coord-to-tile lookup map: Map<string, HexTile> keyed by "col,row" for O(1) neighbor lookup.

    3. For each tile, examine all 6 hex edges:
       a. Compute the neighbor hex for this edge direction
       b. Look up the neighbor tile in the map
       c. If neighbor not found (edge of map) or already processed (edgeSet dedup), skip
       d. Compute elevDiff = Math.abs(tile.geoParams.elevation - neighbor.geoParams.elevation)
       e. If elevDiff < TICK_THRESHOLD, skip (no ticks for gentle slopes)

    4. For qualifying edges, compute tick marks:
       a. tickCount = Math.min(8, Math.max(3, Math.floor(elevDiff / TICK_DENSITY_STEP)))
       b. Get the two vertex positions of this hex edge (same geometry as HexGridLines: vertex i and vertex (i+1)%6)
       c. Apply Y-flip to vertex positions
       d. Distribute tickCount ticks evenly along the edge
       e. For each tick position:
          - Compute position along edge via lerp: t = (k + 1) / (tickCount + 1) for k in [0..tickCount-1]
          - Compute edge midpoint at t
          - Compute perpendicular direction to edge
          - Emit a short line segment: center +/- perpendicular * TICK_LENGTH
          - Tick lines point toward the HIGHER elevation side (uphill direction)

    5. Edge deduplication: use the same edgeKey + edgeSet pattern from HexGridLines.ts.
       Track processed (hexA, hexB) pairs so shared edges emit ticks once, not twice.

    6. Assemble all tick segments into a single BufferGeometry.
       Material: LineBasicMaterial({ color: TICK_COLOR, transparent: true, opacity: TICK_OPACITY }).
       Set renderOrder = RENDER_ORDER.ELEVATION_TICKS.

    7. Constants (NFP #1 -- all named, all tunable):
       - TICK_THRESHOLD = 0.08 (minimum elevation difference to show ticks)
       - TICK_DENSITY_STEP = 0.03 (elevation diff per tick -- lower = more ticks per given diff)
       - TICK_LENGTH = 0.8 (half-length of each tick mark in world units)
       - TICK_COLOR = 0x2a1a0a (dark brown, blends with mountain terrain)
       - TICK_OPACITY = 0.6
       - TICK_MIN = 3 (minimum ticks per qualifying edge)
       - TICK_MAX = 8 (maximum ticks per qualifying edge)

    8. Fail-soft: if tiles is empty or all same elevation, return empty LineSegments (no crash).
  </action>
