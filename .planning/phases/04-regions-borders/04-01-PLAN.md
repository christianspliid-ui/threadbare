    **1. Implement `detectRegionsBorderCost()` in regionDetection.ts:**

    ```typescript
    // Constants (NFP #1 Tunability)
    export const REGION_TARGET_SIZE = 120;
    export const REGION_MIN_SIZE = 20;
    export const REGION_MAX_SIZE = 200;
    export const REGION_MAP_LABEL_MIN_SIZE = 30;

    export const BORDER_COSTS = {
      COAST: 1.0,
      MOUNTAIN: 0.9,
      RIVER: 0.7,
      STEEP_ELEVATION: 0.5,  // elevation diff > 0.15
      BIOME_CHANGE: 0.4,
      SAME_TERRAIN: 0.1,
      ELEVATION_THRESHOLD: 0.15,
    } as const;
    ```

    Algorithm:
    1. Build a tile map (`"col,row" -> HexTile`) and a river-edge lookup (`"col1,row1-col2,row2" -> true`) from riverPaths
    2. Seed initial regions from provinceCapitalHexes (one seed per capital). If no capitals available, place seeds every ~sqrt(REGION_TARGET_SIZE) hexes on land.
    3. Priority-queue (min-heap by cost) flood-fill from all seeds simultaneously. For each hex dequeued, assign to the seed's region if not yet assigned. Enqueue neighbors with cost = accumulated cost + edgeBorderCost(current, neighbor, hasRiverEdge).
    4. After assignment: merge any region with fewer than REGION_MIN_SIZE hexes into its lowest-cost neighbor region.
    5. Split any region with more than REGION_MAX_SIZE hexes: find the highest-cost internal edge and split along it (BFS from each side).
    6. Compute centroid for each region: arithmetic mean of col/row, then snap to nearest hex IN the region.
    7. Build hexRegionId map from results.
    8. Return `RegionCluster[]` with sequential `id` values starting at 0.

    The priority queue can be a simple array-based min-heap. At 60K hexes, O(n log n) Dijkstra is needed.
