    **1. Create `src/engine/regionPolitical.ts`:**

    ```typescript
    export function assignPoliticalRegions(
      geographicRegions: RegionCluster[],
      hexRegionId: Map<string, number>,
      provinces: Province[],
      provinceCapitalHexes: HexCoord[],
      provinceIds: Int16Array,
      cols: number,
      seed: number,
    ): { baronies: BaronyRegion[]; kingdoms: KingdomRegion[]; hexBaronyId: Map<string, number>; hexKingdomId: Map<string, number> }
    ```

    Algorithm:
    - One province = one barony. For each province, collect all geographic regions whose majority hexes fall within that province (by provinceIds lookup). The barony's hexes = union of its geographic regions' hexes.
    - Barony capital = province capitalHex.
    - Barony centroid = mean of hex coords, snapped to nearest in-barony hex.
    - Kingdom grouping: group all baronies with same non-null cultureId into one kingdom. Kingdom capital = the barony capital of the barony containing the province with role=capital (PROVINCE_ROLE_CAPITAL=0). Kingdom centroid = mean of barony centroids.
    - Wilderness baronies (cultureId=null) get no kingdom parent.
    - Build hexBaronyId and hexKingdomId maps from assignments.
    - Generate placeholder names using seeded PRNG: `mulberry32(seed + id)` picking from adjective+noun lists (e.g., "Stonemark", "Eastmarch", "Greyvale").

    **2. Wire into hexGrid.ts `generateWorld()`:**
    After detectRegionsBorderCost, call `assignPoliticalRegions(...)` and populate `regionData.baronies`, `regionData.kingdoms`, `regionData.hexBaronyId`, `regionData.hexKingdomId`.

    **3. Create `src/components/HexMapV2/scene/BorderMesh.ts`:**

    Factory function `createBorderMesh(regionData: RegionData, tiles: HexTile[], cols: number): { kingdomMesh: THREE.Mesh; baronyMesh: THREE.Mesh }`:
    - Walk every hex pair (check 3 of 6 neighbors to avoid double-count): directions 0, 1, 2 only.
    - For each pair: if different kingdom → add edge to kingdom positions array. Else if different barony → add edge to barony positions array.
    - Hex edge vertices: for hex at world position (wx, wy) with HEX_SIZE=10, vertex i is at `(wx + 10*cos(60*i deg), wy + 10*sin(60*i deg))`. Direction d maps to edge between vertex d and vertex (d+1)%6. **Y-flip: threeY = -svgY** (same as HexFillMesh convention).
    - Build quad-strip geometry for each edge using the RiverMesh pattern: `buildThickEdge(x0, y0, x1, y1, halfWidth, positions)`. Kingdom halfWidth = 1.5 world units, barony halfWidth = 0.75 world units.
    - Material: `new THREE.MeshBasicMaterial({ color: 0xC83030, side: THREE.DoubleSide })`.
    - Both meshes get `renderOrder = RENDER_ORDER.BORDERS` (6).
    - Z position for border vertices: `0.035` (above rivers at 0.03, below signifiers).
    - **REGN-06 enforcement:** Only political borders (barony/kingdom differences) generate geometry. Geographic-only region boundaries produce nothing.

    **4. Create `src/components/HexMapV2/scene/CapitalMarkers.ts`:**

    Factory function `createCapitalMarkers(regionData: RegionData): THREE.Points`:
    - Collect all barony capital hexes. Convert each to world position via `hexToPixel(capitalHex, HEX_CONSTANTS.HEX_SIZE)` with Y-flip.
    - Build `Float32BufferAttribute` positions array (x, -y, 0.04 for z — above borders).
    - Build `Float32BufferAttribute` sizes array: 6.0 for kingdom capitals, 3.0 for barony-only capitals.
    - Material: `new THREE.PointsMaterial({ color: 0xC83030, sizeAttenuation: false, vertexColors: false })`.
    - Note: THREE.Points doesn't support per-point sizes via attribute with PointsMaterial. Instead, create two separate Points objects: one for kingdom capitals (size=6) and one for barony capitals (size=3). Return as a `THREE.Group`.
    - renderOrder = RENDER_ORDER.LOCATIONS (8).

    **5. Wire into HexMapV2.tsx:**
    - Import `createBorderMesh` and `createCapitalMarkers`.
    - In the scene setup effect (same place as createRiverMesh, createElevationTicks): if `regionData` is available, call both factories and `scene.add()` the meshes.
    - Add `regionData` to HexMapV2Props interface: `regionData?: RegionData`.
    - Add to useEffect dependency array.
