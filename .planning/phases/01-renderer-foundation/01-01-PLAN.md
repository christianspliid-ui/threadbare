**1. `HexSceneSetup.ts`** — Export a `createHexScene` function and types:

```typescript
export interface HexScene {
  renderer: THREE.WebGLRenderer;
  scene: THREE.Scene;
  camera: THREE.OrthographicCamera;
  dispose: () => void;
}

export const SCENE_CONSTANTS = {
  BACKGROUND_COLOR: 0x0a0a0c,
  PIXEL_RATIO_CAP: 2,
  NEAR_PLANE: 0.1,
  FAR_PLANE: 10000,
} as const;
```

`createHexScene(canvas: HTMLCanvasElement, width: number, height: number): HexScene`:
- Create `WebGLRenderer` with `{ canvas, antialias: true, alpha: false }`, set pixelRatio to `Math.min(window.devicePixelRatio, SCENE_CONSTANTS.PIXEL_RATIO_CAP)`, set size to `(width, height)`.
- Create `Scene` with background color `SCENE_CONSTANTS.BACKGROUND_COLOR`.
- Create `OrthographicCamera` with frustum based on width/height. Position camera at z=100.
- Return `{ renderer, scene, camera, dispose }` where dispose cleans up renderer.

Also export `resizeHexScene(hexScene: HexScene, width: number, height: number): void` — updates renderer size and camera frustum.

**2. `HexFillMesh.ts`** — Export:

```typescript
export const HEX_CONSTANTS = {
  HEX_SIZE: 10,           // Flat-top radius in world units (tunable)
  GRID_COLS: 200,
  GRID_ROWS: 300,
  GRID_LINE_OPACITY: 0.12,
  BRIGHTNESS_NOISE_RANGE: 0.05,
} as const;
```

`buildHexGeometry(size: number): THREE.BufferGeometry` — Creates a flat-top hex polygon (6 triangles from center, vertices at 60-degree intervals starting from 0 degrees for flat-top). Use the formula: `angle = (Math.PI / 180) * (60 * i)` for each vertex i=0..5. Build 6 triangles: center->v[i]->v[i+1].

`createHexFillMesh(tiles: HexTile[], seed: number): THREE.InstancedMesh`:
- Build hex geometry using `HEX_CONSTANTS.HEX_SIZE`.
- Create `MeshBasicMaterial({ vertexColors: false })`. Note: use `InstancedMesh` with `mesh.instanceColor` for per-instance colors rather than vertex colors.
- Create `InstancedMesh(geo, mat, tiles.length)`.
- For each tile: use `hexToPixel(tile.coord, HEX_CONSTANTS.HEX_SIZE)` from `../../lib/hexMath` to get `(x, y)`. Set matrix: `position.set(x, -y, 0)` (flip Y: SVG y-down vs Three.js y-up). Set color using `getHexColor(tile.terrain, seed, tile.coord.col, tile.coord.row)` from palette/colorUtils.
- Set `mesh.instanceMatrix.needsUpdate = true` and `mesh.instanceColor!.needsUpdate = true`.
- Set `mesh.renderOrder = RENDER_ORDER.HEX_FILL`.
- Return the mesh.

`updateHexColors(mesh: THREE.InstancedMesh, tiles: HexTile[], seed: number): void` — Re-applies colors to an existing mesh (for dynamic terrain updates).

**3. `HexGridLines.ts`** — Export:

`createHexGridLines(tiles: HexTile[]): THREE.LineSegments`:
- For each tile, compute the 6 edge segments of its hex polygon in world coordinates. Each edge goes from vertex i to vertex i+1. Use same hexToPixel + HEX_SIZE + Y-flip as HexFillMesh.
- Deduplicate shared edges between adjacent hexes (each internal edge shared by 2 hexes — only add once). Use a Set keyed on sorted vertex pair coordinates (rounded to avoid float issues).
- Create `BufferGeometry` from all edge segments.
- Create `LineBasicMaterial({ color: 0x000000, transparent: true, opacity: HEX_CONSTANTS.GRID_LINE_OPACITY })`.
- Create `LineSegments(geo, mat)`, set `renderOrder = RENDER_ORDER.GRID`.
- Return the LineSegments.
