**1. `D3ZoomCamera.ts`** — Export:

```typescript
export const CAMERA_CONSTANTS = {
  MIN_ZOOM: 0.3,              // Full-world zoom (~10px/hex apparent)
  MAX_ZOOM: 10,               // Hero-local zoom (~300px/hex apparent)
  JUMP_TO_DURATION_MS: 500,
  DEFAULT_ZOOM: 1.5,          // Starting zoom level — shows a comfortable region
} as const;
```

`syncCameraToZoom(camera: THREE.OrthographicCamera, transform: d3.ZoomTransform, canvasWidth: number, canvasHeight: number): void`:
- Compute camera frustum from d3 zoom transform following the pattern from RESEARCH.md:
  - `halfW = canvasWidth / 2 / transform.k`
  - `halfH = canvasHeight / 2 / transform.k`
  - `cx = -transform.x / transform.k`
  - `cy = transform.y / transform.k` (Y-flip: d3 y-down, Three.js y-up)
  - Set `camera.left = cx - halfW`, `camera.right = cx + halfW`, `camera.top = cy + halfH`, `camera.bottom = cy - halfH`
  - Call `camera.updateProjectionMatrix()`

`setupD3Zoom(canvas: HTMLCanvasElement, camera: THREE.OrthographicCamera): { zoom: d3.ZoomBehavior<HTMLCanvasElement, unknown>; destroy: () => void }`:
- Create `d3.zoom<HTMLCanvasElement, unknown>()` with `.scaleExtent([CAMERA_CONSTANTS.MIN_ZOOM, CAMERA_CONSTANTS.MAX_ZOOM])`.
- Filter events: allow wheel, drag (mouse button 0), touch. Block double-click zoom (`.filter(event => event.type !== 'dblclick')`).
- On zoom event: call `syncCameraToZoom(camera, event.transform, canvas.clientWidth, canvas.clientHeight)`.
- Apply to canvas: `d3.select(canvas).call(zoom)`.
- Set initial transform to center on the middle of the grid: compute grid center using `hexToPixel({col: GRID_COLS/2, row: GRID_ROWS/2}, HEX_SIZE)`, then create initial transform that centers on that point at `DEFAULT_ZOOM` scale.
- Return `{ zoom, destroy }` where destroy removes the zoom listener.

**2. `CameraAnimator.ts`** — Export:

`animateCameraTo(canvas: HTMLCanvasElement, zoomBehavior: d3.ZoomBehavior<HTMLCanvasElement, unknown>, targetX: number, targetY: number, targetScale?: number, duration?: number): void`:
- `duration` defaults to `CAMERA_CONSTANTS.JUMP_TO_DURATION_MS` (500ms).
- `targetScale` defaults to current zoom scale (no zoom change).
- Get current transform via `d3.zoomTransform(canvas)`.
- Compute target d3 transform: `tx = canvasW/2 - targetX * scale`, `ty = canvasH/2 + targetY * scale` (re-flip Y for d3).
- Use `d3.select(canvas).transition().duration(duration).call(zoomBehavior.transform, targetTransform)` — this is the d3 transition approach (simpler than manual rAF). d3 transitions handle easing and fire zoom events automatically which keep the camera synced.
- If the d3 transition approach causes issues with Three.js rendering (since d3 transition runs on its own timer), fall back to the manual rAF approach from RESEARCH.md Pattern 3: `requestAnimationFrame` loop with ease-in-out quad, calling `d3.select(canvas).call(zoomBehavior.transform, interpolatedTransform)` each frame.

import { describe, it, expect } from 'vitest';
import { syncCameraToZoom, CAMERA_CONSTANTS } from '../D3ZoomCamera';
import * as THREE from 'three';
import { zoomIdentity } from 'd3-zoom';

describe('syncCameraToZoom', () => {
  function makeCamera(): THREE.OrthographicCamera {
    return new THREE.OrthographicCamera(-1, 1, 1, -1, 0.1, 10000);
  }

    const camera = makeCamera();
    const transform = zoomIdentity; // k=1, x=0, y=0
    syncCameraToZoom(camera, transform, 1920, 1080);
    // halfW = 1920/2/1 = 960, halfH = 1080/2/1 = 540
    // cx = 0, cy = 0
    expect(camera.left).toBe(-960);
    expect(camera.right).toBe(960);
    expect(camera.top).toBe(540);
    expect(camera.bottom).toBe(-540);
  });

  it('zooming in (k=2) halves the visible frustum', () => {
    const camera = makeCamera();
    const transform = zoomIdentity.scale(2); // k=2, x=0, y=0
    syncCameraToZoom(camera, transform, 1920, 1080);
    // halfW = 1920/2/2 = 480, halfH = 1080/2/2 = 270
    expect(camera.left).toBe(-480);
    expect(camera.right).toBe(480);
    expect(camera.top).toBe(270);
    expect(camera.bottom).toBe(-270);
  });

  it('panning shifts camera center correctly', () => {
    const camera = makeCamera();
    // d3 transform with translation: x=100, y=200, k=1
    const transform = zoomIdentity.translate(100, 200);
    syncCameraToZoom(camera, transform, 1920, 1080);
    // cx = -100/1 = -100, cy = 200/1 = 200 (Y-flip)
    // frustum: [-100-960, -100+960] x [200-540, 200+540]
    expect(camera.left).toBe(-1060);
    expect(camera.right).toBe(860);
    expect(camera.top).toBe(740);
    expect(camera.bottom).toBe(-340);
  });

    const camera = makeCamera();

    syncCameraToZoom(camera, transform, 800, 600);
    // halfW = 800/2/4 = 100, halfH = 600/2/4 = 75
    // cx = -(-200)/4 = 50, cy = 100/4 = 25
    expect(camera.left).toBe(50 - 100);
    expect(camera.right).toBe(50 + 100);
    expect(camera.top).toBe(25 + 75);
    expect(camera.bottom).toBe(25 - 75);
  });

`screenToHex(screenX: number, screenY: number, camera: THREE.OrthographicCamera, canvas: HTMLCanvasElement): HexCoord | null`:
- Convert screen pixel coordinates to Three.js NDC: `ndcX = (screenX / canvas.clientWidth) * 2 - 1`, `ndcY = -(screenY / canvas.clientHeight) * 2 + 1`.
- Unproject from NDC to world coordinates using the orthographic camera: create a `THREE.Vector3(ndcX, ndcY, 0)` and call `.unproject(camera)`. This gives the world-space point under the cursor.
- Convert world coordinates to hex coordinates using the inverse of `hexToPixel`: given world `(wx, wy)` where `wy` is already Y-flipped (negate it back to get SVG-space Y), then:
  - `col = Math.round(wx / (HEX_CONSTANTS.HEX_SIZE * HEX_SCALE_X))`
  - Adjust for odd-q offset: `adjustedY = -wy - (col % 2 === 1 ? HEX_SCALE_Y * HEX_CONSTANTS.HEX_SIZE / 2 : 0)`
  - `row = Math.round(adjustedY / (HEX_SCALE_Y * HEX_CONSTANTS.HEX_SIZE))`
- Validate: if `col < 0 || col >= HEX_CONSTANTS.GRID_COLS || row < 0 || row >= HEX_CONSTANTS.GRID_ROWS`, return `null`.
- Return `{ col, row }`.

NOTE: The exact inverse hex math may need refinement — use the "nearest hex" approach from redblobgames.com/grids/hexagons/#pixel-to-hex. Convert world point to fractional cube coordinates, then round to nearest hex. This is more accurate than the simple round approach above. Use `offsetToCube` and `cubeToOffset` from hexMath.ts for conversions.

`worldToScreen(worldPos: THREE.Vector3, camera: THREE.OrthographicCamera, canvas: HTMLCanvasElement): { x: number; y: number }`:
- Clone worldPos, call `.project(camera)`.
- Convert NDC to screen pixels: `x = (projected.x * 0.5 + 0.5) * canvas.clientWidth`, `y = (-projected.y * 0.5 + 0.5) * canvas.clientHeight`.
- Return `{ x, y }`.
