Create `src/components/StartPage/useThemeMusic.ts` with a custom React hook that manages HTMLAudioElement lifecycle.

**Hook signature:**
```typescript
export function useThemeMusic(src: string): {
  play: () => void;
  fadeOut: () => Promise<void>;
  muted: boolean;
  toggleMute: () => void;
}
```

**Implementation details:**

1. **Audio element creation (useEffect):**
   - Create `new Audio(src)` in a useEffect, store in `useRef<HTMLAudioElement | null>(null)`
   - Set `audio.loop = true`, `audio.volume = 0` (will fade in)
   - Read initial mute state from `localStorage.getItem(THEME_MUTE_STORAGE_KEY) === 'true'`
   - Store muted in `useState<boolean>` initialized from localStorage
   - Set `audio.muted` to match initial muted state
   - Cleanup: `audio.pause(); audio.src = '';` to release media resource

2. **play() function:**
   - Call `audioRef.current.play().catch(() => {})` to swallow autoplay rejection
   - After play succeeds, start fade-in: use `setInterval` stepping `audio.volume` from 0 to `THEME_VOLUME_DEFAULT` (0.4) over `THEME_FADE_IN_MS` (3000ms)
   - Step interval: 50ms, increment per step: `THEME_VOLUME_DEFAULT / (THEME_FADE_IN_MS / 50)`
   - Clamp volume to max `THEME_VOLUME_DEFAULT` and clearInterval when reached
   - Guard: if `audioRef.current` is null, return early

3. **fadeOut() function — MUST return Promise<void>:**
   - Return a new Promise that resolves when volume reaches 0
   - Use `setInterval` stepping `audio.volume` from current to 0 over `THEME_FADE_OUT_MS` (1500ms)
   - Step interval: 50ms, decrement per step: `currentVolume / (THEME_FADE_OUT_MS / 50)`
   - When volume <= 0.01, set volume to 0, pause audio, clearInterval, resolve the Promise
   - IMPORTANT: Do NOT use useEffect for the interval — the interval must survive component unmount. Store interval ID in a plain variable inside the Promise closure, not in a ref.
   - If audio is null or already paused, resolve immediately

4. **toggleMute() function:**
   - Flip `muted` state: `const next = !muted; setMuted(next);`
   - Persist: `localStorage.setItem(THEME_MUTE_STORAGE_KEY, String(next))`
   - Apply: `if (audioRef.current) audioRef.current.muted = next;`

**Anti-patterns to avoid:**
- Do NOT call `play()` in useEffect on mount (browser autoplay policy violation)
- Do NOT use CSS transitions for volume (HTMLAudioElement.volume is a JS property, not CSS)
- Do NOT put fadeOut interval inside useEffect (unmount kills it before completion)
