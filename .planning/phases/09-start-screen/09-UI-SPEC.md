## Typography

All sizes are CSS custom properties from `src/index.css`. Source: CONTEXT.md + design spec.

| Role | Token | Computed px | Weight | Line Height | Font | Usage |
|------|-------|-------------|--------|-------------|------|-------|
| Display / Title | `START_PAGE_TITLE_SIZE` (custom const) | ~40px | 400 (Cinzel regular) | 1.2 | `--font-display` (Cinzel) | "THREADBARE" title only |
| Menu items | `--text-lg` | 21px | 400 | 1.4 | `--font-display` (Cinzel) | New World, Settings, Credits, Continue |

- Menu items: `0.08em` (slight breathing room)
- Lore fragment: default (0em)
- Version stamp: default (0em)

## Color

All tokens are CSS custom properties from `src/index.css`. Source: design spec + CONTEXT.md.

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant (60%) | `--bg-abyss` | `#0a0a0e` | Page background (behind image), gradient overlay base color |
| Secondary (30%) | `--bg-deep` + `--bg-surface` | `#111114` / `#1a1a1f` | Modal backgrounds (Settings, Credits) via existing Modal primitive |
| Accent (10%) | `--accent-gold` | `#d4a040` | Title text, menu item focus underline |
| Text primary | `--text-primary` | `#e8dcc8` | Menu items on hover/focus, modal content headings |
| Text secondary | `--text-secondary` | `#c8b89a` | Lore fragment text |
| Text tertiary | `--text-tertiary` | `#a89880` | Menu items at rest |
| Text muted | `--text-muted` | `#9a8e7e` | Version stamp (bottom-right), mute icon at rest |
| Destructive | n/a | — | No destructive actions in this phase |

**Accent reserved for:** Title text shadow glow, menu item focus-state underline. NOT used for menu items at rest or hover — those use `--text-tertiary` → `--text-primary` transition.

**Gradient overlay (verbatim from design spec):**
```css
background: linear-gradient(
  to bottom,
  transparent 0%,
  transparent 35%,
  rgba(10, 10, 14, 0.4) 50%,
  rgba(10, 10, 14, 0.85) 75%,
  rgba(10, 10, 14, 0.95) 100%
);
```
Opacity midpoint (`0.4`) and floor (`0.95`) are captured as `START_PAGE_GRADIENT_OPACITY_MID` and `START_PAGE_GRADIENT_OPACITY_LOW` constants.

**Title text shadow:**
```css
text-shadow: 0 0 40px rgba(212, 160, 64, 0.3);
```
Provides warmth without bloom. `rgba(212, 160, 64, …)` matches `--accent-gold: #d4a040`.

## Layout Contract

**Viewport:** 1920×1080 primary target (per CLAUDE.md). Nothing scrolls. Nothing renders below the fold.

**CSS structure:**
```
<div class="start-page"> /* position: relative; width: 100vw; height: 100dvh; overflow: hidden */
  <img class="start-page__bg" />           /* object-fit: cover; object-position: center top; position: absolute; inset: 0 */
  <div class="start-page__gradient" />     /* position: absolute; inset: 0; gradient overlay */
  <div class="start-page__content">        /* position: absolute; bottom: 12%; left: 50%; transform: translateX(-50%); text-align: center */
    <h1 class="start-page__title" />       /* THREADBARE */
    <p class="start-page__lore" />         /* two-line lore fragment */
    <nav class="start-page__menu" />       /* menu items */
  </div>
  <button class="start-page__mute" />      /* position: absolute; bottom: 16px; left: 16px */
  <span class="start-page__version" />     /* position: absolute; bottom: 16px; right: 16px */
</div>
```

**Content block vertical position:** Bottom 12%–30% of viewport. Content sits in the gradient's dark zone (lower third), below where the title art and wanderer figure appear.

**Content block max-width:** 500px, centered horizontally.

## Interaction Contract

### Menu items

| State | Color | Decoration | Transition |
|-------|-------|------------|------------|
| Rest | `--text-tertiary` | None | — |
| Hover | `--text-primary` | None | `color 0.3s ease` |
| Focus (keyboard) | `--text-primary` + `--accent-gold` underline | 2px underline in `--accent-gold` | Instant |
| Active / pressed | `--text-primary` | None | — |

- All menu items are `<button>` elements styled as plain text (no backgrounds, no borders, no border-radius, no padding boxes)
- `cursor: pointer` on all items
- No underline at rest (contrast with the clickable-text-underline rule in ui-patterns.md — menu items are the exception because they are the primary affordance on the screen and their interactive nature is clear from context and hover response)
- `Continue` item: hidden entirely (CSS `display: none`) when no save data exists. Not greyed out, not disabled. Will appear conditionally when save system ships.

### Audio / Mute toggle

| State | Icon | Color |
|-------|------|-------|
| Unmuted | `Volume2` (Lucide) | `--text-muted` at rest, `--text-secondary` on hover |
| Muted | `VolumeX` (Lucide) | `--text-muted` at rest, `--text-secondary` on hover |

- Toggle is a `<button>` with `aria-label="Mute theme music"` / `"Unmute theme music"` (dynamic based on state)
- Mute state persists to `localStorage` key `"threadbare_muted"`
- Size: `--text-sm` (17px)

### Page transition (New World)

1. Player clicks "New World"
2. `useThemeMusic.fadeOut()` begins (1500ms fade)
3. StartPage begins CSS opacity fade-out (600ms, `opacity: 0; transition: opacity 600ms ease-out`)
4. On fade complete: `setGamePhase('worldgen')`

Use `AnimateMount` with a custom `anim-fade` class on the entire StartPage wrapper, OR a manual `useState(opacity)` approach — executor's discretion (captured in Claude's Discretion in CONTEXT.md).

### Modal interactions

Settings and Credits modals use the existing `Modal` primitive exactly as designed:
- Dark backdrop (`rgba(0,0,0,0.6)`)
- Gold border (`--border-gold`)
- `max-height: 75vh`, scrollable body
- `anim-fade-up` animation (default for Modal)
- Escape key dismisses
- Backdrop click dismisses

## Accessibility Contract

Source: design spec + ui-patterns.md accessibility baseline.

- All menu items are `<button>` elements (not `<div onClick>`) — keyboard-accessible without `onKeyDown` patches
- Tab order: New World → Continue (if shown) → Settings → Credits → Mute toggle
- Focus ring: `outline: 2px solid var(--accent-gold-dim)` (matches `src/index.css` global focus rule)
- Menu item focus state: `--text-primary` color + 2px `--accent-gold` underline
- Background image: `role="presentation"` and `alt=""` — it is decorative
- Mute button: `aria-label` updated dynamically ("Mute theme music" / "Unmute theme music")
- Settings modal: `role="dialog"` `aria-modal="true"` (handled by Modal primitive)
- Credits modal: `role="dialog"` `aria-modal="true"` (handled by Modal primitive)
- Lore text contrast: `--text-secondary` (#c8b89a) on `rgba(10,10,14,0.85)` near-black — WCAG AA compliant

## Fail-Soft Contract

Source: design spec NFP #4 section.

| Failure | Fallback | Visible to player? |
|---------|----------|--------------------|
| `title-screen.png` fails to load | Solid `--bg-abyss` (#0a0a0e) background — menu fully functional | No error shown |
| `theme-drone.mp3` fails to load | Silent start page — menu fully functional | No error shown |
| `audio.play()` blocked by browser | Catch silently, retry on next user interaction | No error shown |
| Save data missing/corrupted | "Continue" item hidden (same as no-save state) | No error shown |
| Phase state invalid | Default to `'start'` phase | No error shown |
