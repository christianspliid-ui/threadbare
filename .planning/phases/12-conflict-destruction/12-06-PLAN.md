<objective>
Implement destruction and aftermath consequences when battles/sieges resolve — scaling from minor skirmish damage to total city destruction.

Purpose: Battle outcomes must leave visible scars on the world. Destroyed sublocations, tanked prosperity, severed trade routes, displaced refugees, and sphere pressure shifts make conflict feel real and consequential. The player reads the aftermath and understands the weight of what happened.

Output: After a battle resolves, the affected settlement should show reduced prosperity, missing sublocations (if major/total), and refugee encounters at neighbors. Debug panel should show destruction log.
</objective>

## Task Breakdown

### 1. Create aftermath engine

**New file: `src/engine/battleAftermath.ts`**

Constants:
```typescript
export const TOTAL_DESTRUCTION_THRESHOLD = 10;
export const MAJOR_DESTRUCTION_THRESHOLD = 6;
export const SPHERE_PRESSURE_MINOR_MULTIPLIER = 1.0;
export const SPHERE_PRESSURE_MAJOR_MULTIPLIER = 2.0;
export const SPHERE_PRESSURE_TOTAL_MULTIPLIER = 3.0;
export const PROSPERITY_LOSS_MINOR = 0.20;
export const PROSPERITY_LOSS_MAJOR = 0.50;
export const COMMANDER_CAPTURE_DURATION = 10;
export const COMMANDER_DEATH_CHANCE_TOTAL = 0.30;
export const REFUGEE_GENERATION_MAJOR = 1;
export const REFUGEE_GENERATION_TOTAL = 3;
```

`calculateDestructionSeverity(finalMomentum, loserQuintessencePercent): DestructionSeverity`
```typescript
const magnitude = Math.abs(finalMomentum);
if (magnitude >= TOTAL_DESTRUCTION_THRESHOLD && loserQuintessencePercent < 0.15) return 'total';
if (magnitude >= MAJOR_DESTRUCTION_THRESHOLD) return 'major';
return 'minor';
```

`applyAftermath(state, battleNodeId, severity, victorArmyId, loserArmyId): void`

1. **Trade route disruption:**
   - Minor: flag routes through hex as `threatened: true`
   - Major: sever 1-2 trade routes (remove `trades_with` edges)
   - Total: sever all trade routes at location

2. **Prosperity impact:**
   - Get settlement at battle location
   - Reduce prosperity by severity multiplier
   - Clamp to 0

3. **Settlement tier change:**
   - Major: downgrade one tier (city→town, town→hamlet)
   - Total: convert to ruins (set locationSubtype to 'ruins')

4. **Sublocation destruction (major/total):**
   - Major: select 1-2 sublocations via seeded PRNG, remove them
   - Total: remove all sublocations

5. **Sphere pressure:**
   - Apply victor's dominant sphere pressure to affected hexes
   - Multiplied by severity (1x/2x/3x)
   - Total: also erode loser's sphere scores to minimum

6. **Commander fate:**
   ```typescript
   determineCommanderFate(severity, rng): 'retreated' | 'captured' | 'killed'
   ```
   - Minor: always retreated
   - Major: 50% captured, 50% escaped (seeded PRNG)
   - Total: 30% killed, 70% captured (seeded PRNG)
   - Captured: remove from play for COMMANDER_CAPTURE_DURATION ticks
   - Killed: remove agent from graph (permanent loss)

7. **Refugee generation:**
   - Major: generate 1 refugee encounter at nearest non-ruined settlement
   - Total: generate 3 refugee encounters at nearest settlements
   - Refugees shift receiving settlement's sphere alignment

8. **Army cleanup:**
   - Losing army: disband (remove actor node + edges)
   - Winning army: quintessence reduced to current level, thresholds reset
   - Commander of losing army: fate applied

9. **Emit trace:**
   ```typescript
   DestructionTrace with severity, sublocations destroyed, routes severed,
   prosperity before/after, commander fate, sphere pressure applied, refugee count
   ```

## Fail-Soft Table

| Failure | Fallback |
|---------|----------|
| Settlement has no sublocations | Skip sublocation destruction; prosperity loss only |
| No neighboring settlements for refugees | Skip refugee generation |
| Commander already dead/missing | Skip commander fate |
| Prosperity already at 0 | No further reduction |
| Trade route edge missing | Skip route disruption for that route |
| Settlement tier already hamlet | Cannot downgrade further; stays hamlet |
