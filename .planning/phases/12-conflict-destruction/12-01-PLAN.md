</objective>

### 6. Implement faction ambition evaluation phase

**New file: `src/engine/factionAmbitions.ts`**

Constants:
```typescript
export const FACTION_AMBITION_EVALUATION_INTERVAL = 5;
export const EXPANSION_PROSPERITY_THRESHOLD = 0.6;
export const REVENGE_GRIEVANCE_DECAY = 0.02;
export const DIVINE_MANDATE_THREAD_THRESHOLD = 3;
```

Function: `phaseFactionAmbitions(state: GameState): void`

Logic:
1. Every `FACTION_AMBITION_EVALUATION_INTERVAL` ticks, iterate all faction actors
2. For each faction:
   a. Get faction definition from `FACTION_DEFINITIONS`
   b. Check existing `pursues` edges to ambition nodes
   c. If no active ambition OR current ambition completed/abandoned:
      - Score eligible ambitions using `ambitionWeights` × context modifiers (prosperity, grievances, threats)
      - Create new `ambition` graph node with the winning ambition type
      - Add `pursues` edge from faction to ambition node
      - Emit `FactionAmbitionTrace` with event: 'created'
   d. If active ambition exists:
      - Check if target still valid (not destroyed)
      - If invalid: abandon (emit trace), will re-evaluate next interval
      - Decay grievances on revenge ambitions
3. PRNG: Use `state.rng()` for ambition selection when multiple are equally weighted
4. Fail-soft: No eligible ambitions → default to `defensive_consolidation`

| Failure | Fallback |
|---------|----------|
| No eligible ambitions | Default to defensive_consolidation |
| Ambition target destroyed | Abandon ambition, re-evaluate next interval |
| Faction prosperity too low for expansion | Only defensive_consolidation and revenge eligible |
| Faction definition not found | Skip faction (log warning) |
| No qualifying settlements for merc halls | Faction created but with 0 halls (inert) |
