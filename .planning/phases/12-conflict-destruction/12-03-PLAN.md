<objective>
Implement army movement with modified pathfinding costs and Quintessence attrition that silently degrades army health, spawning threshold encounters at critical breakpoints.

Purpose: Armies move slower than agents and burn Quintessence each tick. The player never sees the number — only the consequences when thresholds are crossed. This creates the narrative arc of a campaign: fresh army → supply strain → desertion → collapse.

Output: After `tick 30` in CLI, armies should have moved toward their objectives with visible path progress. `agents` should show army actors with declining quintessence. Threshold encounters should appear in `encounters` output when quintessence crosses 70/50/30/10%.
</objective>

## Task Breakdown

### 1. Create army movement cost system

**New file: `src/engine/armyMovement.ts`**

```typescript
export const ARMY_MOVEMENT_COST_MULTIPLIERS: Record<string, number> = {
  plains: 1.5,
  grassland: 1.5,
  forest: 2.5,
  hills: 2.0,
  mountains: 4.0,
  desert: 3.0,
  swamp: 3.5,
  coast: 1.5,
  water: Infinity,  // armies cannot cross water
};

export const ARMY_ROAD_DISCOUNT = 0.4;

export const ARMY_SPEED: Record<ArmySizeCategory, number> = {
  warband: 2,
  regiment: 1.5,
  host: 1,
};
```

Function: `getArmyMovementCost(terrainType: string, isRoad: boolean, baseAgentCost: number): number`
- Multiply base agent cost by army terrain multiplier
- Apply road discount if on road
- Fail-soft: unknown terrain → use plains multiplier (1.5)

Integration point: The existing `phaseMovement` processes all actors with `MovementState`. Armies are actors, so they already participate. The cost modification needs to be injected at the pathfinding cost calculation level.

**Two options:**
1. Add a `costModifier` field to `MovementState` that the movement execution reads
2. Check for `armyState` on the actor during cost calculation

Prefer option 2 — check if the moving actor has `armyState` in properties, and if so, apply army cost multipliers. This requires modifying the existing movement cost function to accept an optional actor reference.

### 2. Integrate army costs into movement execution

**File: `src/engine/movement/movementExecution.ts`** (or wherever edge costs are computed)

When computing movement cost for an edge:
1. Check if the actor has `properties.armyState`
2. If yes: multiply edge cost by `ARMY_MOVEMENT_COST_MULTIPLIERS[terrainType]`
3. Apply `ARMY_ROAD_DISCOUNT` if on road
4. Scale movement speed by `ARMY_SPEED[armyState.size]` relative to base agent speed

### 3. Create army attrition phase

**New file: `src/engine/armyAttrition.ts`**

Constants:
```typescript
export const ARMY_BASE_ATTRITION = 0.5;
export const TERRAIN_ATTRITION_FACTOR = 0.3;
export const OFF_ROAD_ATTRITION_PENALTY = 0.8;
export const UNDERFUNDED_ATTRITION_PENALTY = 1.5;

export const QUINTESSENCE_THRESHOLDS = {
  strained: 0.70,
  weakened: 0.50,
  critical: 0.30,
  collapse: 0.10,
} as const;
```

Function: `phaseArmyAttrition(state: GameState): void`

Logic:
1. Find all actor nodes with `properties.armyState`
2. For each army:
   a. Get current terrain type from `located_at` edge → location properties
   b. Check if on road (has `road` edge at current location)
   c. Check if faction can pay maintenance (faction Gold capability vs army maintenanceCost)
   d. Calculate attrition:
      ```
      attrition = ARMY_BASE_ATTRITION
        + (terrainCost * TERRAIN_ATTRITION_FACTOR)
        + (isOffRoad ? OFF_ROAD_ATTRITION_PENALTY : 0)
        + (isUnderfunded ? UNDERFUNDED_ATTRITION_PENALTY : 0)
      ```
   e. Subtract from quintessence, clamp to 0
   f. Emit `ArmyAttritionTrace` with full breakdown
   g. Check threshold crossings:
      - Track `thresholdsFired` in armyState (array of fired threshold names)
      - If quintessence crosses a threshold AND that threshold hasn't fired:
        - Initiate corresponding threshold encounter template
        - Mark threshold as fired
      - At quintessence 0: force disbandment (remove army, release commander)

### 4. Army disbandment on collapse

When quintessence reaches 0:
1. Remove army `actor` node from graph
2. Remove all edges (commanded_by, member_of, located_at, pursues)
3. Commander agent's `located_at` edge stays at current position (stranded where army dissolved)
4. Emit `ArmyLifecycleTrace` with event: 'disbanded'
5. Emit `FactionAmbitionTrace` with event: 'abandoned' (army couldn't complete objective)

## Fail-Soft Table

| Failure | Fallback |
|---------|----------|
| Army has no valid path to objective | Army stays, quintessence still degrades → eventual disbandment |
| Unknown terrain type | Use plains cost (1.5) |
| Faction Gold field missing/NaN | Treat as underfunded (max attrition) |
| Quintessence goes below 0 | Clamp to 0, force disbandment |
| Threshold encounter template not found | Skip threshold (log warning), quintessence still degrades |
| Army at water hex (impossible) | Treat as plains, log warning |
