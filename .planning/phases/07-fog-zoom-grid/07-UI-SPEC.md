## Interaction Contracts

### Fog of War

All locked decisions from CONTEXT.md:

| Contract | Value |
|----------|-------|
| Reveal behavior | Instant — no fade, no animation |
| Explored hex rendering | Full terrain color + all static layers (signifiers, locations, labels). NO agents, NO events |
| Unexplored hex rendering | Solid `#0a0a0c` fill. Zero terrain detail. Zero signifiers. Zero grid lines on that hex |
| Fog boundary | Hard edge — matches hard-edge terrain style (TERR-04) |
| Default state | Fog off — `?fog` URL param enables. No change to this default in Phase 7 |
| Click behavior | Clicks on unexplored/remembered hexes silently ignored (existing `handleHexClick` guard in `useViewNavigation`) |

Implementation approach (Claude's Discretion — resolved here): Override `HexFillMesh` per-instance color to `#0a0a0c` for unexplored hexes. Skip all render passes except HEX_FILL for unexplored. This matches the existing InstancedMesh per-instance color pattern established in all prior phases — no new overlay mesh required.

### Zoom LOD

Four tiers defined in requirements. Visibility matrix below is the authoritative contract:

| Layer | Full-world (<1.5) | Continental (1.5–5) | Regional (5–15) | Hero-local (≥15) |
|-------|-------------------|---------------------|-----------------|------------------|
| HEX_FILL | visible | visible | visible | visible |
| COASTLINE | visible | visible | visible | visible |
| GRID | hidden | hidden | visible | visible |
| ELEVATION_TICKS | hidden | hidden | visible | visible |
| RIVERS | hidden | visible | visible | visible |
| ROADS | hidden | hidden | visible | visible |
| BORDERS | visible | visible | visible | visible |
| SIGNIFIERS | hidden | hidden | visible | visible |
| LOCATIONS | hidden | hidden | visible | visible |
| AGENTS | hidden | retinue only (tiny dots) | colored dots | portrait sprites |
| EVENTS | hidden | hidden | hidden | visible |
| LABELS | hidden | hidden | visible | visible |
| FOG | visible | visible | visible | visible |

Tier thresholds align with established Phase 4 thresholds from STATE.md: `full-world <1.5`, `continental <5`, `regional <15`, `hero-local ≥15`.

Transition approach (Claude's Discretion — resolved here): **Smooth continuous opacity fade** over a 20% overlap range around each tier boundary. Elements at the boundary lerp opacity between 0 and 1 as the zoom scale passes through the overlap window. Elements not at the boundary are toggled `mesh.visible = false` entirely (performance skip per ZOOM-04).

### Follow Mode

| Contract | Value |
|----------|-------|
| Trigger | User clicks a "Follow" toggle (see copywriting below) |
| Behavior | Camera lerp-follows the selected agent's hex position during movement animation |
| Camera API | Extend `centerOn()` — call per animation frame when follow mode active |
| Break-out | Any manual pan gesture (d3-zoom drag) disables follow mode immediately |
| Visual indicator | Follow-mode active: gold accent ring on toggle button (`--accent-gold`) |
| Persistence | Follow mode resets to off when agent movement animation completes |

Break-out by manual pan is the most natural gesture for a god-game player re-asserting control. No toggle button click required to exit.

### Road Network

| Contract | Value |
|----------|-------|
| Generation | Pathfinding via `hexMovementPath.ts` between settlement hexes |
| Rendering | `RiverMesh.ts` line geometry pattern — quad-strip polylines along hex-center paths |
| Major road | Solid `#6b5a40`, 2px world-scaled width |
| Trail | Dotted `#4a3d2c`, 1px, dash `[4, 6]` world units |
| Bridge | Small glyph at river-crossing point — icon drawn on canvas texture, placed via `LocationIconMesh` pattern |
| Render order | `ROADS = 5` (already reserved in `RenderLayers.ts`) |
| Zoom visibility | Hidden below regional tier (k < 5), visible at regional and hero-local |

## Copywriting Contract

This phase introduces one new interactive element (follow-mode toggle) and inherits fog-of-war click handling from the existing pattern.

| Element | Copy |
|---------|------|
| Primary CTA (follow mode toggle, inactive) | "Follow Agent" |
| Primary CTA (follow mode toggle, active) | "Following — Pan to stop" |
| Empty state — no agent selected for follow | "Select an agent to follow." |
| Error state — fog-blocked click | (silent — no message. Per existing `handleHexClick` guard pattern. Silently ignored.) |
| Empty state — no roads generated | "No roads connect these settlements yet." (shown only in debug panel if applicable) |
| Destructive actions | None in this phase |

**Thematic note:** "Following — Pan to stop" stays in the game's second-person god-game voice. "Pan to stop" describes the exact break-out gesture.

**Source:** CONTEXT.md (fog click behavior locked — silent ignore), ui-patterns.md §3 (fog click guard), §14 (empty state rules — italic, `var(--text-tertiary)`, `animate-breathe`).

## Visual Verification Checklist

At 1920×1080 (per STYLE.md §Target Resolution), verify:

- [ ] Unexplored hexes render as solid `#0a0a0c` — zero terrain, zero signifiers, zero grid lines visible through fog
- [ ] Hard boundary between explored and unexplored — no gradient, no soft fringe
- [ ] At full-world zoom (k < 1.5): only terrain fill + political borders visible — no signifiers, no agents, no roads, no grid
- [ ] At continental zoom (1.5–5): rivers appear, retinue agent dots visible, other layers hidden
- [ ] At regional zoom (5–15): signifiers, locations, agents, roads, grid lines all appear
- [ ] At hero-local zoom (≥15): agent portraits visible, event indicators visible
- [ ] Zoom tier transitions: opacity fades smoothly — no hard pop-in/out
- [ ] Roads render at `ROADS = 5` order — below signifiers and locations
- [ ] Major roads: solid `#6b5a40`, trails: dotted `#4a3d2c`
- [ ] Bridge icon appears at river-crossing points on roads
- [ ] Follow mode: camera lerps with agent during movement
- [ ] Follow mode: any pan gesture immediately releases follow
- [ ] Follow-mode toggle button: gold border when active, standard raised when inactive
- [ ] Nothing renders below the fold — viewport contract maintained
