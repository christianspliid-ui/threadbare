       - Return array of `{ path, roadType }`.

       - Build a Set of river edge keys: for each consecutive hex pair in each river, create key `"minCol,minRow-maxCol,maxRow"` (normalized order).
       - Walk each road path's consecutive hex pairs. If the edge key exists in riverEdges set, record the crossing with its world midpoint.
       - World midpoint: average of `hexToPixel(from, HEX_SIZE)` and `hexToPixel(to, HEX_SIZE)`, with Y-flip applied.

    6. `createRoadMesh(locations: LocationNode[], tiles: HexTile[], cols: number, rows: number, riverPaths: RiverPath[]): THREE.Group`:

       - For major roads: build quad-strip geometry following `RiverMesh.ts` pattern. Use `ROAD_CONSTANTS.MAJOR_HALF_WIDTH` for width. Material: `MeshBasicMaterial({ color: MAJOR_COLOR, transparent: true, opacity: 0.85 })`. Merge all major road quads into one BufferGeometry, create one Mesh.
       - For trails: build quad-strip geometry with gaps (skip every other segment of TRAIL_DASH_SIZE / TRAIL_GAP_SIZE length). Use `TRAIL_HALF_WIDTH`. Material: `MeshBasicMaterial({ color: TRAIL_COLOR, transparent: true, opacity: 0.7 })`. Merge into one Mesh.
       - For bridges: call `findRiverCrossings`. For each crossing, create a small `THREE.Sprite` with a canvas-drawn bridge icon (simple arch glyph — two vertical lines with an arc on top, drawn in BRIDGE_COLOR). Size the sprite at ~1.5 * HEX_SIZE. Add all bridge sprites to the group.
       - The bridge canvas texture: 64x64 canvas, draw a simple stone arch: two pillars (rectangles) and a semicircular arc connecting their tops, filled with BRIDGE_COLOR. Stroke with slightly darker color for definition.
       - Set `group.visible = false` (default hidden, Plan 03 wires zoom visibility).
       - Return group.

    IMPORTANT: The quad-strip geometry should follow the RiverMesh.ts approach exactly:
    - Convert each hex coord to world position via `hexToPixel(coord, HEX_SIZE)` then Y-flip (negate y).
    - For each consecutive pair of world positions, compute the perpendicular direction.
    - Create 4 vertices (2 on each side of the line at +/- halfWidth).
    - Build triangles from the quad.
    - Merge all quads into a single Float32Array, create one BufferGeometry.
