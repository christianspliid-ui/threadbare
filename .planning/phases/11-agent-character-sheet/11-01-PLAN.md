3. **src/engine/phaseInteractionDepth.ts** — New file. Export `phaseInteractionDepth(state: GameState): void`.
   Logic:
   - Find the ascendant's avatar agent: look for a graph node connected to `state.ascendantId` via a `thread` edge where the node is category `'actor'`.
   - Get avatar's current hex (from `located_at` edge).
   - For each agent (actor nodes in graph that are NOT the avatar):
     - Check if agent is co-located with avatar (same hex via `located_at` edge). If so:
       - Increment `knowledge.coLocationTicks += 1`
       - Increment `knowledge.interactionDepth += DEPTH_COLOCATION_PER_TICK`
       - Emit InteractionDepthTrace with source `'co_location'`
     - Check if agent shares a faction with avatar (both have `member_of` edges to same faction node). If so:
       - Increment `knowledge.interactionDepth += DEPTH_FACTION_PER_TICK`
       - Emit InteractionDepthTrace with source `'faction_ambient'`
   - Use `getOrCreateKnowledge` from revelationHooks to lazily create entries.
