Fix the two emitTrace calls at lines 110-118 and 127-135 in phaseInteractionDepth.ts.

The root cause: `emitTrace` accepts `Omit<TraceEntry, 'id' | 'timestamp'>` where `TraceEntry` is a discriminated union. TypeScript's excess property checking on `Omit` of a union does not recognize `source` as a valid property even though `InteractionDepthTrace` (a union member with `category: 'interaction_depth'`) defines `source`.

Fix: Cast each emitTrace argument object literal explicitly as `Omit<InteractionDepthTrace, 'id' | 'timestamp'>`.

Change line 110-118 from:
```typescript
emitTrace({
  tick,
  category: 'interaction_depth',
  agentId: actor.id,
  summary: `${actor.name} co-location depth: ${depthBefore.toFixed(3)} → ${knowledge.interactionDepth.toFixed(3)}`,
  source: 'co_location',
  depthBefore,
  depthAfter: knowledge.interactionDepth,
});
```
to:
```typescript
emitTrace({
  tick,
  category: 'interaction_depth',
  agentId: actor.id,
  summary: `${actor.name} co-location depth: ${depthBefore.toFixed(3)} → ${knowledge.interactionDepth.toFixed(3)}`,
  source: 'co_location',
  depthBefore,
  depthAfter: knowledge.interactionDepth,
} as Omit<InteractionDepthTrace, 'id' | 'timestamp'>);
```

Apply the same cast pattern to the second emitTrace call at lines 127-135 (the `faction_ambient` source one).

Add the import for `InteractionDepthTrace` from `'../types/trace'` at the top of the file if not already present.
