Create `src/engine/revelationEmitter.ts` with three exported functions:

1. **`emitEncounterRevelations(state: GameState): void`**
   Called after encounter resolution in orchestrator. For each encounter that progressed this tick:
   - Find the encounter's reach/domain (from the unified action or encounter template).
   - Find agents involved in the encounter.
   - For each involved agent that the ascendant's avatar is co-located with (or the avatar itself is involved):
     - Call `revealDomain(knowledge, encounterReach)` for each non-avatar agent involved.
     - Map the reach to an axiological pair using a REACH_TO_VALUE_MAP:
       `{iron: 'courage_prudence', gold: 'honesty_cunning', shadow: 'honesty_cunning', veil: 'mercy_ruthlessness', heart: 'mercy_ruthlessness', eye: 'honesty_cunning', stone: 'courage_prudence', star: 'mercy_ruthlessness', flesh: 'mercy_ruthlessness'}`
     - Call `revealValue(knowledge, mappedPairId)` for each non-avatar agent.
     - If the reveal function returns true (newly revealed), push a TickEvent:
       `{ type: 'domain_revealed', description: "[Agent]'s skill in [reach] becomes apparent", significance: 0.3, agentId, facetId: reach }`
     - Push RevelationTrace to traceBuffer.
   - Increment `knowledge.interactionDepth += DEPTH_ENCOUNTER_OBSERVED` for each observed agent.

2. **`emitDilemmaRevelations(state: GameState): void`**
   Called after dilemma detection in orchestrator. For each dilemma event this tick:
   - Find the dilemma target agent.
   - If the ascendant's avatar is co-located:
     - Increment `knowledge.interactionDepth += DEPTH_DILEMMA`.
     - Count total dilemmas witnessed for this agent (track via a simple counter — could use knownEvents.size filtered by dilemma prefix, or add a `witnessedDilemmaCount` as a derived value from knownEvents entries starting with `'dilemma_'`).
     - If witnessed dilemma count >= DISPOSITION_DILEMMA_THRESHOLD, call `revealDisposition(knowledge)`.
     - Push InteractionDepthTrace.

3. **`emitColocationRevelations(state: GameState): void`**
   Called after colocation detection. For each agent co-located with the ascendant's avatar this tick:
   - On first sighting (knowledge.coLocationTicks === 0 at start of tick, meaning phaseInteractionDepth hasn't run yet — OR check if arms aren't revealed yet):
     - Auto-reveal visible possession subcategories: iterate `card.possessions` (need to access via graph), for items with subcategory in `['arms', 'vestments', 'mounts_beasts']`, call `revealPossession(knowledge, itemNodeId)`.
   - For all co-located agents, auto-reveal faction bonds: if agent and avatar share a faction, call `revealBond(knowledge, agentId, 'faction')` for each faction co-member of the target agent.
   - Push RevelationTrace for each newly revealed facet.
