Add to `src/engine/revelationEmitter.ts`:

**`resolveRevelationAction(actionType: string, state: GameState, targetAgentId: string): void`**

Switch on actionType:

**'observe':**
- Get agent's domain capabilities from graph node properties (`domainCapabilities`).
- Find first domain NOT in `knowledge.revealedDomains` (iterate domains in fixed order: iron, gold, shadow, veil, heart, eye, stone, star, flesh).
- If found, call `revealDomain(knowledge, domain)`. Emit TickEvent: `{ type: 'domain_revealed', description: "[Agent]'s skill in [domain] becomes apparent through divine sight" }`.
- Increment `knowledge.interactionDepth += DEPTH_DIVINE_ACTION`.
- Push RevelationTrace with source `'divine_action'`.

**'scry':**
- Reveal ALL 9 domains: iterate `['iron','gold','shadow','veil','heart','eye','stone','star','flesh']`, call `revealDomain` for each.
- Reveal ALL bonds: get `relates_to` edges from graph for target agent, call `revealBond(knowledge, targetId, 'divine')` for each.
- Reveal ALL hidden possessions: get `possesses`/`bonded_to` edges, call `revealPossession(knowledge, itemNodeId)` for each.
- Increment `knowledge.interactionDepth += DEPTH_DIVINE_ACTION`.
- Push RevelationTrace for each newly revealed facet, all with source `'divine_action'`.
- Emit TickEvent: `{ type: 'scry_complete', description: "Divine sight pierces the veil around [Agent], revealing all" }`.

**'whisper_insight':**
- Get agent's axiological profile from graph node properties.
- Find first value pair NOT in `knowledge.revealedValues` (iterate in profile order by absolute value, highest first).
- If found, call `revealValue(knowledge, pairId)`. Emit TickEvent: `{ type: 'value_revealed', description: "[Agent]'s [value] nature whispers through the divine connection" }`.
- Call `revealDisposition(knowledge)`.
- Increment `knowledge.interactionDepth += DEPTH_DIVINE_ACTION`.

**'dream_sending':**
- Get agent's ambitions from `pursues` edges in graph.
- If any ambitions exist, reveal the first one: call `revealAmbition(knowledge, ambitionNodeId)`. Emit TickEvent: `{ type: 'ambition_revealed', description: "[Agent] reveals their driving ambition in a divine dream" }`.
- Call `revealThreat(knowledge)`. Emit TickEvent if newly revealed: `{ type: 'threat_revealed', description: "Through dreams, you glimpse what [Agent] fears" }`.
- Increment `knowledge.interactionDepth += DEPTH_DIVINE_ACTION`.

**Wire to action resolution:**
Read `src/engine/unifiedActionResolution.ts` to find where action completion is handled. After the existing resolution logic, add a check: if the completed action template has `revelationAction` metadata, call `resolveRevelationAction(metadata.revelationAction, state, targetAgentId)`. This should be a small addition — find the switch/if-chain that handles action types and add a case for revelation actions, or add a post-resolution hook.

Wrap in try/catch for fail-soft (NFP #4).
