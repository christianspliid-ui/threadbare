<objective>
Add actorId attribution to all engine TickEvents where the originating agent is known, and make NarrativeLog entries clickable when actorId is present.

Purpose: Currently 24 event emitters across the engine omit actorId even when the actor is in scope. About 12 of these have an identifiable agent (the rest are global/system events like doom_escalation or essence_gain where no single actor is responsible). Adding actorId enables click-to-navigate in the chronicle UI and improves trace debugging.

Output: Engine events carry actorId, NarrativeLog shows clickable entries for agent-attributed events.
</objective>
