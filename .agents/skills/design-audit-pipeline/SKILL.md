# Design Audit Pipeline

Spawns three audit subagents in a single message at plan-doc finalization. Each auditor is independent — they receive the role-prompt and plan-doc path, audit without access to the other auditors' work, and return a ≤300-word verdict. The orchestrator merges the three verdicts into the plan-doc tail and the Linear handoff comment.

## Constants

| Constant | Value | Purpose |
|---|---|---|
| `DESIGN_AUDIT_NFP_MAX_WORDS` | 300 | NFP-auditor output cap. Mirrors intent-judge's structured-finding cap. |
| `DESIGN_AUDIT_PILLAR_MAX_WORDS` | 300 | Pillar-auditor output cap. |
| `DESIGN_AUDIT_VISION_MAX_WORDS` | 300 | Vision-auditor output cap. |
| `DESIGN_AUDIT_TIMEOUT_SECONDS` | 60 | Per-subagent wall-time budget. Three parallel auditors → 60s total. Trips fail-soft. |
| `DESIGN_AUDIT_MODEL` | `sonnet` | Auditor model for v1. Structural checks against compiled brief — Sonnet is sufficient. |
| `DESIGN_AUDIT_RETRY_ON_REVISE` | `false` | v1: surface REVISE verdicts to the author for inline fix. No auto-retry. |
| `DESIGN_BRIEF_STALENESS_DAYS` | 14 | Threshold at which auditors fall back to source files and emit `design-brief-stale` drift note. |

## Invocation

```
/design-audit <plan-doc-path>
```

Example:

```
/design-audit Docs/plans/2026-06-13-thr-378-forked-plan-audit.md
```

The auto-trigger fires when Cowork finishes a plan doc and intent-judge returns Allow. Manual invocation via the slash command is documented in `.claude/commands/design-audit.md`.

## Orchestrator wiring

**Sequencing in the Cowork design workflow:**

1. Plan doc written to `Docs/plans/`.
2. Brainstorm companion written to `TheFantasyWorldSimulator/Brainstorms/`.
3. **intent-judge** runs (THR-411). Returns Allow / Revise / Block / Escalate. Only continue if Allow.
4. If intent-judge returns Allow → invoke **design-audit-pipeline** (this skill).
5. Spawn three subagents in a **single message** (all three `Agent` calls in one tool-use block):
   - NFP auditor — prompt from `agents/nfp-prompt.md`, `{{PLAN_DOC_PATH}}` substituted
   - Pillar auditor — prompt from `agents/pillar-prompt.md`, `{{PLAN_DOC_PATH}}` substituted
   - Vision auditor — prompt from `agents/vision-prompt.md`, `{{PLAN_DOC_PATH}}` substituted
6. Orchestrator collects the three verdicts and writes them into the plan-doc tail under `## Forked-audit verdicts`.
7. If any auditor returns FAIL or REVISE → surface finding to the author before transitioning Linear state. Do NOT apply `plan-pending-commit` or move to Ready for Dev until the finding is resolved.
8. If all three PASS or PASS-with-note → apply `plan-pending-commit` label and transition Linear state as normal.

**Subagent spawn template:**

```
Agent({
  description: "NFP compliance audit for <plan-doc>",
  subagent_type: "general-purpose",
  model: "sonnet",
  prompt: <contents of agents/nfp-prompt.md with {{PLAN_DOC_PATH}} replaced>
})
```

Repeat for pillar and vision auditors. All three calls in one message — they run in parallel.

## Verdict merge format

Write the following block at the end of the plan doc:

```markdown
## Forked-audit verdicts

*Generated by design-audit-pipeline — <YYYY-MM-DD>*

### NFP audit

<Verbatim ≤300-word NFP auditor output>

### Three-pillar audit

<Verbatim ≤300-word pillar auditor output>

### Vision audit

<Verbatim ≤300-word vision auditor output>
```

If an auditor timed out, write `audit-timeout: <dim>` in place of its output. If output exceeded 300 words, truncate and append `[design-audit-overflow: truncated to 300 words]`.

## Fail-soft

| Failure case | Behavior |
|---|---|
| Subagent times out (>60s) | Mark `audit-timeout: <dim>` in verdicts table. Fall back to inline self-audit for that dimension only. Does not block handoff. |
| Subagent returns >300 words | Truncate to first 300 words. Append `[design-audit-overflow]` drift note. Does not block handoff. |
| Plan doc missing structural element (no NFP table, no pillar headings) | Affected auditor returns `BLOCK: plan doc lacks <X>`. Surface to author; do not transition Linear state. |
| `Docs/design-brief.md` stale | Auditors fall back to source files and emit `design-brief-stale` drift note. |
| Skill itself missing or corrupt | Fall back to inline self-audit (today's behavior). Open a drift-scan Linear issue. |
| All three subagents fail | Fall back to inline self-audit. Surface "forked audit unavailable — manual audit ran" in Linear handoff comment. |

Every failure degrades to today's inline self-audit behavior, never worse (NFP #6).
